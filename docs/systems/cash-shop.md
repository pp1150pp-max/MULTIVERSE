# แคชช็อป (คริสตัลมิติ)

เจ้าของตกลง 2026-11-15 · แผนเดิม: [docs/plans/cash-shop.md](../plans/cash-shop.md) · กติกาและการตรวจค่า: `src/shared/cashShop.ts` · server: `server/cashShop.ts`, `server/admin-cash.ts` · หน้าต่างในเกม: `src/client/cashShop.ts` · แท็บ admin: `src/admin/cashShop.ts`

## เงิน: คริสตัลมิติ

- เงินเติมของเกม (เดิมเรียก "เพชร" เจ้าของเปลี่ยนชื่อ) เก็บ**ต่อบัญชี** คอลัมน์ `accounts.crystals` (บัญชีเก่าได้ 0)
- **เติมเงินจริงแบบกึ่งมือผ่านพร้อมเพย์** (2026-11-22): [topup.md](topup.md) · อีกทางคือ owner "เสก" ให้ในหน้าบัญชีของ /admin (เจ้าของสั่ง 2026-11-20 เหมือนเสกทอง): ช่อง "เสกคริสตัลมิติ" ใส่จำนวน 1–1,000,000 กด "ให้คริสตัล" หรือ "ลดคริสตัล" (ลดเกินที่มี = ปฏิเสธ) · สวิตช์ `crystalGrant` (ค่าเริ่ม owner ตั้งต่อ role ในแท็บ "สิทธิ์") · ลง audit `crystal-give` / `crystal-take` · ผู้เล่นที่ออนไลน์ได้ยอดใหม่ทันที · API `POST /api/admin/accounts/:id/crystals` `{ delta }` · Guest ไม่มี
- ผู้เล่นได้ยอดตอนเข้าเกม (`welcome.cashState`) และทุกตัวละครของบัญชีได้ยอดใหม่หลังซื้อ (`{ t: 'cashState' }`)

## สินค้า

- **ของแต่งตัว** (`cos:<id>`): ราคา = ราคาในแท็บ "จัดการของแต่งตัว" (`cos_shop`) ชิ้นที่ซ่อนหรือไม่มีราคาไม่ขาย · ซื้อได้ครั้งเดียวต่อบัญชี เข้าบัญชีทันที (ตาราง `account_cosmetics`, `granted_by = 'แคชช็อป'`)
- **ของใช้และหิน** (`stone:<ชนิด>`): ใบคูณ EXP 50 · ใบคูณดรอป 50 · โทรโข่ง 30 · หินตีบวก 100 · หินกันระดับลด 150 · หินสุ่มค่า 80 · หินสุ่มสเตตัส 80 (ค่าในโค้ด `CASH_STONE_PRICE` "ชุด ก") ครั้งละ 1–10 ชิ้น **ส่งเข้าจดหมายของบัญชี** ผู้ส่ง "แคชช็อป" หมดอายุ 30 วัน · หินไม่ผูก เทรด/ขายได้ · ใบคูณและโทรโข่งผูกกับตัวละครที่กดรับ (กติกาเดิม)
- กล่องปริศนาไม่ขายในร้าน (เจ้าของตกลงไว้ในแผนกล่องปริศนา)

## การตั้งค่า (/admin แท็บ "แคชช็อป" ในหมวด "ปรับเกม")

- สิทธิ์ `cashShop` (ดู: owner + GM) และ `cashShopEdit` (บันทึก: owner) ตั้งต่อ role ได้ในแท็บ "สิทธิ์"
- **เปิดขาย** (ค่าเริ่ม: ปิด = ผู้เล่นดูสินค้าได้แต่ซื้อไม่ได้ มีแถบ "ร้านยังไม่เปิดขาย")
- รายชิ้น: ขาย/ไม่ขาย · ราคา (ช่องของแต่งตัวบันทึกลง `cos_shop` เดียวกับแท็บจัดการของแต่งตัว เว้นว่าง = ไม่ขาย) · ราคาลด (ต้องต่ำกว่าราคาเต็ม การ์ดโชว์ราคาเดิมขีดฆ่าและป้าย "ลดราคา") หรือพิมพ์เป็น % เช่น `20%` (1–99, เจ้าของ 2026-11-22: เก็บเป็น `pct` ราคา = ราคาเต็ม × (100−%) ปัดลง อย่างน้อย 1 ตามราคาเต็มเมื่อราคาเปลี่ยน ป้ายมุมเป็น "-20%" ใส่ได้แบบเดียว) · จำกัดต่อบัญชีตลอดไป (หิน) · เวลาเริ่ม/หมดเวลาขาย (พิมพ์เป็นเวลาไทย) · ป้ายมุม ใหม่/ขายดี · ติด "แนะนำ"
- **แพ็กเกจเติม** (คริสตัล + โบนัส + โบนัสครั้งแรก ราคาบาท) เริ่มว่าง ผู้เล่นเห็นในหน้าต่างปุ่ม + · ปุ่ม "เติม" ใช้ได้เมื่อเปิดการเติมในแท็บ "เติมเงิน" ([topup.md](topup.md)) ไม่งั้นเป็น "เร็วๆ นี้"
- ประวัติการซื้อ 200 รายการล่าสุด (ตาราง `cash_purchases`)
- หน้าบัญชีใน /admin แสดงยอดคริสตัลมิติของบัญชี (ดูอย่างเดียว)
- เก็บในตาราง `settings` key `cash_shop` **เฉพาะที่ต่างจากค่าเริ่ม** (ไม่มีแถว = ปิดขาย ราคาในโค้ด ไม่มีแพ็กเกจ) · server ตรวจแบบเข้มตอนบันทึก ผ่อนตอนอ่าน DB · ส่ง `base` (409 ถ้าค่าของเซิร์ฟเปลี่ยนหลังโหลดหน้า) · audit action `cash-shop` (และ `cos-shop` ถ้าราคาของแต่งตัวเปลี่ยน)
- API: `GET /api/admin/cash-shop` → `{ cfg, cosShop, canEdit, recent }` · `POST /api/admin/cash-shop` `{ cfg, cosPrices?, base }`
- บันทึกแล้วทุกคนที่ออนไลน์ได้รายการใหม่ทันที (`{ t: 'cash', cat }`) รวมตอนเปลี่ยนราคา/ซ่อนในแท็บจัดการของแต่งตัว และตอนเพิ่ม/ลบลูกแก้วตีบวก

## การซื้อ (server เป็นคนหักและให้ของ)

- action `cashBuy { req, id, qty, price }` (`price` = ราคาต่อชิ้นที่ผู้เล่นเห็น ไม่ตรงกับตอนนี้ = "ราคาเปลี่ยนแล้ว") ตอบ `{ t: 'cashBuy', req, ok, msg }` · 1 ครั้ง/300 ms ต่อคน
- ตรวจ (`cashBuyError` ใช้ทั้ง server และปุ่มในเกม): ไม่ใช่ Guest · ร้านเปิดขาย · มีสินค้าและอยู่ในช่วงเวลา (เวลา server) · จำนวน 1–10 (ของแต่งตัว 1) · ของแต่งตัวยังไม่มี · ไม่เกินจำกัด · คริสตัลพอ
- ทำใน transaction เดียว: `UPDATE accounts SET crystals = crystals - ? WHERE id = ? AND crystals >= ?` (สองตัวละครของบัญชีเดียวกันกดพร้อมกันได้แค่เท่าที่มีคริสตัล) → นับจำกัดซ้ำ → ของแต่งตัว `INSERT OR IGNORE` (มีแล้ว = ย้อน ไม่เสียคริสตัล) หรือจดหมาย → แถว `cash_purchases` · ไม่สำเร็จ = ย้อนทั้งหมด

## หน้าต่างในเกม

- เปิดจากไอคอนแถวมุมขวาบน "แคชช็อป" · ตารางเมนู · NPC **พ่อค้าคริสตัล** ในเมือง (ยืนที่เดิมของช่างแต่งตัว ข้างผู้ดูแลคลัง `deg(202.5, 7.2)` · เจ้าของสั่ง 2026-11-16 ให้เอาช่างแต่งตัวออกจากเมืองไปก่อน หน้าต่าง "แต่งตัว" ยังเปิดจากเมนูได้ · เอากลับได้ที่ `src/shared/sim/terrain.ts`) · ปุ่ม "ซื้อในแคชช็อป" ในหน้าต่างแต่งตัว
- แท็บ แนะนำ · ของแต่งตัว (เมนูซ้ายตามชนิด) · ของใช้ (ใบคูณ / โทรโข่ง) · หิน
- การ์ดสีทอง: ภาพ ชื่อ "ซื้อได้ x/y" / "ไม่จำกัดจำนวน" / "มีแล้ว" เวลาเหลือ ป้ายมุม แถบราคา · ชี้ = กล่องรายละเอียด · กด (หรือแตะบนมือถือ) = หน้าต่างซื้อ: ภาพ คำอธิบาย จำนวน 1–10 ปุ่ม "ลองสวม" (ของแต่งตัว เห็นแค่ตัวเอง ถอดเมื่อปิด · **ลองได้เฉพาะในเมือง/safe zone** เจ้าของ 2026-11-25 ดู [cosmetics.md](cosmetics.md)) ราคารวม เหตุผลที่ซื้อไม่ได้ และปุ่มยืนยัน
- ยอดคริสตัลมุมขวาบน ปุ่ม + เปิดแพ็กเกจ / QR พร้อมเพย์ของคำขอที่รอยืนยัน ([topup.md](topup.md))
- **หน้าตา "ตลาดมิติ"** (เจ้าของสั่งปรับ 2026-11-16): เหล็กดำขอบบรอนซ์แบบ UI เดิม + แสงคริสตัลม่วง-ฟ้าเฉพาะจุด · กรอบหน้าต่างและหน้าต่างซื้อเป็น `border-image` (ยืดได้ มุมไม่เพี้ยน) · การ์ดเป็นภาพเดียวแล้ววางข้อความบนแผ่นชื่อ/แผ่นราคาเป็น % ของภาพ · การ์ดขอบคริสตัลสำหรับของแนะนำ/ลดราคา · ริบบิ้นมุมเขียว/แดง/ม่วง (ข้อความเกมพิมพ์เอง) · แบนเนอร์บนแท็บแนะนำ · ภาพกองคริสตัล 4 ขนาดในหน้าต่างแพ็กเกจ (ตามลำดับจำนวนคริสตัล)

## VIP (เจ้าของ 2026-11-23)

- ซื้อด้วยคริสตัลมิติในแคชช็อป (แท็บ "VIP") **ผูกกับบัญชี** ทุกตัวละครได้ · เก็บเวลาหมดใน `accounts.vip_until` (ms, 0 = ไม่เคยเป็น) · เวลาเดินตลอดแม้ไม่ออนไลน์ · **ซื้อซ้ำ = บวกวันต่อจากเวลาที่เหลือ** (`vipExtend`)
- **แพ็ก VIP ตั้งใน /admin แท็บแคชช็อป** ส่วน "แพ็ก VIP" (จำนวนวัน 1–3,650 + ราคาคริสตัล ไม่เกิน 10 แพ็ก จำนวนวันห้ามซ้ำ) · **ไม่มีแพ็ก = ไม่ขาย VIP** (ค่าเริ่ม) · ขายเฉพาะตอนร้านเปิดขาย · เก็บใน `cash_shop.vip`
- ได้อะไร (ตัดสินที่ server ทั้งหมด, `src/shared/vip.ts`): **EXP +10%** (ปัดลง คิดหลังลด Auto 50% และใบคูณ ×2 → ใบคูณ+VIP = ×2.2) · **โอกาสดรอป +10%** (ของผู้ได้สิทธิ์เก็บก่อน คูณต่อจากใบคูณดรอป ไม่รวมทอง/จำนวนคงที่ เหมือนใบคูณ) · **เทรดไม่จำกัด** ([trade.md](trade.md)) · % ทั้งสองปรับแยกในแท็บปรับสมดุล (`vipExpPct` / `vipDropPct` 0–100, ค่าในโค้ด 10) · EXP ปาร์ตี้แต่ละคนคิดตาม VIP ของตัวเอง
- server ตั้ง `Player.vip` (ไม่เซฟลงตัวละคร) จาก `Session.vipUntil` ทุก tick → หมดเวลาแล้วโบนัสหยุดทันที · อัปเดตเมื่อเข้าเกม ซื้อ และแอดมินให้/ถอด (ทุกตัวละครของบัญชีที่ออนไลน์ `world.vipChanged`)
- การซื้อ: action `cashBuy` เดิม id `vip:<วัน>` qty 1 `price` = ราคาที่เห็น (เปลี่ยน = "ราคาเปลี่ยนแล้ว") · transaction เดียว: หักคริสตัล → ต่อเวลา → แถว `cash_purchases` (item `vip:<วัน>`) · ตรวจด้วย `vipBuyError`
- **ป้าย VIP + เวลาที่เหลือ แสดงในหน้าแคชช็อปเท่านั้น** (เจ้าของเลือก): ป้าย "VIP · เหลือ …" ข้างยอดคริสตัล + แท็บ VIP บอกสถานะ สิ่งที่ได้ และปุ่มซื้อแต่ละแพ็ก (ถามยืนยันก่อน)
- **แอดมินให้/ถอด VIP** หน้าบัญชีใน /admin: "เพิ่มวัน VIP" (1–3,650 วัน ต่อจากที่เหลือ) / "ถอด VIP" (ถามก่อน เวลาที่เหลือหายหมด) · สวิตช์ `vipGrant` (ค่าเริ่ม owner) · audit `vip-give` / `vip-remove` · API `POST /api/admin/accounts/:id/vip` `{ days }` หรือ `{ remove: true }` · Guest ไม่ได้
