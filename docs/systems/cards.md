# ระบบการ์ดมอนสเตอร์ (รู การเสียบ และผลการ์ด)

แผนเต็มและตารางการ์ดทั้ง 47 ใบอยู่ที่ [docs/plans/card-system.md](../plans/card-system.md) · ไฟล์นี้เก็บกติกาที่ทำแล้วและเจ้าของตกลงแล้ว

ตัวเลขทุกตัวปรับได้ในแท็บ **"การ์ด"** ของ `/admin` (`CARD_NUM_FIELDS` ใน `src/shared/data/cards.ts`, เก็บเฉพาะค่าที่ต่างจากโค้ดใน `settings` key `card_tuning`, ลง `admin_audit`, มีผลทันที) · โค้ดเกมต้องอ่านผ่าน `cardDef()` / `cardNum()` (`src/shared/cardTuning.ts`) ห้ามอ่านค่าคงที่ตรง ๆ

## การ์ดเป็นไอเทม (PR 1)
- การ์ด `card_<monster>` เป็นชนิดหิน (`StoneKind`) ซ้อนช่องละ 10 ใบ เทรด คลัง จดหมาย ตลาด ขายพ่อค้าได้ (ราคา `sell_<ระดับ>`)

## เจาะรู (PR 2, เจ้าของตกลง 2026-11-26)
- **ทำที่ NPC ช่างตีเหล็ก** เมนูที่ 4 "เจาะรู" (`index.html` `data-mode="drill"`, `src/client/ui/forge.ts`)
- **เจาะได้ทุกชิ้นทุกความหายาก** (อุปกรณ์ 10 ช่องสวม ไม่รวมของแต่งตัว) รวมของเก่าในเซฟ ใส่อยู่ก็เจาะได้
- ใช้ทอง + **หินเจาะรู** (`drill`, หินช่างชนิดที่ 5 ใน `BLACKSMITH_STONES`) 1 ก้อน · ผล 0 / 1 / 2 ช่อง ตาม `drill0` / `drill1` / `drill2` (โค้ด 40 / 50 / 10%)
- ค่าทอง = (15 + iLv × 6) × `drillCostMult` (โค้ด 5) × ตัวคูณความหายากเดียวกับสุ่มค่า (ธรรมดา 1 · ดี 1.5 · หายาก 2 · มหากาพย์ 3 · ตำนาน 5) (`drillCost()` ใน `src/shared/cardSockets.ts`)
- **เจาะได้ครั้งเดียวต่อชิ้น** ได้ 0 ช่องก็เจาะใหม่ไม่ได้ · ใช้คูลดาวน์ช่างเดียวกับตีบวก/สุ่มค่า
- รูไม่เปลี่ยนตอนตีบวก สุ่มค่า สุ่มสเตตัส
- **หินเจาะรูดรอป** (เจ้าของ 2026-11-26): มอนที่ดรอปไอเทมได้ `drillDropMonster` (โค้ด 0.2%) · บอส `drillDropBoss` ต่อกุญแจ (โค้ด 10%) · ใบคูณดรอป/VIP คูณเหมือนหินอื่น · admin เสก/แนบจดหมายได้ (`BLACKSMITH_STONES` ในตัวเลือกของ) · ขายพ่อค้า 1,000 G
- เก็บใน `Item.sockets` (ไม่มี = ยังไม่เจาะ · 0 = เจาะแล้วไม่ได้ช่อง · 1–2)

## เสียบ / ถอดการ์ด (PR 3, เจ้าของตกลง 2026-11-26)
- **เสียบจากกระเป๋าได้ทุกที่** ไม่ต้องไปหา NPC: คลิกการ์ดในกระเป๋า (จอสัมผัส: ปุ่ม "ดู / เสียบการ์ด") → หน้าต่างดูการ์ดมีส่วน "เสียบการ์ด" ใต้การ์ด แสดงอุปกรณ์ที่เจาะรูแล้วและกลุ่มตรงกัน (ที่สวมอยู่ก่อน แล้วในกระเป๋า) กดชิ้นไหน = เสียบลงช่องว่างแรกของชิ้นนั้น (`src/client/ui/cardPopup.ts`)
- การ์ดต้องตรงกลุ่ม: ⚔ อาวุธ/อาวุธรอง · 🛡 หมวก เกราะ ถุงมือ เข็มขัด รองเท้า · 💍 สร้อย แหวน (`SLOT_CARD_GROUP`) ใช้กลุ่มที่ปรับใน /admin
- การ์ดใบเดียวกันใส่ได้ทั้ง 2 ช่อง ผลบวกกัน
- ค่าเสียบ `socketCost` / ค่าถอด `unsocketCost` (โค้ด 0 = ฟรี)
- **ถอด = การ์ดแตก** หายไปเลย ต้องกดยืนยัน · เปิดที่ **Shift+คลิก** อุปกรณ์ที่มีรู (ในกระเป๋าหรือที่สวมอยู่) หรือปุ่ม "ดู/ถอดการ์ด" ในรายละเอียดไอเทม (จอสัมผัส) → หน้าต่างรูของชิ้นนั้น ปุ่ม "ถอด (การ์ดแตก)" ต่อช่อง
- ช่องเต็มต้องถอดใบเดิมก่อน ไม่มีเปลี่ยนในขั้นเดียว
- เก็บใน `Item.cards` (ยาวเท่า `sockets`, null = ว่าง, ไม่มีฟิลด์เมื่อว่างทุกช่อง) · อุปกรณ์เก็บแค่ว่าการ์ดใบไหนอยู่ช่องไหน → ปรับผลการ์ดใน /admin แล้วการ์ดที่เสียบอยู่เปลี่ยนตามทันที (server คำนวณสเตตัสทุกคนใหม่ตอนบันทึก)
- การ์ดติดไปกับอุปกรณ์ทุกทาง: เทรด คลัง จดหมาย ตลาด ขาย · ตอนโหลด (`upgradeItem` → `cleanSockets`) จำนวนรูผิด = ยังไม่เจาะ, การ์ดที่ไม่มีจริง = ช่องว่าง
- action `drill` / `socketCard` / `unsocketCard` (ครบ 5 ที่) ห้ามระหว่างเทรด (`TRADE_LOCKED`) · server ตรวจทุกอย่างเอง (ของของผู้เล่นจริง สวมอยู่หรือในกระเป๋า ไม่ใช่คลัง, ระยะ NPC เฉพาะเจาะ, กลุ่ม ช่องว่าง การ์ดในกระเป๋า ทอง หิน)

## ผลการ์ด (PR 4, เจ้าของตกลง 2026-11-26)
- คิดจากการ์ดบนอุปกรณ์ที่**สวมอยู่**เท่านั้น ผลชนิดเดียวกันบวกกัน แล้วตัดที่เพดาน `cap_<ผล>` (0 = ไม่จำกัด) → `Player.cardFx` (`cardFxTotal`)
- **HP% MP% ATK% DEF%** คูณ**ผลรวมทั้งหมดก่อนตัวคูณอาชีพ**: คลาส + เลเวล + อุปกรณ์ + ตีบวก + **โบนัสเซ็ต** (เจ้าของ 2026-11-26) · โบนัสเซ็ตยังไม่โดนตัวคูณอาชีพเหมือนเดิม จึงคูณการ์ด % แยกให้ · บัฟสกิล/พาสซีฟไม่รวม · ต่างจากโบนัสอัลบั้มที่คูณหลังตัวคูณอาชีพ
- **ลดคูลดาวน์ / เจาะเกราะ ของการ์ด บวกกับมอดเสริมชื่อเดียวกันบนอุปกรณ์** (เจ้าของเลือก "บวกกัน"): ส่วนของการ์ดตัดที่เพดานการ์ดก่อน แล้วบวกเข้า `stats.cdr` / `stats.armorPen` ยอดรวมยังหยุดที่เพดานเดิม (ลดคูลดาวน์ `cdrCap` 75% · เจาะเกราะ 100%)
- ดูดเลือด: ทุกครั้งที่ตีโดน ฟื้น HP ตาม % ของดาเมจจริง บวกกับดูดเลือดพายุดาบตอนที่ทำงาน
- ลดดาเมจที่ได้รับ: หลังสูตร `mitigate` ของการโจมตีมอน (`hitPlayer`) และดาเมจจากท่ามอน (`hurtPlayer`) ไม่รวมลาวา
- ดาเมจต่อบอส: คูณต่อจากตัวคูณบอสของอาชีพ ใช้กับบอสเท่านั้น
- ยาฟื้นเพิ่ม: คูณต่อจากโบนัสยาของอาชีพ (HP และ MP)
- EXP %: คูณ EXP ที่ได้ทุกทาง (ฆ่าเองและส่วนแบ่งปาร์ตี้) ก่อนลด Auto 50% / ใบคูณ / VIP
- ทอง %: ทองที่ดรอปของคนที่ได้สิทธิ์เก็บก่อน (คนตีมากสุด)
- ดาเมจโจมตีปกติ %: ตีธรรมดาของอาชีพเท่านั้น ไม่รวมสกิล
- หน้าต่างตัวละครมีส่วน **"ผลการ์ด"** ใต้สเตตัส ผลที่ชนเพดานบอก "(เต็ม)"

## ปรับระดับการ์ดใน /admin (เจ้าของ 2026-11-26)
- แท็บ "การ์ด" มีช่องเลือกระดับ (หายาก/มหากาพย์/ตำนาน) ต่อใบ แบบเดียวกับกลุ่มช่อง · เก็บเฉพาะที่ต่างจากโค้ด (`CardChange.rarity`) ลง audit
- ราคาขายพ่อค้า สีชื่อ/ขอบไอคอน กรอบการ์ด และกองรวมการ์ด (`tunedFusePool` ใน `cardTuning.ts`) ตามระดับที่ปรับ · อัลบั้มไม่ขึ้นกับระดับ
- **อัตราดรอปการ์ดตามระดับ** (เจ้าของ 2026-11-26): `drop_rare` / `drop_epic` / `drop_legendary` ในแท็บการ์ด /admin (โค้ด 0.01% / 0.1% / 0.1%) ใช้ระดับที่ปรับแล้วของการ์ดใบนั้น · มอนทั่วไปสุ่มครั้งเดียวต่อการฆ่า บอสในห้องบอสสุ่มทีละกุญแจ · แทน `dropMonster`/`dropBoss`/`dropBossExtra` เดิม (ค่าที่เคยบันทึกย้ายเอง: มอน→หายาก, นกแก้ว (หรือบอส)→มหากาพย์, บอส→ตำนาน)

## รวมการ์ด (PR 8, เจ้าของตกลง 2026-11-26)
- **ที่ช่างตีเหล็ก เมนูที่ 5 "รวมการ์ด"** (`index.html` `data-mode="fuse"`, `src/client/ui/forge.ts`): 3 ช่องการ์ด ใส่โดยคลิกการ์ดในกระเป๋า (ตอนเปิดเมนูนี้ คลิกการ์ด = ใส่ช่อง ไม่เปิดหน้าดูการ์ด) ลากลงหน้าต่าง หรือคลิกรายการการ์ดทางขวา · คลิกการ์ดในช่อง = เอาออก · ปุ่ม "นำออก" = ล้างทั้ง 3 ช่อง · มีตารางโอกาส · ถามยืนยันก่อนรวม · ได้แล้วเปิดหน้าดูการ์ดใบที่ได้
- กติกา (`src/shared/cardFuse.ts` `fuseBlock`): การ์ด 3 ใบ **ระดับเดียวกัน (ระดับที่ปรับใน /admin) และชั้นเดียวกัน** ซ้ำกันได้ · **คนละชั้นรวมไม่ได้** · ได้ 1 ใบสุ่มเท่ากันจากทุกใบในระดับและชั้นนั้น (`tunedFusePool`) อาจได้ใบเดิม
- ค่าทอง `fuseCost_<ระดับ>` (โค้ด หายาก 5,000 · มหากาพย์ 20,000 · ตำนาน 100,000 G) · เปิด/ปิดต่อระดับ `fuseOn_<ระดับ>` (โค้ด: มหากาพย์ปิด เพราะมีชั้นละใบเดียว)
- **การ์ดชั้น 2 รวมได้เมื่อ `floor2Drop` = 1 เท่านั้น** (เจ้าของ 2026-11-26) · **การ์ดที่ได้จากการรวมไม่ประกาศทั้งเซิร์ฟ** แม้เป็นตำนาน (เจ้าของ 2026-11-26)
- action `fuseCards` ครบ 5 ที่ ตอบด้วย `fused` · ห้ามระหว่างเทรด · server ตรวจระยะ NPC คูลดาวน์ช่าง การ์ด 3 ใบ กติกาข้างบน การ์ดในกระเป๋า ทอง และช่องว่างของใบที่ได้ (หักการ์ดแล้วใบใหม่ไม่มีที่ = คืนการ์ด ไม่หักทอง)

## หน้าดูการ์ด: แสงตามระดับ (เจ้าของ 2026-11-26)
- `src/client/cardView.ts` (`cardLook`) ใช้ทั้งในเกมและแท็บการ์ด /admin: **หายาก** แถบแสงขาววิ่งผ่าน · **มหากาพย์** แถบแสงขาว + ประกายสีระยิบ · **ตำนาน** โฮโลสีรุ้งที่เปลี่ยนสีตามมุมเอียง · แสงเป็นลำสีตามระดับหมุนช้า ๆ หลังการ์ด · จอสัมผัส: ไม่แตะ = แสงวิ่งช้า ๆ เอง
- ค่าในแท็บการ์ด หัวข้อ "หน้าตาการ์ด": `viewShine` (สวิตช์รวม) · `viewShinePct_<ระดับ>` ความแรงแยกต่อระดับ (0 = ไม่มีแสง, โค้ด 45/55/65 · ค่า `viewShinePct` เดิมที่เคยบันทึกย้ายไปทั้ง 3 ระดับเอง) · `viewSparkle` ประกายมหากาพย์ · `viewRainbow` โฮโลตำนาน · `viewRays` แสงพุ่งหลังการ์ด · `viewIdle` แสงวิ่งเองบนจอสัมผัส · `viewTiltDeg` เอียงสูงสุด
- เมนูกราฟิกของผู้เล่นระดับ "ปิด" = ไม่มีแสง ประกาย โฮโล และแสงพุ่ง (การ์ดยังเอียงได้)
- **กรอบการ์ด** ใช้ `card_frame_clean_<ระดับ>.webp`: กรอบบางเดิมที่เอาสีชมพู/ม่วงแดงที่ค้างตามขอบในและเงาใบไม้ออก (`node tools/clean_card_frames.cjs` อ่าน `card_frame_thin_*` · ชื่อไฟล์ใหม่กันแคชเบราว์เซอร์/Cloudflare)

## UI อื่น
- tooltip อุปกรณ์: "ยังไม่เจาะรู" / "เจาะแล้ว: ไม่มีช่อง" / "◇ ช่องว่าง" / "◆ การ์ดหมาป่า: ..." · **ไอคอนไม่มีเครื่องหมายรู** เห็นรูเฉพาะตอนเอาเมาส์ชี้ที่อุปกรณ์ (เจ้าของ 2026-11-26)
- พ่อค้า "ขายที่เลือกตามระดับ" **ข้ามของที่เจาะรูแล้ว** (มีหรือไม่มีการ์ด) เหมือนของที่ตีบวกแล้ว (`isBulkSellable`) · ขายของที่เจาะแล้วทีละชิ้นต้องยืนยัน ถ้ามีการ์ดเตือนว่าราคาไม่รวมการ์ด
- /admin หน้าบัญชี (สวิตช์ `itemEdit`): แก้ "รูการ์ด" (ยังไม่เจาะ / 0–2 ช่อง) และการ์ดแต่ละช่อง (server ตรวจกลุ่ม) · แก้ไอเทมโดยไม่แตะรู = รูและการ์ดเดิมอยู่ครบ · audit บอกรูและการ์ด
