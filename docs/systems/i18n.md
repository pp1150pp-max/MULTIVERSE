# ภาษาอังกฤษ (English / i18n)

เจ้าของตกลง 2026-11-22: เกมเลือกได้ 2 ภาษา ไทย / English · ภาษาไทยยังเป็นต้นฉบับ (โค้ดเขียนข้อความไทยเหมือนเดิม) · ข้อความที่ยังไม่มีคำแปลแสดงเป็นไทย

## กติกาที่ตกลงแล้ว

- **ตัวเลือกภาษา** อยู่ที่ เมนู → ตั้งค่า → แท็บทั่วไป แถว `ภาษา / Language` dropdown ไทย / English (ทั้งแถวไม่ถูกแปล ใครก็หาเจอ) · ในหน้าตั้งค่า "เปิด/ปิด" แปลเป็น On/Off ไม่ใช่ Open/Close (`CONTEXT` ใน `src/client/i18n.ts`)
- **มีผลตอนเปิดเกมครั้งถัดไป** (รีเฟรช / กลับไปเลือกตัวละคร / ออกจากระบบ ทั้งหมดโหลดหน้าใหม่) ไม่เปลี่ยนทันทีระหว่างเล่น · ใต้แถวบอก `มีผลเมื่อเปิดเกมใหม่ / Takes effect when you open the game again` จนกว่าจะเปิดใหม่
- **ครั้งแรก** (ยังไม่เคยเลือก) เลือกตามภาษาของเบราว์เซอร์: ภาษาไทย → ไทย, อื่น ๆ → English
- ที่เลือกจำไว้ในเบราว์เซอร์ (`localStorage` คีย์ `multiverse-lang`) ไม่ผูกกับบัญชี
- **ขอบเขต**: ทุกหน้าจอของผู้เล่น (หน้า Login/เลือกตัวละคร, HUD, หน้าต่างทั้งหมด) ชื่อและคำอธิบายอาชีพ/สกิล/มอน/บอส/ไอเทม/ของแต่งตัว และข้อความที่ server ส่งมา (ปาร์ตี้ เทรด ตลาด จดหมายระบบ ฯลฯ)
- **ไม่แปล**: หน้า `/admin` (ไทยต่อไป) · ข้อความที่ผู้เล่นพิมพ์เอง (แชท โทรโข่ง ฟองแชท) · ชื่อตัวละคร · หัวข้อ/เนื้อหาจดหมาย · ประกาศที่เจ้าของพิมพ์ · `privacy.html` / `terms.html` (ยังเป็นไทย)
- ภาพในเกมไม่มีตัวหนังสือไทย (ตรวจแล้ว 2026-11-22) · ถ้าเพิ่มภาพที่มีตัวหนังสือ ให้ใช้ตัวหนังสือ HTML ทับแทน (เจ้าของเลือก)
- **สวิตช์ /admin**: แท็บปรับสมดุล การ์ด "ภาษาอังกฤษ" (`BalanceTuning.english`, ค่าในโค้ด = เปิด) · ปิด = ทุกคนเห็นไทย และซ่อนปุ่มเลือกภาษา (คนที่เปิดเกมค้างเป็นอังกฤษจะกลับเป็นไทยตอนเปิดเกมใหม่) · ลง audit ตามแบบแท็บปรับสมดุล

## ทำงานยังไง (สำหรับคนแก้โค้ด)

- **พจนานุกรม** `src/shared/i18n/en/*.ts`: คีย์คือข้อความไทย *ตรงตามที่ขึ้นบนจอ* ค่าคือภาษาอังกฤษ · ส่วนที่เปลี่ยนได้ใช้ `{0}` `{1}` (หรือ `{name}`) เช่น `'{0} เข้าร่วมปาร์ตี้': '{0} joined the party'`
  - ชื่อมอนและสกิลเอาจากฟิลด์ `name` ภาษาอังกฤษในข้อมูลเอง (`src/shared/i18n/dict.ts`) ไม่ต้องเขียนซ้ำ
- **ตัวแปล** `src/shared/i18n/translator.ts` (ไม่มี DOM ใช้ได้ทั้ง server และเทสต์): ตรงตัว → แม่แบบ `{0}` (ค่าที่จับได้แปลซ้ำอีกรอบ เช่นชื่อไอเทมในข้อความ server) → แปลทีละท่อนไทยที่คั่นด้วยตัวเลข/อังกฤษ/สัญลักษณ์ (`5 วิ` → `5 s`) → ไม่เจอ = คืนไทย
- **ฝั่งเบราว์เซอร์** `src/client/i18n.ts`: ภาษาตัดสินครั้งเดียวตอนโหลดหน้า (`LANG`) · โหมด English เท่านั้นที่ติดตั้งตัวแปลบนหน้า (`MutationObserver`) แปลทุกข้อความ/`title`/`placeholder`/`aria-label`/`alt` ที่ขึ้นบนจอ รวม `alert`/`confirm`/`prompt` · **โหมดไทยไม่มีอะไรเปลี่ยนเลย** (ไม่ติดตั้งตัวแปล)
  - ข้อความที่ผู้เล่นเขียนเอง: ใส่ `translate="no"` (`noTranslate(el)` / `said(text)` ใน `src/client/i18n.ts`) ตัวแปลข้ามทั้งกิ่ง
  - ตัวหนังสือที่วาดบน canvas (ป้ายในแผนที่ใหญ่ การ์ดของแต่งตัว) ไม่ผ่านหน้า → เรียก `t('ข้อความไทย')` เอง
  - โค้ดที่อ่านข้อความบนจอกลับมาเทียบกับข้อความไทย จะไม่ตรงเมื่อเป็นอังกฤษ → เทียบกับ `t(ข้อความ)` ด้วย (ตัวอย่าง `src/client/market.ts`)
- **server** ส่งข้อความไทยเหมือนเดิม ไม่รู้ภาษาผู้เล่น · เบราว์เซอร์แปลตอนขึ้นจอ · มีแค่ `GET /api/lang` → `{ english }` บอกสวิตช์ /admin ก่อนหน้า Login จะขึ้น (เบราว์เซอร์จำไว้ใช้ครั้งหน้า)

## เพิ่มข้อความใหม่

1. เขียนข้อความไทยในโค้ดตามปกติ (ไม่ต้องเรียก `t()` ยกเว้นวาดบน canvas)
2. `node --import tsx tools/i18n-extract.ts` → จำนวนข้อความไทยที่ยังไม่มีภาษาอังกฤษ · `-- --missing` → รายการแยกตามไฟล์ (คีย์ตรงตามที่ต้องใส่พจนานุกรม)
3. เพิ่มคำแปลใน `src/shared/i18n/en/*.ts` ไฟล์ที่เข้าหมวด
4. ตอนเล่นโหมด English เปิด console พิมพ์ `__i18nMisses()` = ข้อความไทยที่ขึ้นจอจริงแต่ยังไม่มีคำแปล (เช่นข้อความจากไฟล์ `*Tuning.ts` ที่ตัวดึงคีย์ข้ามไป)
5. เทสต์ `tests/i18n.test.ts`: fallback, แม่แบบ, ค่าทุกตัวเป็นอังกฤษ, คีย์ทุกตัวมีไทย
