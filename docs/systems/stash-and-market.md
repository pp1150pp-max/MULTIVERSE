# คลังเก็บของ และตลาดฝากขาย

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · แผนเต็มของตลาด: [docs/plans/consignment-npc.md](../plans/consignment-npc.md)

## คลังเก็บของ

- คลังเก็บของ (ผู้ดูแลคลังในเมือง, `src/shared/sim/stash.ts`) ใช้ร่วมกันทุกตัวละครในบัญชีเดียวกัน เริ่ม 30 ช่อง ซื้อเพิ่มทีละ 10 สูงสุด 90 (5,000/10,000/20,000/40,000/80,000/160,000 G) เก็บของ ยา และทอง
  - เปิดจากหน้าต่างคุย NPC = หน้าต่างคลังทั้งก้อนอยู่ในหน้าต่างคุยที่ขยาย คลิกฝาก/เบิกได้ (เจ้าของ 2026-11-27, สวิตช์ `npcTalk.stashPane`, ดู [world-and-ui.md](world-and-ui.md) "คลังในหน้าต่างคุย")
  - เก็บในตาราง `stashes` และเซฟพร้อมตัวละครใน transaction เดียว · Guest ใช้คลังไม่ได้ (server ปฏิเสธ และขึ้นข้อความให้สมัคร)

## ตลาดฝากขาย

- เปิดจากหน้าต่างคุย NPC = หน้าต่างตลาดทั้งก้อนอยู่ในหน้าต่างคุยที่ขยาย คลิกของในกระเป๋าขวา = เลือกมาลงขาย (เจ้าของ 2026-11-27, สวิตช์ `npcTalk.marketPane`, ดู [world-and-ui.md](world-and-ui.md) "ตลาดในหน้าต่างคุย")
- ตลาดฝากขาย (นายหน้าตลาด `broker` ข้างพ่อค้าในเมือง, กติกา `src/shared/sim/market.ts`, server `server/market.ts`, หน้าต่าง `src/client/market.ts`)
  - ลงขายได้อุปกรณ์ (รวมที่ตีบวกแล้ว) และหิน (ทั้งกอง หรือเลือกจำนวนบางส่วน ดู [items-and-forge.md](items-and-forge.md)) ยาลงขายไม่ได้ · ราคา 1–100,000,000 G แก้ไม่ได้ · 20 ช่องต่อบัญชี · วางขาย 48 ชม.
  - ค่าลงขาย 5% จ่ายตอนลง ไม่คืน ไม่มีขั้นต่ำ · ภาษีเมื่อขายได้ 5% · ซื้อของบัญชีตัวเองไม่ได้ · Guest ดูได้แต่ซื้อขายไม่ได้
  - ข้อมูลอยู่ใน DB เท่านั้น (`market_listings`, `market_listing_stats`) ทุกการย้ายของ/ทองเขียนรายการตลาดพร้อมเซฟตัวละครใน transaction เดียว
  - เงินที่ขายได้ และของที่หมดเวลา/ยกเลิก รอใน "กล่องรับของ" ที่ NPC (ไม่หมดอายุ) · ขายได้ตอนออนไลน์ = ป้ายกลางจอ + แชท + เสียง, ออฟไลน์ = สรุปตอนเข้าเกม · มีของรอรับ = "!" บนหัว NPC
  - หน้าซื้อกรองตามหมวด อาชีพ ความหายาก สเตตัส (สูงสุด 3 ตัว พร้อมค่าขั้นต่ำ) เลเวล +ขั้นต่ำ ราคา และ "ใส่ได้เท่านั้น" แต่ละแถวแสดงรูปไอเทมและสเตตัสทุกบรรทัดพร้อม tier
  - **หมวด "การ์ด"** (เจ้าของ 2026-11-25, ท้ายรายการหมวด): การ์ดมอน `card_<monster>` ลงขายแล้วเข้าหมวดนี้ (`MarketKind` `'card'`) ไม่ใช่หินตีบวก · ในหมวดนี้แถวความหายากเหลือ หายาก/มหากาพย์/ตำนาน (ระดับการ์ด) + แถว "กลุ่มการ์ด" อาวุธ/เกราะ/เครื่องประดับ (ชี้ดูช่องที่ใส่ได้) เลือกได้หลายอัน ไม่เลือก = ทั้งหมด · ระดับ/กลุ่มอ่านจาก `cardDef` ตอนค้นหา (DB ไม่เก็บระดับการ์ด) เจ้าของปรับใน /admin แล้วรายการเก่าตามทันที · เลเวลไม่กรองการ์ด · การ์ดที่ลงขายไว้ก่อนมีหมวด (เก็บเป็น `stone`) ย้ายเข้าหมวดการ์ดเองตอน server เปิด · ตัวกรอง "มีรู/มีการ์ด" ของอุปกรณ์ยังไม่มี (รอเจาะรู/เสียบการ์ด แผนการ์ด PR 3) · ไม่มีค่าใน /admin (หมวดเป็นแค่การจัดกลุ่ม)
  - หน้าต่างตลาด (2026-11-10): แต่ละแถวแสดงสเตตัสบรรทัดละตัวแบบ tooltip · ตัวกรอง Lv/+/ราคา/สเตตัสซ่อนหลังปุ่ม "ตัวกรองเพิ่มเติม" (จำสถานะตลอดรอบเล่น) · หน้าลงขายโชว์ราคาต่ำสุดที่ขายอยู่และราคาเฉลี่ย 5 ครั้งล่าสุดที่ขายได้ (ต่อชิ้น/ต่อก้อน) · หินแสดงราคาต่อหน่วย · ยืนยันซื้อบอกทองคงเหลือ · คลิกขวาของในกระเป๋าตอนยืนใกล้นายหน้า = เมนู ลงขาย / หาชิ้นแบบนี้ / วางลงพื้น (ไม่เปรียบเทียบกับของที่สวม — เจ้าของยังไม่เอา)
  - กันสแปมค้นหา: token bucket ต่อบัญชี (สูงสุด 8 เติม 1 ต่อวินาที, ใช้ร่วมทุกตัวละครของบัญชี, รวมการขอราคาอ้างอิง) · ค้นหาซ้ำเหมือนเดิมภายใน 3 วินาทีตอบจากแคช (ไม่กินโทเคน ล้างเมื่อมีลงขาย/ซื้อ/ยกเลิก/หมดเวลา) · เกินแล้วตอบ "ค้นหาเร็วเกินไป รอสักครู่" · ตัวเลขอยู่ใน `server/market-throttle.ts`
  - กดซื้อสำเร็จ: แถวนั้นหายจากรายการทันทีไม่ต้องรอค้นหาใหม่ (เจ้าของ 2026-11-20 ซื้อแล้วรู้สึกดีเล) · คำสั่งตลาดที่โดนกันรัว 0.1 วิของ server (ไม่มีข้อความ) เบราว์เซอร์ส่งซ้ำเองหลัง 0.15 วิ (เดิมค้นหารอ 1.5 วิ) · ข้อความ "ซื้อ … แล้ว" ไม่ถูกลบ
