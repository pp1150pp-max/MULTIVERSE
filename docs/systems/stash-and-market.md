# คลังเก็บของ และตลาดฝากขาย

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · แผนเต็มของตลาด: [docs/plans/consignment-npc.md](../plans/consignment-npc.md)

## คลังเก็บของ

- คลังเก็บของ (ผู้ดูแลคลังในเมือง, `src/shared/sim/stash.ts`) ใช้ร่วมกันทุกตัวละครในบัญชีเดียวกัน เริ่ม 30 ช่อง ซื้อเพิ่มทีละ 10 สูงสุด 90 (5,000/10,000/20,000/40,000/80,000/160,000 G) เก็บของ ยา และทอง
  - เก็บในตาราง `stashes` และเซฟพร้อมตัวละครใน transaction เดียว · Guest ใช้คลังไม่ได้ (server ปฏิเสธ และขึ้นข้อความให้สมัคร)

## ตลาดฝากขาย

- ตลาดฝากขาย (นายหน้าตลาด `broker` ข้างพ่อค้าในเมือง, กติกา `src/shared/sim/market.ts`, server `server/market.ts`, หน้าต่าง `src/client/market.ts`)
  - ลงขายได้อุปกรณ์ (รวมที่ตีบวกแล้ว) และหินทั้งกอง ยาลงขายไม่ได้ · ราคา 1–100,000,000 G แก้ไม่ได้ · 20 ช่องต่อบัญชี · วางขาย 48 ชม.
  - ค่าลงขาย 5% จ่ายตอนลง ไม่คืน ไม่มีขั้นต่ำ · ภาษีเมื่อขายได้ 5% · ซื้อของบัญชีตัวเองไม่ได้ · Guest ดูได้แต่ซื้อขายไม่ได้
  - ข้อมูลอยู่ใน DB เท่านั้น (`market_listings`, `market_listing_stats`) ทุกการย้ายของ/ทองเขียนรายการตลาดพร้อมเซฟตัวละครใน transaction เดียว
  - เงินที่ขายได้ และของที่หมดเวลา/ยกเลิก รอใน "กล่องรับของ" ที่ NPC (ไม่หมดอายุ) · ขายได้ตอนออนไลน์ = ป้ายกลางจอ + แชท + เสียง, ออฟไลน์ = สรุปตอนเข้าเกม · มีของรอรับ = "!" บนหัว NPC
  - หน้าซื้อกรองตามหมวด อาชีพ ความหายาก สเตตัส (สูงสุด 3 ตัว พร้อมค่าขั้นต่ำ) เลเวล +ขั้นต่ำ ราคา และ "ใส่ได้เท่านั้น" แต่ละแถวแสดงรูปไอเทมและสเตตัสทุกบรรทัดพร้อม tier
