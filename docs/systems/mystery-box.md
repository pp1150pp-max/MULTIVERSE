## ลูกแก้วเป็นไอเทม

- ลูกแก้วจากกล่องเป็นไอเทมในกระเป๋า ชนิด = id ลูกแก้ว (`orb_<n>`, `OrbStoneKind` ใน `types.ts`) ใช้กองแบบหิน ซ้อนได้ 10 ต่อลูกเดียวกัน · เทรด ฝากคลัง ลงตลาดแท็บใหม่ "ของแต่งตัว" ได้ · **ขายพ่อค้าไม่ได้**
- คลิกใช้ (`useOrbItem`) → ลูกแก้วเข้าบัญชี (`account_cosmetics`, granted_by `mystery_box`) แล้วเซฟตัวละครทันที · มีอยู่แล้ว = ใช้ไม่ได้ ของไม่หาย เก็บไว้เทรด/ขาย · Guest ใช้ไม่ได้ (มีของแต่งตัวไม่ได้)
- ไอคอนวาดจากชุดสีของลูกแก้วนั้น · ถ้าลูกแก้วถูกลบใน /admin ไอเทมที่ค้างอยู่ขึ้น "ลูกแก้ว (ถูกนำออกแล้ว)" ใช้ไม่ได้
- **แคชช็อปเลิกขายลูกแก้ว**: ยังโชว์ให้ดู/ลองใส่ แต่ขึ้น "🎁 เปิดได้จากกล่องปริศนา" แทนราคา ซื้อไม่ได้ (server ตรวจ) · สวิตช์ "ขายลูกแก้วในแคชช็อปด้วย" ใน /admin เปิดขายกลับได้

## หน้า /admin แท็บ "กล่องปริศนา" (หมวดปรับเกม)

- สิทธิ์: ดู `mysteryBox` (owner+GM) · บันทึก `mysteryBoxEdit` (owner)
- ปรับได้: เปิด/ปิดกล่อง · โอกาสดรอปมอน/บอส (%) · ขายลูกแก้วในแคชช็อป · รายแถว: ใส่ในกล่อง, % ที่ตั้ง หรือ "แบ่งส่วนที่เหลือ", จำนวน (ของ 1–10, ทอง 1–100,000,000), ประกาศทั้งเซิร์ฟ
- คอลัมน์ "โอกาสจริงต่อกล่อง" คำนวณสดตอนแก้ (ฟังก์ชันเดียวกับที่ server สุ่ม) พร้อม "1 ใน N" · % ที่ตั้งรวมเกิน 100% บันทึกไม่ได้
- เก็บใน `settings` key `mystery_box` เฉพาะค่าที่ต่างจากโค้ด · ส่ง `base` กันบันทึกทับ (409) · ลง audit `mystery-box` · มีผลทันที
