# เอฟเฟกต์สกิล: ชั้นเสริม (ตัวอย่าง 5 สกิล)

ตกลงกับเจ้าของ 2026-11-15 · ยังอยู่ใน branch `feature/skill-fx-layer` ให้เจ้าของลองใน `npm run dev` ก่อน

## กติกาที่ตกลงแล้ว

- เป็น "ชั้นเสริม" ทับบนภาพแผ่นเฟรมเดิม ไม่วาดภาพใหม่ ใช้ร่วมกับภาพใหม่ของเพื่อนเจ้าของได้ (ค่าผูกกับชื่อภาพเอฟเฟกต์ `SkillEffect` ไม่ผูกกับไฟล์ภาพ)
- ตัวอย่าง 5 สกิล (เจ้าของเลือก): ดาบพิพากษา `sw_judgement` · พายุดาบ `whirlwind` · ดาวตก `mg_starfall` · ลูกไฟ `fireball` · ยิงหัว `headshot`
- สวิตช์เปิด/ปิดเพื่อเทียบอยู่ใน /admin อย่างเดียว (เจ้าของเลือก) ไม่มีปุ่มลัดในเกม
- Bloom ยังไม่ทำในรอบนี้
- ภาพเท่านั้น Sim ไม่อ่านค่าเหล่านี้ ไม่เปลี่ยนกติกา/ตัวเลขเกม

## ประกอบด้วย

- แสงเรือง: สำเนาภาพเดียวกันแบบ additive ขยาย ~1.12–1.15 เท่า + แสงฟุ้งนุ่มด้านหลัง (ภาพหลักยังวาดแบบเดิม ขอบดำไม่หาย)
- แสงบนพื้น สีตามสาย ขึ้นเร็วจางช้า
- อนุภาค: ประกาย เศษ ถ่านไฟ ดาว ฝุ่น (สูงสุด 90 ชิ้นพร้อมกัน มือถือ 40 และจำนวนครึ่งเดียว) · ลูกไฟ/กระสุนยิงหัวมีแสงรอบลูกและหาง
- จังหวะท่า: แสงชาร์จที่ตัวผู้ร่ายตอนกดสกิล (ทุกคนเห็น) · ภาพขยายเด้งตอนปล่อย
- ตอนโดน (เฉพาะจอของคนที่ร่ายเอง): มอนกะพริบขาว · ค้างภาพ (ค่าเริ่มต้น 65 ms ตามความหนักของท่า ไม่เกิน 1 ครั้ง/0.15 วิ เกมยังเดินต่อ) · จอสั่นตามความหนัก · ตัวเลขคริเด้งใหญ่ขึ้น (ตัวเลขคริของทุกท่า)

## ผลข้างเคียงที่รู้แล้ว

ค่าผูกกับภาพเอฟเฟกต์ จึงติดไปกับท่าอื่นที่ใช้ภาพเดียวกันด้วย (แค่แสง/อนุภาค ไม่มีค้างภาพ): `sw_bigsword`+`crater` (ท่าดาบยักษ์อีกท่าในสายคมดาบ, `crater` ของอุกกาบาต) · `explosion` (ระเบิดของเมจอีกท่า) · `mg_starhit` (ดาวของเมจอีกท่า) · `reticle` (ท่าเล็งอื่นของมือปืน)
