สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · ข่าวที่หน้านี้แสดงมาจาก [news.md](news.md) · ภาษา: [i18n.md](i18n.md)

เจ้าของตกลง 2026-11-28 · หน้าเว็บแนะนำเกมแยกจากตัวเกม สำหรับเปิด close beta (28 พ.ย. – 5 ธ.ค. 2569 18:00 น. เวลาไทยทั้งสองวัน) เจ้าของเลือก **แบบ A ภาพเต็มจอ** จากตัวอย่าง 3 แบบใน `tools/mockups/landing/` (a/b/c.html, เปิดผ่าน static server ที่ root ของ repo) · ทำด้วย taste-skill (ติดตั้งเฉพาะ worktree ไม่ commit)

โค้ด: หน้า `landing.html` (Vite entry แยก ไม่แตะหน้าเกม/หน้าเข้าสู่ระบบ) · `src/landing/main.ts` (นับถอยหลัง ข่าว ภาษา เมนูมือถือ) · `src/landing/landing.css` · ค่า/ตัวตรวจ `src/shared/landing.ts` · server `server/landing.ts` · การ์ด /admin ใน `src/admin/news.ts` · เทสต์ `tests/landing-server.test.ts`

## บนหน้า

- **หัวหน้า (fixed):** โลโก้ · หน้าแรก ข่าวสาร อาชีพ โลกของเกม บอส ระบบเด่น (ลิงก์ของส่วนที่กำลังดูเป็นสีทอง `aria-current`) · ปุ่ม EN/TH · ปุ่ม "เข้าเกม" · จอแคบ (≤860px) เมนูเป็นปุ่ม ☰ เปิดเต็มจอ Esc ปิด
- **หน้าแรก:** ภาพหน้า login ของเกม (`paper/ui/login_bg.png`) เต็มจอ โลโก้ บรรทัด "เล่นฟรีบนเบราว์เซอร์ ทั้ง PC และมือถือ" นับถอยหลัง ปุ่ม "เข้าเกม" ใหญ่สีทอง
- **นับถอยหลัง 3 สถานะ:** ก่อนเริ่ม "Close Beta เริ่มในอีก" นับถึงเวลาเริ่ม · ระหว่างเปิด "Close Beta เปิดแล้ว! เหลือเวลาอีก" นับถึงเวลาจบ · หลังจบ ซ่อนตัวเลข ขึ้น "Close Beta จบแล้ว ขอบคุณทุกคนที่มาร่วมทดสอบ" · ใต้ตัวเลขบอกช่วงวันเวลา (คำนวณจากค่าที่ตั้ง)
- **ข่าว:** 4 ประกาศล่าสุดที่ไม่ได้ซ่อนจากตาราง `news` (อันเดียวกับปุ่ม "มีอะไรใหม่" ในเกม) หัวข้อ + 3 บรรทัดแรก · แสดงเป็นข้อความล้วน (ไม่ใช่ HTML) · ข้างกันเป็นแผง "เริ่มเล่นใน 1 นาที" + ปุ่มเข้าเกม (ไม่มีช่องเข้าสู่ระบบบนหน้านี้)
- **อาชีพ 3 ใบ** (ภาพหน้าโหลด sword/gunslinger/mage + พาสซีฟ) · **ชั้น 1–2** (ภาพ portal_1 / floor2_1 + 8 แมพพร้อมช่วงเลเวล) · **บอส 8 ตัว** (ภาพการ์ด) · **ระบบเด่น 8 ข้อ** · ปุ่มเข้าเกมท้ายหน้า · ท้ายหน้าลิงก์ privacy/terms
- ทุกปุ่ม "เข้าเกม" ไปที่ `https://play.multiverse-game.com`
- ข้อเท็จจริงบนหน้า (ชื่อแมพ เลเวล บอส ระบบ) เอามาจาก `src/shared/data/` และไฟล์ระบบ ถ้าเกมเปลี่ยนให้แก้ข้อความใน `landing.html` + คำแปลใน `src/landing/main.ts`

## ภาษา

- ไทยเป็นหลัก ข้อความไทยอยู่ใน `landing.html` (`data-i18n="key"`) คำแปลอังกฤษอยู่ในตาราง `EN` ของ `src/landing/main.ts` (ไม่ใช้ระบบแปลของเกม หน้าเบา) · ไม่มีคำแปล = แสดงไทย
- ปุ่ม EN/TH สลับทันที และเขียนค่าเดียวกับเกม (localStorage `multiverse-lang`) → ถ้าหน้าอยู่โดเมนเดียวกับเกม เข้าเกมแล้วเป็นภาษาเดียวกัน · ครั้งแรกตามภาษาเบราว์เซอร์
- ข่าวจาก DB เป็นภาษาไทยเสมอ (ไม่แปล)
- สวิตช์ "ภาษาอังกฤษ" (แท็บปรับสมดุล) ปิด = หน้าเป็นไทยอย่างเดียว ซ่อนปุ่ม EN (ส่งมากับ `/api/landing` ช่อง `english`)

## เวลาและข่าวจาก server

- `GET /api/landing` (ไม่ต้องล็อกอิน) → `{ start, end, news, english }` · `Access-Control-Allow-Origin: *` (ข้อมูลเดียวกับที่ Guest เห็นในเกม จึงเปิดให้หน้าอยู่โดเมนอื่นอ่านได้) · `Cache-Control: public, max-age=30`
- หน้าอยู่บน server เกม (`/landing`) = เรียก `/api/landing` ของตัวเอง · อยู่โฮสต์อื่นของ `multiverse-game.com` = เรียก `https://play.multiverse-game.com/api/landing`
- server ล่ม/เรียกไม่ได้ = ใช้ช่วงเวลาในโค้ด (`LANDING_DEFAULT`) และแผงข่าวขึ้น "โหลดข่าวไม่ได้ในตอนนี้ ดูประกาศล่าสุดได้ในเกมที่ปุ่ม 'มีอะไรใหม่'" (ต่างจาก "ยังไม่มีประกาศ" ที่ขึ้นเมื่อ server ตอบแต่ไม่มีข่าว)
- ทดสอบ 3 สถานะ: เติม `?now=2026-12-01T12:00:00Z` ท้ายลิงก์ (แกล้งให้นาฬิกาเป็นเวลานั้น เฉพาะเบราว์เซอร์นั้น)

## /admin (แท็บ "มีอะไรใหม่" การ์ด "หน้าแนะนำเกม (close beta)")

- เวลาเริ่ม · เวลาจบ (ช่องวันเวลา เวลาไทย) · สวิตช์ "แสดง 4 ประกาศล่าสุดบนหน้าแนะนำเกม" (ค่าในโค้ด เปิด)
- ดู = สิทธิ์ `news` (owner + GM) · แก้ = `newsEdit` (owner) ใช้สิทธิ์เดียวกับประกาศ ปรับต่อ role ได้ในแท็บสิทธิ์
- server ตรวจ: เวลาเป็นตัวเลขระหว่างปี 2024–2100 · จบต้องหลังเริ่ม · สวิตช์เป็น true/false · ผิด = 400
- เก็บใน `settings` key `landing` เฉพาะค่าที่ต่างจากโค้ด · ลง `admin_audit` action `landing` (เฉพาะเมื่อค่าเปลี่ยน) · หน้าใช้ค่าใหม่ภายใน ~30 วินาที (cache)

## ภาพ

- ใช้ภาพของเกมทั้งหมด (ไม่มีภาพสต็อก) · PNG ใน `landing.html` ถูกเปลี่ยนเป็น WebP ตอน build (`tools/vite-sprites-webp.ts`) เช่น login_bg 3.6 MB → ~430 KB · ภาพนอกจอแรกโหลดแบบ lazy
- **ยังไม่มี (เว้นไว้ได้):** ภาพ key art แนวนอนสำหรับหน้าแรกโดยเฉพาะ (ตอนนี้ใช้ภาพหน้า login) · ภาพหน้าแรกขนาดเล็กสำหรับมือถือ · ภาพ og สำหรับแชร์ลิงก์หน้านี้ (ตอนนี้ใช้ og-image-2.jpg ของเกม) · ภาพแผนที่/ภาพในเกมจริง (screenshot) · วิดีโอตัวอย่าง
