# หีบสมบัติ + ศาลเจ้า (แมพฟาร์มชั้น 1)

เจ้าของตกลง 2026-11-27 ("ใช้ตามที่เสนอ") · ให้รางวัลคนที่เดินสำรวจแมพเอง · ตัวเลขทุกค่าด้านล่างเป็นค่าในโค้ด ปรับได้ใน `/admin`

## กติกาที่ตกลงแล้ว

- **วางได้เฉพาะแมพฟาร์มชั้น 1** (ป่ามรกต หนองน้ำหมอก ดินแดนหิมะ เกาะภูเขาไฟ, `TREASURE_MAP_IDS` ใน `src/shared/mapSchema.ts`) · แมพอื่นรวมแมพสร้างเอง `validateMap` ไม่ให้ผ่าน
- ค่าเริ่ม: **หีบ 4 ใบ ศาล 2 แห่งต่อแมพ** (`FARM_TREASURE` ใน `zones.ts` อบลงไฟล์แมพแล้ว) เจ้าของย้าย/เพิ่ม/ลบเองในตัวแก้แมพ ได้ไม่เกิน 30 อย่างละแมพ
- **หีบ:** ยืนกดเปิด **1.5 วิ** (มีหลอด) ถ้าเดิน ตี ใช้สกิล แดช โดนตี โดนสตัน ตาย หรือเปิด Auto ระหว่างนั้น = หยุด · **คนแรกที่เปิดเสร็จได้ของ** แล้วหีบหายไป **เกิดใหม่ที่เดิมใน 10 นาที** (ใครเปิดไม่ทันขึ้นว่า "มีคนเปิดหีบนี้ไปก่อนแล้ว")
  - ได้ **ทองทุกหีบ** = 50 × เลเวลกลางของแมพ ±30% (ป่ามรกต ~275 G, เกาะภูเขาไฟ ~1,775 G) **บวกสุ่ม 1 แถว** จากตารางด้านล่าง
  - ของเข้ากระเป๋าเลย · กระเป๋าเต็ม = ของตกที่หีบ **เก็บได้เฉพาะคนเปิด** ตลอดเวลาที่อยู่บนพื้น (30 วิ แล้วหาย เหมือนของดรอปทั่วไป)
  - อุปกรณ์สุ่มตามเลเวลของคนเปิด (ไม่ออกนอกช่วงเลเวลของแมพ) และอาชีพของคนเปิด · ใบคูณดรอปไม่มีผล
  - หีบนับแยกต่อแชนแนล · หีบที่ถูกเปิดถูกจำไว้ที่ server ไม่ใช่ใน Sim: แชนแนลว่างปิดแล้วเปิดใหม่ หีบยังหายอยู่ (ย้าย CH ไปมาไม่ได้หีบใหม่) นับเวลาด้วยนาฬิกาจริง · รีสตาร์ท server = หีบกลับมาครบ
- **ศาลเจ้า:** แตะ (กด T / แตะบนจอสัมผัส / คลิก) ได้บัฟ 1 อย่างนาน **3 นาที** · ใช้ศาลเดิมซ้ำได้อีกใน **10 นาที ต่อคน ต่อศาล** (คนอื่นใช้ศาลเดียวกันได้)
  - บัฟ 3 แบบ: **พลังโจมตี +15%** (คูณพลังโจมตีรวม) · **ความเร็วเคลื่อนที่ +20%** (อยู่นอกเพดานความเร็วของไอเทม แบบเดียวกับบัฟสกิล) · **EXP +30%** (คูณหลังใบคูณ EXP ก่อน VIP)
  - ตั้งต่อศาลในตัวแก้แมพว่าให้บัฟไหน หรือ **"สุ่ม 1 ใน 3"** ทุกครั้งที่แตะ
  - ต่างชนิดซ้อนกันได้ · ชนิดเดียวกันจากอีกศาล = เริ่มนับ 3 นาทีใหม่ · **ตายแล้วบัฟหาย** · คูลดาวน์ไม่หายเมื่อตาย
  - บัฟและคูลดาวน์ไม่เซฟลงตัวละคร แต่ติดตัวข้ามแมพ/แชนแนล และ server จำไว้ตอนออกเกม (ไม่เกิน 24 ชม.) เข้าใหม่นับต่อ หักเวลาที่ออกไป · รีสตาร์ท server = เริ่มใหม่
  - HUD: ป้ายบัฟแถวเดียวกับใบคูณ (ATK/ความเร็ว แยกป้าย · EXP รวมในป้าย "EXP +x%" เมื่อสวิตช์ `buffTotal` เปิด)
- **Auto Play ไม่เปิดหีบ ไม่ใช้ศาล** (server ปฏิเสธ `p.autoOn` · เบราว์เซอร์ไม่ขึ้นข้อความชวนกดระหว่าง Auto)
- **Guest ใช้ได้ทั้งสองอย่าง**
- server ตัดสินทุกอย่าง: action `chest` / `shrine` + id → `Sim.startChest` / `Sim.useShrine` ตรวจสวิตช์ มีชีวิต ไม่ใช่ Auto ระยะ (2.5 หน่วย) หีบยังอยู่ คูลดาวน์

## ตารางของในหีบ (ค่าในโค้ด, `CHEST_ROWS` ใน `src/shared/treasure.ts`)

| ของ | โอกาส |
|---|---|
| อุปกรณ์เขียว | 30% |
| อุปกรณ์ฟ้า | 15% |
| อุปกรณ์ม่วง | 3% |
| อุปกรณ์ส้ม | 0.5% |
| หินสุ่มค่า | 6% |
| หินสุ่มสเตตัส | 6% |
| หินตีบวก | 3% |
| หินกันระดับลด | 2% |
| กล่องปริศนา | 2% |
| กุญแจบอสของแมพนั้น | 1% |
| ยา HP กลาง ×3 / ยา MP กลาง ×3 / ม้วนคัมภีร์กลับเมือง | แบ่งที่เหลือ (31.5%) เท่ากัน = 10.5% |

แถวที่ไม่ตั้ง % แบ่งส่วนที่เหลือเท่า ๆ กัน (แบบกล่องปริศนา) · แมพที่ไม่มีบอส แถวกุญแจไม่ออก ส่วนของมันไปแถวที่แบ่งที่เหลือ

## /admin

แท็บ **"แมพ"** (สิทธิ์ `balance` เหมือนการ์ดมินิเกมระลอก):
- **ตัวแก้แมพ** เครื่องมือ 📍 "NPC / ประตู": ปุ่ม "＋ เพิ่มหีบสมบัติ" / "＋ เพิ่มศาลเจ้า" (เห็นเฉพาะแมพฟาร์มชั้น 1) · หมุดส้ม = หีบ หมุดชมพู = ศาล ลากย้าย · Delete ลบ · ศาลเลือกบัฟที่ช่องขวา (พลังโจมตี/ความเร็ว/EXP/สุ่ม) · เผยแพร่ตามขั้นตอนแมพปกติ ([map-editor.md](map-editor.md)) สิทธิ์ `mapEdit`
- **การ์ด "หีบสมบัติ + ศาลเจ้า"**: สวิตช์เปิด/ปิดหีบ และศาล · เวลาเกิดใหม่ เวลายืนเปิด ระยะกด ทองต่อเลเวล ทองแกว่ง ± เวลาบัฟ คูลดาวน์ศาล % บัฟ 3 แบบ · ตารางของในหีบ (เปิด/ปิด % จำนวน รายแถว + โอกาสจริงขณะพิมพ์ รวมเกิน 100% บันทึกไม่ได้)
- เก็บใน `BalanceTuning.treasure` เฉพาะค่าที่ต่างจากโค้ด · ลง `admin_audit` ผ่าน audit ของแท็บปรับสมดุล · มีผลทันที (หีบที่เปิดไปแล้วนับเวลาเดิมจนกลับมา บัฟที่ได้ไปแล้วใช้ % เดิมจนหมด)

## เลย์เอาต์ที่เผยแพร่ก่อนมีระบบนี้

แมพฟาร์มที่เจ้าของเคยเผยแพร่ใน DB ก่อน 2026-11-27 ไม่มีฟิลด์ `chests`/`shrines` เลย → เกมและตัวแก้ใช้หีบ/ศาลจากไฟล์ที่มากับเกมให้ (`withBundledTreasure` ใน `mapRegistry.ts`) · ถ้าเจ้าของลบหมด (รายการว่าง) = ไม่มีจริง
