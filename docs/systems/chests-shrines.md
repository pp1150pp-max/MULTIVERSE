# หีบสมบัติ (แมพฟาร์มชั้น 1–2) + ศาลเจ้า (ชั้น 1)

เจ้าของตกลง 2026-11-27 ("ใช้ตามที่เสนอ") · ให้รางวัลคนที่เดินสำรวจแมพเอง · ตัวเลขทุกค่าด้านล่างเป็นค่าในโค้ด ปรับได้ใน `/admin`

## กติกาที่ตกลงแล้ว

- **หีบ: แมพฟาร์มชั้น 1 และ 2 ทั้ง 8 แมพ** (`CHEST_MAP_IDS` ใน `src/shared/mapSchema.ts`, ชั้น 2 เจ้าของเพิ่ม 2026-11-28 ใช้ค่าและตารางเดียวกับชั้น 1) · **ศาลเจ้า: ชั้น 1 เท่านั้น** (`SHRINE_MAP_IDS`) · แมพอื่นรวมแมพสร้างเอง `validateMap` ไม่ให้ผ่าน
- ค่าเริ่ม: **หีบ 4 ใบต่อแมพ ศาล 2 แห่งต่อแมพชั้น 1** (`FARM_TREASURE` ใน `zones.ts` อบลงไฟล์แมพแล้ว) เจ้าของเพิ่ม/ลบ (และย้ายศาล) เองในตัวแก้แมพ ได้ไม่เกิน 30 อย่างละแมพ
- **หีบเกิดจุดสุ่มใหม่ทุกครั้ง ทั่วทั้งแมพ** (เจ้าของ 2026-11-28, `src/shared/chestSpots.ts`): ตอนเกิดครั้งแรกและทุกครั้งที่เกิดใหม่หลังถูกเปิด · จำนวนหมุดหีบในแมพ = จำนวนหีบ
  - **ไม่เกิด:** ในน้ำวน (รวมเกาะกลาง) ทะเลสาบน้ำแข็ง **แอ่งน้ำที่วาดบนพื้น** (หนองน้ำหมอกและแมพชั้น 2, `src/shared/groundPools.ts` ที่ server กับ browser ใช้ร่วมกัน) แอ่งน้ำทะเล (ของวาง `tide_pool`) ลาวา (เผื่อขอบ 2 หน่วย) บนของกีดขวาง (ต้องมีที่โล่งรัศมี 1.2) ติดขอบแมพ (4 หน่วย) เขตปลอดภัยของเมือง และ**ที่เดินจากจุดเริ่มไปไม่ถึง**
  - **ระยะห่าง** (ปรับใน /admin, ค่าในโค้ด): หีบอื่นและจุดเดิมของตัวเอง 30 · จุดเริ่ม/จุดพัก 25 · ประตู/วงวาร์ป 12 · จุดเรียกบอส 16 · แมพแคบจนไม่มีจุดผ่าน ลดระยะลงครึ่งหนึ่งไปเรื่อย ๆ (ข้อ "ไม่เกิด" ด้านบนไม่ลด)
  - ปิดสวิตช์ "สุ่มจุด" (`randomSpots`) = หีบอยู่ที่หมุดในตัวแก้แมพเหมือนเดิม
  - จุดเก็บต่อ CH ที่ server เหมือนหีบที่ถูกเปิด (ย้าย CH ไปมา/ห้องว่างเปิดใหม่ จุดไม่เปลี่ยน) · รีสตาร์ท server หรือเผยแพร่ผังที่เปลี่ยนไป = สุ่มใหม่
  - server ค้นจุดที่วางหีบได้ทุกแมพตอนเปิดเครื่อง (ราว 1 วิ) หลังเผยแพร่ผังใหม่ค้นเฉพาะแมพที่เปลี่ยนตอนมีคนเข้าครั้งแรก
  - browser รู้เฉพาะหีบที่อยู่ใกล้ (`INTEREST_RADIUS`) และยังไม่ถูกเปิด (snapshot `chests` ส่งเฉพาะตอนเปลี่ยน)
- **หีบ:** ยืนกดเปิด **1.5 วิ** (มีหลอด) ถ้าเดิน ตี ใช้สกิล แดช โดนตี โดนสตัน ตาย หรือเปิด Auto ระหว่างนั้น = หยุด · **คนแรกที่เปิดเสร็จได้ของ** แล้วหีบหายไป **เกิดใหม่ที่จุดสุ่มใหม่ใน 10 นาที** (ใครเปิดไม่ทันขึ้นว่า "มีคนเปิดหีบนี้ไปก่อนแล้ว")
  - ได้ **ทองทุกหีบ** = 50 × เลเวลกลางของแมพ ±30% (ป่ามรกต ~275 G, เกาะภูเขาไฟ ~1,775 G) เข้ากระเป๋าเลย
  - **บวกของ 10 ชิ้น** (เจ้าของ 2026-11-27): **อุปกรณ์ม่วงแน่นอน 1 ชิ้น** (นับรวมใน 10) อีก 9 ชิ้นสุ่มจากตารางด้านล่างทีละชิ้น **ออกซ้ำได้**
  - ของทั้ง 10 ชิ้น **ตกพื้นรอบหีบทั้งหมด** (ไม่เข้ากระเป๋าเอง) **เก็บได้เฉพาะคนเปิด** ตลอดเวลาที่อยู่บนพื้น (30 วิ แล้วหาย เหมือนของดรอปทั่วไป)
  - อุปกรณ์สุ่มตามเลเวลของคนเปิด (ไม่ออกนอกช่วงเลเวลของแมพ) และอาชีพของคนเปิด · ใบคูณดรอปไม่มีผล
  - หีบนับแยกต่อแชนแนล · หีบที่ถูกเปิดถูกจำไว้ที่ server ไม่ใช่ใน Sim: แชนแนลว่างปิดแล้วเปิดใหม่ หีบยังหายอยู่ (ย้าย CH ไปมาไม่ได้หีบใหม่) นับเวลาด้วยนาฬิกาจริง · รีสตาร์ท server = หีบกลับมาครบ
- **ศาลเจ้า:** แตะ (กด T / แตะบนจอสัมผัส / คลิก) ได้บัฟ 1 อย่างนาน **3 นาที** · ใช้ศาลเดิมซ้ำได้อีกใน **10 นาที ต่อคน ต่อศาล** (คนอื่นใช้ศาลเดียวกันได้)
  - บัฟ 3 แบบ: **พลังโจมตี +15%** (คูณพลังโจมตีรวม) · **ความเร็วเคลื่อนที่ +20%** (อยู่นอกเพดานความเร็วของไอเทม แบบเดียวกับบัฟสกิล) · **EXP +30%** (คูณหลังใบคูณ EXP ก่อน VIP)
  - ตั้งต่อศาลในตัวแก้แมพว่าให้บัฟไหน หรือ **"สุ่ม 1 ใน 3"** ทุกครั้งที่แตะ
  - ต่างชนิดซ้อนกันได้ · ชนิดเดียวกันจากอีกศาล = เริ่มนับ 3 นาทีใหม่ · **ตายแล้วบัฟหาย** · คูลดาวน์ไม่หายเมื่อตาย
  - บัฟและคูลดาวน์ไม่เซฟลงตัวละคร แต่ติดตัวข้ามแมพ/แชนแนล และ server จำไว้ตอนออกเกม (ไม่เกิน 24 ชม.) เข้าใหม่นับต่อ หักเวลาที่ออกไป · รีสตาร์ท server = เริ่มใหม่
  - HUD: ป้ายบัฟแถวเดียวกับใบคูณ (ATK/ความเร็ว แยกป้าย · EXP รวมในป้าย "EXP +x%" เมื่อสวิตช์ `buffTotal` เปิด)
- **Auto Play ไม่เปิดหีบ ไม่ใช้ศาล** (server ปฏิเสธ `p.autoOn` · เบราว์เซอร์ไม่ขึ้นข้อความชวนกดระหว่าง Auto)
- **Guest ใช้ได้ทั้งสองอย่าง**
- server ตัดสินทุกอย่าง: action `chest` / `shrine` + id → `Sim.startChest` / `Sim.useShrine` ตรวจสวิตช์ มีชีวิต ไม่ใช่ Auto ระยะ (2.5 หน่วย) หีบยังอยู่ คูลดาวน์

## ตารางของในหีบ (ค่าในโค้ด, `CHEST_ROWS` ใน `src/shared/treasure.ts`)

| ของ | โอกาส |
|---|---|
| อุปกรณ์เขียว | 30% |
| อุปกรณ์ฟ้า | 15% |
| อุปกรณ์ม่วง | 15% |
| อุปกรณ์ส้ม | 5% |
| หินสุ่มค่า | 6% |

โอกาสเหล่านี้ใช้กับแต่ละชิ้นที่สุ่ม (9 ชิ้น) ไม่รวมชิ้นม่วงแน่นอน · แถวที่ไม่ตั้ง % แบ่งส่วนที่เหลือเท่า ๆ กัน (แบบกล่องปริศนา) · แมพที่ไม่มีบอส แถวกุญแจไม่ออก ส่วนของมันไปแถวที่แบ่งที่เหลือ

## /admin

แท็บ **"แมพ"** (สิทธิ์ `balance` เหมือนการ์ดมินิเกมระลอก):
- **ตัวแก้แมพ** เครื่องมือ 📍 "NPC / ประตู": ปุ่ม "＋ เพิ่มหีบสมบัติ" / "＋ เพิ่มศาลเจ้า" (หีบ: แมพฟาร์มชั้น 1–2 · ศาล: ชั้น 1) · หมุดหีบกำหนดจำนวน ตำแหน่งใช้เมื่อปิดสุ่มจุด · หมุดส้ม = หีบ หมุดชมพู = ศาล ลากย้าย · Delete ลบ · ศาลเลือกบัฟที่ช่องขวา (พลังโจมตี/ความเร็ว/EXP/สุ่ม) · เผยแพร่ตามขั้นตอนแมพปกติ ([map-editor.md](map-editor.md)) สิทธิ์ `mapEdit`
- **การ์ด "หีบสมบัติ + ศาลเจ้า"**: สวิตช์เปิด/ปิดหีบ ศาล ออร่า และสุ่มจุดเกิดหีบ · ระยะสุ่มจุด 4 ค่า · เวลาเกิดใหม่ เวลายืนเปิด ระยะกด ทองต่อเลเวล ทองแกว่ง ± · ของต่อหีบ (ค่าเริ่ม 10) · ม่วงแน่นอน (ค่าเริ่ม 1, ไม่เกินของต่อหีบ) เวลาบัฟ คูลดาวน์ศาล % บัฟ 3 แบบ · ตารางของในหีบ (เปิด/ปิด % จำนวน รายแถว + โอกาสจริงขณะพิมพ์ รวมเกิน 100% บันทึกไม่ได้)
- เก็บใน `BalanceTuning.treasure` เฉพาะค่าที่ต่างจากโค้ด · ลง `admin_audit` ผ่าน audit ของแท็บปรับสมดุล · มีผลทันที (หีบที่เปิดไปแล้วนับเวลาเดิมจนกลับมา บัฟที่ได้ไปแล้วใช้ % เดิมจนหมด)
