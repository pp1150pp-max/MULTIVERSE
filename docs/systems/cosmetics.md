## ค่าการวางและหน้าตาของแต่ละชิ้น (เจ้าของตั้ง 2026-11-10)

- ทุกชิ้นของ ปีก / สัตว์ขี่ / สัตว์เลี้ยง / ออร่า มีค่าปรับ**แยกรายชิ้น** (`COS_TUNE_FIELDS` ใน `src/shared/cosTuning.ts`) ค่าในโค้ดอยู่ที่ `cosTuneDefaults()`
  - ปีก: ขนาด `h` (1.625 = ใหญ่กว่าเดิม 25%, #197) · โคนปีกอยู่ที่ `root` (0.6) ของความสูงภาพ วางที่กลางหลัง: สูง `backStand` (1.35) ตอนยืน / `backSeat` (1.0 จากอาน) ตอนขี่ (#200) · ถอยไปข้างหลัง `back` (0.22) · ขยับซ้าย/ขวาบนจอ `shift` (0, บวก = ขวาของจอ ทุกทิศ ตอนหันซ้ายกลับด้านเองตามภาพ, 2026-11-11 · มีทั้งปีก สัตว์ขี่ และออร่า) · วาดหลังตัวห่าง `depth` (0.15) แต่ทับหลังเมื่อหันหลังให้กล้อง ถ้าเปิด `overBack` (#200) · ความเร็วกระพือตอนยืน `flap` / ตอนเดิน `flapWalk`

  - สัตว์เลี้ยง: ขนาด `h` · ระยะตามหลัง `back` · ระยะด้านข้าง `side` · บิน `fly` · ความสูงลอย `float` · ระยะลอยขึ้นลง `bob` · ความเร็วขยับ `anim`
  - ออร่า: ขนาดวง `size` · ความสว่าง `alpha` · ระยะเต้น `pulse` · ประกายต่อวินาที `sparks` · ขนาดประกาย `sparkSize` · รอยเท้าทุก ๆ `stepEvery` วินาที · ขนาดรอยเท้า `stepSize`
  - กรอบชื่อ/ฟองแชทไม่มีค่าปรับ (เป็นข้อความบนหน้าจอ ไม่ใช่ภาพ 3D)
  - ป้ายชื่อขยับตามความสูงที่นั่งของสัตว์ขี่ด้วย (`seatOf` ใน `src/client/cosmeticViews.ts`)
- **แท่นทดลอง**: `/admin` แท็บ "ของแต่งตัว" (`src/client/cosPreview.ts` โหลดเมื่อเปิดแท็บเท่านั้น · ตอน `npm run dev` เปิดได้ที่ `/cosmetics.html` ด้วย แบบไม่มีปุ่มของเซิร์ฟ ไม่ถูก build ไปกับเกม) สวิตช์ `cosPreview` ใน `FEATURE_ROLES` (owner และ GM)
  - เลือกอาชีพ เลือกของทีละช่อง (หรือไม่ใส่) ขี่/ลง หันตัวครบ 8 ทิศ (ปุ่มกลาง = หมุนเองทีละทิศ) เดินเป็นวง เดิน WASD/คลิกพื้น ตาย/ฟื้น ซูมกล้อง
  - สไลเดอร์ของแต่ละชิ้นที่สวมอยู่ เปลี่ยนแล้วเห็นทันที · ตัวเลขสีฟ้า = ต่างจากค่าที่บันทึกไว้ล่าสุด
  - **ปรับตำแหน่งเป็นแกน X/Y/Z (เจ้าของตกลง 2026-11-11)** X = ซ้าย/ขวาของตัวละคร (+ = ขวา) · Y = ขึ้น/ลง · Z = หน้า(+)/หลัง หมุนตามทิศที่ตัวละครหัน (`COS_AXES` ใน `cosTuning.ts`)
    - แกนอ่านจากค่าเดิมโดยไม่เปลี่ยนชื่อ จึงใช้เซฟเก่าได้ตรง ๆ ตำแหน่งไม่กระโดด: ปีก X=`shift` · Y ตอนยืน=`backStand` · Y ตอนขี่=`backSeat` (ยังแยก 2 ค่า) · Z=−`back` / สัตว์ขี่ X=`shift` Y=`seat` Z=`z` (ใหม่ ค่าเริ่ม 0) / สัตว์เลี้ยง X=−`side` Y=`float` Z=−`back` / ออร่า X=`shift` · **ข้อควรรู้:** ค่าหลัก X ของ ปีก/สัตว์ขี่/ออร่า ยังเป็น "ซ้าย/ขวาบนจอ" แบบเดิม (กลับด้านเองตามภาพตอนหันซ้าย) ไม่ใช่หมุนตามตัวเพื่อให้เซฟเก่าไม่ขยับ ส่วนปรับของแต่ละมุมเป็นแกนของตัวละครจริง
    - **ซ่อนตามชนิด:** ออร่ามีแต่ X · สัตว์เลี้ยงที่เดินพื้น (`fly` ปิด) ไม่มี Y
    - **ซ่อนตามมุม:** เลือก "มุมที่ปรับตำแหน่ง" ได้ทุกมุม (ค่าหลัก) หรือ 1 ใน **8 ทิศ** (หน้า · เฉียงหน้าขวา · ขวา · เฉียงหลังขวา · หลัง · เฉียงหลังซ้าย · ซ้าย · เฉียงหน้าซ้าย · เลือกแล้วตัวละครหันตามให้ · กดลูกศรหันตัวก็เลือกทิศนั้นให้ด้วย กลับไปปรับค่าหลักให้เลือก "ทุกมุม" ในช่องนี้) หน้า/หลังตรงซ่อน Z · ซ้าย/ขวาซ่อน X · ทิศเฉียงแสดงครบ X/Y/Z · เกมก็ไม่ใช้แกนที่ซ่อนในทิศนั้น "ซ้าย/ขวา" คือด้านของจอที่ตัวละครหันไปหา
    - **ค่าแยกตามทิศ (เจ้าของตกลง 2026-11-11 หลังเริ่มแยกแค่ 3 กลุ่มแล้วทับกัน):** "ค่าหลัก" ต่อแกน (ใช้ทุกทิศ) + "ส่วนปรับ" ของแต่ละทิศแยกกันครบ 8 ทิศ เก็บเป็นช่อง `d<x|y|z>_at_<ทิศ>` (`front` `frontRight` `right` `backRight` `back` `backLeft` `left` `frontLeft` ค่าเริ่ม 0) บวกเข้าค่าหลักเฉพาะทิศนั้น · ส่วนปรับเป็นแกนของตัวละคร (ขวา/ขึ้น/หน้า) หมุนตามที่หัน
    - **เซฟเก่าที่เคยเก็บเป็น 3 กลุ่ม** (`d<x|y|z>_front/side/back`) แปลงตอนอ่านโดย `checkCosTuning`: front → หน้า+เฉียงหน้าซ้าย+เฉียงหน้าขวา · side → ซ้าย+ขวา · back → หลัง+เฉียงหลังซ้าย+เฉียงหลังขวา (ค่าเดียวกันกับที่เคยใช้ ตำแหน่งบนจอไม่กระโดด · ทิศที่เซฟเองแล้วชนะค่าเก่า) เขียนกลับเป็นรูปแบบใหม่ตอนบันทึกครั้งถัดไป
  - **บันทึกแยกรายชิ้น/รายมุม (เจ้าของตกลง 2026-11-11)** ในกล่องของแต่ละชิ้นมีปุ่มตามที่เลือกใน "มุมที่ปรับตำแหน่ง": ทุกมุม = "บันทึก/คืนค่าหลัก" (ทุกช่องที่ไม่ใช่ส่วนปรับมุม) · เลือกทิศ = "บันทึก/คืนค่าทิศ…" (ส่วนปรับของทิศนั้นทิศเดียว ไม่กระทบทิศอื่น) เซฟ**เฉพาะชิ้นนั้น**กับเฉพาะส่วนนั้น ชิ้นอื่น/ทิศอื่น/ค่าอื่นของชิ้นเดิมคงตามที่บันทึกไว้ล่าสุด (`savePartOf` ใน `cosTuning.ts`) คืนค่าก็เฉพาะชิ้นกับส่วนนั้น · ปุ่ม "บันทึกเป็นค่าเริ่มต้นทั้งเซิร์ฟ" เดิมยังเซฟทุกชิ้นทุกค่า
  - ปุ่ม: คัดลอกค่า · **คืนค่าชิ้นนี้/ทุกชิ้นเป็นค่าที่บันทึกไว้ล่าสุดของเซิร์ฟ** (ไม่ใช่ค่าในโค้ด · ถ้ายังไม่เคยบันทึกก็คือค่าในโค้ด) · โหลดค่าของเซิร์ฟ · บันทึกเป็นค่าเริ่มต้นทั้งเซิร์ฟ · คืนค่าของเซิร์ฟเป็นค่าในโค้ด
  - ทดลองในแท็บไม่เปลี่ยนอะไรในเกม
- สองสวิตช์นี้ตั้งต่อ role ได้ในแท็บ "สิทธิ์" (`FEATURE_INFO`: "ทดลองของแต่งตัว" / "บันทึกของแต่งตัวทั้งเซิร์ฟ") ค่าเริ่มต้นตามด้านล่าง
- **บันทึกเป็นค่าเริ่มต้นทั้งเซิร์ฟ** ค่าเริ่มต้นได้**เฉพาะเจ้าของ** (สวิตช์ `cosLook`) · ถามยืนยันก่อนบันทึก · GM ทดลองได้แต่บันทึกไม่ได้
  - API `GET /api/admin/cos-look` (`cosPreview`) · `POST /api/admin/cos-look` `{ tuning }` หรือ `{ reset: true }` (`cosLook`)
  - เก็บในตาราง `settings` key `cos_tuning` **เฉพาะค่าที่ต่างจากในโค้ด** (id ของแต่งตัว → ค่าที่เปลี่ยน) ไม่มีแถว = ใช้ค่าในโค้ดทั้งหมด (DB เก่าใช้ได้เลย) · ของชิ้นใหม่ที่เพิ่มทีหลังใช้ค่าในโค้ดของมันเอง
  - server ตรวจทุกค่าตอนบันทึก (`checkCosTuning` แบบเข้ม): ต้องเป็นของที่มีจริง (ไม่ใช่กรอบชื่อ) ชื่อค่าต้องตรงช่อง ตัวเลขอยู่ในช่วงของสไลเดอร์ เปิด/ปิดต้องเป็น true/false ผิด = 400 · ปัดทศนิยม 3 ตำแหน่ง
  - ตอนอ่านจาก DB ตรวจแบบผ่อน: ของ/ค่าที่โค้ดไม่รู้จักแล้วถูกทิ้ง ที่เหลือใช้ต่อ
  - ส่งให้ browser ตอนเข้าเกม (`welcome.cosTuning`) และส่งให้ทุกคนที่ออนไลน์ทันทีเมื่อเปลี่ยน (`{ t: 'cosTuning' }`) · หน้าต่าง "แต่งตัว" ในเกม (รวมตอนลองสวม) ใช้ค่าชุดเดียวกัน
  - ลง `admin_audit` (action `cos-look`) ว่าเปลี่ยนค่าไหนจากเท่าไรเป็นเท่าไร เช่น `wings_angel.lift 0.8 → 0.9` (บันทึกค่าเดิมซ้ำไม่ลง)

## หน้าจัดการของแต่งตัว: ซ่อน/แสดง ราคาเพชร วางค่าหลายชิ้น (เจ้าของตกลง 2026-11-13)

- `/admin` หมวด "หน้าตา" แท็บ **"จัดการของแต่งตัว"** (`src/admin/cosManage.ts`) · ทุกชิ้นทุกช่อง (รวมกรอบชื่อ/ฟองแชท)
- หมายเหตุ: ผู้เล่นสวมได้เฉพาะชิ้นที่บัญชี "มี" (admin ให้ในหน้าบัญชี ตาราง `account_cosmetics`) แท็บ "ร้าน" ในหน้าต่าง "แต่งตัว" แค่ลองสวม
- **สิทธิ์**: ดูแท็บ = สวิตช์ `cosManage` (owner+GM) · บันทึกซ่อน/ราคา = `cosManageEdit` (owner) · บันทึกค่าที่วาง = `cosLook` เดิม (owner) · ตั้งต่อ role ได้ในแท็บ "สิทธิ์"
- **ซ่อน/แสดงรายชิ้น** (ค่าในโค้ด = แสดงทุกชิ้น)
  - ชิ้นที่ซ่อนไม่โชว์ในหน้าต่าง "แต่งตัว" ทั้งแท็บ "ร้าน" และ "ของฉัน" (ที่กำลังลองสวมอยู่ถูกถอดออก) และสวมใหม่ไม่ได้
  - คนที่สวมอยู่แล้วใส่ต่อได้ คนอื่นยังเห็น · ใน "ของฉัน" เห็นชิ้นนั้นเฉพาะตอนสวมอยู่ (ป้าย "ปิดชั่วคราว ถอดแล้วสวมใหม่ไม่ได้") ถอดได้ ถอดแล้วหาย สวมกลับไม่ได้จนกว่าจะแสดงกลับ
  - server ตรวจใน `wearCosmetic` (`server/world.ts`, กติกา `mayPutOnCos` ใน `src/shared/cosShop.ts`) ไม่เชื่อ client · ไม่มีใครถูกถอดของเพราะการซ่อน
  - admin ยังให้ชิ้นที่ซ่อนแก่บัญชีได้ (หน้าบัญชีมีป้าย "ซ่อนอยู่") ผู้เล่นได้ไปเก็บไว้ สวมได้เมื่อแสดงกลับ
  - มีผลทันที: ส่งรายการ id ที่ซ่อนตอนเข้าเกม (`welcome.cosHidden`) และให้ทุกคนที่ออนไลน์เมื่อเปลี่ยน (`{ t: 'cosHidden', ids }`) · ไม่ส่งราคาให้ผู้เล่น
- **ราคาเพชรรายชิ้น (ยังไม่ขาย)** จำนวนเต็ม 1–1,000,000 (`COS_PRICE_MIN/MAX`) เว้นว่าง = ยังไม่ตั้งราคา (ค่าในโค้ด) ไม่มีราคา 0 · เก็บและแสดงในหน้า admin เท่านั้น ยังไม่มีเงินเพชร ไม่มีระบบเติม/ซื้อ ผู้เล่นไม่เห็นราคา · ร้านค้าในอนาคตอ่านด้วย `cosPrice()`
- ที่เก็บ: ตาราง `settings` key `cos_shop` **เฉพาะชิ้นที่ต่างจากโค้ด** (`{ id: { hidden?: true, price?: n } }`) ไม่มีแถว = แสดงทุกชิ้น ไม่มีราคา (DB เก่าใช้ได้เลย) · server ตรวจแบบเข้มตอนบันทึก (`checkCosShop`: ของต้องมีจริง ชื่อค่าต้องเป็น hidden/price ค่าถูกชนิด/ช่วง ผิด = 400) ตอนอ่านจาก DB ตรวจแบบผ่อน
  - API `GET /api/admin/cos-shop` (`cosManage`) คืน `{ shop, tuning, canEdit, canPaste }` · `POST /api/admin/cos-shop` `{ shop }` ทั้งชุด (`cosManageEdit`) · ถามยืนยันพร้อมรายการที่เปลี่ยนก่อนบันทึก
  - ลง `admin_audit` action `cos-shop` เช่น `wings_bat: ซ่อน, pet_cat: ราคา — → 500 เพชร` (บันทึกค่าเดิมซ้ำไม่ลง)
- **วางค่าจากแท่นทดลอง (แก้หลายชิ้นพร้อมกัน)**
  - ในแท่นทดลองปรับหลายชิ้น กด "คัดลอกค่าที่ตั้งไว้" แล้ววางในช่องของแท็บนี้ กด "ดูตัวอย่าง" = รายการชิ้นที่จะเปลี่ยน แต่ละค่า "ชื่อค่า: เดิม → ใหม่" ติ๊กออกเพื่อข้ามบางชิ้น แล้วกด "บันทึก n ชิ้นที่เลือก" (ถามยืนยัน)
  - ความหมายของข้อความ: ทุกชิ้นที่มีในข้อความใช้ค่าตามข้อความ (ค่าที่ไม่มีในข้อความ = ค่าในโค้ด) · ชิ้นที่ไม่มีในข้อความไม่ถูกแตะ (`pasteCosTuning` ใน `cosTuning.ts`)
  - ปุ่มคัดลอกตอนนี้ใส่**ทุกชิ้น** (ชิ้นที่เป็นค่าในโค้ดเป็น `{}`) เพื่อให้วางแล้วคืนชิ้นที่ถูกปรับกลับเป็นค่าในโค้ดได้ด้วย · ข้อความแบบเก่า (มีแค่ชิ้นที่เปลี่ยน) และแบบเก่ากว่า (ส่วนปรับ 3 กลุ่ม) ยังวางได้
  - ใช้ที่เก็บเดิม `cos_tuning` ตรวจแบบเข้มเดิม ส่งให้ทุกคนทันทีเดิม · server รวมค่าเอง: `POST /api/admin/cos-look` `{ paste, only?, base }` · ถ้าค่าของเซิร์ฟเปลี่ยนไปหลังดูตัวอย่าง (`base` ไม่ตรง) = 409 ให้กดโหลดใหม่ · audit `cos-look` ขึ้นต้น "วางค่า: "
- เทสต์: `tests/cos-look.test.ts` (ตรวจค่า ซ่อน/ราคา วางค่า สิทธิ์ audit ส่งให้ผู้เล่น) · `tests/cosmetics-server.test.ts` (ซ่อนแล้วคนที่สวมยังใส่อยู่ คนอื่นยังเห็น สวมใหม่ไม่ได้ ถอดแล้วสวมกลับไม่ได้ ให้ได้ แสดงกลับแล้วสวมได้)
