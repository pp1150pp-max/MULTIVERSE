# ของแต่งตัว (ปีก สัตว์ขี่ สัตว์เลี้ยง ออร่า กรอบชื่อ/ฟองแชท)

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · รายการของอยู่ที่ `src/shared/data/cosmetics.ts` · หน้าต่าง "แต่งตัว" ในเกมอยู่ที่ `src/client/cosmetics.ts`

## ค่าการวางและหน้าตาของแต่ละชิ้น (เจ้าของตั้ง 2026-11-10)

- ทุกชิ้นของ ปีก / สัตว์ขี่ / สัตว์เลี้ยง / ออร่า มีค่าปรับ**แยกรายชิ้น** (`COS_TUNE_FIELDS` ใน `src/shared/cosTuning.ts`) ค่าในโค้ดอยู่ที่ `cosTuneDefaults()`
  - ปีก: ขนาด `h` · ความสูงบนหลัง `lift` (0.8 วัดจากภาพ: ไหล่สูง ~1.35 จากเท้า, #195) · ถอยไปข้างหลัง `back` (0.22) · ระยะหน้า/หลังตัว `depth` · ความเร็วกระพือตอนยืน `flap` / ตอนเดิน `flapWalk`
  - สัตว์ขี่: ขนาด `h` · ความสูงที่นั่ง `seat` · ที่นั่งยกเพิ่มตอนหันหน้า/หลังเข้ากล้อง `headOnLift` · สัตว์ขี่อยู่หน้าผู้ขี่ตอนหันหน้า/หลัง `front` · อยู่หลังผู้ขี่ตอนหันข้าง/เฉียง `behind` · ท่ายืนบนบอร์ด `board` · ความเร็วขยับขา `anim`
  - สัตว์เลี้ยง: ขนาด `h` · ระยะตามหลัง `back` · ระยะด้านข้าง `side` · บิน `fly` · ความสูงลอย `float` · ระยะลอยขึ้นลง `bob` · ความเร็วขยับ `anim`
  - ออร่า: ขนาดวง `size` · ความสว่าง `alpha` · ระยะเต้น `pulse` · ประกายต่อวินาที `sparks` · ขนาดประกาย `sparkSize` · รอยเท้าทุก ๆ `stepEvery` วินาที · ขนาดรอยเท้า `stepSize`
  - กรอบชื่อ/ฟองแชทไม่มีค่าปรับ (เป็นข้อความบนหน้าจอ ไม่ใช่ภาพ 3D)
  - ป้ายชื่อขยับตามความสูงที่นั่งของสัตว์ขี่ด้วย (`seatOf` ใน `src/client/cosmeticViews.ts`)
- **แท่นทดลอง**: `/admin` แท็บ "ของแต่งตัว" (`src/client/cosPreview.ts` โหลดเมื่อเปิดแท็บเท่านั้น · ตอน `npm run dev` เปิดได้ที่ `/cosmetics.html` ด้วย แบบไม่มีปุ่มของเซิร์ฟ ไม่ถูก build ไปกับเกม) สวิตช์ `cosPreview` ใน `FEATURE_ROLES` (owner และ GM)
  - เลือกอาชีพ เลือกของทีละช่อง (หรือไม่ใส่) ขี่/ลง หันตัวครบ 8 ทิศ (ปุ่มกลาง = หมุนเองทีละทิศ) เดินเป็นวง เดิน WASD/คลิกพื้น ตาย/ฟื้น ซูมกล้อง
  - สไลเดอร์ของแต่ละชิ้นที่สวมอยู่ เปลี่ยนแล้วเห็นทันที · ตัวเลขสีฟ้า = ต่างจากค่าในโค้ด
  - ปุ่ม: คัดลอกค่า · คืนค่าชิ้นนี้/ทุกชิ้นเป็นค่าในโค้ด · โหลดค่าของเซิร์ฟ · บันทึกเป็นค่าเริ่มต้นทั้งเซิร์ฟ · คืนค่าของเซิร์ฟเป็นค่าในโค้ด
  - ทดลองในแท็บไม่เปลี่ยนอะไรในเกม
- **บันทึกเป็นค่าเริ่มต้นทั้งเซิร์ฟ** ได้**เฉพาะเจ้าของ** (สวิตช์ `cosLook`) · ถามยืนยันก่อนบันทึก · GM ทดลองได้แต่บันทึกไม่ได้
  - API `GET /api/admin/cos-look` (`cosPreview`) · `POST /api/admin/cos-look` `{ tuning }` หรือ `{ reset: true }` (`cosLook`)
  - เก็บในตาราง `settings` key `cos_tuning` **เฉพาะค่าที่ต่างจากในโค้ด** (id ของแต่งตัว → ค่าที่เปลี่ยน) ไม่มีแถว = ใช้ค่าในโค้ดทั้งหมด (DB เก่าใช้ได้เลย) · ของชิ้นใหม่ที่เพิ่มทีหลังใช้ค่าในโค้ดของมันเอง
  - server ตรวจทุกค่าตอนบันทึก (`checkCosTuning` แบบเข้ม): ต้องเป็นของที่มีจริง (ไม่ใช่กรอบชื่อ) ชื่อค่าต้องตรงช่อง ตัวเลขอยู่ในช่วงของสไลเดอร์ เปิด/ปิดต้องเป็น true/false ผิด = 400 · ปัดทศนิยม 2 ตำแหน่ง
  - ตอนอ่านจาก DB ตรวจแบบผ่อน: ของ/ค่าที่โค้ดไม่รู้จักแล้วถูกทิ้ง ที่เหลือใช้ต่อ
  - ส่งให้ browser ตอนเข้าเกม (`welcome.cosTuning`) และส่งให้ทุกคนที่ออนไลน์ทันทีเมื่อเปลี่ยน (`{ t: 'cosTuning' }`) · หน้าต่าง "แต่งตัว" ในเกม (รวมตอนลองสวม) ใช้ค่าชุดเดียวกัน
  - ลง `admin_audit` (action `cos-look`) ว่าเปลี่ยนค่าไหนจากเท่าไรเป็นเท่าไร เช่น `wings_angel.lift 0.8 → 0.9` (บันทึกค่าเดิมซ้ำไม่ลง)
- เทสต์: `tests/cos-look.test.ts`
