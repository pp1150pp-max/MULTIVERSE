# ลิงก์ไอเทมในแชท

กติกาในไฟล์นี้เจ้าของตกลงแล้ว (2026-11-23, choice cards) ข้อที่มี "(ตัดสินเอง)" = ผู้พัฒนาเลือกเอง เจ้าของอนุมัติในแผนแล้ว · ห้ามเปลี่ยนกติกาอื่นโดยไม่ถาม

## กติกา

- **Ctrl+คลิก** (Mac: ⌘+คลิก หรือ Ctrl+คลิก) ไอเทมใน **กระเป๋า · ชุดที่ใส่ · คลัง · ร้านพ่อค้า (แท็บซื้อ)** = ใส่ `[ชื่อไอเทม]` ลงช่องพิมพ์ตรงเคอร์เซอร์
  - แชทปิดอยู่ = เปิดให้เอง · **หน้าต่างโทรโข่งเปิดอยู่ = ใส่ในโทรโข่งแทน**
  - Ctrl+คลิกไม่ทำอย่างอื่น (ไม่สวม ไม่ใช้ ไม่ซื้อ ไม่ลาก ไม่ขาย) และช่องพิมพ์ไม่หลุดโฟกัส
  - ชื่อที่ใส่: อุปกรณ์ = ชื่อพร้อม +ตีบวก (`[+7 ดาบ…]`) · ยา/หิน = ชื่อชนิด ไม่มีจำนวน (ตัดสินเอง)
- ใช้ได้กับ **แชททั่วไป ปาร์ตี้ กระซิบ (`/w`, `/r`, แท็บกระซิบ) และโทรโข่ง**
- **ข้อความละไม่เกิน 3 ลิงก์** (`CHAT_LINK_MAX`) · ใส่แล้วยาวเกินช่อง (แชท 120 / โทรโข่ง 100 ตัว) = ใส่ไม่ได้ ขึ้นข้อความเตือน · ลบชื่อออกจากช่องพิมพ์ = ลิงก์นั้นหาย
- คนที่เห็นข้อความ: ชื่อไอเทม **เป็นสีตามความหายาก** (ยา/หินใช้สีของชนิด) **คลิก = หน้าต่างป๊อปอัป "ข้อมูลไอเทม"** แบบเดียวกับ tooltip (ค่าสเตตัส tier +ตีบวก) ค้างจนกดปิด/Esc ลากได้ ใช้บนมือถือได้
  - ข้อมูลคือ **ของชิ้นนั้นตอนส่ง** (สำเนา ไม่อัปเดตตาม) · ของจากร้านพ่อค้า = ของชนิดนั้น 1 ชิ้น
  - อุปกรณ์เทียบกับของที่ **คนดู** ใส่อยู่ (ตัวเลขเขียว/แดง เหมือน tooltip ในกระเป๋า) (ตัดสินเอง)
  - คลิกได้ทั้งตอนแชทเปิด (ประวัติ) และตอนปิด (บรรทัดที่ยังไม่จาง) และบนป้ายโทรโข่ง
- ฟองคำพูดเหนือหัว และ log แชทใน /admin เห็นเป็นข้อความธรรมดา `[ชื่อไอเทม]`
- **สวิตช์ใน /admin** แท็บปรับสมดุล การ์ด Auto Play ("ลิงก์ไอเทมในแชท", `BalanceTuning.chatLinks`, ค่าในโค้ดเปิด) · ปิด = server ไม่ส่งลิงก์ (ชื่อเป็นข้อความธรรมดา) และ Ctrl+คลิกไม่ทำอะไร

## ความปลอดภัย (server ตัดสิน: `src/shared/chatLinks.ts`, `server/world.ts` `chatLinks()`)

- เบราว์เซอร์ส่งแค่ **ตำแหน่ง** ของไอเทม: `{bag:i}` `{stash:i}` `{slot}` หรือ `{shop:'hp:s'…|'phoenix'|'return_scroll'}` ไม่ส่งข้อมูลไอเทม
- server หาของจริงในกระเป๋า/คลัง/ชุดของ **ผู้ส่งเอง** แล้วถ่ายสำเนา (ตัด `uid` `pity` `tierK` `mulK`) · ร้านพ่อค้ารับเฉพาะของที่ขายจริง
- ลิงก์ถูกเก็บก็ต่อเมื่อ `[ชื่อ]` ที่ server สร้างเองอยู่ในข้อความ (หลังตัดอักขระควบคุมและตัดความยาวแล้ว) ตามลำดับ ไม่ซ้อนกัน · ไม่เจอ/ช่องว่าง/ref ผิดรูป = ทิ้งลิงก์นั้น (ข้อความยังส่ง)
- ผู้รับวาดข้อความด้วย `textContent` ทั้งหมด (ไม่มี HTML จากผู้เล่น) และตรวจตำแหน่งลิงก์ซ้ำ (`validLinks`)

## ข้อความ (`src/shared/net/protocol.ts`)

- client → server: `chat` และ `act: 'megaphone'` มี `links?: ChatLinkRef[]`
- server → client: `chat` และ `announce` (โทรโข่ง) มี `links?: { at, len, entry }[]` (`at`/`len` = ตำแหน่ง `[ชื่อ]` ในข้อความ)

## ยังไม่มี

- มือถือกด Ctrl ไม่ได้: ยังไม่มีปุ่ม "ลิงก์ในแชท" ในหน้ารายละเอียดไอเทมของมือถือ (ทำต่อได้ถ้าเจ้าของต้องการ)
- ช่องอื่นที่มีไอเทม (ช่างตีเหล็ก เทรด ตลาด ซื้อคืน) ยังไม่รองรับ Ctrl+คลิก
