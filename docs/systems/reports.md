# แจ้งปัญหา / ข้อเสนอแนะ (รายงานจากผู้เล่น)

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · หน้า admin: [accounts-and-admin.md](accounts-and-admin.md)
เจ้าของตกลงกติกาและตัวเลขทั้งหมดไว้เมื่อ 2026-11-10 (เพดานต่อ IP และทั้งเซิร์ฟเสนอและอนุมัติพร้อมแผน) ห้ามเปลี่ยนโดยไม่ถามเจ้าของ

## ฝั่งผู้เล่น

- ปุ่ม **แจ้งปัญหา** ในเมนูระบบ (`src/client/sysmenu.ts`) เปิดหน้าต่าง `src/client/report.ts` (ลากได้เหมือนหน้าต่างอื่น)
- เลือกหัวข้อ: บัค / แลค-หลุด / รายงานผู้เล่น / อยากให้เพิ่ม-ข้อเสนอแนะ / อื่น ๆ แล้วพิมพ์ข้อความ **10–500 ตัวอักษร**
- ระบบแนบให้เองโดยผู้เล่นไม่ต้องพิมพ์: แมพ, ห้อง (channel ของห้องบอส ถ้ามี), ตำแหน่ง, เลเวล, ping/FPS ล่าสุด, เวลา — **server เป็นคนใส่ทั้งหมด** ไม่รับค่าจาก client
- ปุ่มส่งเป็นสีเทาพร้อมนับถอยหลังหลังส่งสำเร็จ และข้อความปฏิเสธของ server แสดงเป็นภาษาไทยใต้ปุ่ม
- Guest ไม่มีปุ่มนี้ และ server ปฏิเสธถ้าส่งมาเอง

## กันสแปม (ตรวจที่ server ทั้งหมด `server/reports.ts`, ตัวเลขอยู่ `src/shared/reports.ts`)

| ข้อ | ค่า |
|---|---|
| ต่อบัญชี | 1 รายงาน / 60 วินาที · ไม่เกิน 5 รายงาน / 24 ชม. |
| ต่อ IP (`server/clientIp.ts`) | ไม่เกิน 15 รายงาน / 24 ชม. |
| ทั้งเซิร์ฟ | ไม่เกิน 60 รายงาน / ชั่วโมง |
| ข้อความซ้ำ | ปฏิเสธข้อความเดิมที่บัญชีเดียวกันส่งใน 24 ชม. (ไม่สนช่องว่าง/ตัวพิมพ์) |
| ข้อมูล | หัวข้อต้องอยู่ในรายการ · ตัดอักขระควบคุม/อักขระมองไม่เห็นออก (ขึ้นบรรทัดใหม่ได้) แล้วนับความยาวที่ server |
| คนที่ถูกห้าม | บัญชีที่อยู่ในตาราง `report_bans` ถูกปฏิเสธ |

- นับจากตาราง `reports` ซึ่งเก็บเฉพาะรายงานที่รับแล้ว (รายงานที่ถูกปฏิเสธไม่ถูกเก็บและไม่นับ) ดังนั้นเพดานไม่หายตอนรีสตาร์ท server
- ลำดับตรวจ: Guest → ถูกห้าม → หัวข้อ → ความยาว → 60 วินาที → 5/วัน → ต่อ IP → ซ้ำ → ทั้งเซิร์ฟ

## ฝั่ง server และ DB

- ตาราง `reports` (ข้อความ หัวข้อ สถานะ บริบท IP) และ `report_bans` สร้างด้วย `CREATE TABLE IF NOT EXISTS` ใน `server/db.ts` DB เก่าใช้ต่อได้โดยไม่ต้อง migrate
- action `reportSend` (แบบมี `req` ตอบด้วยข้อความ `report`) แก้ครบ 5 ที่: `Sim`/`Player` ไม่เกี่ยว · `Backend` · `ActionMsg` · `OnlineBackend` · `onAction` ใน `server/world.ts` (`onReport`)
- เฉพาะหัวข้อ **รายงานผู้เล่น** ส่งข้อความในแชทถึง owner/GM ที่ออนไลน์ทันที (ตามสวิตช์ `reports`) หัวข้ออื่นรอดูที่หน้า admin
- ยังไม่มีระบบตอบกลับผู้เล่น (เจ้าของสั่งไว้ก่อน) · ยังไม่ลบรายงานเก่าอัตโนมัติ

## หน้า /admin แท็บ "รายงาน"

- API ใน `server/admin-reports.ts`: `GET /api/admin/reports?topic=&status=&before=` · `POST /api/admin/reports/status` · `POST /api/admin/reports/ban`
- สวิตช์ใน `FEATURE_ROLES`: `reports` (owner และ GM: ดูรายการ เปลี่ยนสถานะ) · `reportBan` (owner เท่านั้น: ห้าม/อนุญาตให้บัญชีส่งรายงาน)
- กรองตามหัวข้อและสถานะได้ · สถานะ: ใหม่ / กำลังดู / แก้แล้ว / ปิด · ทุกการเปลี่ยนสถานะและการห้ามลง `admin_audit` (`report-status`, `report-ban`, `report-unban`)
- เทสต์: `tests/reports.test.ts`
