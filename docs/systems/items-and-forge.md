# กระเป๋า ยา ไอเทม tier และช่างตีเหล็ก

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · ตัวเลขตีบวกอยู่ใน `src/shared/data/enhance.ts`

## กระเป๋าและยา

- กระเป๋า 30 ช่อง ยาอยู่ในกระเป๋าร่วมกับของสวมใส่ ช่องละไม่เกิน 10 ขวด ขายให้พ่อค้าได้ครึ่งราคา
- ยามี 3 ขนาดต่อชนิด เติมเป็นตัวเลขคงที่ (ไม่ใช่ %) — ดู `src/shared/data/potions.ts`
- ปุ่มยาด่วน (1/2) ใช้ขนาดที่ผู้เล่นเลือก (คลิกยาในกระเป๋า) ถ้าหมดจะใช้ขนาดเล็กสุดที่เหลือ
- พ่อค้ามีปุ่มขายของทั้งหมดตามระดับความหายาก (ไม่ขายของที่ตีบวกแล้ว และถามยืนยันก่อน)

## Tier ของสเตตัส

- สเตตัสบนไอเทมมี tier T1–T5 แบบ Path of Exile 2 (`src/shared/data/items.ts`): แต่ละ tier มีช่วงของตัวเอง tooltip แสดง `+34 พลังโจมตี T1: 30–40`
  - ช่วงทั้งหมดของแต่ละบรรทัด: ต่ำสุด = 40% ของสูงสุด (`RANGE_FLOOR`) วางให้ค่าเฉลี่ยเท่าเดิม · ความกว้าง T1–T3 25% · T4 15% · T5 10% (`TIER_BAND`) · โอกาส 3/9/18/30/40% (บอสเพิ่ม tier ดี)
  - สเตตัส % (คริ, ดาเมจคริ, ความเร็วโจมตี/เคลื่อนที่) และฟื้น HP/MP มีทศนิยม 1 ตำแหน่ง ที่เหลือเป็นจำนวนเต็ม (ถ้าเลขเล็กจนแบ่งไม่พอ tier สูงถูกดันขึ้นให้ห่างกันอย่างน้อย 1)
  - `StatLine.min/max` คือช่วงของ tier นั้น · ไอเทมเก่า (ไม่มี `tierV`) ถูกแปลงตอนโหลด (`upgradeItem`): ค่าเดิมไม่เปลี่ยน ได้ tier ตามที่ค่าตกในตารางใหม่ · ไอเทมก่อนมี tier (ไม่มี `lines`) ไม่แตะและสุ่มไม่ได้
- บรรทัดบนไอเทม = สเตตัสหลักของชนิดไอเทม + (อาวุธหลักเท่านั้น) บรรทัดโอกาสคริล็อก + สเตตัสเสริมตามความหายาก 0/1/2/3/4 (แหวน +1) → ของ Legendary มี 6 บรรทัดทุกช่อง (เจ้าของตั้ง 2026-11-08)
  - บรรทัดคริของอาวุธหลัก (`LOCKED_LINE`) ได้ทุกชิ้นทุกความหายาก อยู่ต่อจากพลังโจมตี นับเป็นสเตตัสหลัก (หินสุ่มสเตตัสไม่เปลี่ยน) ใช้ช่วงคริเสริมเต็ม (ไม่ลด)
  - สเตตัสเสริมพลังโจมตี ความเร็วโจมตี โอกาสคริ ดาเมจคริ ได้ครึ่งเดียวของตาราง `AFFIXES` (`EXTRA_SCALE`) · สเตตัสหลักไม่ลด
  - ของที่เซฟก่อน `TIER_VERSION` 3 ถูกแปลงตอนโหลด: บรรทัดเสริม 4 ชนิดนี้ลดครึ่ง และอาวุธหลักได้บรรทัดคริล็อก (สุ่มโดยใช้ uid เป็น seed จึงได้ค่าเดิมทุกครั้ง รวมถึงในตลาด)

## ช่างตีเหล็ก

- ช่างตีเหล็กมี 3 เมนู: ตีบวก / **สุ่มค่าตัวเลข** (ทุกบรรทัด tier เดิม) / **สุ่มสเตตัส** (สุ่ม 1 บรรทัดจากสเตตัสเสริม เปลี่ยนชนิด+tier+ค่า สเตตัสหลักไม่เปลี่ยน; ไอเทมที่ไม่มีสเตตัสเสริมสุ่ม tier+ค่าของสเตตัสหลัก 1 บรรทัดแทน)
- จ่ายทอง (ไม่มีไอเทมผลึก): (15 + iLv×6) × 3 (ค่าตัวเลข) หรือ × 6 (สเตตัส) × ความหายาก 1/1.5/2/3/5 (`src/shared/data/reroll.ts`) · ถามยืนยันทุกครั้ง · ใช้กับของในกระเป๋าและที่สวมอยู่ ไม่ใช่ในคลัง · +N ยังอยู่ · ไอเทม admin ที่เกินช่วงนับเป็น T1 และสุ่มแล้วกลับเข้าช่วงปกติ
- โอกาสตีบวกสำเร็จ (ตามระดับเป้าหมาย, เจ้าของตั้ง 2026-11-08): +1 ถึง +4 = 100% · +5 ถึง +7 = 40% · +8 ถึง +9 = 20% · +10 = 10% · +11 ถึง +15 = 15/10/5/2.5/1% (คงเดิม) · บวก pity +1% ต่อครั้งที่ล้ม (`SUCCESS` ใน `src/shared/data/enhance.ts`)
- หน้าต่างช่างตีเหล็ก (ตามภาพตัวอย่าง "Enchant Item" ของเจ้าของ): ซ้าย = เมนู 3 ระบบ + คำอธิบาย (+ ปุ่มตารางโอกาสสำเร็จในเมนูตีบวก) · กลาง = ช่องวางไอเทมบนวงเวท · ขวา = ข้อมูล**ปัจจุบัน**ของไอเทม (ไม่พรีวิวค่าหลังตี/สุ่ม; หลังสุ่มบอก "เดิม …") ต่อด้วยโอกาสสำเร็จ/ค่าทอง/หิน/ช่องติ๊กหินกันระดับลด · ล่าง = ปุ่มใหญ่ (ชื่อตามเมนู) + "นำออก" (เอาของออกจากช่อง ปิดหน้าต่างใช้ ✕) + แถบทอง/หินของเมนูนั้น
  - ตีบวกที่ระดับเป้าหมาย +11 ถึง +15 (ตีจาก +10→+11 ถึง +14→+15) ไม่บอกโอกาสสำเร็จ แสดง `??` ทั้งในแผงขวา (`#forge-cost`) และตาราง (`#forge-rates`) · pity ในระดับนี้บอกแค่ "ล้มมาแล้ว n ครั้ง (โอกาสเพิ่มขึ้น)" ไม่บอกตัวเลข · คำอธิบายกติกา +1% ต่อครั้งที่ล้มยังแสดงตามเดิม · ซ่อนแค่การแสดงผล (`HIDDEN_RATE_FROM` ใน `src/client/hud.ts`) โอกาสจริงไม่เปลี่ยน
  - เปิดมาช่องว่างและเปิดกระเป๋าให้ทางขวา · ใส่ของได้ทั้งลากจากกระเป๋า ลากจากช่องที่สวมอยู่ (ของยังสวมอยู่) หรือคลิก (ระหว่างเปิดช่างตีเหล็ก คลิกอุปกรณ์ = วางในช่องแทนการสวม/ถอด) · ยาและหินไม่รับ
  - ทำด้วย CSS ล้วนรอเพื่อนวาดภาพจริง: ทุกส่วนมี id ของตัวเอง (`#forge-menu`, `#forge-stage`/`#forge-circle`/`#forge-slot`, `#forge-info`/`#forge-item`/`#forge-cost`, `#forge-go`, `#forge-cancel`, `#forge-foot`, `#forge-rates`) · ไม่มี scrollbar · ความกว้างเว้นที่ให้กระเป๋า (ใช้สูตรเดียวกับ `--inv-w`) ทดสอบแล้วที่ 1280×600 และ 1024×768 ทั้ง HUD แบบ orbs/bars
