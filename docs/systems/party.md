# ปาร์ตี้

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · กติกาในไฟล์นี้เจ้าของตกลงแล้วทั้งหมด (2026-11-09 ข้อที่มี "เจ้าของเลือก" = ถามเพิ่มระหว่างทำ) ห้ามเปลี่ยนโดยไม่ถาม

## กติกา (server เป็นผู้ตัดสิน: `server/party.ts`, ตัวเลขใน `src/shared/party.ts`)

- ปาร์ตี้มีได้สูงสุด 3 ตัวละคร (`PARTY_MAX`) · คนสร้างเป็นหัวหน้า · เฉพาะหัวหน้าชวนและเตะได้
  - หัวหน้าออก → สมาชิกคนถัดไป (ตามลำดับที่เข้า) เป็นหัวหน้า · เหลือคนเดียว → ปาร์ตี้ถูกยุบ
  - คนที่ยังไม่มีปาร์ตี้กด "ชวน" ได้เลย (ระบบสร้างปาร์ตี้ให้ โดยคนชวนเป็นหัวหน้า) หรือกด "สร้างปาร์ตี้" ก่อนก็ได้ · ถ้าคำชวนถูกปฏิเสธจะเหลือปาร์ตี้คนเดียวค้างไว้ (กดออกเองได้) (เจ้าของเลือก)
- Guest เข้าปาร์ตี้ไม่ได้ ถูกชวนไม่ได้ และไม่ขึ้นในช่องค้นหา
- บัญชีเดียวเล่นได้หลายตัวพร้อมกัน แต่ปาร์ตี้หนึ่งมีตัวละครจากบัญชีเดียวกันได้ 1 ตัว
- ชวนคนที่อยู่ปาร์ตี้อื่น → ขึ้นข้อความว่าเขาต้องออกจากปาร์ตี้เดิมก่อน
- คำชวนหมดอายุใน 30 วินาที (`INVITE_TTL`) ถ้าไม่ตอบ = ปฏิเสธ · ชวนคนเดิมซ้ำได้ทุก 10 วินาที (`REINVITE_GAP`)
  - ทุกเงื่อนไขตรวจอีกครั้งตอนกดยอมรับ (ระหว่าง 30 วิ ปาร์ตี้อาจเต็มหรือยุบไปแล้ว)
- ตั้งค่า "ไม่รับคำชวนปาร์ตี้" (เมนู → ตั้งค่า) **จำในเบราว์เซอร์** (localStorage `multiverse-party-block`) ส่งให้ server ตอนเข้าเกมและตอนเปลี่ยน (เจ้าของเลือก)
- หลุดการเชื่อมต่อ/ปิดแท็บ: ยังอยู่ในปาร์ตี้ 60 วินาที (`OFFLINE_GRACE`) แสดงเป็นออฟไลน์ กลับมาภายใน 60 วิยังอยู่ปาร์ตี้เดิม
  - กดออกเอง (กลับไปเลือกตัวละคร / ออกจากระบบ) = ออกจากปาร์ตี้ทันที (เบราว์เซอร์ปิด WebSocket ด้วย code `WS_CLOSE_QUIT` = 4000)
  - โดน GM เตะ/แบน หรือ server ปิด = ออกทันที (เจ้าของเลือก) · ล็อกอินตัวเดิมจากที่อื่น (takeover) = ยังอยู่ปาร์ตี้ (เจ้าของเลือก)
  - **ปาร์ตี้ไม่ถูกเซฟ** รีสตาร์ท server = ปาร์ตี้หายหมด รูปแบบเซฟตัวละครไม่เปลี่ยน
- ข้อความระบบในแชท (แท็บปาร์ตี้ + ทั้งหมด/ระบบ): เข้าร่วม, ออก, ถูกเตะ, หลุดนานเกิน, หัวหน้าคนใหม่, และที่เจ้าของให้เก็บไว้: ยุบปาร์ตี้, ส่งคำชวนแล้ว/ปฏิเสธ/หมดเวลา, ชวนซ้ำได้อีกใน N วิ

## ของดรอป

- สมาชิกปาร์ตี้ทุกคน**บนแมพเดียวกัน**นับเป็นเจ้าของสิทธิ์เก็บของก่อน (~10 วิ, `LOOT_PRIORITY_TIME`) เหมือนเป็นของที่ตัวเองดรอป รวมทอง
  - ผูกตอนดรอปกับปาร์ตี้ของคนที่ทำดาเมจมากสุด (`Loot.ownerParty`) แล้วตรวจตอนเก็บว่ายังอยู่ปาร์ตี้นั้น (`Loot.canTake(player, time)`)

## EXP

1. คิด EXP ของแต่ละคนแบบเดิมก่อน (`shareExp`: สัดส่วนดาเมจ × `expGapMult`)
2. คนที่ได้ EXP เก็บ 50% (`EXP_KEEP`) อีก 50% แบ่งเท่า ๆ กันให้สมาชิกที่มีสิทธิ์
   - มีสิทธิ์ = อยู่แมพเดียวกัน + ยังมีชีวิต (ตายแล้วไม่ได้จนกว่าจะฟื้น) + เลเวลต่ำกว่าคนได้ไม่เกิน 5 (`EXP_LEVEL_GAP`) · เลเวลสูงกว่ามีสิทธิ์
   - ไม่มีใครมีสิทธิ์ → คนได้เก็บ 100%
   - ปัดลง เศษให้คนที่ได้ EXP (เจ้าของเลือก) รวมแล้วเท่าเดิมพอดี (`splitExp` ใน `src/shared/party.ts`)
3. ตัวอย่างของเจ้าของ: ปาร์ตี้ Lv30, Lv29, Lv5 · Lv30 ได้ 100 → Lv30 50, Lv29 50, Lv5 0 · ปาร์ตี้ Lv30, 29, 28 → 50, 25, 25 (เทสต์ใน `tests/party.test.ts`)

## UI (`src/client/party.ts`, CSS ท้าย `src/style.css` ส่วน party)

- ไอคอน "ปาร์ตี้" ในแถวไอคอนมุมขวาบน ระหว่างกระเป๋ากับแผนที่ และในตารางเมนู Esc · ยังใช้ `ico_blank` + 👥 (เปลี่ยนเป็น `badge('party')` เมื่อมี `ico_party.png`)
- หน้าต่างปาร์ตี้ (ลากได้): สร้างปาร์ตี้, รายชื่อสมาชิก (ชื่อ เลเวล หลอด HP/MP ไอคอนหัวหน้า ♛ ป้ายออฟไลน์), ปุ่ม "ชวน" + ช่องค้นหาชื่อบางส่วน (ผู้เล่นออนไลน์ที่ไม่ใช่ Guest), ปุ่มออกจากปาร์ตี้ (มีกล่องยืนยัน)
  - คลิกขวาที่สมาชิก (หัวหน้าเท่านั้น) → เมนูจัดการ มีแค่ "เตะ" (เพิ่มอย่างอื่นต้องถามเจ้าของ)
- คลิกซ้ายที่ผู้เล่นคนอื่นในโลก → เมนู "ชวนเข้าปาร์ตี้" (มอนสเตอร์และของ/NPC ใต้เมาส์มาก่อน)
- กล่องคำชวน: ยอมรับ / ปฏิเสธ + นับถอยหลัง 30 วิ
- แผงสมาชิกบน HUD ใต้การ์ดตัวละคร: สมาชิกคนอื่น (ไม่รวมตัวเอง) หลอด HP/MP เลเวล ชื่อ ไอคอนหัวหน้า ป้ายออฟไลน์
- แชทแท็บ "ปาร์ตี้": อยู่แท็บนี้แล้วกด Enter = ส่งเข้าปาร์ตี้ · พิมพ์ `/p ข้อความ` ส่งเข้าปาร์ตี้จากแท็บไหนก็ได้ (เจ้าของเลือก) · ลง `chat_log` ด้วยคำนำหน้า `[ปาร์ตี้]` (/admin อ่านได้, เจ้าของเลือก)
- ชื่อบนหัวสมาชิกเป็นสีเขียว · มินิแมพ/แผนที่ใหญ่: สมาชิกบนแมพเดียวกันเป็นจุดเขียวขอบขาว เห็นแม้อยู่ไกล (มินิแมพติดขอบเมื่ออยู่นอกวง) ข้อมูลมาจาก `SnapshotMsg.party` ไม่ใช่รายชื่อผู้เล่นใกล้ตัว
