# สกิลนักเวท (เจ้าของอนุมัติ 2026-11-14)

ตัวเลขทุกตัวเป็นค่าเริ่มที่แรงก์ 1 และปรับได้ใน /admin (การ์ด "ระบบสกิล" แท็บเมจ) ตัวเลขที่ไม่ใช่ดาเมจ/MP/คูลดาวน์/ระยะอยู่ในคอลัมน์ "ค่าเฉพาะ" ซึ่งปรับได้รายท่าเช่นกัน

- ดาเมจ = ×ATK ต่อครั้งที่โดน · MP = ค่าที่ Lv.1 แรงก์ 1 (โตตามเลเวลตัวละครและแรงก์ตามสูตรเดิม) · CD = คูลดาวน์วินาที
- โตต่อแรงก์ตามค่ากลางเดิม: ดาเมจ +5% · MP +10% · CD −2% · เวลาสถานะ +5%
- **ศัพท์ระยะ:** "ยิง" = ลูกเวทพุ่งไปทางเมาส์ · "จุด" = ลงที่ตำแหน่งเมาส์ภายในระยะ · "รอบตัว" = วงรอบผู้เล่น · "กรวย" = ด้านหน้า
- **กติกากับบอส** (ใช้กับทุกท่า ตามระบบเดิม): สตัน/ตรึงเหลือ 30% กับบอส และไม่มีผลกับบอสที่มีท่าแพทเทิร์น · ผลัก/ดึงไม่มีผลกับบอส · ช้าลง ลดเกราะ ลดพลังโจมตี และติดไฟ/พิษ มีผลกับบอสเต็ม
- ภาพ: ใช้ท่าทาง q/e/r เดิมของเมจ และเอฟเฟกต์เดิม (ระเบิด น้ำแข็ง หลุมอุกกาบาต วง ดิสก์ อนุภาค) เปลี่ยนสีตามสาย ยังไม่มีภาพใหม่
