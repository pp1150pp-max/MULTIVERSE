# นักดาบกระดาษ (ระบบกระดูก 2D) — ทดลอง

เจ้าของสั่ง 2026-11-16 · ลองสไตล์กระดาษตัดแปะกับนักดาบก่อน ถ้าผ่านจะเปลี่ยนทั้งเกมเป็นสไตล์นี้ทีหลัง

## ภาพรวม

- ตัวละครแยกเป็นชิ้นกระดาษ 14 ชิ้น บวกผ้าคลุม 3 แถบ ต่อกันเป็นกระดูก แล้วขยับด้วยการหมุนกระดูก แบบเดียวกับ Spine แต่เขียนเองใน Three.js
- มี 2 มุม คือหน้าเฉียงกับหลังเฉียง แล้วกลับซ้ายขวาให้เป็น 4 ทิศ
- ท่าที่ระบบกระดูกวาด: ยืน วิ่ง และฟัน 3 ท่า (`attack`, `attack_2`, `attack_3`)
- ท่าอื่นใช้ภาพเดิม: ท่าตายกับหลุม ท่าขี่ ท่าฟื้น และคางคก (`RigActor` ห่อ `AnimatedActor` เดิมไว้ข้างใน)
- **ใครเห็น:** เฉพาะเบราว์เซอร์ที่เปิดสวิตช์ใน `/admin` → หน้าตา → นักดาบกระดาษ (เก็บใน localStorage `multiverse-paper-sword`) คนอื่นยังเห็นแบบเดิม
- **ดาบและเกราะ:** มีดาบ 3 แบบ (คาตานาอำพัน ดาบใหญ่ ดาบไฟ) และเกราะ 2 แบบ (เหล็กดำ เงินฟ้า)
  - server ส่งชนิดอาวุธและเกราะที่แต่ละคนใส่จริงใน snapshot (`PlayerSnap.wpn` / `arm`)
  - ไอเทมไหนใช้ภาพไหนตั้งได้ที่ `/admin` → ปรับสมดุล → "นักดาบกระดาษ: ภาพอาวุธและเกราะ" (`BalanceTuning.rigLook`)

## แก้ท่า

`rig.json` เก็บตำแหน่งเป็นสัดส่วนของภาพ (0–1) จึงสลับเป็นชิ้นที่ขนาดต่างกันเล็กน้อยได้

- `pivot`: จุดหมุนบนภาพของชิ้นนั้น
- `at`: จุดต่อบนภาพของชิ้นแม่
- ท่าเก็บเป็นมุมหมุนเพิ่ม (องศา ทวนเข็ม) ของแต่ละกระดูก ที่เวลา `t` (0–1 ของท่า)
- `root` คือการขยับทั้งตัว เป็นพิกเซล แกน y ชี้ขึ้น
- ชิ้นกระดาษวาดหันซ้าย ท่าเดินหน้าจึงเป็นมุมลบ (แขนหรือขาเหวี่ยงไปทางซ้าย)

ลองดูหลังแก้:

```bash
node --import tsx tools/rig_preview.ts preview.png dark katana
```

## ตัดชิ้นใหม่

เซฟภาพไว้ใน `art_templates/papercraft/raw/` ด้วยชื่อเดิม แล้วรัน:

```bash
node tools/cut_rig_parts.mjs --list
```

```bash
node tools/cut_rig_parts.mjs
```

- `--list` ใช้เช็กว่าลำดับชิ้นตรงกับชื่อ
- ลิ้นกระดาษสีเนื้อที่ข้อต่อจะถูกเปลี่ยนเป็นสีเทาเข้ม ให้ดูเหมือนผ้าใต้เกราะ

## ที่ยังไม่ทำ

- ท่าสกิล ท่าพุ่ง ท่าโดนตี ท่าตาย และท่าขี่ ยังเป็นแบบกระดูกไม่ได้
- หน้าแก้ท่าแบบลากกระดูก (ตอนนี้แก้ใน `rig.json`)
- คลาสอื่นและมอนยังไม่ได้ทำ
