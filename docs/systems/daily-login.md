# ล็อกอินรายวัน

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · กติกาปฏิทินอยู่ใน `src/shared/daily.ts` · ฝั่ง server อยู่ใน `server/daily.ts`

## กติกา (เจ้าของตั้ง 2026-11-12)

- ปฏิทินรายเดือน **ต่อบัญชี** (ตัวละครไหนเข้าก่อนก็รับแทนทั้งบัญชี) · Guest ไม่มีปฏิทิน
- **ตัดวันตอน 00:00 เวลาไทย** (UTC+7 คงที่ ไม่มี daylight saving) ไม่ขึ้นกับเวลาของเครื่อง server
- **นับตามวันที่ปฏิทิน**: เข้าเกมวันที่ 12 ได้ของของช่องวันที่ 12 · วันที่ไม่ได้เข้า = พลาด
- **ชดเชยฟรีเดือนละ 3 ครั้ง** (`DAILY_MAKEUPS`) เลือกได้ทุกวันที่ผ่านมาแล้วในเดือนนี้ รวมวันก่อนสมัครบัญชีหรือก่อนระบบเปิด · เดือนก่อนชดเชยไม่ได้ · เดือนใหม่ได้ 3 ครั้งใหม่
- **ของส่งเข้ากล่องจดหมายของบัญชีอัตโนมัติ** ตอนเข้าเกมครั้งแรกของวัน (และตอนเที่ยงคืนสำหรับคนที่ออนไลน์ค้างอยู่ server เช็กทุก 30 วิ) · จดหมายหมดอายุ 30 วันเหมือนจดหมายปกติ · ของใช้ (ใบคูณ/โทรโข่ง) ผูกกับตัวละครที่กดรับ
- ปฏิทินเด้งขึ้นเองตอนได้ของของวันนี้ และเปิดดูได้จากปุ่ม "รายวัน" บน HUD / เมนูระบบ "ล็อกอินรายวัน" · คลิกวันที่พลาดแล้วกดปุ่มชดเชย

## ของรางวัล

- ค่าในโค้ด `DAILY_DEFAULT` (31 ช่อง ใช้ทุกเดือน เดือนสั้นใช้แค่วันที่มี): รอบ 7 วัน หินสุ่มค่า → ใบคูณ EXP → หินสุ่มสเตตัส → ใบคูณดรอป → หินกันระดับลด → โทรโข่ง → หินตีบวก ×2 (วันที่ 21, 28 เป็น ×3) · วันที่ 29 ใบคูณ EXP ×2 · 30 ใบคูณดรอป ×2 · 31 หินกันระดับลด ×2
- ของที่เลือกได้: ใบคูณ EXP/ดรอป, โทรโข่ง, หินช่างตีเหล็ก 4 ชนิด (`DAILY_KINDS`) จำนวน 1–10
- **แท็บ "ล็อกอินรายวัน" ใน /admin** (สวิตช์ `daily` เฉพาะ owner) แก้ของแต่ละวันได้ · DB เก็บเฉพาะวันที่ต่างจากโค้ด (setting `daily_rewards`) · มีผลกับของที่ส่งหลังบันทึก · ลง audit

## การเก็บข้อมูล

- ตาราง `daily_claims (account_id, day 'YYYY-MM-DD', makeup, at)` คีย์หลัก (บัญชี, วัน) กันส่งซ้ำ (เช่นสองตัวละครเข้าพร้อมกัน) · เขียนแถวนี้กับจดหมายใน transaction เดียว
- จดหมายของวันเดียวกันที่ของเหมือนกันใช้ `mail_sends` แถวเดียวร่วมกัน (ตาราง `daily_mail`) ประวัติจดหมายใน /admin จึงขึ้นไม่กี่แถวต่อวัน ผู้ส่งชื่อ "ล็อกอินรายวัน"
