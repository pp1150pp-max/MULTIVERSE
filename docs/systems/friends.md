# เพื่อน บล็อก และกระซิบ

กติกาในไฟล์นี้เจ้าของตกลงแล้ว (2026-11-10) ข้อที่มี "(ตัดสินเอง)" = ผู้พัฒนาเลือกค่าเอง เจ้าของอนุมัติในแผนแล้ว แก้ได้ถ้าเจ้าของไม่เห็นด้วย · ห้ามเปลี่ยนกติกาอื่นโดยไม่ถาม

## กติกา (server เป็นผู้ตัดสิน: `server/friends.ts`, ตัวเลขใน `src/shared/friends.ts`)

- **ผูกกับบัญชี** ไม่ใช่ตัวละคร: เพิ่มตัวละครหนึ่งตัว = เป็นเพื่อนกับทั้งบัญชีนั้น · เก็บถาวรใน DB (ตาราง `friends`, `friend_requests`, `blocks`) ลบบัญชีแล้วแถวหายเอง (ON DELETE CASCADE)
- **Guest ใช้ระบบเพื่อนไม่ได้** (ส่งคำขอ ถูกขอ บล็อก ไม่ได้) แต่สมาชิกบล็อก Guest ได้ (กันกระซิบก่อกวน)
- **รายชื่อเพื่อน** แสดงตัวละครที่เล่นอยู่ (เล่นหลายตัวพร้อมกัน = ตัวที่เข้าเกมล่าสุด) ถ้าออฟไลน์ = ตัวที่เซฟล่าสุด · บอก ออนไลน์/ออฟไลน์ เลเวล คลาส และแมพ (· CH ถ้าแมพนั้นมีแชนแนล) · ไม่มีวาร์ปไปหาเพื่อน แต่มีปุ่ม "ไปห้องเดียวกัน" เมื่ออยู่แมพเดียวกันคนละ CH (ดู [channels.md](channels.md))
  - อัปเดตทันทีเมื่อเพื่อนเข้า/ออกเกม และภายใน ~1 วิ เมื่อเพื่อนเลเวลอัป เปลี่ยนแมพ หรือย้าย CH · เพื่อนเข้าเกม = บรรทัดแชท "เพื่อนของคุณ X เข้าเกมแล้ว" (ตัดสินเอง)
- **คำขอเพื่อน:** พิมพ์ชื่อตัวละคร หรือคลิกตัวละครในเกม · อีกฝ่ายต้องยอมรับ · ส่งหาคนออฟไลน์ได้ คำขอค้างใน DB จนกว่าจะตอบ (ไม่มีหมดอายุ) และเขาเห็นตอนเข้าเกม
  - เพื่อนสูงสุด **50** (`FRIEND_MAX`) ตรวจทั้งสองฝ่าย ตอนส่งและตอนยอมรับ
  - คำขอที่ส่งออกไปรอคำตอบได้พร้อมกันสูงสุด **20** (`FRIEND_PENDING_MAX`, ตัดสินเอง) · ขอคนเดิมซ้ำได้ทุก 10 วิ (`FRIEND_REREQUEST_GAP`)
  - ต่างฝ่ายต่างขอกัน = เป็นเพื่อนกันทันที · ผู้ส่งยกเลิกคำขอได้ · ลบเพื่อนได้ (หายจากทั้งสองฝ่าย)
  - เพิ่มตัวละครในบัญชีตัวเองไม่ได้
- **บล็อก** (สูงสุด 100 บัญชี, `BLOCK_MAX`, ตัดสินเอง): ลบความเป็นเพื่อนและคำขอที่ค้างทั้งสองทาง · คนที่ถูกบล็อก **ส่งคำขอเพื่อน กระซิบ ชวนปาร์ตี้ ขอเทรด** มาหาไม่ได้ · ผู้บล็อกก็ส่งคำขอเพื่อนหาเขาไม่ได้จนกว่าจะปลดบล็อก
  - คนที่ถูกบล็อกไม่ถูกบอกว่าโดนบล็อก: เห็นข้อความกลาง ๆ ("ส่ง...ไม่ได้" หรือแบบเดียวกับคนที่ปิดรับคำชวน/คำขอเทรด)
  - ไม่ซ่อนแชทสาธารณะของคนที่ถูกบล็อก
- **กระซิบ:** หาใครก็ได้ที่ออนไลน์ (ไม่ต้องเป็นเพื่อน) ยกเว้นคนที่บล็อกเรา · Guest ส่งและรับได้ · คนออฟไลน์รับไม่ได้ (ไม่เก็บไว้ส่งทีหลัง) · ใช้จังหวะแชทเดียวกับแชทปกติ (1 บรรทัด / 0.6 วิ) · บันทึกใน log แชทของ /admin เป็น `[กระซิบ→ชื่อ] ข้อความ`
- **ปุ่มลัดในรายชื่อเพื่อน** ใช้ระบบเดิม: ชวนปาร์ตี้ (`partyInvite`, เพื่อนต้องออนไลน์) และขอเทรด (`tradeRequest`, ต้องออนไลน์และอยู่แมพและ CH เดียวกัน)

## หน้าจอ (`src/client/friends.ts`)

- ไอคอน "เพื่อน" (ภาพ `ico_friends.png` สองคนกับหัวใจ) ที่ 7 มุมขวาบน (ถัดจากปาร์ตี้) และในตารางเมนู · Guest ไม่มีไอคอนนี้ · ตัวเลขบนไอคอน = คำขอที่รอเราตอบ
- หน้าต่างมี 3 แท็บ: **เพื่อน** (ช่องพิมพ์ชื่อเพื่อส่งคำขอ + รายชื่อ ปุ่ม กระซิบ / ชวนตี้ / เทรด / ลบ) · **คำขอ** (ยอมรับ/ปฏิเสธ คำขอถึงเรา, ยกเลิกคำขอที่เราส่ง) · **บล็อก** (ช่องพิมพ์ชื่อเพื่อบล็อก + ปลดบล็อก)
  - ปุ่มกดไม่ได้เมื่อเพื่อนออฟไลน์ · เทรดกดได้เฉพาะแมพและ CH เดียวกัน · ลบเพื่อนและบล็อกถามยืนยันก่อน · แมพที่เกมไม่รู้จัก (เช่นห้องบอส) แสดง "พื้นที่พิเศษ"
- คลิกตัวละครในเกม: เมนูเพิ่ม "กระซิบ" (ทุกคน รวม Guest), "เพิ่มเป็นเพื่อน" และ "บล็อก" (สมาชิก)
- แชท: แท็บ **กระซิบ** · `/w ชื่อ ข้อความ` (ชื่อมีเว้นวรรคใส่ `"…"`) · `/r ข้อความ` = ตอบคนที่กระซิบมาล่าสุด · ในแท็บกระซิบพิมพ์ธรรมดา = ส่งหาคนล่าสุดที่คุยด้วย · คลิกบรรทัดกระซิบ = ตอบคนนั้น · กระซิบไม่ขึ้นเป็นฟองเหนือหัว

## ข้อความ (`src/shared/net/protocol.ts`)

- client → server: `friendRequest{name}`, `friendAnswer{acc, yes}`, `friendCancel{acc}`, `friendRemove{acc}`, `friendBlock{name}`, `friendUnblock{acc}`, `friendList` · กระซิบ = `{t:'chat', ch:'whisper', to, text}`
- server → client: `{t:'friends', view}` (เพื่อน คำขอเข้า คำขอออก บล็อก) ส่งตอนเข้าเกม ตอนขอ และทุกครั้งที่เปลี่ยน · กระซิบ = `chat` ที่มี `ch:'whisper'` (มี `to` = ข้อความของเราเองที่ส่งกลับมาให้เห็น)
