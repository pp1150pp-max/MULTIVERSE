# เอฟเฟกต์สกิล: ชั้นเสริม (เจ้าของ 2026-11-15)

ภาพเอฟเฟกต์ของแต่ละสกิลมี 6 เฟรม เล่นแต่ละเฟรมทีละช่วงแล้วหายทันที เลยดูกระตุกและไม่ต่อเนื่อง ชั้นเสริมแก้เรื่องนี้โดยให้เกมวาดของเพิ่มทับลงไปบนภาพ:

- **แสงเรือง:** สว่างขึ้นเร็ว แล้วค่อย ๆ จางหายช้ากว่าภาพราว 1.5 เท่า ภาพจึงจางลงแทนที่จะหายวับ
- **แสงบนพื้น:** วงแสงนุ่ม ๆ ใต้เอฟเฟกต์
- **อนุภาค:** ขยับทุกเฟรมที่จอวาด มี 5 แบบ
  - `spark` ประกายเป็นเส้นพุ่งออก
  - `shard` เศษหนักกระเด็นแล้วตกพื้น
  - `ember` ถ่านไฟลอยขึ้น
  - `star` ดาวกะพริบ
  - `dust` ฝุ่นต่ำ บนมือถือแสดงแค่ครึ่งเดียว
- **เด้ง:** ตอนภาพปรากฏจะขยายเป็น 125% แล้วหดกลับ
- **หนัก (ความรู้สึกตอนโดน):**
  - ทำให้จอสั่น และภาพค้างสั้น ๆ คือเอฟเฟกต์กับท่าทางตัวละครหยุดนิ่ง แต่ตำแหน่งยังเดินตาม server
  - เกิดเฉพาะบนจอของคนที่ร่าย และเฉพาะตอนที่ท่าโดนมอน
  - Sim บอกผ่าน `effect(…, by, hit)` ว่าใครเป็นคนร่ายและท่าโดนหรือเปล่า

## ตั้งค่าที่ไหน

- **ค่าของแต่ละท่า:** อยู่ที่ `FX_RECIPES` ใน `src/client/fxLayer.ts` ใช้ชื่อภาพเป็น key (`whirlwind`, `sw_cleave` ฯลฯ) ตั้งได้ดังนี้
  - `color` สี
  - `glow` ความแรงของแสงเรือง
  - `ground` รัศมีแสงบนพื้น เทียบกับขนาดภาพ
  - `particles` ชนิดและจำนวนอนุภาค
  - `punch` เด้ง
  - `heavy` ความหนักตอนโดน 0–1
- **ค่ารวมทั้งเซิร์ฟ:** ปรับที่ /admin → ปรับสมดุล → "เอฟเฟกต์สกิล (ชั้นเสริม)" (`src/shared/fxLayerTuning.ts`) ตั้งได้ดังนี้
  - เปิด/ปิด
  - ตัวคูณแสงเรือง แสงบนพื้น อนุภาค และจอสั่น
  - เวลาภาพค้างของท่าที่หนัก 1 (ค่าในโค้ด 60 ms และหยุดได้นานสุด 120 ms)
  - ตัวคูณขนาดตัวเลขคริ
  - ตัวเลขดาเมจ (หัวข้อ "ตัวเลขดาเมจ" ในการ์ดเดียวกัน) ดูกติกาใน [balance.md](balance.md#ตัวเลขดาเมจบนจอ-เจ้าของตกลง-2026-11-17)
- **ท่าที่ไม่มีค่าใน `FX_RECIPES`:** ยังเล่นภาพแบบเดิม

## ตอนนี้เปิดท่าไหนแล้ว

**เปิดครบทุกภาพตามค่าแนะนำในเอกสาร** `SKILL_FX_ALL.md` (เจ้าของ 2026-11-15) เริ่มจากพายุดาบก่อน แล้วเจ้าของสั่งให้ทำทุกภาพต่อ
- **ภาพที่ยังไม่มีสกิลใช้** (`sw_wave`, `sw_xslash_gold`, `impact`) ยังไม่ได้ใส่
- **ลูกที่บิน:** อยู่ใน `SHOT_LAYERS` เลือกตามสีของลูก แต่ละลูกมีแสงรอบตัวและหางอนุภาคระหว่างบิน
  - ลูกจากการโจมตีปกติไม่ใส่ เพราะยิงบ่อยเกินไป ได้แก่ #9fd8ff (เมจ), #ffe08a (ปืน), #ffc85a (ยิงรัว) และ #ffb040 (ปืนตอนมีบัฟ)
- **ใครร่าย / โดนไหม:** ใช้ `Sim.asCaster(p, fn)` ครอบทุกอย่างที่ผู้เล่นทำ เอฟเฟกต์ทุกภาพที่เกิดในนั้นจะติด id ของคนร่าย และติดว่าโดนมอนหรือไม่ ครอบคลุม 3 กรณี:
  - ตอนร่าย (`castSkill`)
  - timer ที่ตั้งตอนร่าย เช่น อุกกาบาต ฝนเพลิง และพื้นที่ค้าง
  - ลูกที่บินไปแล้วระเบิด (`PlayerProjectile`)
- **พื้นที่ค้าง** (พื้นเพลิง หมอกพิษ กับระเบิด โดรน ป้อมปืน ฯลฯ) เล่นซ้ำทุกรอบ จึงให้ความหนักเป็น 0 เพื่อไม่ให้จอสั่นตลอด

## ชั้นตั้งของสกิล AOE (เจ้าของ 2026-11-15)

เจ้าของบอกว่าสกิล AOE ดูแบนเหมือนสติกเกอร์ จึงให้แยกภาพเป็น 2 ชั้น
- **ชั้นพื้น:** ใช้ภาพเดิมที่วางราบ
- **ชั้นตั้ง:** ชิ้นเล็กที่วาดจากด้านข้าง เกมจะโปรยหลายชิ้นทั่วพื้นที่ (`src/client/zoneProps.ts`)
  - แต่ละชิ้นค่อย ๆ โผล่จากพื้นและขยับไม่พร้อมกัน ชิ้นที่อยู่หน้าจะบังชิ้นข้างหลัง
  - สกิลที่ร่ายครั้งเดียวจะเล่นชิ้นส่วนรอบเดียว ส่วนพื้นที่ที่ค้างอยู่ (`zone`) จะวนชิ้นส่วนไปจนพื้นที่หาย และถ้าพื้นที่ตามตัวคนร่าย ชิ้นส่วนก็ตามไปด้วย
- **ตาราง:** แต่ละสกิลได้ 1 แถว อยู่ใน `SKILL_PROPS` (`src/client/zonePropsTable.ts`) มีทั้งหมด 34 สกิล ใน 9 แผ่น
  - prompt อยู่ที่ `art_templates/skills/AOE_PROPS.md`
  - แผ่นไหนที่ยังไม่มีไฟล์ เกมจะไม่วาดชั้นตั้งของสกิลในแผ่นนั้น
- **Sim ระบุสกิลให้:** `Sim.asCaster(p, fn, skill)` ติด id สกิลไปกับ `effect(…, skill)` และ `zone(…, follow, skill)` ครอบคลุมทั้งตอนร่าย, timer ที่ตั้งตอนร่าย และลูกที่บินอยู่ ฝั่ง client จึงรู้ว่าต้องวาดชิ้นส่วนของสกิลไหน

## อนุภาค three.quarks (ทดลอง เจ้าของ 2026-11-18)

ลองใช้ไลบรารี [three.quarks](https://github.com/Alchemist0823/three.quarks) วาดอนุภาคของสกิล อนุภาคทั้งหมดถูกรวมวาดทีเดียวบนการ์ดจอ จึงใส่ได้เยอะกว่าแบบ sprite ทีละตัว
- **เวอร์ชัน:** `three.quarks` 0.16.0 (ล็อกเลขตายตัว) เพราะเกมใช้ three 0.170 ส่วน 0.17 ขึ้นไปต้องใช้ three 0.182 ขึ้นไป
- **โค้ด:** `src/client/quarksFx.ts` สร้างเอฟเฟกต์เป็นแม่แบบครั้งเดียว แล้ว clone ทุกครั้งที่เล่น ภาพอนุภาควาดบน canvas ไม่มีไฟล์ภาพ
- **เกือบทั้งหมดอยู่ฝั่ง client:** ใช้ `effect(…, by, skill)` ที่ Sim ส่งมาอยู่แล้ว ฝั่ง Sim เพิ่มแค่ติด id คนร่ายให้ `meteor` (ขั้นที่ 2) ไม่แก้ protocol
- **สวิตช์:** /admin → ปรับสมดุล → "เอฟเฟกต์สกิล (ชั้นเสริม)" → "ใช้ three.quarks วาดอนุภาคของสกิล" (`fxLayer.quarks`) ค่าในโค้ด **ปิด** ปิดชั้นเสริมทั้งหมดก็ปิดตัวนี้ด้วย และใช้ "× อนุภาค" ของการ์ดเดียวกัน
- **ท่าที่ใช้ตอนนี้:** อุกกาบาตของเมจท่าเดียว
  - ลูกไฟที่ตกลงมา: three.quarks แทนลูกไฟเดิม (แกนเรือง ไฟ ควันเป็นหาง)
  - ตอนตก: ภาพหลุมเดิมยังเล่น three.quarks วาดทับ (แสงวาบ ลูกไฟ ประกาย ควัน ถ่านไฟลอยจากพื้น 2.5 วิ)
- **ลดภาระ (ขั้นที่ 2, 2026-11-18):** ตั้งในการ์ดเดียวกัน เก็บเฉพาะค่าที่ต่างจากโค้ด ลง audit
  - จำนวนอนุภาคจริง = ในโค้ด × "× อนุภาค" × "× อนุภาคของคนอื่น" (`quarksOthers` ค่าในโค้ด 0.5 เฉพาะท่าที่ไม่ใช่ของเรา) × "× อนุภาคบนจอสัมผัส" (`quarksTouch` ค่าในโค้ด 0.5 เฉพาะมือถือ/แท็บเล็ต ใช้การตรวจ `pointer: coarse` แบบเดียวกับฝุ่นของชั้นเสริม)
  - "อนุภาคบนจอสูงสุด" (`quarksCap` ค่าในโค้ด 3,000): บนจอเกินแล้ว ท่าใหม่ของคนอื่นไม่วาดจนกว่าจะลดลง ท่าของเราไม่ถูกตัดเลย · 0 = ไม่วาดของคนอื่นเลย
  - ค่าเริ่มต้นมาจากการวัดในหน้าทดสอบ (เต็มห้อง 19 คน ใช้ CPU ราว 1 ms/เฟรม บนคอม)
  - ใครร่าย: `effect(…, by)` เดิม และ `meteor(x, z, duration, by)` ที่ `Sim.asCaster` ติด id คนร่ายให้แล้ว ถ้าไม่รู้ว่าใคร = วาดเหมือนของเรา
- **ยังไม่ทำ:** เมนูให้ผู้เล่นเลือกคุณภาพเอง ต่ำ/กลาง/สูง (ยังไม่มีเมนูกราฟิกในเกม ต้องถามเจ้าของก่อน), ท่าอื่น ๆ, โหลด three.quarks เฉพาะตอนเปิดสวิตช์
