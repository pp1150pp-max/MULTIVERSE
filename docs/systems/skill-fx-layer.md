# เอฟเฟกต์สกิล: ชั้นเสริม (เจ้าของ 2026-11-15)

ภาพเอฟเฟกต์ของแต่ละสกิลมี 6 เฟรม เล่นแต่ละเฟรมทีละช่วงแล้วหายทันที เลยดูกระตุกและไม่ต่อเนื่อง ชั้นเสริมแก้เรื่องนี้โดยให้เกมวาดของเพิ่มทับลงไปบนภาพ:

- **แสงเรือง:** สว่างขึ้นเร็ว แล้วค่อย ๆ จางหายช้ากว่าภาพราว 1.5 เท่า ภาพจึงจางลงแทนที่จะหายวับ
- **แสงบนพื้น:** วงแสงนุ่ม ๆ ใต้เอฟเฟกต์
- **อนุภาค:** ขยับทุกเฟรมที่จอวาด มี 5 แบบ
  - `spark` ประกายเป็นเส้นพุ่งออก
  - `shard` เศษหนักกระเด็นแล้วตกพื้น
  - `ember` ถ่านไฟลอยขึ้น
  - `star` ดาวกะพริบ
  - `dust` ฝุ่นต่ำ บนมือถือแสดงแค่ครึ่งเดียว
- **เด้ง:** ตอนภาพปรากฏจะขยายเป็น 125% แล้วหดกลับ
- **หนัก (ความรู้สึกตอนโดน):**
  - ทำให้จอสั่น และภาพค้างสั้น ๆ คือเอฟเฟกต์กับท่าทางตัวละครหยุดนิ่ง แต่ตำแหน่งยังเดินตาม server
  - เกิดเฉพาะบนจอของคนที่ร่าย และเฉพาะตอนที่ท่าโดนมอน
  - Sim บอกผ่าน `effect(…, by, hit)` ว่าใครเป็นคนร่ายและท่าโดนหรือเปล่า

## ตั้งค่าที่ไหน

- **ค่าของแต่ละท่า:** อยู่ที่ `FX_RECIPES` ใน `src/client/fxLayer.ts` ใช้ชื่อภาพเป็น key (`whirlwind`, `sw_cleave` ฯลฯ) ตั้งได้ดังนี้
  - `color` สี
  - `glow` ความแรงของแสงเรือง
  - `ground` รัศมีแสงบนพื้น เทียบกับขนาดภาพ
  - `particles` ชนิดและจำนวนอนุภาค
  - `punch` เด้ง
  - `heavy` ความหนักตอนโดน 0–1
- **ค่ารวมทั้งเซิร์ฟ:** ปรับที่ /admin → ปรับสมดุล → "เอฟเฟกต์สกิล (ชั้นเสริม)" (`src/shared/fxLayerTuning.ts`) ตั้งได้ดังนี้
  - เปิด/ปิด
  - ตัวคูณแสงเรือง แสงบนพื้น อนุภาค และจอสั่น
  - เวลาภาพค้างของท่าที่หนัก 1 (ค่าในโค้ด 60 ms และหยุดได้นานสุด 120 ms)
  - ตัวคูณขนาดตัวเลขคริ
- **ท่าที่ไม่มีค่าใน `FX_RECIPES`:** ยังเล่นภาพแบบเดิม

## ตอนนี้เปิดท่าไหนแล้ว

ตอนนี้เปิดแค่ **พายุดาบ** (`whirlwind`) ท่าเดียว ตามที่เจ้าของบอกให้ลองท่าเดียวก่อน ค่าที่ใช้:
- สี `#9fe0ff`
- เรือง 0.8
- พื้น 1.1
- spark×10
- หนัก 0.35

ค่าแนะนำของท่าอื่นอยู่ในเอกสาร `SKILL_FX_ALL.md` ที่เจ้าของส่งมา ถ้าเจ้าของเห็นพายุดาบแล้วโอเค ค่อยเพิ่มท่าอื่นลงใน `FX_RECIPES` จากเอกสารนั้น
