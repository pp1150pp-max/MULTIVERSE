# เทรดระหว่างผู้เล่น

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · กติกาในไฟล์นี้เจ้าของตกลงแล้ว (2026-11-09) ข้อที่มี "(ตัดสินเอง)" = ผู้พัฒนาเลือกค่าตามแบบปาร์ตี้เพราะเจ้าของไม่ได้ระบุ แก้ได้ถ้าเจ้าของไม่เห็นด้วย · ห้ามเปลี่ยนกติกาอื่นโดยไม่ถาม

**เจ้าของยืนยันแล้ว (2026-11-09):** ปัดภาษีลง (ต่ำกว่า 34 G ไม่เสียภาษี) · บัญชีเดียวกันเทรดกันเองไม่ได้ · ขณะเปิดหน้าต่างเทรดจัดการของไม่ได้ และ Esc/✕/ยกเลิก = ยกเลิกเทรด

## กติกา (server เป็นผู้ตัดสิน: `server/trade.ts`, ตัวเลขและการคำนวณใน `src/shared/trade.ts`)

- **ใครเทรดได้:** ทั้งคู่ต้องเป็นตัวละครของบัญชีสมาชิก (Guest เทรดไม่ได้ ถูกขอไม่ได้) · อยู่แมพและ CH เดียวกัน (ระยะห่างไม่สำคัญ, ดู [channels.md](channels.md)) · มีชีวิตทั้งคู่
  - ตัวละครของ**บัญชีเดียวกัน**เทรดกันเองไม่ได้ (ตัดสินเอง: กันการโอนของข้ามตัวและกันปัญหาคลังร่วมกัน)
  - คนที่กำลังเทรดอยู่ ขอเทรดหรือถูกขอไม่ได้
- **คำขอ** (เหมือนคำชวนปาร์ตี้): A ขอ B → B ยอมรับ / ปฏิเสธ / หมดเวลา 30 วิ (`TRADE_REQUEST_TTL`) นับเป็นปฏิเสธ
  - ขอคนเดิมซ้ำได้ทุก 10 วิ (`TRADE_REREQUEST_GAP`) · ส่งคำขอที่รอคำตอบได้ครั้งละ 1 คำขอ และคนหนึ่งมีคำขอรอตอบได้ 1 คำขอ (ตัดสินเอง)
  - ทุกเงื่อนไขตรวจอีกครั้งตอนกดยอมรับ
- ตั้งค่า "ไม่รับคำขอเทรด" (เมนู → ตั้งค่า ถัดจาก "ไม่รับคำชวนปาร์ตี้") **จำในเบราว์เซอร์** (localStorage `multiverse-trade-block`) ส่งให้ server ตอนเข้าเกมและตอนเปลี่ยน
- **ในหน้าต่างเทรด:** A = คนขอ, B = คนถูกขอ (ทั้งสองจอเห็นเหมือนกัน) · แต่ละฝ่ายเสนอของได้สูงสุด **8 ช่องกระเป๋า** (`TRADE_SLOTS`) + ทอง
  - ยาและหินเสนอ**บางส่วน**ได้ ด้วยกล่องเลือกจำนวนเดิมของฟีเจอร์แบ่งกอง (Shift+ลากไปที่หน้าต่างเทรด) · ไม่ใส่จำนวน = ทั้งกอง · เสนอช่องเดิมซ้ำ = เปลี่ยนจำนวน
  - **ของที่สวมอยู่เสนอไม่ได้** (ต้องถอดลงกระเป๋าก่อน)
  - ของที่เสนอ**ยังอยู่ในกระเป๋า** (มีกรอบเขียวในกระเป๋า) จนกว่าจะแลกจริง → ยกเลิกเมื่อไรของก็อยู่ครบ ไม่ต้องคืน
  - ทองที่เสนอไม่เกินทองที่มี และไม่เกิน 1,000,000,000 (`TRADE_GOLD_MAX`)
- **ขั้นตอน:** ทั้งสองเสนอ → A กดยืนยัน, B กดยืนยัน → นับถอยหลัง **3 วิ** (`TRADE_COUNTDOWN`) → server ตรวจกระเป๋าและทองของทั้งคู่ใหม่ → แลกในครั้งเดียว → สำเร็จ
  - **ใครแก้ข้อเสนอ (เพิ่ม/เอาออก/เปลี่ยนจำนวน/เปลี่ยนทอง) หลังมีคนยืนยัน → ยกเลิกการยืนยันของ "ทั้งสองฝ่าย"** รวมถึงระหว่างนับถอยหลัง (ยกเลิกการนับด้วย)
  - ยืนยันแล้ว ต้องกดยืนยันใหม่ทั้งคู่ · การยืนยันอ้างอิงเลขเวอร์ชันของข้อเสนอที่เห็น (`ver`) ถ้าอีกฝ่ายเพิ่งแก้ในเสี้ยววินาทีนั้น การยืนยันจะถูกปฏิเสธ (กันการยืนยันข้อเสนอที่ไม่ได้เห็น)
  - ไม่มีของและทองเลยทั้งสองฝ่าย = กดยืนยันไม่ได้ (ตัดสินเอง) · กดยืนยันที่แลกไม่ได้แน่ (เช่น กระเป๋าอีกฝ่ายเต็ม) ถูกปฏิเสธทันทีพร้อมข้อความ แทนที่จะรอ 3 วิแล้วล้ม (ตัดสินเอง)
  - กดยืนยันซ้ำ (ดับเบิลคลิก) ไม่มีผลเพิ่ม
  - ปิดหน้าต่าง (✕) / Esc / กด "ยกเลิก" = ยกเลิกการเทรด (เปิดเมนูหรือหน้าต่างอื่นไม่ยกเลิก) · ขณะเทรด จัดการของไม่ได้: สวมใส่/ถอด/ทิ้ง/ขาย/ซื้อ/ตีบวก/สุ่ม/คลัง/ตลาด/จดหมาย/จัดเรียง/แบ่งกอง (server ปฏิเสธพร้อมข้อความ) · เก็บของ ใช้ยา Auto ยังทำได้ แต่ตอนแลกจริง server ตรวจว่าของที่เสนอยังครบตามที่เสนอ ถ้าไม่ครบ (เช่น ดื่มยาที่เสนอไปแล้ว) ยกเลิกทั้งเทรดโดยไม่มีอะไรเปลี่ยน
- **ภาษีทอง 3%** (`TRADE_TAX_PCT`, เจ้าของเลือก): ผู้ส่งเสียเท่ายอดที่เสนอ **ผู้รับได้ 97%** ภาษีหักจากยอดนั้นและ**หายออกจากเกม**
  - ตัวอย่างของเจ้าของ: A เสนอทอง 1,000 → A เสีย 1,000 · B ได้ 970 · ภาษี 30 หายไป
  - ปัดภาษีลง (`floor`): เสนอต่ำกว่า 34 G ไม่เสียภาษี (ตัดสินเอง) · ทั้งสองฝ่ายส่งทองได้ แต่ละยอดโดนภาษีแยกกัน
  - ภาษีเป็นของที่เหลือหลังหักเท่านั้น ไอเทมไม่โดนภาษี
- **กระเป๋าต้องพอ:** หลังแลก กระเป๋าแต่ละฝั่ง (หลังเอาของที่ตัวเองเสนอออกแล้ว จึงแลก 1 ต่อ 1 ได้แม้กระเป๋าเต็ม) ต้องมีที่ใส่ของที่ได้รับ (ยา/หินรวมเข้ากองเดิมได้) ถ้าไม่พอ → ปฏิเสธ/ยกเลิก พร้อมข้อความว่าต้องเว้นช่องว่างอย่างน้อยกี่ช่อง
- **ยกเลิกทันที** (ของและทองอยู่ที่เดิมครบ ทั้งสองฝั่งได้รับข้อความ): ผู้เล่นคนใดตาย · หลุดการเชื่อมต่อ/ปิดเกม/ออกเอง/ล็อกอินซ้ำจากที่อื่น · เปลี่ยนแมพหรือย้าย CH · server ปิด · คำขอที่ค้างอยู่ของคนนั้นถูกยกเลิกด้วย
- **เทรดไม่ถูกเซฟ** รีสตาร์ท server = เทรดที่เปิดอยู่หายหมด (ไม่เสียอะไร เพราะของยังอยู่ในกระเป๋า)

## ความปลอดภัย (ห้ามพลาด)

- server เป็นผู้ตัดสินเท่านั้น ทุกค่าที่ client ส่ง (ช่อง จำนวน ทอง เวอร์ชัน ชื่อ ไอดี) ตรวจใน `Trades` / `onTrade` ใน `server/world.ts`
- การแลกคำนวณบนสำเนา (`planSwap`) ก่อน แล้วค่อยเขียนลงผู้เล่น จากนั้น **บันทึกตัวละครทั้งสองฝั่งและแถวประวัติเทรดใน transaction เดียว** (`db.transaction`, เหมือนตลาด/จดหมาย) · บันทึกล้ม = คืนค่าในหน่วยความจำและยกเลิกเทรด ฐานข้อมูลไม่เปลี่ยน
- ของที่เสนอต้องเป็น "ชิ้นเดิมเป๊ะ" ที่อีกฝ่ายเห็น (เทียบทั้งชิ้น ไม่ใช่แค่ uid) และอยู่ช่องเดิมในกระเป๋า
- คนเดียวเปิดเทรดได้ทีละ 1 เทรด (ตาม character id) · เทรดจบแล้วลบออกจากหน่วยความจำก่อนแจ้งผู้เล่น จึงแลกซ้ำไม่ได้
- ตัวละครสองตัวของบัญชีเดียวกันเทรดกันเองไม่ได้ → ไม่มีเคส `stash` ร่วมกันถูกเขียนทับสองครั้ง

## ประวัติเทรด (`trade_log` ใน `server/db.ts`, หน้า /admin แท็บ "เทรด")

- บันทึกเฉพาะเทรดที่**สำเร็จ**: เวลา แมพ ตัวละครสองฝั่ง (id, ชื่อ, บัญชี) ของที่แต่ละฝั่งให้ (ข้อความ: ชื่อ [ระดับหายาก] เลเวล / จำนวน) ทองที่ส่งและภาษีของแต่ละฝั่ง · ไม่ลบอัตโนมัติ และไม่ผูกกับตัวละคร (ลบตัวละครแล้วประวัติยังอยู่)
- แท็บ "เทรด" ใน `/admin`: ใหม่สุดก่อน หน้าละ 30 + ค้นหาชื่อตัวละคร (ฝ่ายใดก็ได้) · สิทธิ์คือสวิตช์ `tradeLog` ใน `FEATURE_ROLES` (`src/shared/admin.ts`) ตอนนี้ **owner เท่านั้น** เปิดให้ GM โดยเพิ่ม `'gm'` · อ่านอย่างเดียว (route `GET /api/admin/trades` ใน `server/admin-trade.ts`)

## UI (`src/client/trade.ts`, CSS ท้าย `src/style.css` ส่วน trade)

- ขอเทรด 2 ทาง: คลิกซ้ายที่ผู้เล่นในโลก → เมนู "ขอเทรดกับ X" (อยู่ถัดจาก "ชวนเข้าปาร์ตี้") · หรือเมนู Esc → ไอคอน "เทรด" → หน้าต่างค้นหาชื่อผู้เล่นที่ออนไลน์ (ใช้ผลค้นหาชุดเดียวกับปาร์ตี้) · Guest ไม่เห็นเมนู/ไอคอนเทรด
- กล่องคำขอ: ยอมรับ / ปฏิเสธ + นับถอยหลัง 30 วิ
- หน้าต่างเทรดตามแบบที่เจ้าของให้: 2 คอลัมน์ ผู้เล่น A / ผู้เล่น B, "ของที่เสนอ" 8 ช่อง + ตัวนับ (เช่น 2 / 8), "ทองที่เสนอ" (ช่องของตัวเองพิมพ์ได้ อีกฝั่งอ่านอย่างเดียว), สถานะแต่ละคน "ยืนยันแล้ว" (เขียว) / "รอยืนยัน" (ส้ม), "สถานะการเทรด" (รอทั้งสองฝ่าย / นับถอยหลัง 3 วิ) และปุ่ม "ยืนยัน" / "ยกเลิก"
  - เสนอของ: คลิกของในกระเป๋า (เปิดกระเป๋าให้อัตโนมัติ) หรือลากไปวางที่หน้าต่างเทรด · Shift+ลาก = เลือกจำนวนของยา/หิน · คลิกของในช่องเสนอของตัวเอง = เอาออก
  - CSS เรียบง่ายสไตล์แผงเดิม ทุกส่วนมี id ของตัวเอง (`trade-win`, `trade-a-slots`, `trade-a-slot-0`…`trade-b-slot-7`, `trade-a-gold`, `trade-a-state`, `trade-status`, `trade-confirm`, `trade-cancel` ฯลฯ) ให้เพื่อนวาดภาพทับทีหลัง · ไอคอนเมนูเทรดยังใช้ `ico_blank` + 🤝

## ยังไม่ทำ (ทีหลัง)

- เทรดข้ามแมพ/ข้ามบัญชีเดียวกัน · แชทในหน้าต่างเทรด · ประวัติเทรดให้ผู้เล่นดูเอง · แจ้งเตือนในหน้า /admin เมื่อเทรดทองก้อนใหญ่ผิดปกติ
