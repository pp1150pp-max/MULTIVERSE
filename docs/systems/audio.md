# เสียง (เพลง + เอฟเฟกต์)

โค้ด: `src/client/audio/` · ค่าทั้งเซิร์ฟ: `src/shared/audioTuning.ts`

## กติกาที่ตกลงกับเจ้าของ

- **เสียงสังเคราะห์ด้วยโค้ด (WebAudio)** (เจ้าของเลือก 2026-11-22) เพลงเป็นชิปทูนประจำแมพ 4 เพลง + เพลงบอส (`music.ts`) · **ข้อยกเว้นเดียว: เพลงห้องบอสเป็นไฟล์** (เจ้าของ 2026-11-25 ดูหัวข้อ "เพลงห้องบอส (ไฟล์)") เสียงเอฟเฟกต์ยังไม่มีไฟล์
- เสียงแบ่ง 6 หมวด: สกิลผู้เล่น / บอส / มอน / ตัวละครและไอเทม / หน้าต่างและการแจ้งเตือน / บรรยากาศแมพ
  - **/admin → ปรับสมดุล → การ์ด "เสียงเอฟเฟกต์":** เปิด/ปิด + × ความดัง (×0–×2) รายหมวด ทั้งเซิร์ฟ เก็บใน `BalanceTuning.audio` เฉพาะค่าที่ต่างจากโค้ด (ค่าในโค้ด เปิด ×1) มีผลทันทีหลังบันทึก ลง audit
  - **ผู้เล่น (เมนู → ตั้งค่า → แท็บ "เสียง", `src/client/audio/panel.ts` วาดลงแท็บ 2026-11-26 · ไอคอน 🔊 เสียงในตารางเมนูเปิดแท็บนี้):** ปิดเสียงทั้งหมด (สวิตช์) / เพลง / เอฟเฟกต์ / แถบเลื่อนรายหมวด 6 อัน เก็บในเครื่อง (`localStorage` `multiverse-audio-v1`) ปล่อยแถบเลื่อนแล้วเล่นเสียงตัวอย่างของหมวดนั้น
  - ความดังจริง = เอฟเฟกต์² × หมวดของผู้เล่น² × ความดังหมวดใน /admin (/admin ปิด = เงียบ)
- เจ้าของเลือกแบบรายหมวดอย่างเดียว ไม่ปรับทีละเสียง

## สกิลผู้เล่น (`skillSounds.ts`)

- ทุกสกิลที่กดใช้ได้ของทั้ง 3 อาชีพมีเสียงของตัวเอง (ตั้งชื่อตาม id สกิล) เล่นตอนร่าย (event `anim` ที่บอกชื่อสกิล) ตีธรรมดาและพุ่งหลบใช้เสียงเดิมใน `sfx.ts`
- ประกอบจากชิ้นเสียงร่วม (ดาบฟัน กระแทก เหล็ก ไฟ น้ำแข็ง สายฟ้า พิษ เวท มืด ปืน กลไก จรวด บัฟ) แต่ละสกิลผสม/ระดับเสียง/จังหวะต่างกัน
- เสียงตอนสกิลลงเป้า (`IMPACT_OF`): ระเบิด หลุมอุกกาบาต กระแทก สายฟ้าลง ระเบิดเวท ดาวตกโดน ระเบิดปืน กระแทกเกราะ ตราสาป
- ของคนอื่นเบาลงครึ่งหนึ่ง เสียงเบาลงตามระยะและแพนซ้าย/ขวา (`gameAudio.ts`)

## บอส (`bossSounds.ts` + เสียงคาถาใน `sfx.ts`)

| บอส | ตีธรรมดา | ท่าสกิล | เข้าเฟส/คลั่ง |
|---|---|---|---|
| หมี | ตะปบ + คำราม | กระแทกพื้น | คำรามใหญ่ |
| แม่มดหนอง | ฟันไฟตะเกียง | กระแทกพื้นโคลน · ร่ายคาถา · ขวดยาพิษแตก · มือโคลน · คำสาปคางคก (เสียงร้องกบ) | หัวเราะคลั่ง |
| เยติ | หมัดน้ำแข็ง | กระแทกพื้นน้ำแข็ง · กระโดดหนี/ตกลงมา (หิมะฟุ้ง) · พายุหิมะเรียกลูกน้อง | หิมะฟุ้ง + คำราม |
| หัวใจภูเขาไฟ | — | อุกกาบาต (ยกหินขึ้น/หวีดตก/ตกกระแทก) · คลื่นไฟวงแหวน · ลำไฟหมุน · ระเบิดใหญ่ (สะสมพลัง/ระเบิด) | เต้นหัวใจ 2 ครั้ง + ไฟคำราม (เฟส 1, 2) |

- บอสที่คลั่งแต่ไม่มีเสียงคำรามของตัวเองใช้ `boss_arrive` (บอสปรากฏใช้ `boss_appear` ดูชุดที่ 2) · ป้ายกลางจอไม่เล่นเสียงเองแล้ว
- ลูกน้องเยติกระโดดยังใช้ `boss_slam` เดิม · ปูยักษ์ชั้น 2 ยังไม่มี (อยู่ branch `floor2`)

## เสียงชุดที่ 2 (`extraSounds.ts`, เจ้าของเลือก 2026-11-22)

- **ฝีเท้า:** เฉพาะตัวเราเอง (เจ้าของเลือก) ทุก 1.5 หน่วยที่เดิน ตามพื้นของแมพ: ป่า = หญ้า · หนอง = โคลน · หิมะ = หิมะ · ภูเขาไฟ = เถ้า · เมือง = หิน · แดช/วาร์ปไม่นับ
- **เปิด/ปิดหน้าต่าง:** ทุกหน้าต่าง `.panel` ที่สลับ `hidden` (ดักจากหน้าเว็บ ไม่ต้องแก้ทีละหน้าต่าง)
- **ของดรอปตกพื้น:** ทอง · ไอเทมธรรมดา/ยา/หิน · แรร์ · epic · ตำนาน (เสียงต่างกันชัด) ของที่ผู้เล่นทิ้งเองไม่มีเสียง ไม่ดังตอนเพิ่งเข้าแมพ
- **มอน:** เง้าตีใกล้เรา (เสียงฟาด) · มอนธรรมดาที่เริ่มไล่ในระยะ 12 (เสียงร้อง) · บอสใช้เสียงของตัวเอง
- **การแจ้งเตือน:** แชททั่วไป (เสียงเบา) · กระซิบ/ปาร์ตี้ · จดหมายใหม่ (รวมรางวัลล็อกอินรายวันที่ส่งทางจดหมาย) · คำเชิญปาร์ตี้/เทรด/ห้องบอส · เควสพร้อมส่ง (สอนระบบ ล่ากุญแจ ล่าชุด) · ข้อความของตัวเองไม่มีเสียง
- **บรรยากาศแมพ (หมวดใหม่ "บรรยากาศแมพ"):** สุ่มเป็นระยะ ป่า = นก ใบไม้ · หนอง = กบ ฟองน้ำ · หิมะ = ลม น้ำแข็ง · ภูเขาไฟ = ลาวาเดือด เสียงครืน · เมือง = เสียงคนคุย นก ระฆัง
- **เพลงเมือง:** เมืองศูนย์กลาง `nexus_city` มีเพลงของตัวเอง (`town` ใน `music.ts`)
- **บอสปรากฏ:** `boss_appear` (กลองรัว + แตร) ตอนบอสห้องขึ้นและตอนบอสสนามเกิดใหม่ · นับถอยหลังบอสเกิด 5 วิสุดท้ายดังทุกวิ (มินิเกมก็ใช้)
- **แคชช็อป:** ซื้อสำเร็จ · **กล่องสุ่ม:** ตอนกดเปิด

## เพลงห้องบอส (ไฟล์) (เจ้าของ 2026-11-25)

- แนวกอทิกมืด คอรัสไร้คำ ออร์แกนโบสถ์ เครื่องสายหนัก คีย์ไมเนอร์ · เพลงใหม่ทั้งหมด (ห้ามลอกทำนอง/เนื้อร้อง และห้ามใส่ชื่อเพลง/ศิลปินใน prompt) · เจนด้วย **Mureka** · prompt + วิธีแปลงไฟล์: `art_templates/music/BOSS_GOTHIC.md`
- 2 เพลงตามชั้น: `boss_gothic_f1` (ห้องบอสชั้น 1) · `boss_gothic_f2` (ชั้น 2) ที่ `public/assets/music/<ชื่อ>.mp3` · แปลงด้วย `node tools/convert_music.mjs` (ตัดเงียบ ต่อหัวท้ายให้วนเนียน −18 LUFS 128 kbps)
- เล่นวนตั้งแต่**เข้าห้องจนออก** (รวมช่วงนับถอยหลังและหลังบอสตาย) เฟดเข้า/ออกแบบเดียวกับเพลงเดิม · ใช้แถบ "เพลงประกอบ" ของผู้เล่น · ไม่เร่งตอนบอสคลั่ง (เร่งไฟล์ = เสียงเพี้ยน)
- **ไม่มีไฟล์ / โหลดไม่ได้ = chiptune เดิม** (ลองใหม่หลัง 60 วิ) · ระหว่างโหลดค้างเพลงที่เล่นอยู่ไม่เกิน 3 วิ · เก็บในหน่วยความจำเฉพาะเพลงที่กำลังใช้ (`songFiles.ts`)
- ออกจากแมพ = เพลงสู้บอสไม่ตามไปแมพใหม่
- **/admin → ปรับสมดุล → การ์ด "เพลงห้องบอส":** เปิด/ปิดเพลงไฟล์ · × ความดังเพลงไฟล์เทียบ chiptune (×0–×2 ค่าในโค้ด ×0.8) · เลือกต่อห้องบอส (เพลงชั้น 1 / ชั้น 2 / chiptune) · ฟังตัวอย่างและเห็นว่ามีไฟล์หรือยัง · เก็บใน `BalanceTuning.audio.music` เฉพาะค่าที่ต่างจากโค้ด มีผลทันที ลง audit
- เพิ่มเพลงใหม่: เพิ่มชื่อใน `BOSS_SONGS` + `BOSS_SONG_NAME` (`src/shared/audioTuning.ts`) แล้ววางไฟล์
- เพลงที่เลือก: ชั้น 1 "Aeternum" 2:59 · ชั้น 2 "深海の聖唱" V9.5 Preview 1:00 (กอทิกผสมบทสวดชาวเรือเสียงเบสทุ้ม คงธีมทะเล เจ้าของให้ใช้ตัว 1 นาทีวนลูป) **ยังไม่มีไฟล์ในเกม**
- ⚠️ บัญชี Free ของ Mureka ดาวน์โหลดไม่ได้และไม่มีสิทธิ์เชิงพาณิชย์ (เมนู Download / Commercial license ติด VIP) → ต้องสมัครแพลนเสียเงินก่อน
