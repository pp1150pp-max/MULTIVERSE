# น้ำ ลม และแสง (shader)

แผนทั้งหมดอยู่ใน [docs/plans/shaders.md](../plans/shaders.md) ไฟล์นี้เก็บของที่**ทำแล้ว**และกติกาที่ตกลงกับเจ้าของ

ทำแล้ว: **กลุ่มน้ำและทะเลเมฆ** (PR 1) · ยังไม่ทำ: แสง (3a, ถัดไป) → ลม (2a) → ละอองลอย (2c) → ธง/ใบเรือ (2b) → bloom (3b)

## กติกา (เจ้าของ 2026-11-26)

- **"ปิด" = ภาพเหมือนก่อนมีเอฟเฟกต์** ใช้ทางวาดเดิม ไม่ใช่เปิดเอฟเฟกต์แล้วตั้งความแรงเป็น 0
- ยังเป็นงานกระดาษ: ขยับเบา ช้า ขอบคม ไม่เบลอ ไม่ทำเป็นน้ำ 3D สมจริง
- ตั้งค่าผู้เล่นแถวเดียว **น้ำ ลม และแสง: สูง / ต่ำ / ปิด** (แท็บกราฟิก และหน้าต่างกราฟิกแบบเดิม) เก็บในเครื่อง (`mv.gfx`) มีผลทันที
- ยังไม่เคยเลือก: คอม = สูง · จอสัมผัส = ต่ำ · เบราว์เซอร์ที่วาดเกมด้วย CPU = บังคับปิด
- สวิตช์เปิดในโค้ด ปิดได้ใน /admin
- ภาพแผนที่ที่อบ (`bakeMap`) ไม่เปลี่ยน ใช้ฟ้าวาดด้วยโค้ดและน้ำนิ่งเหมือนเดิมทุกระดับ
- ไม่แตะ `src/shared/sim` และ server การชนและการเล่นไม่เปลี่ยน

## กลุ่มน้ำ ได้อะไรในแต่ละระดับ

| อย่าง | ปิด | ต่ำ | สูง |
|---|---|---|---|
| ทะเลเมฆชั้น 2 | ฟ้าวาดด้วยโค้ด เลื่อนเฉพาะตอนเดิน | ภาพกระดาษ เลื่อนเอง | ภาพกระดาษ ขอบบิดเบา ๆ + ก้อนเมฆลอยซ้อน |
| น้ำท่าเรือ | ภาพน้ำเลื่อนช้า 1 ชั้น | 2 ชั้นเลื่อนคนละทิศ | + คลื่น เส้นฟองขาวรอบแพ ประกาย |
| บ่อน้ำ / ลาวา | เลื่อนช้า (น้ำแข็งนิ่ง) | เหมือนปิด | ภาพกระเพื่อม + แถบสว่าง · ลาวาช้ากว่าและเรืองวูบ · น้ำแข็งนิ่ง |
| น้ำวน (แมพ 4, ห้องคราเคน) | หมุน 4 ชั้น | + แถบสว่างหมุนเข้ากลาง | + เกลียวบิด กลางวนมืดเต้นช้า |
| คลื่นฟองรอบน้ำวน (ห้องคราเคน) | นิ่ง | โยกเบา ๆ | โยกเบา ๆ |

- ชั้น 1 (อวกาศ) ไม่เปลี่ยน
- ฟ้าพายุใช้กับธีม `grave` และ `kraken` (รวมห้องบอสและแมพสร้างเอง) ธีมอื่นของชั้น 2 ใช้ฟ้ากลางวัน · ระดับปิดเป็นฟ้ากลางวันแบบเดิมทุกแมพ
- น้ำตกขอบเมือง (`hb_falls_a/b`) ไม่ได้ทำ เพราะไม่มีแมพใดวางภาพนี้

## ค่าใน /admin

ปรับสมดุล → หน้าตา-เอฟเฟกต์-เสียง → การ์ด **"น้ำ ลม และแสง (shader)"** (ค่าอยู่ใน `fxLayer`, `src/shared/fxLayerTuning.ts` เก็บเฉพาะที่ต่างจากโค้ด ลง audit)

| ค่า | ความหมาย |
|---|---|
| `shader`, `shWater` | สวิตช์ใหญ่ และสวิตช์กลุ่มน้ำ |
| `shaderDefault`, `shaderTouchDefault`, `shaderMax` | ระดับเริ่มต้นบนคอม / จอสัมผัส และสูงสุดที่เลือกได้ (2 สูง 1 ต่ำ 0 ปิด) |
| `cloudDrift` | × ความเร็วทะเลเมฆ |
| `waterSpeed`, `waterWave`, `waterFoam` | × ความเร็วน้ำท่าเรือ, แรงคลื่น (ท่าเรือ+บ่อน้ำ), ฟองและประกาย |
| `lavaWave` | × การไหลและเรืองของลาวา |
| `whirlTwist`, `whirlGlow` | × เกลียวบิด และแถบสว่างของน้ำวน |

## ภาพ

ภาพดิบ 4 ภาพตาม [FLOOR2_SKY.md](../../art_templates/papercraft_maps/FLOOR2_SKY.md) อยู่ใน `art_templates/papercraft_maps/raw/floor2_sky/` (ไม่ commit) ตัดด้วย

```
node tools/cut_papercraft.cjs floor2_sky
```

ได้ `public/assets/sprites/paper/sky/`: `sky_day` `sky_storm` (1024×1024 ปูซ้ำ) และ `clouds_day` `clouds_storm` (แผ่น 4×2 ขนาด 1536×640)

## โค้ด

| ไฟล์ | ทำอะไร |
|---|---|
| `src/client/gfxPrefs.ts` | ระดับที่ใช้อยู่ (`gfxShader`, `gfxWater`) กติกาเลือกระดับคือ `shaderLevelFor` ใน `fxLayerTuning.ts` |
| `src/client/cloudSea.ts` | ทะเลเมฆระดับต่ำและสูง |
| `src/client/harborGround.ts` | น้ำท่าเรือ (ช่อง B ของ mask = ระยะห่างจากแพ ใช้วาดฟอง) |
| `src/client/world.ts` | บ่อน้ำใน `GROUND_FRAG`, `updateWater`, `updateSky` |
| `src/client/whirlpool.ts` | น้ำวน (`onBeforeCompile` บน material เดิม) |
| `src/client/waterFx.ts` | ลาย noise ที่ใช้ร่วมกัน |

เปลี่ยนระดับด้วย uniform ทั้งหมด จึงไม่ต้อง compile shader ใหม่ตอนเล่น · ShaderMaterial ใหม่ที่วาดใน scene ต้องมี `#include <colorspace_fragment>`
