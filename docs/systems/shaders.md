# น้ำ ลม และแสง (shader)

แผนทั้งหมดอยู่ใน [docs/plans/shaders.md](../plans/shaders.md) ไฟล์นี้เก็บของที่**ทำแล้ว**และกติกาที่ตกลงกับเจ้าของ

ทำแล้ว: **กลุ่มน้ำและทะเลเมฆ** (PR 1) · **แสงทั้งจอ** (PR 3a) · ยังไม่ทำ: ลม (2a, ถัดไป) → ละอองลอย (2c) → ธง/ใบเรือ (2b) → bloom (3b)

## กติกา (เจ้าของ 2026-11-26)

- **"ปิด" = ภาพเหมือนก่อนมีเอฟเฟกต์** ใช้ทางวาดเดิม ไม่ใช่เปิดเอฟเฟกต์แล้วตั้งความแรงเป็น 0 · ยกเว้นการแก้ภาพแมพ [ขอบเมืองท่าเรือและแพยกสูง](#ขอบเมืองท่าเรือ-เจ้าของ-2026-11-27) ที่เห็นทุกระดับ
- ยังเป็นงานกระดาษ: ขยับเบา ช้า ขอบคม ไม่เบลอ ไม่ทำเป็นน้ำ 3D สมจริง
- ตั้งค่าผู้เล่นแถวเดียว **น้ำ ลม และแสง: สูง / ต่ำ / ปิด** (แท็บกราฟิก และหน้าต่างกราฟิกแบบเดิม) เก็บในเครื่อง (`mv.gfx`) มีผลทันที
- ยังไม่เคยเลือก: คอม = สูง · จอสัมผัส = ต่ำ · เบราว์เซอร์ที่วาดเกมด้วย CPU = บังคับปิด
- สวิตช์เปิดในโค้ด ปิดได้ใน /admin
- ภาพแผนที่ที่อบ (`bakeMap`) ไม่เปลี่ยน ใช้ฟ้าวาดด้วยโค้ดและน้ำนิ่งเหมือนเดิมทุกระดับ
- ไม่แตะ `src/shared/sim` และ server การชนและการเล่นไม่เปลี่ยน

## กลุ่มน้ำ ได้อะไรในแต่ละระดับ

| อย่าง | ปิด | ต่ำ | สูง |
|---|---|---|---|
| ทะเลเมฆชั้น 2 | ฟ้าวาดด้วยโค้ด เลื่อนเฉพาะตอนเดิน | ภาพกระดาษ เลื่อนเอง | ภาพกระดาษ ขอบบิดเบา ๆ + ก้อนเมฆลอยซ้อน |
| น้ำท่าเรือ | ภาพน้ำเลื่อนช้า 1 ชั้น | 2 ชั้นเลื่อนคนละทิศ | + คลื่น เส้นฟองขาวรอบแพ ประกาย |
| บ่อน้ำ / ลาวา | เลื่อนช้า (น้ำแข็งนิ่ง) | เหมือนปิด | ภาพกระเพื่อม + แถบสว่าง · ลาวาช้ากว่าและเรืองวูบ · น้ำแข็งนิ่ง |
| น้ำวน (แมพ 4, ห้องคราเคน) | หมุน 4 ชั้น | + แถบสว่างหมุนเข้ากลาง | + เกลียวบิด กลางวนมืดเต้นช้า |
| คลื่นฟองรอบน้ำวน (ห้องคราเคน) | นิ่ง | โยกเบา ๆ | โยกเบา ๆ |

- ชั้น 1 (อวกาศ) ไม่เปลี่ยน
- ฟ้าพายุใช้กับธีม `grave` และ `kraken` (รวมห้องบอสและแมพสร้างเอง) ธีมอื่นของชั้น 2 ใช้ฟ้ากลางวัน · ระดับปิดเป็นฟ้ากลางวันแบบเดิมทุกแมพ
- น้ำตกขอบเมือง (`hb_falls_a/b`) ไม่ได้ทำ เพราะไม่มีแมพใดวางภาพนี้

## กลุ่มแสง ได้อะไรในแต่ละระดับ (เจ้าของ 2026-11-27)

| อย่าง | ปิด | ต่ำ | สูง |
|---|---|---|---|
| ขอบมืดที่มุมจอ (ทุกแมพ) | ไม่มี | มี | มี |
| โทนสีแมพ | ไม่มี | ย้อมสี | ย้อมสี + ความอิ่มสี + ความสว่าง |
| ลำแสงแดด | ไม่มี | แถบเฉียง 4 แถบ | + ริ้วในลำแสง |
| หมอก (แมพที่มีหมอกลอยอยู่แล้ว) | เหมือนเดิม | เหมือนเดิม | ไหลเป็นริ้ว + ความหนาปรับต่อแมพ |

ค่าเริ่มต้นที่เจ้าของเลือก

- ขอบมืด 22% ที่มุม กลางจอไม่เปลี่ยน · ห้องบอส ×0.5
- ลำแสง 4 แถบ เอียง 28° โปร่งสุด 14% × `shaftK` (ค่าในโค้ด **1.7** ≈ 24%, เจ้าของเลือกจากภาพเทียบ 2026-11-28) × `shaft` ของแมพ หายใจรอบละ 6–10 วิ เลื่อนช้า ๆ และขยับตามการเดินเล็กน้อย · สีลำแสง = สีย้อมของแมพผสมขาวอุ่น
- หมอกไหล `mistFlow` **0.5** (เจ้าของ 2026-11-28: ×1 เห็นเป็นเส้นแนวนอนชัดเกิน)
- โทน "อ่อน" · ความอิ่มสีและความสว่างทุกแมพ 1

| แมพ | สีย้อม | แรง | ลำแสง |
|---|---|---|---|
| ป่ามรกต | `#ffe59a` | 7% | 1 |
| เมืองกลาง, ท่าเรือ | `#ffe2b8` | 4% | 0.5 |
| หาดเรือแตก | `#ffd36b` | 8% | 1 |
| อ่าวลักลอบ (ตอนเย็น) | `#ff8f73` | 16% | 1 |
| แมพอื่น ห้องบอส แมพสร้างเอง | ไม่ย้อม | 0 | 0 |

- ห้องบอส: หมอกไม่หนาขึ้น (แม้ในริ้ว) · **หมอกผีของกัปตันเรือคนตาย** (`hazards.ts`) เป็นกลไกเกม ไม่แตะ
- ไม่ใช้ `EffectComposer`: `postFx.ts` วาดแผ่นเต็มจอทับหลัง `renderer.render` เดิม ผสมเข้าหาสีเท่านั้น ของขาวจึงไม่ล้น · ระดับสูงคัดลอกภาพจอ**เฉพาะแมพที่ความอิ่มสีหรือความสว่างไม่ใช่ 1**
- ป้ายชื่อ เลขดาเมจ HUD และหมึกคราเคนเป็น DOM จึงไม่โดน
- ภาพแผนที่ที่อบไม่โดน

## ขอบเมืองท่าเรือ (เจ้าของ 2026-11-27)

แผ่นน้ำของ `harbor_town` เคยถูกตัดเป็นเส้นตรงหยักขั้นบันไดตามรูปเกาะ (ไม่มีหน้าผาปิดแบบแมพอื่น) เจ้าของเลือกแก้เป็น **น้ำตกลงทะเลเมฆ**

- ขอบน้ำเป็นโค้งเล็ก ๆ แบบกระดาษฉีก (`IslandOutline.softened`) มีฟองขาวริมขอบ
- ด้านที่หันเข้ากล้องมีม่านน้ำเป็นริ้วยาวไม่เท่ากัน ปลายเป็นฟองจางหายในเมฆ (`src/client/harborFalls.ts`)
- **เห็นทุกระดับรวม "ปิด"** (เป็นการแก้แมพ จึงยกเว้นกติกา "ปิด = เหมือนเดิม") ระดับปิดเป็นภาพนิ่ง ต่ำ/สูงไหล
- ภาพแผนที่อบใช้ขอบใหม่ด้วย
- ของประดับยังจัดตามรูปเกาะเดิม (ขอบใหม่ไม่อยู่ด้านในของขอบเดิม) ไม่เปลี่ยนการชนหรือพื้นที่เดิน · แมพอื่นไม่เปลี่ยน
- /admin: สวิตช์ `harborFalls` (ปิด = ขอบแบบเดิม) และ `harborFallDepth` (2–12 ค่าในโค้ด 5) มีผลตอนเข้าแมพครั้งถัดไป

### แพไม้ยกสูงเหนือน้ำ (เจ้าของ 2026-11-27)

แพกับน้ำเคยดูแบนเท่ากัน เจ้าของเลือก **ขอบไม้หนา + เสาปักน้ำ + เงา**

- วาดใน `HARBOR_FRAG` เฉพาะจุดที่เป็นน้ำใต้ขอบแพด้านที่หันเข้ากล้อง พื้นที่เดินและตำแหน่งแพไม่เปลี่ยน
- `paintHarborSides` เลื่อนรูปแพเข้าหากล้องทีละขั้นลงภาพช่วย บอก shader ว่าจุดน้ำนั้นอยู่ลึกจากขอบแพเท่าไร
- เห็นทุกระดับ · ภาพแผนที่อบไม่เปลี่ยน · แมพชั้น 2 อื่นไม่ต้องแก้ (บ่อน้ำมีขอบตลิ่งอยู่แล้ว)
- /admin: `harborDeckHeight` (0–2 ค่าในโค้ด 1.3 · 0 = แบนแบบเดิม) มีผลตอนเข้าแมพครั้งถัดไป

## ค่าใน /admin

ปรับสมดุล → หน้าตา-เอฟเฟกต์-เสียง → การ์ด **"น้ำ ลม และแสง (shader)"** (ค่าอยู่ใน `fxLayer`, `src/shared/fxLayerTuning.ts` เก็บเฉพาะที่ต่างจากโค้ด ลง audit)

| ค่า | ความหมาย |
|---|---|
| `shader`, `shWater` | สวิตช์ใหญ่ และสวิตช์กลุ่มน้ำ |
| `shaderDefault`, `shaderTouchDefault`, `shaderMax` | ระดับเริ่มต้นบนคอม / จอสัมผัส และสูงสุดที่เลือกได้ (2 สูง 1 ต่ำ 0 ปิด) |
| `cloudDrift` | × ความเร็วทะเลเมฆ |
| `waterSpeed`, `waterWave`, `waterFoam` | × ความเร็วน้ำท่าเรือ, แรงคลื่น (ท่าเรือ+บ่อน้ำ), ฟองและประกาย |
| `lavaWave` | × การไหลและเรืองของลาวา |
| `whirlTwist`, `whirlGlow` | × เกลียวบิด และแถบสว่างของน้ำวน |
| `shPost`, `shShafts` | สวิตช์กลุ่มแสง (ปิด = ไม่มีทั้งกลุ่ม รวมหมอกไหล) และสวิตช์ลำแสง |
| `vignette` (0–0.6), `bossRoomPostK` (0–1) | ความมืดที่มุมจอ และ × แสงในห้องบอส |
| `shaftK`, `shaftSpeed`, `shaftAngle` | × ความแรง, × ความเร็ว และความเอียงของลำแสง (องศาจากแนวตั้ง) |
| `mistFlow` | × หมอกไหลเป็นริ้ว |

ตาราง **โทนสี หมอก และลำแสง ต่อแมพ** ในการ์ดเดียวกัน: สีย้อม แรงย้อม (0–0.5) × ความอิ่มสี (0–1.5) × ความสว่าง (0.7–1.2) × หมอก (0–2) × ลำแสง (0–2) และปุ่มคืนค่า · เก็บใน `BalanceTuning.sceneGrade` (`src/shared/sceneGrade.ts`) เฉพาะที่ต่างจากโค้ด ลง audit · ใช้กับแมพสร้างเองได้
