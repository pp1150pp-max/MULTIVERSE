# หน้า Login, Guest และหน้าผู้ดูแล /admin

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md) · สำรอง/กู้คืน DB: [server-ops.md](server-ops.md)

## หน้า Login

- หน้าแรกคือแผง **Login**: ฟอร์มเข้าสู่ระบบ/สมัคร แล้วตามด้วยปุ่ม **Guest Login** (ไม่มี Singleplayer แล้ว เซฟ SP เก่าในเบราว์เซอร์ถูกทิ้ง ไม่ import)
  - เจ้าของสั่งให้ปุ่ม Guest Login เป็นแค่รูปไปก่อน กดแล้วไม่เกิดอะไร ระบบ Guest บน server ยังอยู่ครบ เปิดกลับด้วย `GUEST_LOGIN_ENABLED` ใน `src/client/menu.ts`

## Guest

- Guest = บัญชีชั่วคราวบน server (`accounts.is_guest = 1`) มีตัวละคร 1 ตัว เบราว์เซอร์เก็บแค่ token (`multiverse-guest-token`) ห้ามเชื่อข้อมูลตัวละครจากเบราว์เซอร์
  - ถูกลบ (ตัวละครด้วย) เมื่อไม่ได้ออนไลน์เกิน 24 ชม. นับจาก `last_online` · server ไล่ลบตอนเปิดและทุก 1 ชม. คนที่ออนไลน์อยู่ไม่ถูกลบ
  - สมัครสมาชิกจากเบราว์เซอร์ที่มี Guest → บัญชี Guest กลายเป็นบัญชีจริง ตัวละครย้ายมาด้วย (นับใน 3 ช่อง) · เข้าสู่ระบบบัญชีเดิมไม่ย้าย
  - "เริ่ม Guest ใหม่" ลบ Guest เดิมเมื่อสร้างตัวใหม่สำเร็จ · สร้าง Guest ได้ไม่เกิน 5 ตัวต่อ IP ต่อชั่วโมง (`GUEST_PER_IP_HOUR` ใน `src/shared/api.ts`)
  - ระหว่างเล่นมีป้าย Guest บน HUD · ไม่มีบทนำ The Seeker ตอนเริ่ม (คุยเองได้)

## หน้าผู้ดูแล /admin

- หน้าผู้ดูแล `/admin` (`admin.html`, `src/admin/`, API ใน `server/admin.ts`) ใช้บัญชีเกมเดิม · role ใน `accounts.admin_role`: `owner` (ทุกอย่าง + ให้/ถอน GM + ดูประวัติ) และ `gm` (ดู + แก้ตัวละคร)
  - แท็บ admin ที่เปิดค้างข้ามการอัปเดต server จะขึ้นแถบ "หน้า admin มีเวอร์ชันใหม่" + ปุ่มโหลดหน้าใหม่ (เทียบชื่อไฟล์ `assets/admin-<hash>.js` ของหน้าที่เปิดอยู่กับที่ server เสิร์ฟตอนนี้ ตรวจตอนเปลี่ยนแท็บ, กลับมาที่หน้าต่าง และทุก 2 นาที · ไม่โหลดใหม่เอง กันฟอร์มที่พิมพ์ค้างหาย · ไม่ทำงานใน `npm run dev`)
  - ตั้ง owner ได้จาก command line เท่านั้น: `npm run admin-role -- <ชื่อผู้ใช้> owner|gm|none` (DB ตาม `DB_FILE` ค่าเริ่มต้นคือ DB จริง)
  - server ตรวจ role ทุก request · แก้ตัวละครออนไลน์ผ่าน Player ตัวจริงใน `server/world.ts` แล้วเซฟทันที · ทุกการกระทำลงตาราง `admin_audit`
  - เพดานต่อครั้ง (ทอง 1,000,000 / ไอเทม 10 ชิ้น) อยู่ใน `src/shared/admin.ts`
  - แท็บ "จดหมาย" (ส่งจดหมาย/ของแนบถึงผู้เล่น ดูประวัติ ดึงกลับ) คือสวิตช์ `mail` ใน `FEATURE_ROLES` (owner เท่านั้นตอนนี้) · กติกาอยู่ใน [mail.md](mail.md)
  - เสกไอเทมได้ทุกชนิดจากฟอร์มเดียว: ช่อง "ชนิด" มีอุปกรณ์ + กลุ่ม "ยา" (HP/MP × เล็ก/กลาง/ใหญ่) + "หินช่างตีเหล็ก" (หินกันระดับลด/หินตีบวก) · เลือกยา/หินแล้วซ่อนความหายาก/ตีบวก/เลเวล/สเตตัส · owner และ GM เสกยา/หินได้ · นับทีละขวด/ก้อน ครั้งละ 1–10 · เข้ากระเป๋าแบบเก็บของ (เติมกองเดิมก่อน แล้วใช้ช่องว่าง) ใส่ไม่หมด = ใส่เท่าที่ได้แล้วบอก "ใส่ได้ n/m" · API `items` ส่ง `{ kind: 'potion', potion, size, count }` / `{ kind: 'stone', stone, count }` (`adminStack`, `addStackToBag` ใน `src/shared/admin.ts`)
  - แท็บ "เทรด" (ประวัติเทรดที่สำเร็จระหว่างผู้เล่น อ่านอย่างเดียว) คือสวิตช์ `tradeLog` ใน `FEATURE_ROLES` (owner เท่านั้นตอนนี้) · กติกาอยู่ใน [trade.md](trade.md)
  - แท็บ "รายงาน" (รายงานปัญหา/ข้อเสนอแนะจากผู้เล่น เปลี่ยนสถานะ ห้ามรายงานต่อบัญชี) คือสวิตช์ `reports` (owner และ GM) และ `reportBan` (owner เท่านั้น) ใน `FEATURE_ROLES` · กติกาอยู่ใน [reports.md](reports.md)
  - แท็บ "ลูกแก้วตีบวก" (ที่ทดลองหน้าตาลูกแก้วตีบวก: ชุดสี รูปทรง ขนาด จำนวนลูก เดินดูได้ · ทดลองไม่เปลี่ยนอะไรในเกม) คือสวิตช์ `orbPreview` ใน `FEATURE_ROLES` (owner และ GM, เจ้าของตั้ง 2026-11-10) · โค้ดอยู่ `src/client/orbPreview.ts` โหลดเมื่อเปิดแท็บเท่านั้น · ตอน `npm run dev` เปิดได้ที่ `/orbs.html` ด้วย (ไม่ถูก build ไปกับเกม) · บันทึกเป็นหน้าตาของทั้งเซิร์ฟได้เฉพาะสวิตช์ `orbLook` (owner เท่านั้น) กติกาอยู่ใน [items-and-forge.md](items-and-forge.md)
  - เครื่องมือ owner (ผู้ใช้ทั้งหมด, ตั้งรหัสผ่านชั่วคราว, แบน, ประกาศ, สำรองข้อมูล) เปิดให้ GM ได้ทีละอย่างที่ `FEATURE_ROLES` ใน `src/shared/admin.ts` (เพิ่ม `'gm'`) · การลบบัญชี/ตัวละครเป็นของ owner เสมอ (ไม่มีสวิตช์)
  - แบน: คอลัมน์ `accounts.ban_until` / `ban_reason` · login และการเข้าโลกถูกปฏิเสธพร้อมเหตุผล
  - ประวัติ: `play_sessions` (เข้า-ออก, IP, GPU, ping/FPS เฉลี่ย) เก็บ 90 วัน, `chat_log` เก็บ 30 วัน, `online_samples` (จำนวนคนออนไลน์ทุก 1 นาที) เก็บ 90 วัน · ตัวเลขอยู่ที่ `HISTORY_DAYS` ใน `src/shared/admin.ts` · ลบของเก่าทุกชั่วโมง
  - ตารางการเข้าเล่น (แท็บ "การเข้าเล่น" และแท็บ "การเข้าเล่น" ในหน้าบัญชี ซึ่งกรองเฉพาะบัญชีนั้น ใช้ `sessionsTable()` ตัวเดียวกันใน `src/admin/main.ts`): เรียง/แบ่งหน้าที่ server ทุกแถวที่เก็บไว้ · กดหัวคอลัมน์ (หรือช่อง "เรียงตาม" + ปุ่ม ▲/▼) · ค้นหาชื่อผู้ใช้/ตัวละคร/IP (บางส่วน ไม่สนตัวพิมพ์ ≤ 50 ตัว, Guest ค้นด้วยคำว่า "Guest") · ช่วงวันที่เข้าเล่น (ตามเวลาเครื่องผู้ดู ทั้งวัน) · 25/50/100 แถวต่อหน้า + เลขหน้า
    - "นานเท่าไร" ของคนที่กำลังเล่นนับถึงตอนนี้ · ค่าว่าง (ไม่ทราบ, ไม่มี GPU/Ping/FPS รวมถึง Ping/FPS ของคนที่ยังเล่นอยู่ซึ่งยังไม่ลง DB) อยู่ท้ายตารางเสมอทั้งเรียงขึ้นและลง
    - API `GET /api/admin/sessions?sort=&dir=&page=&size=&q=&from=&to=&account=` คืน `{ rows, total, page, size }` (`SessionPage`) · server ตรวจทุกค่า ผิด = 400 · คอลัมน์เรียงมาจาก whitelist `SESSION_SORTS` (`sessionSortSql` ใน `server/db.ts`) ไม่เอาค่าจาก client ใส่ SQL · หน้าเกินจำนวน = หน้าสุดท้าย
    - ตารางกลายเป็นการ์ดเมื่อกล่องแคบกว่า 700px (มือถือ และในหน้าบัญชี) ด้วย container query
