# ระบบสกิล

แผนเต็มอยู่ใน `D:\Claude\Game\SKILL_SYSTEM_PLAN.md` (นอก repo) · กติกาอยู่ใน `src/shared/skillBook.ts` · ค่าที่ปรับได้อยู่ใน `src/shared/skillTuning.ts` · หน้าต่างสกิลอยู่ใน `src/client/skillWindow.ts`

## กติกา (เจ้าของตั้ง 2026-11-14)

- สกิลมี 3 ชนิด: **สกิลธรรมดา** ใส่ได้ที่ Q กับ E, **สกิลอัลติ** ใส่ได้ที่ R และ **พาสซีฟ** ใส่ได้ครั้งละ 1 แบบ ส่วนโจมตีปกติกับแดชเป็นท่าพื้นฐาน ไม่นับเป็นสกิล
- แต่ละคลาสมี 3 สาย สายละ 10 ท่า (สกิลธรรมดา 8 ท่า อัลติ 2 ท่า) และมีพาสซีฟ 3 แบบ ผสมสกิลข้ามสายได้
  - ใน PR ระบบหลัก แต่ละคลาสยังมีแค่สกิลเดิม 3 ท่า โดยสกิล R เดิม (พุ่งชน อุกกาบาต ยิงหัว) เป็นอัลติชั่วคราว
  - PR ของแต่ละคลาสจะเพิ่มท่าครบตามตารางที่เจ้าของอนุมัติ
- **แต้มสกิล:**
  - ได้เลเวลละ 1 แต้มจนถึง Lv.40 รวม 40 แต้ม เลเวล 41–80 ไม่ได้แต้มเพิ่ม (เจ้าของ 2026-11-19 ตอนขยายเพดานเป็น Lv80: คงเดิมไว้ก่อน ปรับ "ได้แต้มสกิลถึงเลเวล" ใน /admin ได้ถึง 80 และแรงก์สูงสุดได้ถึง 20)
  - ระบบไม่ได้เก็บจำนวนแต้มไว้ในเซฟ แต่คำนวณจากเลเวล ตัวละครเก่าจึงได้แต้มย้อนหลังเอง
- **เรียนและอัปแรงก์:**
  - เรียนท่าใหม่ใช้ 1 แต้ม ได้แรงก์ 1 แล้วอัปแรงก์ละ 1 แต้ม แรงก์สูงสุด 10 รวมถึงพาสซีฟ
  - ท่าแรกที่เรียนของแต่ละชนิดจะใส่ลงช่องว่างให้เอง
- **เลเวลที่ปลดล็อก** ใช้ตามลำดับของท่าในสาย
  - สกิลธรรมดา: Lv 1 / 3 / 6 / 9 / 12 / 16 / 20 / 25
  - อัลติ: Lv 5 / 10
  - พาสซีฟ: Lv 10 / 20 / 30
- **คืนแต้ม:**
  - คืนได้ทีละแต้ม ถ้าคืนแรงก์ 1 จะลืมท่านั้นและถอดออกจากช่อง
  - คืนแต้มสกิลนี้ทั้งหมด (ปุ่มในกล่องรายละเอียด) และรีเซ็ตสกิลทั้งหมด (ปุ่มมุมขวาล่างของผังดาว) ใช้ราคาต่อแต้มเดียวกัน ถามยืนยันพร้อมราคารวมก่อนทุกครั้ง ถ้าทองไม่พอจะไม่คืนเลยสักแต้ม (เจ้าของ 2026-11-15, `Sim.refundSkill(p, id, true)` / `Sim.resetSkills`)
  - ฟรีถ้าแต้มรวมยังน้อยกว่า 32 (Lv.31 ลงมา) หลังจากนั้นเสีย 1,000 G ต่อแต้ม (เจ้าของ 2026-11-17 เดิมฟรีถึง Lv.20)
  - คืนระหว่างต่อสู้ไม่ได้
- **ใส่หรือเปลี่ยนสกิล** ทำได้ทุกที่เมื่อไม่ได้ต่อสู้ ใช้ตัวจับเวลา `COMBAT_LINGER` ซึ่งนับ 5 วิหลังโจมตีหรือโดนตี
- **คูลดาวน์ผูกกับตัวสกิล** (`Player.cd` ใช้ id ของสกิลเป็นคีย์) ถอดสกิลแล้วใส่กลับ คูลดาวน์ก็ไม่รีเซ็ต
- **การเติบโตตามแรงก์** เป็นเส้นตรงจากแรงก์ 1 ค่าเริ่มของสกิลเดิมต่อแรงก์:
  - ดาเมจ +5%
  - MP +10% ซึ่งคูณต่อจาก MP ตามเลเวลของคลาส (#256)
  - คูลดาวน์ −2%
  - เวลาสถานะ +5% (สตัน ช้าลง ลดเกราะ ไม่รับดาเมจ ดูดเลือด)
- เซฟเก่าที่ไม่มี `CharacterData.skills` จะเริ่มจากศูนย์: ยังไม่ได้เรียนสกิลใด ช่อง Q/E/R ว่าง และมีแต้มตามเลเวล

## server และหน้าต่าง

- มี action 3 อย่าง คือ `skillLearn`, `skillRefund` และ `skillWear` ซึ่ง `Sim.learnSkill`, `Sim.refundSkill` และ `Sim.wearSkill` ตรวจทุกเงื่อนไขเอง ได้แก่ สกิลเป็นของคลาส เลเวล แต้ม แรงก์สูงสุด ทอง การต่อสู้ และชนิดของช่อง
- เปิดหน้าต่างสกิลได้ 3 ทาง: ปุ่ม K, ไอคอน "สกิล" แถวบนขวา และเมนู
  - หน้าต่างเป็นกลุ่มดาวหน้าเดียว (เจ้าของ 2026-11-14): ดาวกลางคือคลาส พาสซีฟอยู่รอบดาวกลาง และ 3 สายแตกออกเป็นแขน (ซ้ายบน ขวาบน ล่าง) แต่ละสายมีสีของตัวเอง
  - บนแขน สกิลธรรมดาเรียงตามเลเวลที่ปลด ดวงใกล้ดาวกลางปลดก่อน อัลติเป็นดาวใหญ่มีวงแหวน อยู่ข้างแขน
  - เส้นบอกแค่ลำดับ ถึงเลเวลก็เรียนได้เลย ไม่ต้องเรียนดวงก่อนหน้า ดาวที่เรียนแล้วเป็นสีทองพร้อมแรงก์ และเส้นที่มาถึงจะเรืองทอง ดาวที่ยังล็อกเป็นเส้นประบอกเลเวล
  - กดดาวเพื่อดูรายละเอียดและปุ่มเรียน คืนแต้ม และใส่ช่อง ด้านบนแสดงช่อง Q/E/R ช่องพาสซีฟ แต้มคงเหลือ และราคาคืนแต้ม
  - ปุ่ม "+ อัปแรงก์" กับ "− คืนแต้ม" อยู่แถวแรกใต้บรรทัดแรงก์เสมอ ไม่ขยับ (เจ้าของ 2026-11-20): ยังไม่เรียน = คืนแต้มกดไม่ได้ · แรงก์เต็ม = ปุ่มขึ้น "แรงก์สูงสุดแล้ว" กดไม่ได้ · กดคืนแต้มภายใน 0.7 วิหลังกด + ไม่นับ (กันกดรัวแล้วพลาดไปโดน)
  - ผังวางใน `src/client/skillMap.ts` เทสต์ `tests/skill-map.test.ts` ตรวจว่าดาวไม่ทับกันเมื่อมีครบ 30 ท่า + พาสซีฟ 3
  - ผังย่อให้พอดีหน้าต่าง (ไม่ต่ำกว่า 70%) บนจอแคบเลื่อนดูได้ และรายละเอียดย้ายไปอยู่ใต้ผัง
  - **ซูมและเลื่อนผัง** (เจ้าของ 2026-11-19, ฝั่งเบราว์เซอร์ล้วน): ล้อเมาส์ซูมตรงจุดที่ชี้ · กดลากพื้นหลังหรือลากทับดาวเพื่อเลื่อน (ลากแล้วไม่นับเป็นคลิก ไม่เลือกดาว) · ปุ่ม + − ⤾ (ขนาดเริ่มต้น) มุมขวาบนของผัง · นิ้วถ่าง/หุบซูม ลากนิ้วเดียวเลื่อน · ซูมคิดเป็น % ของขนาดพอดีกรอบ (100 = ตอนเปิดหน้าต่าง) ค่าโค้ด 50–250% · เปิดหน้าต่างใหม่หรือเปลี่ยนขนาดจอ = กลับ 100% กลางผัง · เลื่อนได้เท่าขอบผัง (ซูมออกจนเล็กกว่ากรอบ ผังอยู่กลางกรอบ) · วาดด้วย `transform: scale` ใน `sk-sizer`
  - ฉากหลังคือ `ui/skill_sky.png` ที่เจ้าของเจนเอง (prompt ใน `art_templates/skills/PROMPTS.md`) ถ้ายังไม่มีไฟล์จะใช้ท้องฟ้าดาวที่วาดด้วย CSS
- ไอคอนสกิลบอกจำนวนแต้มที่ยังไม่ได้ใช้
- สกิลที่ยังไม่มีไอคอนจะแสดงไอคอนว่าง (`ico_blank`) ไปก่อน เจ้าของจะเจนไอคอนจริงเองจาก GPT โดย prompt อยู่ใน `art_templates/skills/PROMPTS.md`
- ท่าทางของสกิลใช้แอนิเมชันของคลาส (`SkillDef.anim` = q/e/r) ไม่ว่าจะใส่ไว้ช่องไหน และเสียงก็ตามแอนิเมชันนั้น

## /admin (แท็บ "ระบบสกิล" ในหมวดปรับเกม)

- **แยกเป็นแท็บของตัวเอง (เจ้าของตกลง 2026-11-19)** เดิมเป็นการ์ดในแท็บปรับสมดุล (`src/admin/skills.ts`) · ใช้สวิตช์สิทธิ์ `balance` เดิม (owner+GM) · เก็บใน settings `balance` คีย์ `skills` เดิม เฉพาะค่าที่ต่างจากโค้ด ลง audit `balance` (หัวข้อ "ระบบสกิล ทั้งเซิร์ฟ")
  - การ์ด "ระบบสกิล: ค่ารวม" (ค่ากลางข้างล่าง) + การ์ด "ค่ารายสกิล": เลือกอาชีพ → ผังดาวแบบเดียวกับที่กด K ในเกม (`constellation()` ใน `src/client/skillMap.ts` ไม่มีสถานะเรียน/แต้ม) ซูม/เลื่อนได้เสมอ (ล้อ ลาก นิ้วถ่าง ปุ่ม +/−/⤾) → คลิกดาว = แผงแก้ค่าข้าง ๆ (จอแคบอยู่ใต้ผัง) มีทุกช่องเดิม + "ได้จริง แรงก์ 1 → สูงสุด" + ปุ่มคืนค่าในโค้ดเฉพาะสกิลนั้น
  - ดาวขอบทอง = ต่างจากโค้ด · จุดส้ม = แก้แล้วยังไม่บันทึก · ช่องค้นหาชื่อสกิล (ทุกอาชีพ กดผลแล้วไปที่ดาว ดาวที่ไม่ตรงจะจาง) · ใต้ผังมีรายชื่อสกิลที่ต่างจากโค้ดทุกอาชีพ กดไปที่ดาวได้
  - บันทึกส่ง `part: 'skills'` = server เปลี่ยนแค่ค่าสกิล ค่าอื่นของแท็บปรับสมดุลคงตามที่บันทึกไว้ (แท็บปรับสมดุลส่ง `part: 'rest'` กลับกัน) · **ปุ่มคืนค่าแยกกัน** (เจ้าของเลือก): "↺ คืนค่าระบบสกิลในโค้ด" คืนแค่ระบบสกิล ปุ่มคืนค่าของแท็บปรับสมดุลไม่แตะระบบสกิลแล้ว

- ค่ากลางที่ปรับได้: แต้มต่อเลเวล, เลเวลสุดท้ายที่ได้แต้ม, แรงก์สูงสุด, เกณฑ์คืนแต้มฟรี, ราคาคืนแต้ม และเลเวลปลดล็อกของแต่ละชนิดตามลำดับ
- สวิตช์ "ผังสกิลซูม/เลื่อนได้" (`mapZoom` โค้ด เปิด) + ซูมต่ำสุด/สูงสุดเป็น % (`zoomMin` 50, `zoomMax` 250) ปิดสวิตช์ = ผังพอดีกรอบแบบเดิม ไม่มีปุ่ม/ล้อ/pinch
- ค่ารายสกิลที่ปรับได้ แยกเป็นแท็บตามคลาส:
  - ดาเมจ ×ATK และ % ต่อแรงก์
  - MP และ % ต่อแรงก์
  - คูลดาวน์และ % ต่อแรงก์
  - เวลาสถานะ % ต่อแรงก์
- แต่ละแถวมีตัวอย่างค่าที่ได้จริงที่แรงก์ 1 และแรงก์สูงสุด
- เก็บเฉพาะค่าที่ต่างจากโค้ด (`BalanceTuning.skills`) และลง audit
- ระยะและรัศมีของสกิลเดิมยังอยู่ในโค้ด (`skillRanges.ts`) PR ของแต่ละคลาสจะทำให้ปรับได้ใน /admin

### "+ ต่อแรงก์" ของค่าพิเศษทุกตัว (เจ้าของ 2026-11-20)

- ทุกค่าพิเศษ (`params`) ของทุกสกิลมีช่อง "+ ต่อแรงก์" ในแผงสกิลของแท็บนี้ (ข้างค่าหลัก) = จำนวนที่บวกเพิ่มต่อแรงก์ที่เกิน 1 ในหน่วยของค่านั้น (เช่น จำนวนดวง +1 ต่อแรงก์, ห่างดวงละ −0.01 วิ ต่อแรงก์) · ใต้ช่องโชว์ค่าที่ได้ที่แรงก์ 1 / 5 / สูงสุด
- สูตร: ค่าที่แรงก์ r = ค่าหลัก (โตตาม % แล้ว ถ้าเป็นค่า `*`/`†`) + ต่อแรงก์ × (r − 1) แล้วบีบให้อยู่ในช่วงต่ำสุด–สูงสุดของค่านั้น · ค่าจำนวนนับ (ดวง สาย นัด ระลอก ... = ค่าในโค้ดเป็นจำนวนเต็มและหน่วยไม่ใช่ วิ % ม. °) ปัดเป็นจำนวนเต็ม
- ค่า `*` (โตตามเวลาสถานะ %/แรงก์) และ `†` (โตตามดาเมจ %/แรงก์) **ซ้อนกับ + ต่อแรงก์ได้**: โต % ก่อน แล้วค่อยบวก + ต่อแรงก์ · ถ้าอยากคุมค่าเดียวด้วย + ต่อแรงก์ล้วน ๆ ให้ตั้ง % ของสกิลนั้นเป็น 0
- โค้ดเป็น 0 ทุกตัว (เกมไม่เปลี่ยน) · เก็บใน `BalanceTuning.skills[id].paramsPerRank` เฉพาะค่าที่ไม่ใช่ 0 · ช่วงที่ตั้งได้ ± (สูงสุด − ต่ำสุดของค่านั้น) ÷ 9 · ลง audit บรรทัด "… + ต่อแรงก์ a → b"
- ใช้ผ่าน `skillParam(sk, key, rank)` ที่เดียว หน้าต่างสกิล (ตอนนี้/แรงก์ถัดไป) และตอนร่ายจึงตรงกัน · รัศมีวงของสกิลจุด/ระเบิดตามแรงก์ในการร่ายด้วย (`skillReach(sk, b, rank)`) แต่วงชี้เป้าบนจอยังใช้ค่าแรงก์ 1

### เอฟเฟกต์พิเศษรายสกิล + ตีธรรมดา (เจ้าของ 2026-11-20)

- **เอฟเฟกต์พิเศษ**: ในกล่องรายละเอียดของสกิล (แท็บ "ระบบสกิล" → ค่ารายสกิล) มีหัวข้อ "เอฟเฟกต์พิเศษ" กด "+ เพิ่ม" เลือกชนิด ใส่ตัวเลข เลือก "ใช้กับ" แล้วกด ✕ เพื่อลบ · ใส่ได้ทุกสกิลที่ไม่ใช่พาสซีฟ และตีธรรมดาของทุกอาชีพ · **ไม่เกิน 4 อันต่อสกิล**
- ชนิดและช่วงที่ server ยอมรับ (`EXTRA_DEF` ใน `src/shared/skillTuning.ts`):
  - สตัน 0–5 วิ
  - ทำให้ช้า 0–90% นาน 0–15 วิ
  - ไฟ/พิษ (ดาเมจต่อเนื่อง) 0–10 ×ATK ต่อวิ นาน 1–15 วิ (ติดทุก 1 วิ ผ่าน `hitMonster` จึงคริได้และใช้กติกาบอสตามปกติ)
  - ลดเกราะ 0–90% นาน 0–15 วิ
  - ลดพลังโจมตี 0–90% นาน 0–15 วิ
  - ผลักกระเด็น 0–10 ม. (ระยะที่ถูกผลักจริงตามที่กรอก · แก้ 2026-11-20: เดิมกรอก 10 ผลักจริงแค่ ~1 ม. เพราะส่งเป็นความเร็วที่ลดทอนเอง)
- **ใช้กับ**: มอนธรรมดาเท่านั้น / บอสเท่านั้น / ทั้งคู่ · ลูกน้องที่บอสเรียกนับเป็นมอนธรรมดา (`Monster.isBoss` = `behavior: 'boss'`)
- **ติดทุกครั้งที่สกิลโดน**: ทุกลูก ทุกระลอก ทุกวิของสกิลที่ทำดาเมจต่อเนื่อง และของที่วางไว้ (ป้อมปืน โดรน กับระเบิด) · `Sim.hitMonster` หาสกิลจาก `HitOpts.src` → `HitOpts.skill` → สกิลที่กำลังทำงาน (`asCaster`) · กระสุนจำสกิลตอนสร้าง (`Sim.addProjectile`) · ตีธรรมดาส่ง `src` = id ตีธรรมดา (`slash` / `bolt` / `shot`) · `src` ใช้เลือกเอฟเฟกต์พิเศษอย่างเดียว ไม่เปลี่ยนพาสซีฟ ภาพ หรือวงเวทดีบัฟ
- **ซ้ำกับของที่สกิลทำอยู่แล้ว = เอาค่าที่แรงกว่า** (สตัน ช้า ลดเกราะ ลดพลังโจมตี ผลัก) พร้อมเวลาของค่านั้น ถ้าแรงเท่ากันเอาเวลาที่นานกว่า · ไฟ/พิษของเอฟเฟกต์พิเศษไม่ซ้อนกันเอง (1 อันต่อมอน×ผู้เล่น×สกิล โดนซ้ำ = นับเวลาใหม่ เอาดาเมจที่สูงกว่า) แต่ซ้อนกับไฟของสกิลเองได้ · จังหวะไฟ/พิษไม่ให้เอฟเฟกต์พิเศษซ้ำ (`HitOpts.noExtra`)
- **กติกาบอสเดิมยังใช้**: บอสโดนสตันแค่ 30% · บอสที่มีท่าพิเศษ (หัวใจภูเขาไฟ) ไม่ติดสตัน · ผลักบอสไม่ได้ → ผลักแบบ "บอสเท่านั้น" จึงไม่มีผล
- **กันสตันค้าง**: สตันจากเอฟเฟกต์พิเศษสตันมอนตัวเดิมซ้ำจากสกิลเดิมได้เมื่อพ้น **2 วิ** นับจากครั้งก่อน (`extraStunGap` การ์ดค่ารวม 0–30 วิ, 0 = ทุกครั้ง)
- ตัวเลขไม่โตตามแรงก์ (ค่าเดียวทุกแรงก์)
- **ผู้เล่นเห็น**: tooltip ปุ่มสกิล หน้าต่างสกิล (K) และ tooltip บัฟ แสดงบรรทัด "เพิ่ม: สตัน 0.5 วิ (มอนธรรมดา)" ต่อท้ายค่าพิเศษ (`skillParamLines`)
- **ตีธรรมดา**: ปุ่ม "⚔ ตีธรรมดา" ใต้แท็บอาชีพ (เหนือช่องค้นหา) ปรับได้: ดาเมจ ×ATK (โค้ด 1), ระยะ ม. (ฟัน 2.3 / ลูกเวท 11 / ยิงเร็ว 12), ตีต่อวิ (โค้ด นักดาบ 1.7 / นักเวท 1.4 / มือปืน 2.6, 0.2–10 คูณกับความเร็วโจมตี % อีกที) + เอฟเฟกต์พิเศษ · ไม่มี MP คูลดาวน์ แรงก์ · Auto Play ยืนห่างตามสัดส่วนระยะที่ตั้ง · บัฟสายยิงเร็วของมือปืน (on-hit, ยิงแยก) คิดต่อจากดาเมจที่ตั้ง ส่วนพายุกระสุนใช้ค่าของมันเอง
- เก็บใน `BalanceTuning.skills`: `effects` (ทั้งรายการต่อสกิล เก็บเฉพาะสกิลที่มี), `basicRate` (เฉพาะอาชีพที่ต่าง), ดาเมจ/ระยะตีธรรมดาใน `skills.<id>` เดิม, `extraStunGap` · ลง audit (`skillChanges`) · ปุ่ม "↺ สกิลนี้กลับเป็นค่าในโค้ด" ล้างเอฟเฟกต์พิเศษด้วย · เทสต์ `tests/skill-extras.test.ts`

### กับระเบิดแบบสแตค (charges, เจ้าของ 2026-11-19)

- เก็บได้หลายอันตามแรงก์: **แรงก์ 1 = 1 อัน, แรงก์ 5 = 2 อัน, แรงก์ 10 = 3 อัน** · **คืนทีละอัน**: ใช้แล้วนับคูลดาวน์ของสกิล (รวมแรงก์ + มอดลดคูลดาวน์) คืน 1 อัน จบแล้วถ้ายังไม่เต็มนับอันถัดไปต่อ · ขึ้นแรงก์จนสแตคสูงสุดเพิ่มตอนที่ยังไม่เต็ม = ได้อันที่เพิ่มคืนทันทีในเฟรมถัดไป
- วางติดกันต้องห่างอย่างน้อย **0.3 วิ** (`mineGap`) · กับระเบิดบนพื้นพร้อมกันได้เท่าจำนวนสแตคสูงสุด วางเกินอันเก่าสุดหาย (`Player.mines`)
- **วางไม่ชะงัก**: ไม่ติดระบบหยุดตอนโจมตี ทั้ง Sim (`skipsAttackRoot`) และที่เบราว์เซอร์ทำนาย (สวิตช์ `mineNoRoot` ปิด = ชะงักเหมือนสกิลอื่น)
- สถานะ: `Player.charges[id]` (ไม่มี = เต็ม) · `cd[id]` = เวลาจนคืนอันถัดไป · `cd[id + ':gap']` = หน่วงวางติด · ไม่เซฟ (ตัวใหม่เริ่มเต็ม) · server ส่ง `ch` ใน snapshot ส่วนตัว (ไม่ส่งเมื่อเต็มหมด) · คูลดาวน์ผูกกับ id สกิลเหมือนเดิม เปลี่ยนสกิล/รีเซ็ตแต้มไม่รีเซ็ตสแตค
- HUD: ไอคอนโชว์ `×จำนวนที่เหลือ` + วงคูลดาวน์ของอันที่กำลังคืน (มือถือด้วย) · tooltip บอก "เก็บได้ N / M อัน" · หน้าต่างสกิลบอก "เก็บได้ N อัน" ตามแรงก์ · Auto Play ใช้ `Player.skillReady` (มีสแตคและพ้นหน่วง)

## พาสซีฟและบัฟ (hook ร่วม 3 คลาส)

- `src/shared/passives.ts` เป็นแกนกลาง แต่ละคลาสเขียนพาสซีฟของตัวเองใน `src/shared/passives/<class>.ts`
  - hook ที่มี: `stats` `dealMult` `takenMult` `onCast` `onKill` `onDash` และ `skillScale` (ดาเมจและขนาดวงระเบิดของสกิล)

  - บวกแบบ flat หลัง `finishStats` และไม่เซฟ
  - ตายแล้วบัฟหาย (`clearSkillBuffs`)
- เรียน คืนแต้ม หรือใส่สกิล จะคำนวณสเตตัสใหม่ (`recompute`)
- `HitOpts.critBonus` เพิ่มโอกาสคริเฉพาะการโจมตีนั้น
- `ProjOpts.bonus/after` คือดาเมจเพิ่มตามเป้าตอนกระสุนโดน และสิ่งที่ทำหลังโดน

- ส่วนที่นักดาบเพิ่มในแกนกลาง: hook `dashCdMult` (คูณคูลดาวน์แดชธรรมดา) · สถานะบน `Player`: `reflect/reflectUntil` (สะท้อนดาเมจ), `steadyUntil` (ไม่โดนสตันและไม่กระเด็น), `addTakenMult` / `addDmgMult` (ร่ายซ้ำ ค่าที่แรงกว่าชนะ เวลาต่อใหม่) · ทั้งหมดไม่เซฟ หายเมื่อตาย

  - ระเบิด `gs_blast` ใช้ร่วมกันทั้งสายอาวุธพิเศษ
- ของที่วางไว้ (กับระเบิด โดรน ป้อมปืน ควัน และไฟติดเป้า) เกิดจาก sim ส่งเอฟเฟกต์ซ้ำทุกจังหวะ
- พาสซีฟแสดงเอฟเฟกต์ตอนทำงาน:
  - สายตาเหยี่ยว: ตาเหยี่ยวขึ้นบนเป้าทุกครั้งที่คริ (hook `onCrit`)
  - นิ้วไกไว: ประกายที่ปืนทุก 4 นัดของการยิงปกติ (hook `onBasic`)
  - กระสุนพิเศษ: วงหกเหลี่ยมบนระเบิดที่ขยายใหญ่ขึ้น

### สายปราการอิงพลังป้องกันและ HP (เจ้าของอนุมัติ 2026-11-15)

รายละเอียดอยู่ใน [docs/plans/sword-bulwark-scaling.md](../plans/sword-bulwark-scaling.md) ทุกค่าเป็น `params` ของแต่ละท่า จึงปรับได้ใน /admin

- **ท่าโจมตี** (ปฐพีแยก กระแทกเกราะ คลื่นสั่นสะเทือน ปฐพีถล่ม): โดนแต่ละครั้งได้ดาเมจเพิ่ม DEF × `defDmg`% และ HP สูงสุด × `hpDmg`%
  - ค่าเริ่มต้นคือ 100% และ 3%
  - ส่วนเพิ่มนี้โตตามดาเมจ %/แรงก์
- **ท่าบัฟ** (ยั่วยุ ตั้งรับ ปักหลัก ราชันย์ไม่ล้ม): ได้โล่ดูดซับ = HP สูงสุด × `shieldHp`% + DEF × `shieldDef`%
  - โล่ใช้ระบบกลางเดียวกับของเมจ คือ `giveShield`
- **เกราะสะท้อน**: สะท้อนแต่ละครั้งได้ดาเมจเพิ่ม DEF × `reflectDef`% (เก็บไว้ที่ `Player.reflectFlat`)
- **ปลุกใจนักรบ**: ทุกคนในวงได้ DEF เพิ่มอีก `casterDef`% ของ DEF ผู้ร่าย
