# ระบบสกิล

แผนเต็มอยู่ใน `D:\Claude\Game\SKILL_SYSTEM_PLAN.md` (นอก repo) · กติกาอยู่ใน `src/shared/skillBook.ts` · ค่าที่ปรับได้อยู่ใน `src/shared/skillTuning.ts` · หน้าต่างสกิลอยู่ใน `src/client/skillWindow.ts`

## กติกา (เจ้าของตั้ง 2026-11-14)

- สกิลมี 3 ชนิด: **สกิลธรรมดา** ใส่ได้ที่ Q กับ E, **สกิลอัลติ** ใส่ได้ที่ R และ **พาสซีฟ** ใส่ได้ครั้งละ 1 แบบ ส่วนโจมตีปกติกับแดชเป็นท่าพื้นฐาน ไม่นับเป็นสกิล
- แต่ละคลาสมี 3 สาย สายละ 10 ท่า (สกิลธรรมดา 8 ท่า อัลติ 2 ท่า) และมีพาสซีฟ 3 แบบ ผสมสกิลข้ามสายได้
  - ใน PR ระบบหลัก แต่ละคลาสยังมีแค่สกิลเดิม 3 ท่า โดยสกิล R เดิม (พุ่งชน อุกกาบาต ยิงหัว) เป็นอัลติชั่วคราว
  - PR ของแต่ละคลาสจะเพิ่มท่าครบตามตารางที่เจ้าของอนุมัติ
- **แต้มสกิล:**
  - ได้เลเวลละ 1 แต้มจนถึง Lv.40 รวม 40 แต้ม เลเวล 41–50 ไม่ได้แต้มเพิ่ม
  - ระบบไม่ได้เก็บจำนวนแต้มไว้ในเซฟ แต่คำนวณจากเลเวล ตัวละครเก่าจึงได้แต้มย้อนหลังเอง
- **เรียนและอัปแรงก์:**
  - เรียนท่าใหม่ใช้ 1 แต้ม ได้แรงก์ 1 แล้วอัปแรงก์ละ 1 แต้ม แรงก์สูงสุด 10 รวมถึงพาสซีฟ
  - ท่าแรกที่เรียนของแต่ละชนิดจะใส่ลงช่องว่างให้เอง
- **เลเวลที่ปลดล็อก** ใช้ตามลำดับของท่าในสาย
  - สกิลธรรมดา: Lv 1 / 3 / 6 / 9 / 12 / 16 / 20 / 25
  - อัลติ: Lv 5 / 10
  - พาสซีฟ: Lv 10 / 20 / 30
- **คืนแต้ม:**
  - คืนได้ทีละแต้ม ถ้าคืนแรงก์ 1 จะลืมท่านั้นและถอดออกจากช่อง
  - ฟรีถ้าแต้มรวมยังน้อยกว่า 21 (Lv.20 ลงมา) หลังจากนั้นเสีย 1,000 G ต่อแต้ม
  - คืนระหว่างต่อสู้ไม่ได้
- **ใส่หรือเปลี่ยนสกิล** ทำได้ทุกที่เมื่อไม่ได้ต่อสู้ ใช้ตัวจับเวลา `COMBAT_LINGER` ซึ่งนับ 5 วิหลังโจมตีหรือโดนตี
- **คูลดาวน์ผูกกับตัวสกิล** (`Player.cd` ใช้ id ของสกิลเป็นคีย์) ถอดสกิลแล้วใส่กลับ คูลดาวน์ก็ไม่รีเซ็ต
- **การเติบโตตามแรงก์** เป็นเส้นตรงจากแรงก์ 1 ค่าเริ่มของสกิลเดิมต่อแรงก์:
  - ดาเมจ +5%
  - MP +10% ซึ่งคูณต่อจาก MP ตามเลเวลของคลาส (#256)
  - คูลดาวน์ −2%
  - เวลาสถานะ +5% (สตัน ช้าลง ลดเกราะ ไม่รับดาเมจ ดูดเลือด)
- เซฟเก่าที่ไม่มี `CharacterData.skills` จะเริ่มจากศูนย์: ยังไม่ได้เรียนสกิลใด ช่อง Q/E/R ว่าง และมีแต้มตามเลเวล

## server และหน้าต่าง

- มี action 3 อย่าง คือ `skillLearn`, `skillRefund` และ `skillWear` ซึ่ง `Sim.learnSkill`, `Sim.refundSkill` และ `Sim.wearSkill` ตรวจทุกเงื่อนไขเอง ได้แก่ สกิลเป็นของคลาส เลเวล แต้ม แรงก์สูงสุด ทอง การต่อสู้ และชนิดของช่อง
- เปิดหน้าต่างสกิลได้ 3 ทาง: ปุ่ม K, ไอคอน "สกิล" แถวบนขวา และเมนู
  - หน้าต่างจัดเป็น 3 คอลัมน์ตามสาย แต่ละคอลัมน์มีสีของตัวเอง และอัลติมีกรอบทอง
  - แถวพาสซีฟอยู่ด้านล่าง ด้านบนแสดงช่อง Q/E/R ช่องพาสซีฟ แต้มคงเหลือ และราคาคืนแต้ม
  - บนจอแคบ (≤700px) สลับคอลัมน์เป็นแท็บ
- ไอคอนสกิลบอกจำนวนแต้มที่ยังไม่ได้ใช้
- สกิลที่ยังไม่มีไอคอนจะแสดงไอคอนว่าง (`ico_blank`) ไปก่อน เจ้าของจะเจนไอคอนจริงเองจาก GPT โดย prompt อยู่ใน `art_templates/skills/PROMPTS.md`
- ท่าทางของสกิลใช้แอนิเมชันของคลาส (`SkillDef.anim` = q/e/r) ไม่ว่าจะใส่ไว้ช่องไหน และเสียงก็ตามแอนิเมชันนั้น

## /admin (แท็บปรับสมดุล การ์ด "ระบบสกิล")

- ค่ากลางที่ปรับได้: แต้มต่อเลเวล, เลเวลสุดท้ายที่ได้แต้ม, แรงก์สูงสุด, เกณฑ์คืนแต้มฟรี, ราคาคืนแต้ม และเลเวลปลดล็อกของแต่ละชนิดตามลำดับ
- ค่ารายสกิลที่ปรับได้ แยกเป็นแท็บตามคลาส:
  - ดาเมจ ×ATK และ % ต่อแรงก์
  - MP และ % ต่อแรงก์
  - คูลดาวน์และ % ต่อแรงก์
  - เวลาสถานะ % ต่อแรงก์
- แต่ละแถวมีตัวอย่างค่าที่ได้จริงที่แรงก์ 1 และแรงก์สูงสุด
- เก็บเฉพาะค่าที่ต่างจากโค้ด (`BalanceTuning.skills`) และลง audit
- ระยะและรัศมีของสกิลเดิมยังอยู่ในโค้ด (`skillRanges.ts`) PR ของแต่ละคลาสจะทำให้ปรับได้ใน /admin
