# เมือง แมพ ภาพ และหน้าต่าง UI

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md)

## เมืองศูนย์กลางมิติ

- แมพกลาง **เมืองศูนย์กลางมิติ** (`nexus_city`, `ZONE_HUB` ใน `src/shared/data/zones.ts`) เป็นจุดเริ่มต้นของทุกคน: เข้าเกมที่เมืองเสมอ (ยกเว้นหลุดแล้วกลับภายใน 60 วิ = กลับแมพ/CH/จุดเดิม ดู [channels.md](channels.md)) ตายในแมพ 1–4 แล้วฟื้นที่เมือง NPC ทั้งหมดอยู่ที่เมือง · จุดเกิดในเมือง (เข้าเกม/ฟื้น) สุ่มรอบน้ำพุ ห่างจากกลาง 4.6–6.2 (นอกม้านั่งรอบน้ำพุ) ไม่ให้ทุกคนเกิดทับกัน (`spawnPoint` ใน `Sim.ts`, เจ้าของตั้ง 2026-11-10, ขยับระยะ 2026-11-18)
- **ผังเมือง (เจ้าของ 2026-11-19 รอบ 6):** เมืองกว้างครึ่งละ 20 น้ำพุใหญ่พร้อมม้านั่งตรงกลางบนลานกลมรัศมี 8.5 (`HUB_PLAZA_RADIUS`) · **กำแพง 2 ด้านบนของจอเป็นตึกแถวติดกัน** หันหน้าเข้าน้ำพุ: แถวบนซ้ายมีคลังกับร้านคริสตัล (ผู้ดูแลคลัง พ่อค้าคริสตัล) · แถวบนขวามีโรงตีเหล็กกับหอกิลด์และกระดานเควส (ช่างตีเหล็ก The Seeker) · **กำแพง 2 ด้านล่างเป็นตลาด** แยกสองฝั่งถนนไปประตูล่าง และเว้นถนนให้โล่ง: ฝั่งล่างซ้ายมีพ่อค้า ฝั่งล่างขวามีนายหน้าตลาด ยืนหน้าแผงของตัวเองฝั่งลาน มีของตามอาชีพรอบตัว · ทุกอย่างหันเข้าน้ำพุและวางขนานกำแพง · ช่างแต่งตัวยังไม่กลับเข้าเมือง · **ระยะพักที่น้ำพุ 6.5** · ทั้งเมืองเป็นภาพกระดาษเสมอ ไม่ขึ้นกับสวิตช์ภาพกระดาษ · ไม่มีสวิตช์ผังเก่า/ใหม่ใน /admin (เจ้าของสั่งว่าไม่ต้องมี) · prompt ภาพ: `art_templates/papercraft_maps/HUB.md` ข้อ 7
  - เขตเมือง (`safe`) ห้ามต่อสู้ทั้งสองฝ่าย (ปุ่มหลบใช้ได้) มอนสเตอร์เข้าไม่ได้ และเปิด Auto Play ในเมืองไม่ได้ (ทุ่งรอบเมืองเปิดได้) server เป็นผู้บังคับ
  - ประตู 4 มุม ไม่จำกัดเลเวล: บน ป่ามรกต · ขวา หนองน้ำหมอก · ล่าง ดินแดนหิมะ · ซ้าย เกาะภูเขาไฟ แต่ละแมพหมุนผัง (`rotateZone`) ให้แคมป์และประตูกลับเมืองอยู่ฝั่งตรงข้ามกับที่เดินเข้า
  - ทุ่งแต่ละมุมใช้ธีมของแมพนั้น ผสมกันตรงรอยต่อ (`quadrants`, `themeAt`) มีมอนสเตอร์ตัวที่ 1 และ 2 ของแมพนั้น 8 และ 7 ตัว ยืนเดี่ยวหน้าประตู · ตัวเมืองเป็นซากเมืองมีกำแพงล้อม พื้นอิฐ (ภาพ `ruin_*`, `town_*`, `ground/brick.png` ถ้ายังไม่มีจะยืมภาพเก่าแทน)
  - การเดินชน (เจ้าของเลือก 2026-11-10): NPC ทึบเหมือนเดิม · ชนของกลมชิ้นเดียว (NPC น้ำพุ ต้นไม้) ไถลอ้อม (`Player.walkStep`) · มุมอับของ 2 ชิ้น/ขอบแมพ = หยุดนิ่ง ไม่สั่น · คลิกโดนของทึบ = เดินไปจุดยืนข้าง ๆ ที่ใกล้ที่สุด (`Terrain.standSpot`) · เดินไปจุดหมายแล้วตัวละครแทบไม่ขยับ 0.8 วิ = เลิกเดิน (`src/client/walkTo.ts`) · คุย NPC/พัก/เก็บของเสร็จ ล้างจุดหมายทันที
  - **คลิกเดินแล้วสลับแท็บ ตัวเดินต่อจนถึง** (เจ้าของ 2026-11-18, `serverWalkTo` ใน `server/world.ts`): แท็บซ่อน = เบราว์เซอร์หยุดส่ง input (server ถือว่า input เก่าเกิน 0.5 วิ = ปล่อยทุกปุ่ม) · เบราว์เซอร์ส่งจุดที่คลิกเดินไปกับทุก input (`InputMsg.to`, ไม่มี = ไม่ได้เดินด้วยคลิก) และส่งอีกครั้งทันทีตอนแท็บซ่อน · server ตรวจค่า (ตัวเลขจริง อยู่ในขอบแมพ ย้ายออกจากของทึบด้วย `standSpot` ไม่ได้ = ไม่รับ) · input เงียบ + มีจุดคลิกค้าง + ไม่ได้เปิด Auto = server พาเดินเอง (`Player.moveTarget` แบบ Auto: เดินตรง ไถลอ้อมของกลมชิ้นเดียว **ไม่หาทางอ้อมกำแพง** แทบไม่ขยับ 0.8 วิ = หยุด) · **ไม่มีจุดคลิก = หยุดแบบเดิม** (เน็ตค้างตัวไม่เดินเอง) · ระหว่างนั้น snapshot บอก `serverMoves` · กลับมาที่แท็บ: เบราว์เซอร์ส่ง input ไม่มีตำแหน่ง → server เลิกพาเดิน เบราว์เซอร์เลื่อนไปที่จริงอย่างนุ่ม (settle) แล้วเดินต่อเองถ้ายังไม่ถึง · ตำแหน่งที่เบราว์เซอร์ส่งมาระหว่าง server พาเดินไม่นับ · จบเมื่อ ถึง/ติด/ตาย/เปลี่ยนแมพ-วาร์ป-ฟื้น (epoch)/เปิดหน้าต่างเทรด/เปิด Auto/หลุดแล้วฟาร์มต่อ (`goAway`)/ปิดสวิตช์ · /admin แท็บปรับสมดุล การ์ด "Auto Play": สวิตช์ "เดินต่อเมื่อสลับแท็บ" (`Balance.walkHidden` ค่าในโค้ด เปิด เก็บเฉพาะที่ต่าง ลง audit) ปิด = สลับแท็บแล้วตัวหยุดแบบเดิม · เทสต์ `tests/walk-hidden-server.test.ts`
- **ผังแมพชั้น 1 เป็นข้อมูล JSON ไม่ใช่โค้ดสุ่ม:** ตำแหน่งบ้าน ของประดับ NPC ประตู จุดเกิดมอน และเขตเดินได้ของเมืองกลางกับฟาร์มทั้ง 4 ขยับได้ในแท็บ "แมพ" ของ `/admin` ไม่ต้องแก้โค้ด รายละเอียด (รูปแบบ JSON, เผยแพร่/ย้อนกลับ, สิทธิ์, ข้อจำกัด) อยู่ใน [map-editor.md](map-editor.md)

## Auto Play และการแบ่งของ

- Auto Play ปิดเองเมื่อผู้เล่นเดินเอง แต่กดโจมตีหรือสกิลเองได้โดย Auto ยังเปิดอยู่
  - server เป็นคนเล่น Auto (`src/shared/sim/autoplay.ts`) จึงฟาร์มต่อได้แม้สลับแท็บ
- **Auto ฟาร์มต่อหลังหลุดการเชื่อมต่อ** (เจ้าของตกลง 2026-11-17, `goAway`/`sweepAway` ใน `server/world.ts`)
  - หลุด (ไม่ได้กดออกเกม) ขณะเปิด Auto → ตัวละครอยู่ในโลกต่อ Auto ฟาร์มเหมือนปกติทุกอย่าง (EXP 50% เท่า Auto ปกติ ดรอปปกติ ส่วนแบ่งปาร์ตี้ปกติ) ได้นานสุด **30 นาที** (ค่าในโค้ด)
  - **ปิดแท็บ/ปิดเบราว์เซอร์/รีโหลดหน้า = ออกจากโลกทันที ไม่ฟาร์มต่อ** (เจ้าของตกลง 2026-11-17) · เบราว์เซอร์ส่ง close code `WS_CLOSE_PAGE_GONE` (4001) ตอน `pagehide` · ยังนับเป็นหลุดแบบเดิม (ที่ในปาร์ตี้/จุดเดิมเก็บ 60 วิ เปิดกลับภายใน 60 วิ = จุดเดิม Auto เปิดต่อ) · log `left: page closed (tab closed / reload)` · ปิดแอปมือถือทิ้งโดยไม่ได้ปิดแท็บ เบราว์เซอร์อาจไม่ส่งอะไร = นับเป็นหลุดธรรมดา (ฟาร์มต่อ)
  - **ไม่รวม Guest** (กันบอทฟาร์มด้วยบัญชี Guest): Guest หลุด = ออกจากโลกทันทีเหมือนเดิม · ไม่รวมตอนอยู่ห้องบอส ตอนตาย และตอน server กำลังนับถอยหลังปิด
  - จบเมื่อ: ครบเวลา · Auto หยุดเอง (ยาหมด/กระเป๋าเต็มตามตัวเลือกของผู้เล่น, เข้าเขตเมือง, บอส) · ม้วนกลับเมือง (รอร่ายจบถึงเมืองก่อน) · ตาย · เจ้าของปิดสวิตช์ → เซฟแล้วออกจากโลก (แล้วนับเป็นหลุดตามปกติ: ที่ในปาร์ตี้และจุดเดิมเก็บต่ออีก 60 วิ)
  - ระหว่างนั้น: เทรดที่ค้างถูกยกเลิกตอนหลุด ขอเทรดด้วยไม่ได้ ไม่ถูกเชิญ/ดึงเข้าห้องบอส · เซฟตอนหลุดและทุกรอบเซฟอัตโนมัติ · server ปิด = เซฟทุกคนเหมือนเดิม · นับเป็นคนออนไลน์ (อยู่ในโลก) · `/admin` แท็บออนไลน์มีป้าย "หลุด · Auto" · ปาร์ตี้เห็นเป็นออนไลน์ + "หลุด · Auto"
  - เข้าเกมตัวเดิมอีกครั้ง (เชื่อมต่อใหม่เอง หรือล็อกอินใหม่) = ได้ตัวที่กำลังฟาร์มคืน ที่จุดเดิม Auto ยังเปิด ไม่มีตัวซ้ำในโลก (ทางเดียวกับ takeover)
  - กลับมาภายใน 60 วิ (`CH_RECONNECT_MS`) หลังหลุดแบบไหนก็ได้ ถ้าตอนหลุด Auto เปิดอยู่ = Auto เปิดต่อ (Guest ด้วย) · server บอกเบราว์เซอร์ใน `welcome.auto`
  - /admin แท็บปรับสมดุล → การ์ด "Auto Play": สวิตช์ "Auto ฟาร์มต่อหลังหลุดการเชื่อมต่อ" + จำนวนนาที (1–240, ค่าในโค้ด 30) เก็บใน `BalanceTuning.auto.offline/offlineMin` เฉพาะที่ต่างจากโค้ด ลง audit
- **เชื่อมต่อใหม่เอง** (2026-11-17, `src/client/net/online.ts`): หลุดแล้วเบราว์เซอร์ต่อใหม่เองหลังรอ 1, 2, 4, 8, 15, 15, 15 วิ (รวมราว 1 นาที) ขึ้นป้าย "กำลังเชื่อมต่อใหม่…" เกมยังอยู่บนจอ · กลับมาที่จอ/เน็ตกลับมา = ลองทันที · ไม่ได้ข้อความจาก server เลย 15 วิขณะเปิดจออยู่ = ถือว่าหลุด (socket ค้าง) · ไม่ลองใหม่ถ้าโดนเตะ (เข้าจากที่อื่น แบน server ปิด/รีสตาร์ท: server ส่งข้อความ kick ก่อนปิดทุกครั้ง) · ลองครบไม่สำเร็จขณะเปิดจอ = หน้าจอ "หลุดการเชื่อมต่อ" + ปุ่มเดิม · ขณะแท็บซ่อน (มือถือปิดจอ) ไม่ยอมแพ้ ลองทุก 15 วิไปเรื่อย ๆ กลับมาที่จอ = เริ่มนับใหม่
- **ไม่มีมอนในวง = กลับไปยืนรอที่จุดที่กด Auto** (เจ้าของสั่ง 2026-11-19, `homePoint` ใน `autoplay.ts`): เดิมวิ่งไปรอที่จุดเกิดมอนในวง → ตอนนี้เดินกลับ `anchor` (จุดแรกที่กด Auto) แล้ว **ยืนนิ่ง** (ไม่เดินวน) มอนเกิดในวงเมื่อไหร่ค่อยไปตีตามเดิม · ถึงจุดภายใน 1 หน่วยแล้วยืนนิ่ง เดินกลับก็ต่อเมื่อห่างเกิน 2.5 (กันสั่นไปมา) · จุดที่ใช้ไม่ได้ (ในห้องบอส/ลาวา) หรือเดินไปไม่ใกล้ขึ้นเลย 3 วิ (ติดกำแพง) = ยืนรอที่เดิม · ข้อความ "รอมอนเกิด" (IDLE_HINT) ทำงานเหมือนเดิม · ใช้ได้ทั้งตอนเล่นปกติและตอนหลุดฟาร์มต่อ (รันใน Sim บน server ทางเดียวกัน) · /admin แท็บปรับสมดุล การ์ด "Auto Play": สวิตช์ "ไม่มีมอนในวง = กลับไปรอที่จุดกด Auto" (`BalanceTuning.auto.homeWait` ค่าในโค้ด เปิด เก็บเฉพาะที่ต่าง ลง audit มีผลทันที) ปิด = แบบเดิม (วิ่งไปรอจุดเกิดมอนในวง) · เทสต์ `tests/auto-home.test.ts`
- **ตัวเลือก Auto** (เจ้าของตกลง 2026-11-13, `AutoSettings` ใน `src/shared/sim/Player.ts`, AI ใน `autoplay.ts`) · ตัวเลือกที่ผู้เล่นยังไม่เคยเปลี่ยนเอง ใช้ค่าเริ่มต้นจาก /admin เสมอ (เจ้าของเปลี่ยนค่าเริ่มต้น = มีผลทันทีแม้คนที่ออนไลน์) · ช่องไหนผู้เล่นเปลี่ยนเอง จำเป็นของตัวละคร (`AutoSettings.optsSet`)
  - **ลำดับเก็บของ:** ตีก่อน *(ค่าเริ่มต้น)* = มีมอนที่เล็งเราอยู่ (`target` = เรา ไม่สนระยะ) ตีให้หมดก่อน แล้วเก็บของในวงก่อนหามอนตัวใหม่ · สมดุล (แบบเดิม) = ของใกล้ตัว (5) เก็บแม้มีมอนดุร้ายใกล้ (3.5) ของไกลเก็บตอนไม่มี · เก็บของก่อน = เห็นของในวงไปเก็บทันที
  - **ของคนอื่น:** เก็บของคนอื่นด้วย *(ค่าเริ่มต้น)* / เก็บเฉพาะของตัวเอง (ของเรา + ปาร์ตี้ + ของไม่มีเจ้าของ) · ทั้งสองแบบไม่ไปของที่ยังติดสิทธิ์ 10 วิของคนอื่น (`canTake`)
  - **ข้ามของที่เก็บไม่ได้:** เดินไปหาของชิ้นเดิมแล้วไม่เข้าใกล้ขึ้น (≥0.25) นาน 4 วิ = เลิกสนใจชิ้นนั้นถาวร (กันวนค้างที่ของติดสิ่งกีดขวาง/เก็บไม่ได้)
  - **ยา HP หมด / ยา MP หมด / กระเป๋าเต็ม** (ตั้งแยก): สู้ต่อ *(ค่าเริ่มต้น)* / หยุด Auto / ม้วนกลับเมือง (รอจนไม่มีมอนเล็งเราก่อนค่อยร่าย แล้วปิด Auto · ไม่มีม้วน = หยุด Auto) · ข้อความบอกเหตุผลทุกครั้ง
  - **เป้าหมาย:** ตัวที่ตีเราก่อน *(ค่าเริ่มต้น)* = มอนที่เล็งเรามาก่อน (มีตัวใหม่มาตีระหว่างเดินไปหาตัวอื่น = เปลี่ยนเป้าทันที) แล้วตัวใกล้สุด · ใกล้สุด = ใกล้สุดอย่างเดียว
  - **มอนที่ไม่ตี:** ติ๊กออกรายชนิดจากรายชื่อมอนของแมพที่อยู่ (ชนิดจากแมพอื่นยังจำไว้) ถ้ามันตีเราก่อนจะตีกลับเสมอ
  - **/admin แท็บปรับสมดุล → การ์ด "Auto Play"** (สิทธิ์ `balance`, เก็บใน `BalanceTuning.auto` เฉพาะที่ต่างจากโค้ด, `src/shared/autoTuning.ts`): ค่าเริ่มต้นทุกตัวเลือก · เวลาข้ามของ (1–30 วิ) · ระยะของใกล้ตัว/ระยะนับว่าโดนตีของแบบสมดุล · สวิตช์ทั้งเซิร์ฟ 4 ตัว ปิดแล้วผู้เล่นเลือกไม่ได้ (ขึ้น "ปิดโดยผู้ดูแล") และ Auto ใช้แบบปลอดภัยแทน: เก็บของก่อน→สมดุล, ของคนอื่น→ของตัวเอง, ม้วน→หยุด Auto, มอนที่ไม่ตี→ตีทุกชนิด (ค่าที่ผู้เล่นเลือกยังจำไว้ เปิดสวิตช์คืนแล้วใช้ได้อีก)
- แบ่ง EXP ตามสัดส่วนดาเมจ, คนที่ทำดาเมจมากสุดมีสิทธิ์เก็บของก่อน 10 วินาที · อยู่ปาร์ตี้: สิทธิ์เก็บของแชร์ทั้งปาร์ตี้ และ EXP แบ่งต่ออีกชั้น ([party.md](party.md))
- EXP ต่อเลเวล (`expToNext` ใน `src/shared/formulas.ts`): สูตรฐาน `floor(30 × Lv^2.1) + 40` แล้วคูณตามช่วง Lv 1–9 ×1 · Lv 10–19 ×2 · Lv 20–29 ×2.5 · Lv 30+ ×3 (เจ้าของตั้ง 2026-11-08) · คูณเพิ่มอีกชั้น (เจ้าของตั้ง 2026-11-09, `expRampMult`): Lv ≤19 ×1 · Lv 20→30 ไล่ขึ้นเส้นตรง ×1→×2 · Lv 30→49 ×2→×3 แล้วขึ้นต่อด้วยความชันเดิม (สูตร `l<20 ? 1 : l<=30 ? 1+(l-20)/10 : 2+(l-30)/19`, ราว ×4.6 ที่ Lv79) รวมทั้งเกมราว ×2.4 · ตายเสีย 10% ของ EXP เลเวลถัดไป
- **เพดานเลเวล 80** (เจ้าของ 2026-11-19, `MAX_LEVEL` ใน `formulas.ts` เดิม 50) สำหรับชั้น 2 · โค้ง EXP Lv50–80 ใช้สูตรเดิมต่อ (Lv50 ≈1.02 ล้าน, 60 ≈1.75 ล้าน, 70 ≈2.77 ล้าน, 79 ≈3.98 ล้าน) · /admin แท็บปรับสมดุล การ์ด "EXP ที่ต้องใช้อัปเลเวล": ตัวคูณต่อช่วง 10 เลเวล (ตาม `TIER_BANDS`) ×0.1–×10 ค่าในโค้ด ×1 (`BalanceTuning.expMult`, `setExpTune`) มีผลทันทีทั้ง server และหลอด EXP ในเบราว์เซอร์ ลง audit
- **Auto กดสกิลเมื่อสกิลนั้นถึงจริงเท่านั้น ทุกอาชีพ** (นักเวทวงรอบตัว เจ้าของ 2026-11-19 · ขยายทุกอาชีพทุกชนิดสกิล 2026-11-20 หลังเจ้าของเห็น Auto กดสกิลทันทีที่ตีธรรมดาถึงแล้วสกิลไม่โดน, `AutoPlay.inReach` ใน `autoplay.ts`): เช็คแบบเดียวกับที่สกิลตีจริง (ระยะสกิลตามที่ปรับใน /admin `skillReach` + ขนาดตัวมอน `radius` **− ระยะเผื่อพลาด**) · ระยะเผื่อ**หักออก**จากระยะสกิล (เจ้าของ 2026-11-20: เดิมบวกเพิ่ม ทำให้คลื่นเพลิงกดตอนมอนอยู่นอกกรวยไม่เกิน 0.5 ม. แล้ววืด เจอบ่อยกับมอนที่ยืนห่าง/โดนผลักออก)
  - วงรอบตัว (`self`) ที่มีดาเมจ = มีมอนตัวไหนก็ได้อยู่ในวง · ฟันด้านหน้า (`cone`) / พุ่ง (`dash`) = เป้าอยู่ในระยะ · ยิง (`shot`) = เป้าอยู่ในระยะ + วงระเบิดปลายทาง (ถ้ามี) · ตกที่จุด (`point`) = เป้าอยู่ในระยะร่าย + วงตก
  - บัฟ/สกิลวงรอบตัวที่ดาเมจ 0 (เช่น โล่มานาหมู่ ตะโกนศึก) และสกิลที่ไม่มีระยะ = กดตามเดิม

  - Auto ไม่เล็งบอสตัวจริงอยู่แล้ว (`pickTarget` ข้าม `isBoss`, ในลานบอส/ห้องบอสปิด Auto) กติกานี้จึงมีผลกับมอนธรรมดาทุกตัว โดยเฉพาะตัวใหญ่

  - ชั้น 2 (เจ้าของ 2026-11-19): 50 ปูยักษ์กระดองปืนใหญ่ (`cannon_crab`) / 60 กัปตันขาไม้ (`pegleg_captain`) / 70 กัปตันผีเรือคนตาย (`ghost_captain`) / 80 คราเคน (`kraken`) · **ประตูที่บอสยังไม่มีใน `MONSTERS` ไม่บล็อก** (เจ้าของเลือก) ตัว Lv50 จึงเลเวลต่อได้จนกว่า PR แมพจะเพิ่มบอสด้วย id นี้ แล้วประตูทำงานเอง · ใครเลเวลเกินประตูไปก่อนนับว่าผ่านแล้ว (`gatesPassedBy`) · ประตู 80 = เพดาน ไว้รองรับถ้าขยายเพดานอีก

## หยุดตอนโจมตี (เจ้าของตกลง 2026-11-18)

วิ่งแล้วโจมตีเคยดู "สไลด์" (ดาบไม่มีท่า `run_attack` ส่วนปืน/เวทมีแต่ก็ยังแปลก) จึงให้ **ทุกอาชีพหยุดกับที่สั้น ๆ ระหว่างท่าโจมตี แล้วค่อยวิ่งต่อ**

- ใช้กับ **ตีธรรมดา + สกิลที่ไม่ใช่ท่าเคลื่อนที่** ระหว่างหยุด: ไม่เดิน แต่ยังหันตามเมาส์/เป้าได้ · กดเดินค้าง/คลิกจุดเดินไว้ = หยุดครบแล้ววิ่งต่อเอง (จุดที่คลิกไม่หาย) · ไม่เปลี่ยนคูลดาวน์ ดาเมจ ความเร็วโจมตี
- **ไม่หยุด** (`NO_ATTACK_ROOT` ใน `src/shared/attackRootTuning.ts`): ท่าพุ่ง/กระโดดถอย/หายตัว (พุ่งชน ไล่ล่า ถอยฟัน หมุนตัวหลบ ระบำดาบ ก้าวเงา เงาสลับร่าง พันคมดาบ ยิงสวนกลับ) และบัฟ/ตะโกน (เร่งเครื่อง ตั้งรับ เกราะสะท้อน ปักหลัก ปลุกใจนักรบ ยั่วยุ ราชันย์ไม่ล้ม บัฟกระสุนทุกตัวของมือปืน โฟกัสสไนเปอร์ สนามเร่งอาคม โล่มานาหมู่ วงคืนพลัง) · สกิลที่ยืนเล็ง/ชาร์จเองอยู่แล้ว (ยิงหัว ยิงประณีต รางแม่เหล็ก เวทชาร์จ ปลดปล่อยพลัง) ใช้เวลาของสกิลนั้น · ทุบทำลาย (`sw_crush`) ชื่อว่ากระโดดแต่ตัวไม่ขยับจริง จึง **หยุด** เหมือนสกิลฟันทั่วไป
- **แดชระหว่างหยุดได้** และยกเลิกการหยุดทันที
- เวลาหยุด: ตีธรรมดา = ค่าต่ออาชีพ แต่ไม่นานกว่าท่าโจมตี (`min(0.5, 0.95 ÷ ความเร็วตี)`) ตีเร็วขึ้นหยุดสั้นลงเอง · สกิล = ค่าตีธรรมดาของอาชีพ × ตัวคูณสกิล
- ค่าในโค้ด: เปิดทั้ง 3 อาชีพ · ดาบ 0.45 วิ เวท 0.4 ปืน 0.3 (ใกล้ความยาวท่าตอนความเร็วตีพื้นฐาน: ดาบ/เวท ~0.5 ปืน ~0.37) · ตัวคูณสกิล ×1 · ปรับใน /admin แท็บปรับสมดุล การ์ด **"หยุดตอนโจมตี"** (สวิตช์ต่ออาชีพ, วิ 0–1, ตัวคูณ 0–3, เก็บเฉพาะที่ต่างจากโค้ด, ลง audit, มีผลทันที)
- **Sim ตัดสิน** (`Player.atkRootT` ไม่เซฟ): ไม่เดินตาม `move`/`moveTo` (รวม Auto Play) · ตำแหน่งที่เบราว์เซอร์ส่งมารับเฉพาะที่ห่างจุดเริ่มหยุดไม่เกิน 0.45 ม. (เผื่อ server หยุดช้ากว่าเบราว์เซอร์ราว ½ ping) · ไม่นับเป็น `serverMoves` (เบราว์เซอร์ยังเดินเอง)
- **เบราว์เซอร์ทำนาย** (`src/client/net/online.ts` `predictAttackRoot`): หยุดตอนส่งปุ่มโจมตี/สกิลที่ server จะใช้ได้จริง (ตีธรรมดาตามตัวนับของตัวเอง, สกิลที่คูลดาวน์พร้อม MP พอ, ไม่ใช่ในเมือง) ทายผิดฝั่งหยุดเกินดีกว่าเดินเลย · ระหว่างหยุดตัวเราไม่ขยับ → เล่นท่าตีแบบยืน ไม่ใช่ `run_attack`

## ท่าตัวละครต่อทิศ (เจ้าของตกลง 2026-11-18)

เจ้าของเห็นว่าวิ่งแล้วดูแปลกในบางทิศ จึงมีแท็บ **/admin → หน้าตา → "ท่าตัวละคร"** (`src/client/animPreview.ts`) ดูท่าทุกทิศพร้อมกันแล้วปรับค่าต่อทิศ

- **ดู:** เลือกอาชีพ (ดาบ ปืน เวท) ภาพ (ภาพเดิม / ภาพกระดาษ / นักดาบกระดูก เฉพาะดาบ) และท่าที่ชุดภาพนั้นมี (ยืน วิ่ง โจมตีขณะวิ่ง โจมตี 1–3 คอมโบ ตาย ขี่สัตว์ ขี่บอร์ด) → เห็นครบ **8 ทิศ** ในตาราง 3×3 วาดด้วยตัววาดจริงของเกม (`AnimatedActor` / `RigActor`) · พื้นเลื่อนสวนเท้าตาม "ความเร็วเคลื่อนที่" + เส้นแนววิ่ง · จังหวะก้าวคิดแบบเดียวกับในเกม (`strideRate` ใน `AnimatedActor.ts`: ความเร็ว ÷ 5 จำกัด ×0.6–×1.6) · สโลว์ หยุด ทีละเฟรม · ป้ายแต่ละช่องบอกแถวภาพที่ใช้ พลิกไหม เฟรมที่เท่าไร และค่าที่ปรับ
- **สาเหตุที่พบ:** (1) กล้องเอียง ~46° วิ่งขึ้น/ลงบนจอเห็นระยะแค่ ×0.72 ของวิ่งด้านข้าง (ทแยง ×0.87) แต่ขาก้าวเร็วเท่ากันทุกทิศ เท้าจึงไถล (2) ภาพมีแค่ 5 แถว (หน้า ทแยงหน้า ข้าง ทแยงหลัง หลัง) ทิศขวาใช้ภาพทิศซ้ายพลิก อาวุธจึงสลับมือ
- **ค่าที่ปรับได้** แยกต่อ **อาชีพ × ภาพ (เดิม/กระดาษ/กระดูก แยกกัน) × ท่า × 8 ทิศบนจอ** (`src/shared/animTuning.ts`): แถวภาพ (อัตโนมัติ/เลือกแถว) · พลิก (อัตโนมัติ/พลิก/ไม่พลิก) · ความเร็ว ×0.25–×3 (ท่าวิ่ง = คูณจังหวะก้าว, ท่าอื่น = คูณ fps; ท่าโจมตีเร็ว/ช้าแค่ภาพ จังหวะตีจริงเท่าเดิม) · เลื่อนขวา/ขึ้น ±1 หน่วย · ขนาด ×0.5–×2 (รอบเท้า) · **นักดาบกระดูกปรับได้แค่ความเร็ว** (ท่าตาย/ขี่ของมันใช้ภาพนักดาบตามสวิตช์ภาพกระดาษของเซิร์ฟ ค่าอยู่ที่ "ภาพเดิม"/"ภาพกระดาษ")
- ปุ่มช่วย: ล้างทิศนี้ · ใช้ค่าทิศนี้กับทุกท่า · ตั้งความเร็วก้าวตามมุมกล้อง (ทุกทิศ ทุกท่าที่เคลื่อนที่ของอาชีพ+ภาพนั้นพร้อมกัน: วิ่ง โจมตีขณะวิ่ง ขี่ — วิ่งกับโจมตีขณะวิ่งใช้ก้าวเดียวกันจึงควรเท่ากัน · ขึ้นลง ×0.72 ทแยง ×0.87 ข้าง ×1) — **ค่าในโค้ดยังเป็น ×1 ทุกทิศ** จนกว่าเจ้าของจะกดแล้วบันทึก
- **สิทธิ์:** ดู/ทดลอง = สวิตช์ `animPreview` (owner + GM) ลองแล้วเห็นเฉพาะหน้านั้น · บันทึกทั้งเซิร์ฟ / คืนค่าเริ่มต้นทั้งหมด = สวิตช์ `animTune` (owner เท่านั้น) · API `GET/POST /api/admin/anim-look`
- เก็บใน settings key `anim_tuning` **เฉพาะค่าที่ต่างจากโค้ด** (ไม่มี = ตามโค้ด) · ลง `admin_audit` action `anim-look` เป็นข้อความไทย (ก่อน → หลัง ต่อท่า/ทิศ) · ส่งให้ทุกคนทาง `welcome.animTuning` และข้อความ `animTuning` ตอนบันทึก **มีผลทันที** ไม่ต้องรีเฟรช (อ่านทุกเฟรมใน `AnimatedActor.applyUV` / `RigActor`) · ค่าที่โค้ดไม่รู้จักแล้ว (ท่า/อาชีพที่ลบ) ถูกข้ามตอนอ่าน
- เทสต์: `tests/anim-look.test.ts`

## จัดเมนูเกม (เจ้าของสั่ง 2026-11-19)

ปุ่มในหน้าต่าง "เมนู" และแถวไอคอนมุมขวาบนตั้งได้จาก `/admin` → ปรับเกม → **"จัดเมนูเกม"** (`src/admin/menuLayout.ts`)

- **กติกา**: ปุ่ม "ตั้งค่า" **อยู่ท้ายสุดของหน้าต่างเมนูเสมอ** (เดิม "เต็มจอ" อยู่หลัง) · ปุ่ม "เมนู" อยู่ท้ายแถวมุมขวาบนเสมอ · ปุ่ม AUTO เปิด/ปิดต้องมีในแถวมุมขวาบน · ทั้งสามตัวซ่อน/ย้ายออกไม่ได้ (server ปฏิเสธ) เพื่อไม่ให้ผู้เล่นเปิดเมนู/ตั้งค่า (ออกจากเกม เปลี่ยนตัวละคร) ไม่ได้
- ตั้งได้ต่อที่ (รายการลำดับของแต่ละที่): ลากเรียง (หรือปุ่ม ↑↓ สำหรับมือถือ) · ✕ ซ่อนจากที่นั้น · ⇄ ย้ายไปอีกที่ · "+" ใส่ปุ่มที่ยังไม่แสดง · ปุ่มเดียวอยู่ได้ทั้งสองที่ (เหมือนค่าในโค้ดที่กระเป๋า/สกิล/ปาร์ตี้ ฯลฯ อยู่ทั้งสองที่)
- ย้ายไม่ได้ (ล็อกที่เดียว): AUTO (โชว์สถานะ ON/OFF → แถวบนเท่านั้น), เมนู (แถวบน), ตั้งค่า (หน้าต่างเมนู), เต็มจอ (ใช้เฉพาะจอสัมผัส → หน้าต่างเมนูเท่านั้น)
- **จอสัมผัส**ไม่มีแถวมุมขวาบน (CSS ซ่อนทั้งแถว) → ปุ่มที่ใส่ไว้แถวบนแต่ไม่อยู่ในหน้าต่างเมนูจะโผล่ในหน้าต่างเมนูเอง (ก่อนปุ่มตั้งค่า) · ยกเว้น "แจ้งปัญหา" ที่ค่าในโค้ดอยู่แถวบนอย่างเดียวมาตลอด (จอสัมผัสไม่เคยมี) คงเดิม
- ป้ายแจ้งเตือน (เลขแดงสกิล จุดแดงจดหมาย ฯลฯ) ตามปุ่มไปทุกที่ (กุญแจป้าย = ชื่อไทยของปุ่มในหน้าต่างเมนู) · ไอคอนเมนูรวมเลขเฉพาะปุ่มที่อยู่ในหน้าต่างเมนู · คีย์ลัดไม่ผูกกับปุ่ม ทำงานเหมือนเดิม · ปุ่ม "กราฟิก" ยังซ่อนตามสวิตช์ `gfxMenu` เดิม
- เก็บใน `BalanceTuning.menuLayout` = `{ menu?: string[], top?: string[] }` เฉพาะรายการที่ต่างจากโค้ด (รายการเต็ม ลำดับ = ลำดับแสดง ไม่มีใน list = ไม่แสดงที่นั่น) · `src/shared/menuLayout.ts` (รายการปุ่ม ชื่อ ข้อจำกัด `checkMenuLayoutTuning`) · ปุ่มใหม่ที่เพิ่มในโค้ดภายหลังจะไม่โผล่ในที่ที่เจ้าของเคยจัดไว้แล้ว ต้องกด "+" เอง
- มีผลกับผู้เล่นที่ออนไลน์ทันที (ผ่านข้อความ `balance` เดิม client วาดเมนูใหม่เอง) · คืนค่าในโค้ด = ปุ่ม "คืนค่าในโค้ดทั้งหมด"
- สิทธิ์: `menuLayout` (ดู owner+GM) · `menuLayoutEdit` (บันทึก owner เท่านั้น) — **ค่าเริ่มต้นที่เลือกเองตามแบบแท็บอื่น ยังไม่ได้ถามเจ้าของ** เปลี่ยนได้ในแท็บ "สิทธิ์" · API `GET/POST /api/admin/menu-layout` (`{ layout }` หรือ `{ reset: true }`) · ลง `admin_audit` action `menu-layout` · บันทึกของแท็บ "ปรับสมดุล" ไม่แตะค่านี้ (`withMenuLayout`)
- เทสต์: `tests/menu-layout.test.ts`

- ผู้เล่นส่งแชท → ขึ้นฟองข้อความเหนือหัวตัวละครนั้น (เหนือป้ายชื่อ) ให้ทุกคนที่เห็นตัวละครนั้น และคนส่งเห็นฟองของตัวเองด้วย (`Floating.bubble` ใน `src/client/floating.ts`, เรียกจาก `backend.onChat` ใน `src/main.ts`)
- จับคู่ตัวละครด้วย**ชื่อ** (ไม่ได้เพิ่ม id ใน protocol) · แชททั้งเซิร์ฟเวอร์ = ฟองขาว · แชทปาร์ตี้ = ฟองน้ำเงิน (`#3a7bd5` ใหม่ ไม่ตรงกับบรรทัดปาร์ตี้ในกล่องแชทที่เป็นสีเขียว `#5dff8a`) · แชทปาร์ตี้ server ส่งให้เฉพาะสมาชิก จึงเห็นเฉพาะในปาร์ตี้
- แสดง 5 วินาทีแล้วหาย (`BUBBLE_MS`) · ข้อความใหม่จากคนเดิมแทนฟองเก่า · ข้อความยาวตัดบรรทัด กว้างสุด ~200px (ไม่ตัดข้อความ)
- ตัวละครอยู่นอกจอ คนละแมพ หรือไม่อยู่ในรายชื่อผู้เล่นของแมพนี้ = ไม่แสดงฟอง · ข้อความ server (ไม่มีชื่อ) ไม่มีฟอง · ใช้ `textContent` เท่านั้น
- หน้าตาเป็น CSS ธรรมดา (`.chat-bubble`) รอเพื่อนวาดภาพทีหลัง

## ป้ายจำนวนคนมุมซ้ายบน (เจ้าของตกลง 2026-11-12)

- ทุกคนเห็น `🌐 ในแมพนี้ N คน · กด Enter เพื่อแชท` (สีฟ้า) นับเฉพาะคนในแมพ + CH เดียวกัน (ห้องบอส = ในห้อง) รวมตัวเอง
- บรรทัดที่สอง `🛡 ออนไลน์ทั้งหมด N คน` (สีทอง) เฉพาะ role `owner` และ `gm` · server ส่งตัวเลขทั้งเซิร์ฟ (`SnapshotMsg.online`) ให้เฉพาะสองตำแหน่งนี้ คนอื่นไม่ได้รับเลย
- เช็ค role ตอนเข้าเกม: ให้/ถอน GM ระหว่างเล่น มีผลเมื่อเข้าเกมครั้งถัดไป
- **มือถือ/iPad (โหมดสัมผัส):** แตะไอเทมในกระเป๋า ช่องที่สวมอยู่ หรือในคลัง เปิดหน้ารายละเอียดไอเทม (`openDetail` ใน `hud.ts`) มีข้อมูลเหมือน tooltip และปุ่มตามสถานการณ์: สวมใส่/ถอด, ใช้ยาหรือม้วน, แบ่งกอง, วางลงพื้น, ย้ายเข้ากระเป๋า และขาย/ฝากคลัง/ลงขายตลาด/วางที่ช่างตีเหล็ก/เสนอเทรด เมื่อเปิดหน้าต่างนั้นอยู่ · PC ใช้ hover/คลิก/คลิกขวาเหมือนเดิม · โหมดสัมผัสไม่แสดง tooltip เลย (iOS ไม่ส่งคลิกถ้าการแตะครั้งแรกทำให้หน้าเปลี่ยน) · กดค้าง 0.5 วินาทีในหน้าต่าง = คลิกขวา (`touch/device.ts`) เช่น ซื้อยาทั้งกอง เมนูแถวปาร์ตี้ ปักหมุดแผนที่

## ตั้งปุ่มเอง (เจ้าของ 2026-11-21)

- เมนู › ตั้งค่า › **ตั้งค่าปุ่ม**: ผู้เล่นย้ายปุ่มของ เดิน 4 ทิศ, สกิล Q/E/R, แดช, ยา HP/MP, Auto, ม้วนกลับเมือง, ขี่, กระเป๋า, หน้าต่างสกิล, แผนที่, ช่วยเหลือ, คุย, แชท ได้ (`src/client/keybinds.ts`, หน้าต่าง `src/client/keybindPanel.ts`)
- คลิกปุ่มของรายการแล้วกดปุ่มใหม่ (Esc = ยกเลิก) · ✕ = เอาปุ่มออก · **รีเซ็ตทั้งหมด** = กลับค่าเริ่มต้นทุกปุ่ม
- ตั้งซ้ำกับปุ่มที่อีกอย่างใช้อยู่ = อันเดิมกลายเป็นไม่มีปุ่ม + ขึ้นแจ้งเตือนปุ่มซ้ำในหน้าต่าง (ตั้งใหม่เองได้)
- เปลี่ยนไม่ได้: Esc, ปุ่มเมาส์, ปุ่มบนจอมือถือ · ลูกศรเดินได้เสมอ · ป้ายบนแถบสกิลเปลี่ยนตามปุ่มที่ตั้ง
- จำไว้ในเบราว์เซอร์เครื่องนั้น (localStorage `multiverse-keybinds`) ไม่ขึ้น server เปลี่ยนเครื่องต้องตั้งใหม่
- ทำงานโดยแปลงปุ่มที่กดจริงเป็นปุ่มเดิมของคำสั่งนั้นใน `Input` (`src/client/input.ts`) เกมส่วนอื่นไม่ต้องแก้ · เทสต์ `tests/keybinds.test.ts`
- /admin › ปรับสมดุล › การ์ด "เอฟเฟกต์สกิล (ชั้นเสริม)": สวิตช์ `fxLayer.keyRebind` "ให้ผู้เล่นตั้งปุ่มเอง" ปิด = ทุกคนใช้ปุ่มตามโค้ดและปุ่มในเมนูหาย (ค่าที่ผู้เล่นตั้งยังเก็บไว้)
- หน้าช่วยเหลือ (H) ยังเขียนปุ่มตามค่าเริ่มต้น
