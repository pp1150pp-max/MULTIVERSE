# เมือง แมพ ภาพ และหน้าต่าง UI

สรุปสั้นอยู่ใน [CLAUDE.md](../../CLAUDE.md)

## เมืองศูนย์กลางมิติ

- แมพกลาง **เมืองศูนย์กลางมิติ** (`nexus_city`, `ZONE_HUB` ใน `src/shared/data/zones.ts`) เป็นจุดเริ่มต้นของทุกคน: เข้าเกมที่เมืองเสมอ (ยกเว้นหลุดแล้วกลับภายใน 60 วิ = กลับแมพ/CH/จุดเดิม ดู [channels.md](channels.md)) ตายในแมพ 1–4 แล้วฟื้นที่เมือง NPC ทั้งหมดอยู่ที่เมือง · จุดเกิดในเมือง (เข้าเกม/ฟื้น) สุ่มรอบน้ำพุ ห่างจากกลาง 2.8–4.3 ไม่ให้ทุกคนเกิดทับกัน (`spawnPoint` ใน `Sim.ts`, เจ้าของตั้ง 2026-11-10)
  - เขตเมือง (`safe`) ห้ามต่อสู้ทั้งสองฝ่าย (ปุ่มหลบใช้ได้) มอนสเตอร์เข้าไม่ได้ และเปิด Auto Play ในเมืองไม่ได้ (ทุ่งรอบเมืองเปิดได้) server เป็นผู้บังคับ
  - ประตู 4 มุม ไม่จำกัดเลเวล: บน ป่ามรกต · ขวา หนองน้ำหมอก · ล่าง ดินแดนหิมะ · ซ้าย เกาะภูเขาไฟ แต่ละแมพหมุนผัง (`rotateZone`) ให้แคมป์และประตูกลับเมืองอยู่ฝั่งตรงข้ามกับที่เดินเข้า
  - ทุ่งแต่ละมุมใช้ธีมของแมพนั้น ผสมกันตรงรอยต่อ (`quadrants`, `themeAt`) มีมอนสเตอร์ตัวที่ 1 และ 2 ของแมพนั้น 8 และ 7 ตัว ยืนเดี่ยวหน้าประตู · ตัวเมืองเป็นซากเมืองมีกำแพงล้อม พื้นอิฐ (ภาพ `ruin_*`, `town_*`, `ground/brick.png` ถ้ายังไม่มีจะยืมภาพเก่าแทน)
  - การเดินชน (เจ้าของเลือก 2026-11-10): NPC ทึบเหมือนเดิม · ชนของกลมชิ้นเดียว (NPC น้ำพุ ต้นไม้) ไถลอ้อม (`Player.walkStep`) · มุมอับของ 2 ชิ้น/ขอบแมพ = หยุดนิ่ง ไม่สั่น · คลิกโดนของทึบ = เดินไปจุดยืนข้าง ๆ ที่ใกล้ที่สุด (`Terrain.standSpot`) · เดินไปจุดหมายแล้วตัวละครแทบไม่ขยับ 0.8 วิ = เลิกเดิน (`src/client/walkTo.ts`) · คุย NPC/พัก/เก็บของเสร็จ ล้างจุดหมายทันที

## Auto Play และการแบ่งของ

- Auto Play ปิดเองเมื่อผู้เล่นเดินเอง แต่กดโจมตีหรือสกิลเองได้โดย Auto ยังเปิดอยู่
  - server เป็นคนเล่น Auto (`src/shared/sim/autoplay.ts`) จึงฟาร์มต่อได้แม้สลับแท็บ
- แบ่ง EXP ตามสัดส่วนดาเมจ, คนที่ทำดาเมจมากสุดมีสิทธิ์เก็บของก่อน 10 วินาที · อยู่ปาร์ตี้: สิทธิ์เก็บของแชร์ทั้งปาร์ตี้ และ EXP แบ่งต่ออีกชั้น ([party.md](party.md))
- EXP ต่อเลเวล (`expToNext` ใน `src/shared/formulas.ts`): สูตรฐาน `floor(30 × Lv^2.1) + 40` แล้วคูณตามช่วง Lv 1–9 ×1 · Lv 10–19 ×2 · Lv 20–29 ×2.5 · Lv 30+ ×3 (เจ้าของตั้ง 2026-11-08) · คูณเพิ่มอีกชั้น (เจ้าของตั้ง 2026-11-09, `expRampMult`): Lv ≤19 ×1 · Lv 20→30 ไล่ขึ้นเส้นตรง ×1→×2 · Lv 30→49 ×2→×3 (สูตร `l<20 ? 1 : l<=30 ? 1+(l-20)/10 : 2+(l-30)/19`) รวมทั้งเกมราว ×2.4 · ตายเสีย 10% ของ EXP เลเวลถัดไป
- **Auto Play ได้ EXP 50%** (2026-11-09): ขณะ Auto เปิด (`Player.autoOn` ตั้งโดย server ทุก tick) EXP ทุกแหล่ง รวมส่วนแบ่งปาร์ตี้ ถูกคูณ 0.5 ปัดลง (`AUTO_EXP_MULT`) · หน้าต่างตั้งค่า Auto มีบรรทัดแจ้ง
- **ประตูบอส** (2026-11-09, `src/shared/data/bossGates.ts`): จะเลเวลเกิน 10/20/30/40 ต้องเคยฆ่าบอสของด่านนั้นอย่างน้อย 1 ครั้ง (หมี / แม่มดหนอง / เยติ / หัวใจภูเขาไฟ)
  - นับเป็นฆ่าบอส: ทุกคนที่อยู่ใน `damageBy` ของบอส + สมาชิกปาร์ตี้ที่ได้ EXP จากการฆ่านั้น
  - ติดประตู: EXP หยุดที่หลอดเต็ม ส่วนเกินหาย แจ้งในแชทครั้งเดียว + แถบ EXP เขียนว่าต้องลงบอสอะไร · ฆ่าบอสแล้วเลเวลอัพทันทีและเลเวลต่อได้ตามปกติ
  - เซฟ: `CharacterData.bossKills?: string[]` · เซฟเก่าไม่มีฟิลด์ → ประตูที่ต่ำกว่าเลเวลปัจจุบันนับว่าผ่านแล้ว (Lv.35 ผ่านหมี/แม่มด/เยติ แต่ต้องฆ่าหัวใจภูเขาไฟ) · ไม่ลดเลเวลใคร · Lv ตรงประตูพอดียังต้องฆ่าบอส
  - `/admin` ตั้งเลเวลได้ตามเดิม: ตั้งสูงขึ้นจะนับประตูที่ต่ำกว่าเลเวลนั้นว่าผ่าน (ไม่ได้ลบ bossKills เดิม) ตั้ง Lv ตรงประตูแล้วยังติด EXP เต็มจนกว่าจะฆ่าบอส
- ผู้เล่นที่เลเวลต่ำกว่าบอสเกิน 5 (ห่าง 6 ขึ้นไป) ทำดาเมจใส่บอสทุกตัวได้แค่ 10% (ลด 90%) ไม่บอกผู้เล่น ตัวเลขดาเมจที่ลอยขึ้นเป็นค่าหลังลดแล้ว (`BOSS_LEVEL_GAP`/`BOSS_UNDERLEVEL_MULT` ใน `src/shared/sim/Sim.ts`, เจ้าของตั้ง 2026-11-08)

## ภาพ

- ภาพในเกมเป็นสไตล์ 16-bit SNES มุม 2D isometric ระดับความละเอียดเดียวกับ Gunslinger สร้างด้วย ChatGPT (prompt อยู่ใน `art_templates/`) พื้นเป็นลายปูซ้ำที่ผสมกันด้วย shader ส่วนตำแหน่งถนน บ่อน้ำ และของตกแต่งคำนวณใน `src/client/world.ts`
- โลโก้เป็นภาพแยกทีละตัวอักษรใน `public/assets/sprites/ui/logo/` แล้วเรียงเป็นคำใน `index.html` ไม่เจนทั้งคำรวดเดียว
- หน้าโหลด (`src/client/loadingScreen.ts`): ภาพประกอบ 5 ภาพ (ไม่ใช่ isometric, prompt ใน `art_templates/loading/`) ครึ่งหนึ่งเป็นภาพคลาสตัวเอง อีกครึ่งสุ่มจากที่เหลือ + เคล็ดลับสุ่ม ขึ้นตอนเข้าเกม (เฉพาะตอนไฟล์ยังโหลดไม่เสร็จ) และทุกครั้งที่เปลี่ยนแมพ ค้าง **3 วินาที** แล้วจางหาย

## หน้าต่าง

- **เมนู Esc / ปุ่มเมนู** (`src/client/sysmenu.ts`) เป็นตารางไอคอน 3 คอลัมน์ ใส่เฉพาะระบบที่มีแล้ว: กระเป๋า ปาร์ตี้ แผนที่ ตั้งค่า Auto / เสียง วิธีเล่น ตั้งค่า (`MENU_ITEMS`) · ระบบใหม่ให้เพิ่มช่องเมื่อทำเสร็จ · ตลาด คลัง ช่างตีเหล็ก เปิดได้ที่ NPC เท่านั้น · badge แจ้งเตือนผู้เล่นบนไอคอน (`SystemMenu.setBadge`): 1 = จุดแดง, 2 ขึ้นไป = ตัวเลข, 0 = ไม่แสดง · ไอคอนเมนูมุมขวาบนแสดงยอดรวม · ตอนนี้ยังไม่มีระบบเรียกใช้
- **แถวไอคอนมุมขวาบน** (ติดทางซ้ายของมินิแมพ ชิดขอบบน): AUTO, กระเป๋า, ปาร์ตี้, จดหมาย, แผนที่, เมนู (เฉพาะที่ใช้บ่อย; ตั้งค่า Auto / เสียง / ตั้งค่า อยู่ในเมนู — เจ้าของตั้ง 2026-11-09 ไม่ให้ซ้ำ) · หน้าตั้งค่าในเมนูไม่มีปุ่มเสียง/วิธีเล่น (อยู่ในตารางเมนูแล้ว) · AUTO สลับ OFF/ON และเรืองเขียวตอนเปิด · ไอคอนเป็นภาพ `public/assets/sprites/ui/ico_*.png` ตัดจาก `art_templates/ui/raw/v2/ปุ่มเมนู.png` (prompt ใน `art_templates/ui/PROMPTS.md`) · เสียง ปาร์ตี้ จดหมาย ยังไม่มีภาพของตัวเอง ใช้ `ico_blank` + อีโมจิ (🔊, 👥, ✉) · ปุ่มแนวตั้งเดิมใต้มินิแมพซ่อนไว้ (ยังอยู่ใน DOM)
- ตั้งค่า = หน้าปุ่มแนวตั้ง: เสียง, HUD style, ปุ่มลัด / วิธีเล่น, ☐/☑ ไม่รับคำชวนปาร์ตี้, กลับไปเลือกตัวละคร, ออกจากระบบ (+ ข้อความ Guest), กลับเข้าเกม, ‹ กลับ · ออกตอนสู้ยังนับถอยหลัง 5 วินาทีเหมือนเดิม

- หน้าต่างที่เปิด/ปิดได้ (กระเป๋า, ปาร์ตี้, พ่อค้า, คลัง, ช่างตีเหล็ก, ตั้งค่า Auto, แผนที่, วิธีควบคุม, เมนู Esc, เสียง) ลากย้ายได้ที่แถบหัว (`src/client/dragwindow.ts`) ไม่จำตำแหน่ง: ปิดแล้วเปิดใหม่หรือดับเบิลคลิกแถบหัว = กลับที่เดิม · HUD และกล่องยืนยันลากไม่ได้ · กระเป๋าที่ลากแล้วอยู่ที่เดิมแม้เปิดร้าน/คลัง
- **ที่ประจำของหน้าต่าง** (เจ้าของตกลง 2026-11-13 · CSS ท้าย `src/style.css`): กระเป๋าชิดขวา · ปาร์ตี้/เพื่อน/จดหมายชิดซ้าย เรียงลงมาทีละ 28px ให้เห็นแถบหัวทุกอัน · ร้าน/คลัง/ช่างตีเหล็ก/ตลาดชิดซ้าย · ตั้งค่า Auto ใต้แถวไอคอนขวาบน · แผนที่ใหญ่ เมนู วิธีควบคุม และที่เหลือกลางจอ · โหมดหลอดแถบ (`.hud-bars`) เลื่อนลงให้พ้นหลอด HP/MP · จอเตี้ยหน้าต่างซ้ายสูงสุดเท่าจอและเลื่อนในตัว
- **สกินช่องควบคุม** (scrollbar, select, input, checkbox, radio, range): ตัวแปร `--ctl-*` ใน `:root` ท้าย `src/style.css` เปลี่ยนเป็นรูปได้ภายหลัง · ช่อง number ซ่อนลูกศร spin (พิมพ์เอา)

## มินิแมพและแผนที่ใหญ่

เจ้าของอนุมัติ 2026-11-10 (โค้ด: `drawMinimap` ใน `src/client/hud.ts`, `src/client/fullmap.ts`, `src/client/mapIcons.ts`)

- **ปุ่มบนมินิแมพ** (ขอบล่างขวา ทรงกลมสไตล์ 16-bit): 🔍 เปิดแผนที่ใหญ่ · + / − ซูมมินิแมพ 3 ระดับ (ไกล / ปกติ / ใกล้ = 1.8 / 2.6 / 3.8 px ต่อหน่วย) จำระดับใน `localStorage` (`multiverse-minimap-zoom`) · ทุกปุ่มมี tooltip ภาษาไทย · คลิกที่มินิแมพเองเปิดแผนที่ใหญ่เหมือนเดิม · ใต้มินิแมพมีที่ว่างสำหรับป้าย ping / ชื่อแมพ·CH
- **แผนที่ใหญ่ไม่ปิดเองหลังคลิกเดิน** ปิดได้ด้วย M, Esc หรือปุ่ม ✕ เท่านั้น
- **เส้นทาง + ธงปลายทาง** (`Game.mapRoute`): วาดทั้งบนมินิแมพและแผนที่ใหญ่ ส่วนที่เหลือของเส้นทางเท่านั้น หายเมื่อถึง/ถูกขวาง/เดินเอง/ตาย/เปลี่ยนแมพ ถ้าปลายทางอยู่นอกมินิแมพจะเป็นลูกศรที่ขอบ
- **หมุดของผู้เล่น** 1 อัน ต่อแมพ: คลิกขวาที่แผนที่ใหญ่เพื่อปัก (คลิกขวาที่อื่น = ย้าย) · คลิกขวาที่หมุดหรือกดปุ่ม "ลบหมุด" = ลบ · แสดงบนแผนที่ใหญ่ และบนมินิแมพ (นอกวงเป็นลูกศรที่ขอบ) · อยู่ฝั่ง client อย่างเดียว ไม่เซฟ ไม่ส่ง server และเริ่มใหม่เมื่อเข้าแมพใหม่
- **ลูกศรขอบมินิแมพ**: NPC ในเมืองและประตูวาปที่อยู่นอกวงมินิแมพ แสดงเป็นไอคอนเล็ก (ชุดเดียวกับแผนที่ใหญ่) ที่ขอบ พร้อมลูกศรทองชี้ทิศ (`drawEdgeMarker`)

## ฟองแชทเหนือหัว

- ผู้เล่นส่งแชท → ขึ้นฟองข้อความเหนือหัวตัวละครนั้น (เหนือป้ายชื่อ) ให้ทุกคนที่เห็นตัวละครนั้น และคนส่งเห็นฟองของตัวเองด้วย (`Floating.bubble` ใน `src/client/floating.ts`, เรียกจาก `backend.onChat` ใน `src/main.ts`)
- จับคู่ตัวละครด้วย**ชื่อ** (ไม่ได้เพิ่ม id ใน protocol) · แชททั้งเซิร์ฟเวอร์ = ฟองขาว · แชทปาร์ตี้ = ฟองน้ำเงิน (`#3a7bd5` ใหม่ ไม่ตรงกับบรรทัดปาร์ตี้ในกล่องแชทที่เป็นสีเขียว `#5dff8a`) · แชทปาร์ตี้ server ส่งให้เฉพาะสมาชิก จึงเห็นเฉพาะในปาร์ตี้
- แสดง 5 วินาทีแล้วหาย (`BUBBLE_MS`) · ข้อความใหม่จากคนเดิมแทนฟองเก่า · ข้อความยาวตัดบรรทัด กว้างสุด ~200px (ไม่ตัดข้อความ)
- ตัวละครอยู่นอกจอ คนละแมพ หรือไม่อยู่ในรายชื่อผู้เล่นของแมพนี้ = ไม่แสดงฟอง · ข้อความ server (ไม่มีชื่อ) ไม่มีฟอง · ใช้ `textContent` เท่านั้น
- หน้าตาเป็น CSS ธรรมดา (`.chat-bubble`) รอเพื่อนวาดภาพทีหลัง

## ป้ายจำนวนคนมุมซ้ายบน (เจ้าของตกลง 2026-11-12)

- ทุกคนเห็น `🌐 ในแมพนี้ N คน · กด Enter เพื่อแชท` (สีฟ้า) นับเฉพาะคนในแมพ + CH เดียวกัน (ห้องบอส = ในห้อง) รวมตัวเอง
- บรรทัดที่สอง `🛡 ออนไลน์ทั้งหมด N คน` (สีทอง) เฉพาะ role `owner` และ `gm` · server ส่งตัวเลขทั้งเซิร์ฟ (`SnapshotMsg.online`) ให้เฉพาะสองตำแหน่งนี้ คนอื่นไม่ได้รับเลย
- เช็ค role ตอนเข้าเกม: ให้/ถอน GM ระหว่างเล่น มีผลเมื่อเข้าเกมครั้งถัดไป
