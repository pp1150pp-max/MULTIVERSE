## เมืองศูนย์กลางมิติ

- **เมืองของชั้น (เจ้าของ 2026-11-19, แผนชั้น 2 ข้อ 4.3):** แต่ละแมพมีชั้น (`ZoneDef.floor` ไม่ใส่ = ชั้น 1) แต่ละชั้นมีเมืองของตัวเอง (`FLOOR_HUBS`, `hubOf`, `isHub` ใน `zones.ts`) ชั้นที่ยังไม่มีเมืองใช้ `nexus_city` แทน
  - ม้วนกลับเมือง ตายแล้วฟื้น และออกจากห้องบอส (กรณีไม่มีแท่นเรียกบอส) พาไปเมืองของชั้นที่ยืนอยู่ · log ม้วน "กลับ<ชื่อเมือง>" (ชั้น 1 = "กลับเมืองศูนย์กลางมิติ")
  - **เข้าเกมใหม่ไปเมืองของชั้นที่ออกล่าสุด** (แผนข้อ 12.3) ถ้าทางขึ้นชั้นนั้นปิดอยู่สำหรับตัวนั้นตอนนี้ (สวิตช์ปิด หรือยังไม่ทำเควส) ไปเกิดที่ `nexus_city` (`loginHub` ใน `src/shared/floors.ts`)
  - มอนในเมืองหาแมพบ้านจากเลเวล โดยข้ามทุกเมือง (`isHub`)
- **ประตูที่ต้องทำเควส (แผนข้อ 4.2):** `PortalDef.requires` = ชื่อสิ่งที่ปลดแล้ว เช่น `floorUnlock(2)` = `'floor2'` เก็บใน `CharacterData.unlocks` (ไม่มี = ยังไม่ปลด เซฟเก่าใช้ได้) เช็กต่อจากเลเวลขั้นต่ำ (`portalLock`) · ยังไม่ปลด = ข้อความ "ไปคุยกับนักเดินเรือแห่งมิติก่อน" · การ์ด "ทางขึ้นชั้น 2" แท็บปรับสมดุลใน /admin มี 2 สวิตช์: `floorGateOpen` ปิด = ทางขึ้นปิดทุกคน (**ค่าในโค้ดปิด** เจ้าของ 2026-11-24: ชั้น 2 เข้า main แต่ยังไม่เปิดให้ผู้เล่น ปิดอยู่ = นักเดินเรือไม่ให้รับ/ส่งเควส ไม่พาขึ้น เข้าเกมใหม่ไป nexus_city · แอดมินเข้าด้วยปุ่มย้ายตัวละครในหน้าบัญชี /admin (สิทธิ์ teleport) · เจ้าของเปิดเองในการ์ดนี้เมื่อพร้อม) · `floorGateQuest` ปิด = ไม่ต้องทำเควส (ยังต้องถึงเลเวล, ค่าในโค้ดเปิด) · ตอนนี้ยังไม่มีประตูไหนใช้ `requires` (ทางขึ้นชั้น 2 เป็น NPC ดูหัวข้อ "ท่าเรือมิติ")

## Auto Play และการแบ่งของ

- Auto Play ปิดเองเมื่อผู้เล่นเดินเอง แต่กดโจมตีหรือสกิลเองได้โดย Auto ยังเปิดอยู่
  - server เป็นคนเล่น Auto (`src/shared/sim/autoplay.ts`) จึงฟาร์มต่อได้แม้สลับแท็บ
- **Auto ฟาร์มต่อหลังหลุดการเชื่อมต่อ** (เจ้าของตกลง 2026-11-17, `goAway`/`sweepAway` ใน `server/world.ts`)
  - หลุด (ไม่ได้กดออกเกม) ขณะเปิด Auto → ตัวละครอยู่ในโลกต่อ Auto ฟาร์มเหมือนปกติทุกอย่าง (EXP 50% เท่า Auto ปกติ ดรอปปกติ ส่วนแบ่งปาร์ตี้ปกติ) ได้นานสุด **30 นาที** (ค่าในโค้ด)
  - **ปิดแท็บ/ปิดเบราว์เซอร์/รีโหลดหน้า = ออกจากโลกทันที ไม่ฟาร์มต่อ** (เจ้าของตกลง 2026-11-17) · เบราว์เซอร์ส่ง close code `WS_CLOSE_PAGE_GONE` (4001) ตอน `pagehide` · ยังนับเป็นหลุดแบบเดิม (ที่ในปาร์ตี้/จุดเดิมเก็บ 60 วิ เปิดกลับภายใน 60 วิ = จุดเดิม Auto เปิดต่อ) · log `left: page closed (tab closed / reload)` · ปิดแอปมือถือทิ้งโดยไม่ได้ปิดแท็บ เบราว์เซอร์อาจไม่ส่งอะไร = นับเป็นหลุดธรรมดา (ฟาร์มต่อ)
  - **ไม่รวม Guest** (กันบอทฟาร์มด้วยบัญชี Guest): Guest หลุด = ออกจากโลกทันทีเหมือนเดิม · ไม่รวมตอนอยู่ห้องบอส ตอนตาย และตอน server กำลังนับถอยหลังปิด
  - จบเมื่อ: ครบเวลา · Auto หยุดเอง (ยาหมด/กระเป๋าเต็มตามตัวเลือกของผู้เล่น, เข้าเขตเมือง, บอส) · ม้วนกลับเมือง (รอร่ายจบถึงเมืองก่อน) · ตาย · เจ้าของปิดสวิตช์ → เซฟแล้วออกจากโลก (แล้วนับเป็นหลุดตามปกติ: ที่ในปาร์ตี้และจุดเดิมเก็บต่ออีก 60 วิ)
  - ระหว่างนั้น: เทรดที่ค้างถูกยกเลิกตอนหลุด ขอเทรดด้วยไม่ได้ ไม่ถูกเชิญ/ดึงเข้าห้องบอส · เซฟตอนหลุดและทุกรอบเซฟอัตโนมัติ · server ปิด = เซฟทุกคนเหมือนเดิม · นับเป็นคนออนไลน์ (อยู่ในโลก) · `/admin` แท็บออนไลน์มีป้าย "หลุด · Auto" · ปาร์ตี้เห็นเป็นออนไลน์ + "หลุด · Auto"
  - เข้าเกมตัวเดิมอีกครั้ง (เชื่อมต่อใหม่เอง หรือล็อกอินใหม่) = ได้ตัวที่กำลังฟาร์มคืน ที่จุดเดิม Auto ยังเปิด ไม่มีตัวซ้ำในโลก (ทางเดียวกับ takeover)
  - กลับมาภายใน 60 วิ (`CH_RECONNECT_MS`) หลังหลุดแบบไหนก็ได้ ถ้าตอนหลุด Auto เปิดอยู่ = Auto เปิดต่อ (Guest ด้วย) · server บอกเบราว์เซอร์ใน `welcome.auto`
  - /admin แท็บปรับสมดุล → การ์ด "Auto Play": สวิตช์ "Auto ฟาร์มต่อหลังหลุดการเชื่อมต่อ" + จำนวนนาที (1–240, ค่าในโค้ด 30) เก็บใน `BalanceTuning.auto.offline/offlineMin` เฉพาะที่ต่างจากโค้ด ลง audit
- **หน้าสรุปผล Auto ตอนไม่แตะเกม** (เจ้าของตกลง 2026-11-27, `src/client/ui/autoSummary.ts`, ตัวนับ `src/shared/sim/autoTally.ts`)
  - เปิด Auto แล้ว**ไม่แตะเกม 3 นาที** (ไม่กดคีย์ ไม่คลิก ไม่แตะจอ ไม่หมุนล้อ · ขยับเมาส์เฉย ๆ ไม่นับ) = ขึ้นหน้าสรุปกลางจอ (พื้นหลังมืด) **นับต่อเรื่อย ๆ ไม่หยุด** จนผู้เล่นกด ✕ หรือ**ดับเบิลคลิก** (มือถือ: แตะ 2 ครั้งใน 0.4 วิ) · ขณะเปิดอยู่ กดคีย์/คลิกอื่นไม่ปิด · ปิดแล้วเริ่มนับใหม่จากตอนนั้น
  - นับตั้งแต่แตะเกมครั้งล่าสุด: EXP ที่ได้จริง (หลังหัก Auto 50% และใบคูณ) · เลเวลอัพ (โชว์เมื่อ > 0) · ทองที่เก็บ · มอนที่ล่า (ทุกตัวที่เราตีแล้วตาย ตามที่ EXP นับ) · ไอเทมรวม + แยกความหายาก (สีตามความหายาก) · หิน/กุญแจ (โชว์เมื่อ > 0) · ยาที่เก็บได้/ที่ใช้ · ตาย (โชว์เมื่อ > 0) · บรรทัดเวลาที่ไม่อยู่ + สถานะ "Auto กำลังทำงาน" หรือ "Auto หยุดแล้ว — <ข้อความ autoOff จาก server>"

  - Auto หยุดระหว่างที่ไม่อยู่ (ยาหมด/กระเป๋าเต็ม/ตาย) ก็ยังขึ้นเมื่อครบเวลา ตัวเลขค้างที่ตอนหยุด

- ผู้เล่นที่เลเวลต่ำกว่าบอสเกิน 5 (ห่าง 6 ขึ้นไป) ทำดาเมจใส่บอสทุกตัวได้แค่ 10% (ลด 90%) ไม่บอกผู้เล่น ตัวเลขดาเมจที่ลอยขึ้นเป็นค่าหลังลดแล้ว (`BOSS_LEVEL_GAP`/`BOSS_UNDERLEVEL_MULT` ใน `src/shared/sim/Sim.ts`, เจ้าของตั้ง 2026-11-08)

## หยุดตอนโจมตี (เจ้าของตกลง 2026-11-18)

วิ่งแล้วโจมตีเคยดู "สไลด์" (ดาบไม่มีท่า `run_attack` ส่วนปืน/เวทมีแต่ก็ยังแปลก) จึงให้ **ทุกอาชีพหยุดกับที่สั้น ๆ ระหว่างท่าโจมตี แล้วค่อยวิ่งต่อ**

- ใช้กับ **ตีธรรมดา + สกิลที่ไม่ใช่ท่าเคลื่อนที่** ระหว่างหยุด: ไม่เดิน แต่ยังหันตามเมาส์/เป้าได้ · กดเดินค้าง/คลิกจุดเดินไว้ = หยุดครบแล้ววิ่งต่อเอง (จุดที่คลิกไม่หาย) · ไม่เปลี่ยนคูลดาวน์ ดาเมจ ความเร็วโจมตี
- **ไม่หยุด** (`NO_ATTACK_ROOT` ใน `src/shared/attackRootTuning.ts`): ท่าพุ่ง/กระโดดถอย/หายตัว (พุ่งชน ไล่ล่า ถอยฟัน หมุนตัวหลบ ระบำดาบ ก้าวเงา เงาสลับร่าง พันคมดาบ ยิงสวนกลับ) และบัฟ/ตะโกน (เร่งเครื่อง ตั้งรับ เกราะสะท้อน ปักหลัก ปลุกใจนักรบ ยั่วยุ ราชันย์ไม่ล้ม บัฟกระสุนทุกตัวของมือปืน โฟกัสสไนเปอร์ สนามเร่งอาคม โล่มานาหมู่ วงคืนพลัง) · สกิลที่ยืนเล็ง/ชาร์จเองอยู่แล้ว (ยิงหัว ยิงประณีต รางแม่เหล็ก เวทชาร์จ ปลดปล่อยพลัง) ใช้เวลาของสกิลนั้น · ทุบทำลาย (`sw_crush`) ชื่อว่ากระโดดแต่ตัวไม่ขยับจริง จึง **หยุด** เหมือนสกิลฟันทั่วไป
- **แดชระหว่างหยุดได้** และยกเลิกการหยุดทันที
- **มือปืนที่มีพาสซีฟประจำอาชีพ "ยิงแล้ววิ่ง"** (Hit and Run, เจ้าของ 2026-11-27, [skills.md](skills.md)): ตีธรรมดาไม่หยุด ส่วนสกิลหยุดตามปกติ · สวิตช์+เลเวลในแท็บระบบสกิล การ์ดพาสซีฟประจำอาชีพ
- เวลาหยุด: ตีธรรมดา = ค่าต่ออาชีพ แต่ไม่นานกว่าท่าโจมตี (`min(0.5, 0.95 ÷ ความเร็วตี)`) ตีเร็วขึ้นหยุดสั้นลงเอง · สกิล = ค่าตีธรรมดาของอาชีพ × ตัวคูณสกิล
- ค่าในโค้ด: เปิดทั้ง 3 อาชีพ · ดาบ 0.45 วิ เวท 0.4 ปืน 0.3 (ใกล้ความยาวท่าตอนความเร็วตีพื้นฐาน: ดาบ/เวท ~0.5 ปืน ~0.37) · ตัวคูณสกิล ×1 · ปรับใน /admin แท็บปรับสมดุล การ์ด **"หยุดตอนโจมตี"** (สวิตช์ต่ออาชีพ, วิ 0–1, ตัวคูณ 0–3, เก็บเฉพาะที่ต่างจากโค้ด, ลง audit, มีผลทันที)
- **Sim ตัดสิน** (`Player.atkRootT` ไม่เซฟ): ไม่เดินตาม `move`/`moveTo` (รวม Auto Play) · ตำแหน่งที่เบราว์เซอร์ส่งมารับเฉพาะที่ห่างจุดเริ่มหยุดไม่เกิน 0.45 ม. (เผื่อ server หยุดช้ากว่าเบราว์เซอร์ราว ½ ping) · ไม่นับเป็น `serverMoves` (เบราว์เซอร์ยังเดินเอง)
- **เบราว์เซอร์ทำนาย** (`src/client/net/online.ts` `predictAttackRoot`): หยุดตอนส่งปุ่มโจมตี/สกิลที่ server จะใช้ได้จริง (ตีธรรมดาตามตัวนับของตัวเอง, สกิลที่คูลดาวน์พร้อม MP พอ, ไม่ใช่ในเมือง) ทายผิดฝั่งหยุดเกินดีกว่าเดินเลย · ระหว่างหยุดตัวเราไม่ขยับ → เล่นท่าตีแบบยืน ไม่ใช่ `run_attack`

## ท่าตัวละครต่อทิศ (เจ้าของตกลง 2026-11-18)

เจ้าของเห็นว่าวิ่งแล้วดูแปลกในบางทิศ จึงมีแท็บ **/admin → หน้าตา → "ท่าตัวละคร"** (`src/client/animPreview.ts`) ดูท่าทุกทิศพร้อมกันแล้วปรับค่าต่อทิศ

- **ดู:** เลือกอาชีพ (ดาบ ปืน เวท) ภาพ (ภาพเดิม / ภาพกระดาษ / นักดาบกระดูก เฉพาะดาบ) และท่าที่ชุดภาพนั้นมี (ยืน วิ่ง โจมตีขณะวิ่ง โจมตี 1–3 คอมโบ ตาย ขี่สัตว์ ขี่บอร์ด) → เห็นครบ **8 ทิศ** ในตาราง 3×3 วาดด้วยตัววาดจริงของเกม (`AnimatedActor` / `RigActor`) · พื้นเลื่อนสวนเท้าตาม "ความเร็วเคลื่อนที่" + เส้นแนววิ่ง · จังหวะก้าวคิดแบบเดียวกับในเกม (`strideRate` ใน `AnimatedActor.ts`: ความเร็ว ÷ 5 จำกัด ×0.6–×1.6) · สโลว์ หยุด ทีละเฟรม · ป้ายแต่ละช่องบอกแถวภาพที่ใช้ พลิกไหม เฟรมที่เท่าไร และค่าที่ปรับ
- **สาเหตุที่พบ:** (1) กล้องเอียง ~46° วิ่งขึ้น/ลงบนจอเห็นระยะแค่ ×0.72 ของวิ่งด้านข้าง (ทแยง ×0.87) แต่ขาก้าวเร็วเท่ากันทุกทิศ เท้าจึงไถล (2) ภาพมีแค่ 5 แถว (หน้า ทแยงหน้า ข้าง ทแยงหลัง หลัง) ทิศขวาใช้ภาพทิศซ้ายพลิก อาวุธจึงสลับมือ
- **ค่าที่ปรับได้** แยกต่อ **อาชีพ × ภาพ (เดิม/กระดาษ/กระดูก แยกกัน) × ท่า × 8 ทิศบนจอ** (`src/shared/animTuning.ts`): แถวภาพ (อัตโนมัติ/เลือกแถว) · พลิก (อัตโนมัติ/พลิก/ไม่พลิก) · ความเร็ว ×0.25–×3 (ท่าวิ่ง = คูณจังหวะก้าว, ท่าอื่น = คูณ fps; ท่าโจมตีเร็ว/ช้าแค่ภาพ จังหวะตีจริงเท่าเดิม) · เลื่อนขวา/ขึ้น ±1 หน่วย · ขนาด ×0.5–×2 (รอบเท้า) · **นักดาบกระดูกปรับได้แค่ความเร็ว** (ท่าตาย/ขี่ของมันใช้ภาพนักดาบตามสวิตช์ภาพกระดาษของเซิร์ฟ ค่าอยู่ที่ "ภาพเดิม"/"ภาพกระดาษ")
- ปุ่มช่วย: ล้างทิศนี้ · ใช้ค่าทิศนี้กับทุกท่า · ตั้งความเร็วก้าวตามมุมกล้อง (ทุกทิศ ทุกท่าที่เคลื่อนที่ของอาชีพ+ภาพนั้นพร้อมกัน: วิ่ง โจมตีขณะวิ่ง ขี่ — วิ่งกับโจมตีขณะวิ่งใช้ก้าวเดียวกันจึงควรเท่ากัน · ขึ้นลง ×0.72 ทแยง ×0.87 ข้าง ×1) — **ค่าในโค้ดยังเป็น ×1 ทุกทิศ** จนกว่าเจ้าของจะกดแล้วบันทึก
- **สิทธิ์:** ดู/ทดลอง = สวิตช์ `animPreview` (owner + GM) ลองแล้วเห็นเฉพาะหน้านั้น · บันทึกทั้งเซิร์ฟ / คืนค่าเริ่มต้นทั้งหมด = สวิตช์ `animTune` (owner เท่านั้น) · API `GET/POST /api/admin/anim-look`
- เก็บใน settings key `anim_tuning` **เฉพาะค่าที่ต่างจากโค้ด** (ไม่มี = ตามโค้ด) · ลง `admin_audit` action `anim-look` เป็นข้อความไทย (ก่อน → หลัง ต่อท่า/ทิศ) · ส่งให้ทุกคนทาง `welcome.animTuning` และข้อความ `animTuning` ตอนบันทึก **มีผลทันที** ไม่ต้องรีเฟรช (อ่านทุกเฟรมใน `AnimatedActor.applyUV` / `RigActor`) · ค่าที่โค้ดไม่รู้จักแล้ว (ท่า/อาชีพที่ลบ) ถูกข้ามตอนอ่าน
- เทสต์: `tests/anim-look.test.ts`

## จัดเมนูเกม (เจ้าของสั่ง 2026-11-19)

ปุ่มในหน้าต่าง "เมนู" และแถวไอคอนมุมขวาบนตั้งได้จาก `/admin` → ปรับเกม → **"จัดเมนูเกม"** (`src/admin/menuLayout.ts`)

- **กติกา**: ปุ่ม "ตั้งค่า" **อยู่ท้ายสุดของหน้าต่างเมนูเสมอ** (เดิม "เต็มจอ" อยู่หลัง) · ปุ่ม "เมนู" อยู่ท้ายแถวมุมขวาบนเสมอ · ปุ่ม AUTO เปิด/ปิดต้องมีในแถวมุมขวาบน · ทั้งสามตัวซ่อน/ย้ายออกไม่ได้ (server ปฏิเสธ) เพื่อไม่ให้ผู้เล่นเปิดเมนู/ตั้งค่า (ออกจากเกม เปลี่ยนตัวละคร) ไม่ได้
- ตั้งได้ต่อที่ (รายการลำดับของแต่ละที่): ลากเรียง (หรือปุ่ม ↑↓ สำหรับมือถือ) · ✕ ซ่อนจากที่นั้น · ⇄ ย้ายไปอีกที่ · "+" ใส่ปุ่มที่ยังไม่แสดง · ปุ่มเดียวอยู่ได้ทั้งสองที่ (เหมือนค่าในโค้ดที่กระเป๋า/สกิล/ปาร์ตี้ ฯลฯ อยู่ทั้งสองที่)
- ย้ายไม่ได้ (ล็อกที่เดียว): AUTO (โชว์สถานะ ON/OFF → แถวบนเท่านั้น), เมนู (แถวบน), ตั้งค่า (หน้าต่างเมนู), เต็มจอ (ใช้เฉพาะจอสัมผัส → หน้าต่างเมนูเท่านั้น)
- **จอสัมผัส**ไม่มีแถวมุมขวาบน (CSS ซ่อนทั้งแถว) → ปุ่มที่ใส่ไว้แถวบนแต่ไม่อยู่ในหน้าต่างเมนูจะโผล่ในหน้าต่างเมนูเอง (ก่อนปุ่มตั้งค่า) · ยกเว้น "แจ้งปัญหา" ที่ค่าในโค้ดอยู่แถวบนอย่างเดียวมาตลอด (จอสัมผัสไม่เคยมี) คงเดิม
- ป้ายแจ้งเตือน (เลขแดงสกิล จุดแดงจดหมาย ฯลฯ) ตามปุ่มไปทุกที่ (กุญแจป้าย = ชื่อไทยของปุ่มในหน้าต่างเมนู) · ไอคอนเมนูรวมเลขเฉพาะปุ่มที่อยู่ในหน้าต่างเมนู · คีย์ลัดไม่ผูกกับปุ่ม ทำงานเหมือนเดิม · ปุ่ม "กราฟิก" ยังซ่อนตามสวิตช์ `gfxMenu` เดิม
- เก็บใน `BalanceTuning.menuLayout` = `{ menu?: string[], top?: string[] }` เฉพาะรายการที่ต่างจากโค้ด (รายการเต็ม ลำดับ = ลำดับแสดง ไม่มีใน list = ไม่แสดงที่นั่น) · `src/shared/menuLayout.ts` (รายการปุ่ม ชื่อ ข้อจำกัด `checkMenuLayoutTuning`) · ปุ่มใหม่ที่เพิ่มในโค้ดภายหลังจะไม่โผล่ในที่ที่เจ้าของเคยจัดไว้แล้ว ต้องกด "+" เอง (ยกเว้นปุ่มใน `ADDED_LATER` ของ `src/shared/menuLayout.ts` ตอนนี้คือ "มีอะไรใหม่" ที่ระบบเติมให้ในหน้าต่างเมนูก่อนตั้งค่าถ้ายังไม่อยู่ทั้งสองที่ ดู [news.md](news.md))
- มีผลกับผู้เล่นที่ออนไลน์ทันที (ผ่านข้อความ `balance` เดิม client วาดเมนูใหม่เอง) · คืนค่าในโค้ด = ปุ่ม "คืนค่าในโค้ดทั้งหมด"

  - ลบปุ่มลัด = หายจากรายการ ลำดับปุ่มอื่นคงเดิม (อ่านค่าที่มีปุ่มที่ไม่มีแล้ว = ตัดเฉพาะปุ่มนั้น) · บันทึกจัดเมนูเกมแล้วปุ่มที่ลบ/เลิกลอย server ลบตำแหน่งลอยของมันออกจากค่าที่เผยแพร่และร่างทันที (ปุ่มใหม่ที่ได้ id เดิมจึงไม่โผล่ที่เดิม ต้องวางแล้วเผยแพร่ใหม่)

## จัดหน้าจอเกม (เจ้าของสั่ง 2026-11-22)

ย้าย / ย่อขยาย / ซ่อน ส่วนของ HUD และหน้าต่างในเกม จาก `/admin` → ปรับเกม → **"จัดหน้าจอเกม"** (`src/admin/hudLayout.ts`) มีผลกับผู้เล่นทุกคน · ลำดับ/ซ่อน/ย้ายปุ่มในเมนูยังเป็นของ "จัดเมนูเกม" (คนละระบบ)

- **ที่เจ้าของเลือก (2026-11-22):** จัดบนภาพจำลองจอใน /admin (ไม่ใช่โหมดแก้ในเกม) · จอคอม (เมาส์) กับจอสัมผัส (`body.touch-ui`) ตั้งแยกกัน 2 ชุด · เฉพาะแอดมิน ผู้เล่นจัดเองไม่ได้ · มีร่างก่อนเผยแพร่ · สิทธิ์ owner+GM ทั้งดูและแก้
- **ภาพจำลอง:** จอคอม 1280×720 / จอสัมผัส 844×390 กล่องต่อส่วน (สลับชั้น HUD / หน้าต่าง) · ลากกล่อง = ย้าย · ลากจุดทองมุมล่างขวา = ย่อ/ขยาย · รายการข้างจอมีช่อง X% Y% ขนาด% ติ๊กซ่อน และ ↺ คืนค่าในโค้ดรายส่วน · **ใต้กล่องคือหน้าจอเกมจริงแบบตัวอย่าง** (เจ้าของสั่ง 2026-11-23): iframe `/?hudMock=1&device=desktop|touch` (`src/client/hudMock.ts`) = หน้าเกมเดียวกันแต่ไม่ล็อกอิน ไม่ต่อ server ไม่มีฉาก 3D ใส่ข้อมูลตัวอย่าง (การ์ดตัวละคร HP/MP บัฟ บอส ปาร์ตี้ เควส แชต แถบสกิล ลูกแก้ว ปุ่มจอสัมผัส แถวไอคอนจริงจาก `menuButtonsHtml` รวมชื่อ/ไอคอน/ปุ่มลัดจากจัดเมนูเกม) ใช้ stylesheet เดียวกับเกม · ลากกล่องแล้วของจริงในตัวอย่างขยับตามทันที (ใส่ CSS เดียวกับเกม `hudLayoutCss`) และกล่องวัดตำแหน่ง/ขนาดจากของจริง (`hudMock.rect`) · ส่วนที่ติ๊กซ่อนแสดงจาง 30% ในตัวอย่าง (ในเกมหายจริง) · ชั้น "หน้าต่าง": ของจริงเฉพาะหน้าต่างที่เป็น HTML ใน index.html (กระเป๋า พ่อค้า คลัง ช่างตีเหล็ก วิธีเล่น) หน้าต่างอื่นต้องมีเกมรันจึงเป็นกล่องตามขนาดที่วัดจากเกมจริง (เจ้าของเลือก) · หน้าตัวอย่างไม่เรียก API แอดมินเอง (แอดมินส่งค่าให้) ผู้เล่นเปิดก็เห็นแค่ภาพนิ่ง · ยังไม่โหลด/โหลดไม่ได้ = ใช้กล่องสำรอง `box` ใน `HUD_PARTS` (วัดจากเกมจริง 2026-11-23 ที่ 1280×720 / 844×390 หน้าต่างที่ล้นจอถูกตัดให้อยู่ในจอ) · ลูกแก้ว HP/MP ไม่มีบนจอสัมผัส (จอสัมผัสใช้แถบเสมอ) จึงไม่อยู่ในรายการจอสัมผัส · ตัวติดตามเควสอยู่ใต้การ์ดตัวละคร ย่อ/ขยายจากมุมซ้ายบน
- **ส่วนที่จัดได้** (`HUD_PARTS` ใน `src/shared/hudLayout.ts` ต่อด้วย DOM id): การ์ดตัวละคร+หลอด HP/MP, บัฟ, สมาชิกปาร์ตี้, หลอดบอส, มินิแมพ, แถวไอคอนมุมขวาบน (เฉพาะจอคอม), ปิง, ตัวติดตามเควส, กล่องแชต, ช่องพิมพ์แชต, แถบสกิล+EXP, ลูกแก้ว HP, ลูกแก้ว MP · จอสัมผัส: ปุ่มเมนู จอย กลุ่มปุ่มโจมตี · หน้าต่าง 25 บาน (กระเป๋า สกิล ปาร์ตี้ … ตลาด)
- **ซ่อนไม่ได้** (server ปฏิเสธ): แถวไอคอนมุมขวาบน (มีปุ่มเมนู/AUTO) · ปุ่มเมนู จอย ปุ่มโจมตี ของจอสัมผัส · หน้าต่างทุกบาน (ผู้เล่นเปิดเอง ย้าย/ย่อขยายได้อย่างเดียว)
- **ค่า:** ต่อส่วนเก็บแค่ส่วนต่างจากค่าในโค้ด `{ x?, y?, s?, hide? }` · x/y = เลื่อนเป็น % ของความกว้าง/สูงจอ (−100…100, ทีละ 0.1) จึงใช้ได้ทุกขนาดจอ · s = ขนาด 0.5–2 ย่อ/ขยายจากมุมที่ส่วนนั้นยึด (`origin`) · เกมใส่เป็น `<style id="hud-layout-style">` ใช้ CSS `translate` / `scale` (บวกกับตำแหน่งเดิมใน stylesheet ไม่ทับ transform เดิม) ซ่อนด้วย `display: none !important` (`src/client/hudLayout.ts`, เช็คทุกเฟรม)
- **หน้าต่างที่ผู้เล่นลาก** (`dragwindow.ts`): ลากได้เหมือนเดิม ระหว่างลากตัด offset ของแอดมินออกแล้ววางตามเมาส์ (ไม่กระโดด) ขนาดยังคงตามที่ตั้ง · ปิดแล้วเปิดใหม่หรือดับเบิลคลิกแถบหัว = กลับที่ที่แอดมินตั้ง
- **ร่าง → เผยแพร่:** ร่างมีอันเดียวทั้งเซิร์ฟ (ตาราง `settings` key `hud_layout_draft` + ใครบันทึก เมื่อไหร่) · ปุ่ม **บันทึกร่าง** · **🎮 ดูในเกม (เฉพาะฉัน)** = บันทึกร่างแล้วเปิดเกมแท็บใหม่ `/?previewHud=1` เกมขอร่างด้วยการล็อกอินของคุณ (`GET /api/admin/hud-layout` ต้องมีสิทธิ์ `hudLayout`) แสดงเฉพาะแท็บนั้น มีป้ายบอกบนจอ ไม่มีสิทธิ์ = เห็นค่าที่เผยแพร่ · **📢 เผยแพร่** = ย้ายร่างไป `BalanceTuning.hudLayout` ผู้เล่นออนไลน์เห็นทันที (ข้อความ `balance` เดิม) แล้วลบร่าง · **ทิ้งร่าง** · **คืนค่าในโค้ดทั้งหมด** (ทั้งสองจอ + ทิ้งร่าง)
- **ปุ่มลัดวางอิสระ** (2026-11-22): ปุ่มลัดที่ติ๊ก "วางอิสระบนจอ" ใน "จัดเมนูเกม" เป็นส่วน `hud-btn-<id>` (ชั้น HUD) · ในโค้ดอยู่มุมซ้ายบนของจอ x/y = ตำแหน่งบนจอ % · ในรายการข้างจอ "+ วางบนจอนี้" (เริ่มที่ขวากลางจอคอม / ซ้ายล่างจอสัมผัส) · 🗑 = เอาออกจากจอนี้ · **ปุ่มโผล่บนจอใดก็ต่อเมื่อค่าที่เผยแพร่มีรายการของปุ่มนั้นบนจอนั้น** (รายการที่เท่ากับค่าในโค้ดก็เก็บไว้ = "วางที่มุม") ซ่อนได้ · สูงสุด 20 · เกมสร้างปุ่มใน `#hud-free` (`.hud-free-btn` ซ่อนไว้ CSS ของ hudLayout ใส่ `display: flex` ให้ที่วางแล้ว) · "ดูในเกม" เห็นปุ่มในร่างก่อนเผยแพร่ · ปุ่มที่ถูกลบแล้วถูกตัดออกจากร่างเมื่อโหลดแท็บ
- **ย้อนฉบับเก่า** (2026-11-22, เจ้าของเลือก 20 ฉบับ): ทุกครั้งที่ **เผยแพร่** หรือ **คืนค่าในโค้ด** เก็บค่าที่ใช้หลังกดลง settings key `hud_layout_history` (ใหม่สุดก่อน ≤ 20 ฉบับ + ใคร เมื่อไหร่) ครั้งแรกเก็บ "ที่ใช้อยู่ก่อนมีประวัติ" ด้วย · กล่อง "ประวัติที่เคยเผยแพร่" ใต้ปุ่ม → **ย้อนเป็นฉบับนี้** = ฉบับนั้นกลายเป็นร่าง (ทับร่างเดิม) ดูในเกมก่อนแล้วกดเผยแพร่เอง · อ่านประวัติแบบผ่อนปรน (ส่วน/ปุ่มที่ไม่มีแล้วถูกข้าม)
- API `GET/POST /api/admin/hud-layout` POST = `{ draft }` | `{ publish: true }` | `{ discard: true }` | `{ reset: true }` | `{ restore: <at> }` · GET ส่ง `history` และ `freeButtons` (ปุ่มลัดวางอิสระจาก menuLayout) ด้วย · บันทึกของแท็บ "ปรับสมดุล" และ "จัดเมนูเกม" ไม่แตะค่านี้ (`withHudLayout`)

- คำตอบต่อ NPC: พ่อค้า ซื้อ/ขายของ + ซื้อคืน · ช่างตีเหล็ก อ่านปุ่มจากเมนูช่างตีเหล็กเอง (ตีบวก สุ่มค่าตัวเลข สุ่มสเตตัส และเมนูที่เพิ่มทีหลังเช่นการ์ด) กดแล้วเปิดเมนูนั้นเลย · ผู้ดูแลคลัง เปิดคลัง · นายหน้าตลาด ตลาดฝากขาย + กล่องรับของ (มีตัวเลขเมื่อมีของรอ) · พ่อค้าคริสตัล แคชช็อป · The Seeker เควสกุญแจบอส + ฟังเรื่องราว (อ่านต่อในกล่องบทพูด คลิกกล่องเพื่ออ่านต่อ) · นักเดินเรือ ทางขึ้นชั้น 2 · ทุกตัวมี "พูดคุย" (สุ่มบทพูดใหม่ ไม่ซ้ำบรรทัดเดิม) และ "ลาก่อน" · NPC ที่มีเควสสอนระบบมีปุ่ม "รับเควส/ส่งเควส: <ชื่อขั้น>" ขึ้นก่อน
- NPC ชั้น 2 (ท่าเรือ) และนักเดินเรือยังไม่มีภาพครึ่งตัวชุดใหม่: ใช้รูปหน้าเดิม (`paper/ui/npc/<ชื่อ>.png`) ในกรอบ + ฉากหลังของงานเดียวกัน
- เดินห่างเกิน `NPC_USE_RANGE` + 1, ตาย, เปลี่ยนแมพ = ปิดเอง · Esc ปิดได้ · ขนาด 16:9 ย่อทั้งก้อนตามจอ มือถือวางแบบเดียวกันแต่เล็กลง
- **D การ์ดเควส**: หน้าต่างเควสสอนระบบ (`tutorial.ts`) เป็นการ์ดกระดาษมีม้วนกระดาษ รางวัลแสดงเป็นไอคอน (ชี้ดูชื่อเต็ม) ปุ่มรับ/ปฏิเสธ · กติกาเควสเดิมทั้งหมด
- **F หน้าต่างได้รับรางวัล**: กดส่งเควสสอนระบบแล้วขั้นนั้นกลายเป็นสำเร็จภายใน 20 วิ = เด้ง "ได้รับรางวัลแล้ว!" พร้อมไอคอนรางวัล (ส่งทางจดหมาย) คลิกที่ใดก็ได้ปิด (`rewardWin.ts`)
- **E คำพูดเหนือหัว**: เดินเข้าใกล้ NPC ในระยะที่ตั้ง = คำพูดสั้น ๆ ลอยเหนือป้าย NPC ค้างตามวินาทีที่ตั้ง ตัวเดิมพูดซ้ำได้ทุก N วิ ไม่ขึ้นขณะหน้าต่างคุยเปิด (`floating.ts` `npcSay`)
- **/admin → ปรับสมดุล → การ์ด "หน้าต่างคุย NPC"** (หมวดระบบ-รางวัล, สวิตช์ `balance`): สวิตช์ใช้หน้าต่างคุย (ค่าในโค้ดเปิด, ปิด = คลิกแล้วเปิดหน้าต่างของ NPC ทันทีแบบเดิม รวมทางลัดเควสสอนระบบเดิม) · สวิตช์คำพูดเหนือหัว + ระยะ (2–20) วินาทีค้าง (1–15) พูดซ้ำทุก (3–300 วิ) · บทพูดทักทาย/เหนือหัวของ NPC ทุกตัว บรรทัดละ 1 ประโยค ≤ 8 บรรทัด ≤ 150 ตัวอักษร · เก็บใน `BalanceTuning.npcTalk` เฉพาะที่ต่างจากโค้ด (`src/shared/npcTalk.ts`) ลง audit มีผลทันที ฝั่งเบราว์เซอร์เท่านั้น

## หน้าต่าง

- **เมนู Esc / ปุ่มเมนู** (`src/client/sysmenu.ts`) เป็นตารางไอคอน 3 คอลัมน์ ใส่เฉพาะระบบที่มีแล้ว: กระเป๋า ปาร์ตี้ แผนที่ ตั้งค่า Auto / เสียง วิธีเล่น ตั้งค่า (`MENU_ITEMS`) · ระบบใหม่ให้เพิ่มช่องเมื่อทำเสร็จ · ตลาด คลัง ช่างตีเหล็ก เปิดได้ที่ NPC เท่านั้น · badge แจ้งเตือนผู้เล่นบนไอคอน (`SystemMenu.setBadge`): 1 = จุดแดง, 2 ขึ้นไป = ตัวเลข, 0 = ไม่แสดง · ไอคอนเมนูมุมขวาบนแสดงยอดรวม · ตอนนี้ยังไม่มีระบบเรียกใช้

- (ปุ่มที่โชว์/ลำดับ ปรับได้ที่ /admin → จัดเมนูเกม ดูหัวข้อ "จัดเมนูเกม" ด้านบน)
- **หน้าตั้งค่าแบบแท็บ** (เจ้าของ 2026-11-26 ตามภาพตัวอย่าง, `src/client/sysmenu.ts` + `settingsUi.ts`, CSS `.set-*` ใน `src/styles/menu-system.css`): หน้าต่างเมนูขยายกว้าง (≤720px) หัว "ตั้งค่า" · **ซ้าย** แท็บแนวตั้งไอคอนอีโมจิ+ชื่อ แท็บที่เลือกสีทองมีหัวลูกศร + ปุ่ม "‹ กลับ" (กลับตารางเมนู) ล่างสุด · **ขวา** หัวข้อแท็บ + เส้นคั่น แล้วแถว "ชื่อซ้าย / ตัวปรับขวา" (dropdown, สวิตช์ เปิด/ปิด, แถบเลื่อน+ตัวเลข, บรรทัด ⓘ คำอธิบาย) · **ล่าง** ปุ่มใหญ่ กลับเข้าเกม (ทอง) / เลือกตัวละคร / ออกจากระบบ (แดง) (Guest: กลับไปหน้า Guest / กลับหน้าแรก + ข้อความสมัครสมาชิก)
  - **ทั่วไป:** ภาษา / Language (dropdown สองภาษา ไม่ถูกแปล ซ่อนเมื่อ /admin ปิดภาษาอังกฤษ มีผลตอนเปิดเกมใหม่) · HP / MP ลูกแก้ว/แถบ · รับคำชวนปาร์ตี้ เปิด/ปิด · รับคำขอเทรด เปิด/ปิด (Guest ไม่มี) · บัญชี Google (ปุ่มผูก/บันทึกด้วย Google เมื่อ server เปิด Google) — สวิตช์ "รับ…" เปิด = รับ (เดิมเป็น ☐ ไม่รับ… ค่าที่เก็บไว้เหมือนเดิม)

## มินิแมพและแผนที่ใหญ่

เจ้าของอนุมัติ 2026-11-10 (โค้ด: `drawMinimap` ใน `src/client/hud.ts`, `src/client/fullmap.ts`, `src/client/mapIcons.ts`)

- **ปุ่มบนมินิแมพ** (ขอบล่างขวา ทรงกลมสไตล์ 16-bit): 🔍 เปิดแผนที่ใหญ่ · + / − ซูมมินิแมพ 3 ระดับ (ไกล / ปกติ / ใกล้ = 1.8 / 2.6 / 3.8 px ต่อหน่วย) จำระดับใน `localStorage` (`multiverse-minimap-zoom`) · ทุกปุ่มมี tooltip ภาษาไทย · คลิกที่มินิแมพเองเปิดแผนที่ใหญ่เหมือนเดิม · ใต้มินิแมพมีที่ว่างสำหรับป้าย ping / ชื่อแมพ·CH
- **แผนที่ใหญ่ไม่ปิดเองหลังคลิกเดิน** ปิดได้ด้วย M, Esc หรือปุ่ม ✕ เท่านั้น
- **เส้นทาง + ธงปลายทาง** (`Game.mapRoute`): วาดทั้งบนมินิแมพและแผนที่ใหญ่ ส่วนที่เหลือของเส้นทางเท่านั้น หายเมื่อถึง/ถูกขวาง/เดินเอง/ตาย/เปลี่ยนแมพ ถ้าปลายทางอยู่นอกมินิแมพจะเป็นลูกศรที่ขอบ
- **หมุดของผู้เล่น** 1 อัน ต่อแมพ: คลิกขวาที่แผนที่ใหญ่เพื่อปัก (คลิกขวาที่อื่น = ย้าย) · คลิกขวาที่หมุดหรือกดปุ่ม "ลบหมุด" = ลบ · แสดงบนแผนที่ใหญ่ และบนมินิแมพ (นอกวงเป็นลูกศรที่ขอบ) · อยู่ฝั่ง client อย่างเดียว ไม่เซฟ ไม่ส่ง server และเริ่มใหม่เมื่อเข้าแมพใหม่
- **ลูกศรขอบมินิแมพ**: NPC ในเมืองและประตูวาปที่อยู่นอกวงมินิแมพ แสดงเป็นไอคอนเล็ก (ชุดเดียวกับแผนที่ใหญ่) ที่ขอบ พร้อมลูกศรทองชี้ทิศ (`drawEdgeMarker`)

## ฟองแชทเหนือหัว

- ผู้เล่นส่งแชท → ขึ้นฟองข้อความเหนือหัวตัวละครนั้น (เหนือป้ายชื่อ) ให้ทุกคนที่เห็นตัวละครนั้น และคนส่งเห็นฟองของตัวเองด้วย (`Floating.bubble` ใน `src/client/floating.ts`, เรียกจาก `backend.onChat` ใน `src/main.ts`)
- จับคู่ตัวละครด้วย**ชื่อ** (ไม่ได้เพิ่ม id ใน protocol) · แชททั้งเซิร์ฟเวอร์ = ฟองขาว · แชทปาร์ตี้ = ฟองน้ำเงิน (`#3a7bd5` ใหม่ ไม่ตรงกับบรรทัดปาร์ตี้ในกล่องแชทที่เป็นสีเขียว `#5dff8a`) · แชทปาร์ตี้ server ส่งให้เฉพาะสมาชิก จึงเห็นเฉพาะในปาร์ตี้
- แสดง 5 วินาทีแล้วหาย (`BUBBLE_MS`) · ข้อความใหม่จากคนเดิมแทนฟองเก่า · ข้อความยาวตัดบรรทัด กว้างสุด ~200px (ไม่ตัดข้อความ)
- **ยกป้ายชื่อผู้เล่น (เจ้าของ 2026-11-24):** ป้ายชื่อบนหัวต่ำจนบังตัว → ค่า `fxLayer.plateLift` (px บนจอ ค่าในโค้ด 0 = ตำแหน่งเดิม −40..150) ยกป้ายชื่อของคนอื่น กรอบชื่อของตัวเอง และฟองแชทพร้อมกัน ใช้กับผู้เล่นทุกอาชีพเท่ากัน ไม่รวมป้ายมอน/NPC · ปรับในแท็บปรับสมดุล /admin การ์ดเอฟเฟกต์ แถวขอบกรอบชื่อ มีผลทันที
- ตัวละครอยู่นอกจอ คนละแมพ หรือไม่อยู่ในรายชื่อผู้เล่นของแมพนี้ = ไม่แสดงฟอง · ข้อความ server (ไม่มีชื่อ) ไม่มีฟอง · ใช้ `textContent` เท่านั้น
- หน้าตาเป็น CSS ธรรมดา (`.chat-bubble`) รอเพื่อนวาดภาพทีหลัง

## ป้ายจำนวนคนมุมซ้ายบน (เจ้าของตกลง 2026-11-12)

- ทุกคนเห็น `🌐 ในแมพนี้ N คน · กด Enter เพื่อแชท` (สีฟ้า) นับเฉพาะคนในแมพ + CH เดียวกัน (ห้องบอส = ในห้อง) รวมตัวเอง
- บรรทัดที่สอง `🛡 ออนไลน์ทั้งหมด N คน` (สีทอง) เฉพาะ role `owner` และ `gm` · server ส่งตัวเลขทั้งเซิร์ฟ (`SnapshotMsg.online`) ให้เฉพาะสองตำแหน่งนี้ คนอื่นไม่ได้รับเลย
- เช็ค role ตอนเข้าเกม: ให้/ถอน GM ระหว่างเล่น มีผลเมื่อเข้าเกมครั้งถัดไป
- **มือถือ/iPad (โหมดสัมผัส):** แตะไอเทมในกระเป๋า ช่องที่สวมอยู่ หรือในคลัง เปิดหน้ารายละเอียดไอเทม (`openDetail` ใน `hud.ts`) มีข้อมูลเหมือน tooltip และปุ่มตามสถานการณ์: สวมใส่/ถอด, ใช้ยาหรือม้วน, แบ่งกอง, วางลงพื้น, ย้ายเข้ากระเป๋า และขาย/ฝากคลัง/ลงขายตลาด/วางที่ช่างตีเหล็ก/เสนอเทรด เมื่อเปิดหน้าต่างนั้นอยู่ · PC ใช้ hover/คลิก/คลิกขวาเหมือนเดิม · โหมดสัมผัสไม่แสดง tooltip เลย (iOS ไม่ส่งคลิกถ้าการแตะครั้งแรกทำให้หน้าเปลี่ยน) · กดค้าง 0.5 วินาทีในหน้าต่าง = คลิกขวา (`touch/device.ts`) เช่น ซื้อยาทั้งกอง เมนูแถวปาร์ตี้ ปักหมุดแผนที่

## ตั้งปุ่มเอง (เจ้าของ 2026-11-21)

- เมนู › ตั้งค่า › **ตั้งค่าปุ่ม**: ผู้เล่นย้ายปุ่มของ เดิน 4 ทิศ, สกิล Q/E/R, แดช, ยา HP/MP, Auto, ม้วนกลับเมือง, ขี่, กระเป๋า, หน้าต่างสกิล, แผนที่, ช่วยเหลือ, คุย, แชท ได้ (`src/client/keybinds.ts`, แท็บ "ปุ่ม" ในหน้าตั้งค่า `src/client/keybindPanel.ts`)
- คลิกปุ่มของรายการแล้วกดปุ่มใหม่ (Esc = ยกเลิก) · ✕ = เอาปุ่มออก · **รีเซ็ตทั้งหมด** = กลับค่าเริ่มต้นทุกปุ่ม
- ตั้งซ้ำกับปุ่มที่อีกอย่างใช้อยู่ = อันเดิมกลายเป็นไม่มีปุ่ม + ขึ้นแจ้งเตือนปุ่มซ้ำในหน้าต่าง (ตั้งใหม่เองได้)
- เปลี่ยนไม่ได้: Esc, ปุ่มเมาส์, ปุ่มบนจอมือถือ · ลูกศรเดินได้เสมอ · ป้ายบนแถบสกิลเปลี่ยนตามปุ่มที่ตั้ง
- จำไว้ในเบราว์เซอร์เครื่องนั้น (localStorage `multiverse-keybinds`) ไม่ขึ้น server เปลี่ยนเครื่องต้องตั้งใหม่
- ทำงานโดยแปลงปุ่มที่กดจริงเป็นปุ่มเดิมของคำสั่งนั้นใน `Input` (`src/client/input.ts`) เกมส่วนอื่นไม่ต้องแก้ · เทสต์ `tests/keybinds.test.ts`
- /admin › ปรับสมดุล › การ์ด "เอฟเฟกต์สกิล (ชั้นเสริม)": สวิตช์ `fxLayer.keyRebind` "ให้ผู้เล่นตั้งปุ่มเอง" ปิด = ทุกคนใช้ปุ่มตามโค้ดและปุ่มในเมนูหาย (ค่าที่ผู้เล่นตั้งยังเก็บไว้)
- หน้าช่วยเหลือ (H) ยังเขียนปุ่มตามค่าเริ่มต้น
- หลุมใต้ศพ: ตามตัวที่ตายทุกเฟรม (ตัวเลื่อนจากจุดที่จอเห็นว่าตายไปจุดที่ server มี หลุมไม่ค้างที่เดิม) · เลื่อนไปข้างหลังตัว `fxLayer.craterBack` 1.0 (ท่าตายกระดาษ ตัวสูงจากเท้า ~0.7) ปรับใน /admin การ์ด "เอฟเฟกต์สกิล" (เจ้าของ 2026-11-23)
- เมืองกลาง: ขอบพื้นอิฐไม่ตัดตรง แตกเป็นก้อนกลืนกับพื้นของแต่ละโซน และมุมโค้งตรงประตู (เจ้าของ 2026-11-23) · ปรับใน /admin การ์ด "เมืองกลาง": ความกว้างขอบ `townEdge` 1.2 (0 = ตัดตรง) · ความโค้งมุม `townRound` 3 · มีผลตอนโหลดแมพเมืองครั้งถัดไป
