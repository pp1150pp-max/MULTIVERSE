# ตัวแก้แมพ (Map Editor)

แท็บ **"แมพ"** ใน `/admin` ให้เจ้าของลากวาง/ย้าย/หมุน/ลบของบนแมพชั้น 1 และชั้น 2 แล้วกดเผยแพร่ โดยไม่ต้องให้ AI แก้โค้ด · แผนเดิมอยู่ที่ [docs/plans/map-editor.md](../plans/map-editor.md) (ไฟล์นี้เขียนตามโค้ดที่มีอยู่จริง ถ้าต่างจากแผน ให้ถือไฟล์นี้)

> **ชั้น 2 (PR 9, 2026-11-21, อยู่บน branch `floor2` จนกว่าเจ้าของทดสอบในเครื่องเสร็จ):** เมืองท่าเรือมิติ `harbor_town`, หาดเรือแตก `shipwreck_beach` และห้องบอสปู `shipwreck_beach_room` (+ อ่าวลักลอบ `smugglers_cove` และห้องกัปตัน `smugglers_cove_room`, PR #5 2026-11-24) อบเป็น JSON schema เดียวกัน ตัวแก้เห็นและแก้ได้เหมือนแมพชั้น 1 · **รูปแพ/แผ่นไม้ของท่าเรือยังอยู่ในโค้ด** (`HARBOR_DECKS` ใน `src/shared/data/harbor.ts` วางรอบกลางแมพ (0,0) ไม่ขึ้นกับจุดเกิด) นอกแพเป็นน้ำ เดินไม่ได้ไม่ว่าไฟล์จะว่าอะไร (`Terrain.isBlocked`) ตัวแก้วาดแพบนน้ำให้เห็น (สีเรียบ ไม่ใช่ภาพพื้นจริง) · วงกั้นริมแพ (ราว 450 วง) อยู่ใน `colliders` ย้าย/ลบได้ แต่ลบแล้วก็ยังเดินลงน้ำไม่ได้ · ภาพของหาดเรือแตกยังไม่ merge (ในเกมเป็นภาพสำรอง) ตัวแก้จึงอาจไม่มีภาพของพวกนี้

## 1. ภาพรวม: ข้อมูลอยู่ที่ไหน

แมพชั้น 1 ทั้ง 5 (`nexus_city`, `emerald_forest`, `misty_marsh`, `frost_reach`, `ashen_isle`) และชั้น 2 (`harbor_town`, `shipwreck_beach`, `smugglers_cove`) เป็นข้อมูล JSON ไม่ใช่โค้ดสุ่มอีกแล้ว เกม (ทั้ง server และเบราว์เซอร์) สร้าง `Terrain` จาก JSON ที่ `MapRegistry` ถืออยู่

| ที่เก็บ | คืออะไร | ใครแก้ |
|---|---|---|
| `src/shared/data/maps/<zoneId>.json` | ค่าตั้งต้นที่ build เข้าเกม ผ่านเทสต์/CI อยู่ใน git | commit ผ่าน PR (หรือปุ่ม "ส่งออกเข้า repo") |
| ตาราง `map_layouts` ใน DB | ร่าง (draft) และแมพที่เผยแพร่ (published) ที่เจ้าของแก้ใน `/admin` | ตัวแก้แมพ |

ไม่ถูกเก็บใน JSON (ยังอยู่ในโค้ดเหมือนเดิม): ชื่อ/เลเวล/สถิติของโซน, ค่าบูสต์มอน (`boost`), บอส/วงสนาม/ขนาดและธีมของห้องบอส (ยังสร้างด้วย `bossRoom()` ใน `zones.ts` ไฟล์ห้องบอสเก็บเฉพาะของประดับ collision และจุดเกิด ดูหัวข้อ 12), ภาพที่เป็นแค่ shader พื้น (หมอก หิมะ หน้าผา ยังคำนวณจาก path/theme/lake)

## 2. รูปแบบ JSON (`src/shared/mapSchema.ts`)

`MapData` (schema 1) หนึ่งไฟล์ต่อแมพ พิกัดเป็นหน่วยโลก (x, z) ไม่ใช่พิกเซล

| ฟิลด์ | ความหมาย |
|---|---|
| `schema`, `id`, `floor`, `rev` | เวอร์ชัน schema (=1), รหัสแมพ, ชั้น (1–9), revision (ไฟล์ใน repo = 0, publish ครั้งแรก = 1) |
| `zone` | `half` (ครึ่งขนาดแมพ), `theme`, `quadrants` (เฉพาะเมืองกลาง), `start`, `safe` |
| `paths` | ทางเดิน (ภาพพื้นเท่านั้น **ไม่กั้นการเดิน**) `{id, w, pts}` · `main` + `branchN` |
| `water` | วงรี `{kind: 'ice'\|'lava', x, z, rx, rz}` (ลาวาทำดาเมจตามค่าเกมเดิม) |
| `props` | ของวาง `{id, key, x, z, h, rot, flip, fade, solid?}` · `rot` 0–359.9° หมุนทั้งภาพและ collision · `solid` = `{r}` วงกลม หรือ `{w, d}` กล่องหมุนตาม `rot` หรือไม่มี = เดินทะลุ |
| `blockers` | polygon ปิดที่เดินเข้าไม่ได้ (≥ 3 จุด ห้ามตัดตัวเอง) |
| `colliders` | วงกลมกั้นที่ไม่ผูกกับชิ้นไหน (น้ำพุ แนวกำแพง ฐานบ้านของเมืองกลาง) ไม่มีภาพ · **ฟิลด์นี้ไม่มีในแผนเดิม** เพิ่มใน PR 2 เพื่ออบเมืองกลางให้เหมือนเดิมเป๊ะ (เจ้าของ OK 2026-11-20) · ตัวแก้ย้าย/ลบ/หมุนให้พร้อมชิ้นที่มันตามอยู่ แต่ยังไม่มีเครื่องมือเพิ่มวงเปล่าเอง |
| `walkable` | `{half}` กรอบเดินได้ (ตั้งต้น = `half − 8`) เป็นสี่เหลี่ยมจัตุรัสเท่านั้น |
| `npcs` | `{id, x, z}` (หนึ่ง NPC หนึ่งหมุด) |
| `rest` | จุดพัก `{kind: 'fountain'\|'campfire', x, z}` |
| `portals` | ประตู `{to, x, z, minLevel}` + เสริม `requires` (ต้องปลดล็อกก่อน), `soonName` (ประตูที่แมพปลายทางยังไม่มี ปิดไว้และบอกชื่อ เช่นท่าเรือ 3 ทิศ · `to` ที่ไม่มีในเกมผ่านการตรวจเมื่อมี `soonName`), `prop` (ภาพประตูที่ไม่ใช่ `portal`) |
| `spawns` | จุดเกิดมอน `{monster, x, z, radius, count, respawn: [min, max]}` |
| `lair` | ที่เรียกบอส `{boss, x, z}` (ถ้าแมพมีบอส) |
| `room` | (เฉพาะห้องบอส) `{of, arena, boss}` ค่าที่ล็อก ดูหัวข้อ 12 |

`validateMap(map, ctx)` (ใช้ทั้งตัวแก้ server และเทสต์ ไม่ throw แม้ข้อมูลพัง) แบ่ง error/warn: รูปแบบ/ช่วงค่า, id ซ้ำ, `key` ภาพที่ไม่มีใน `SHEET_SPECS`, ชิ้น/NPC/ประตู/จุดเกิดนอกกรอบ, NPC/ประตู/จุดเกิดยืนใน collision, polygon พัง, อ้างโซน/มอน/บอสที่ไม่มี, และ **ประตูเดินไม่ถึงจากจุดเริ่ม** (BFS บนตาราง 1 หน่วย) · จุดเริ่มที่ยืนใน collision (กลางน้ำพุของเมืองกลาง) เป็นแค่คำเตือน

> **ต่างจากแผน:** ไม่มีการตรวจ "ชิ้นซ้อนทับกันเกินกำหนด" และไม่มีค่า "ระยะซ้อนทับสูงสุด" ใน `/admin` (ดู "ยังไม่ทำ")

## 4. `MapRegistry` (`src/shared/mapRegistry.ts`)

ตัวถือ layout ของแต่ละโซน ใช้ร่วมกัน server/เบราว์เซอร์
- `get(id)` = layout ที่เกมใช้ตอนนี้: ค่า override (จาก DB) ถ้ามีและสวิตช์เปิด ไม่งั้นใช้ JSON ที่ bundle มา
- `bundled(id)` = JSON ที่มากับเกมเสมอ · `ids()` = 7 แมพ (ชั้น 1 ห้า ชั้น 2 สอง) + ห้องบอส 5 ห้อง · `set()`/`clear()` = ใส่/ถอน override · `setUseOverrides()` = สวิตช์
- `Terrain` ถูกสร้างจาก `MapRegistry.get(zone.id)` · ห้องบอสชั้น 1 มีไฟล์ของตัวเอง `<field>_room` (หัวข้อ 12)
- `refreshZone(id)` (`zones.ts`) สร้าง `ZONES[id]` ใหม่จาก layout ปัจจุบัน (path, ทะเลสาบ, จุดเกิด, ประตู, ที่เรียกบอส) · **ค่า `boost` ของมอนผูกกับ "ลำดับที่" ของจุดเกิดใน layout** (`zone.spawns[i].boost`) ถ้าเพิ่ม/ลบ/สลับลำดับจุดเกิดใน `spawns` บูสต์ของจุดหลังจากนั้นอาจเลื่อนตามไปด้วย ให้เช็คก่อนเผยแพร่แมพที่มีบูสต์

สร้าง `src/shared/data/propCatalog.json` (คลังที่ตัวแก้ใช้ · ผลเหมือนเดิมทุกครั้ง ไม่แก้มือ): `key` จาก `SHEET_SPECS` (`src/client/assets.ts`) + ไฟล์ `.png` ใน `public/assets/sprites/paper/props/` · `category` ตามชื่อ (อาคาร/ตลาด/ป้ายและโคมไฟ/หิน/ต้นไม้/อื่นๆ) · `size` ขนาดภาพ · `h` และ `solid.r` ตั้งต้นที่วัดจากที่ `Terrain` วางจริงทุกโซน · `faceSets` คู่ภาพ `*_front`/`*_back` · `inSheetSpecs` บอกว่าภาพนั้นลงทะเบียนในเกมแล้วหรือยัง

## 6. Server: ตาราง, endpoint, สิทธิ์, audit

**ตาราง `map_layouts`** (SQLite ตัวเดียวกับบัญชี อยู่ในระบบสำรองเดิม): `zone_id, rev, json, status ('draft'|'published'), author, note, updated_at` · ร่างมีได้แถวเดียวต่อแมพ (autosave เขียนทับ) · เผยแพร่ = แถว `published` ใหม่ rev 1, 2, … · เก็บย้อนหลัง **20 revision** ต่อแมพ (`MAP_KEEP_REVS` ใน `server/db.ts`) rev แรกต่อจากไฟล์ใน repo (`rev` ใหม่ = max(ล่าสุดใน DB, rev ของไฟล์ใน repo) + 1)

**Endpoint** (`server/admin-maps.ts`) ค่าจากหน้าเว็บถูกตรวจที่ server ทุกครั้ง · ขนาด body ≤ 2 MB · หมายเหตุ ≤ 200 ตัวอักษร

| Endpoint | ทำอะไร | สิทธิ์ |
|---|---|---|
| `GET /api/admin/maps` | รายการแมพ (rev ใน repo/เผยแพร่/ร่าง) + สวิตช์ | `mapEdit` |
| `GET /api/admin/maps/:id/draft` | ร่าง → ถ้าไม่มีใช้ที่เผยแพร่ล่าสุด → ถ้าไม่มีใช้ไฟล์ใน repo + ผลตรวจ | `mapEdit` |
| `PUT /api/admin/maps/:id/draft` | บันทึกร่าง (ตรวจซ้ำที่ server ร่างที่ไม่ผ่านก็เก็บได้ แต่เผยแพร่ไม่ได้) ตอบสรุป diff | `mapEdit` |
| `POST /api/admin/maps/:id/publish` | เผยแพร่ร่างที่บันทึกไว้เป็น rev ถัดไป (ไม่ผ่านตรวจ = 400) | `mapEdit` |
| `GET /api/admin/maps/:id/revisions[/:rev]` | รายการ revision / JSON ของ rev นั้น | `mapEdit` |
| `POST /api/admin/maps/:id/rollback` | เผยแพร่ rev เก่าซ้ำเป็น rev ใหม่ (ตรวจตามกฎปัจจุบันก่อน) | `mapEdit` + `mapRollback` |
| `GET /api/admin/maps/:id/export` | JSON ที่เผยแพร่ล่าสุดในรูปไฟล์ใน repo (`text`) | `mapEdit` + `mapExport` |
| `GET /api/maps` | `{zoneId: rev}` ของที่เผยแพร่ (สาธารณะ ว่างเมื่อสวิตช์ปิด) | – |
| `GET /api/maps/:id[?rev=N]` | layout ที่เผยแพร่ (มี `rev` = แคชถาวรได้, ไม่มี = `no-store`) เสิร์ฟแม้สวิตช์ปิด เพราะห้องที่สร้างจาก rev นั้นอาจยังเปิดอยู่ | – |

**สิทธิ์** (`FEATURE_GROUPS`/`FEATURE_ROLES` ใน `src/shared/admin.ts` หมวด "ปรับเกม" ปรับต่อ role ได้ที่แท็บ "สิทธิ์"):
- `mapEdit` "แก้แมพ" — owner + GM (ดู/บันทึกร่าง/เผยแพร่/ทดลองเดิน/ดูประวัติ)
- `mapRollback` "ย้อนแมพกลับ revision เก่า" — owner เท่านั้นตั้งต้น (ต้องมี `mapEdit` ด้วย)
- `mapExport` "ส่งออกแมพเข้า repo" — owner เท่านั้นตั้งต้น (ต้องมี `mapEdit` ด้วย)
- สวิตช์ "ใช้แมพจาก DB" ใช้สิทธิ์ `balance` (เก็บใน `BalanceTuning.mapFromDb` ตามกติกา "เก็บเฉพาะที่ต่างจากโค้ด")

**Audit** (`admin_audit`): ทุกการ **บันทึกร่าง** (`map-draft`: ร่างจาก rev ไหน, เพิ่ม/ลบ/แก้กี่ชิ้น, กี่ข้อผิดพลาด), **เผยแพร่** (`map-publish`) และ **ย้อนกลับ** (`map-rollback`) ลงพร้อมผู้ทำ รหัสแมพ rev และสรุปการเปลี่ยน · การเปลี่ยนสวิตช์ลง audit ของแท็บปรับสมดุลเอง · ส่งออก/ทดลองเดินไม่ลง audit

ผู้เล่นทั่วไปไม่เห็นร่าง และไม่มี API เขียนนอกจาก endpoint ที่ตรวจสิทธิ์

## 7. เกมเลือกแมพอย่างไร

ลำดับตอนเกมสร้าง `Terrain` ของโซนหนึ่ง:
1. **แถว `published` ล่าสุดใน DB** ถ้าผ่านการตรวจ (`validateMap`) และสวิตช์ **"ใช้แมพจาก DB" เปิด** (ค่าในโค้ด = เปิด)
2. ไม่งั้นใช้ **JSON ใน repo** (`src/shared/data/maps/`)

ถ้าแถวที่เผยแพร่ไม่ผ่านการตรวจตามกฎปัจจุบัน server ข้ามมัน ใช้ไฟล์ใน repo และเตือนใน log (`[maps] … fails the check`) · **สวิตช์ปิด = ทางหนีฉุกเฉิน** ใช้ไฟล์ใน repo ทุกแมพ ทั้ง server และเบราว์เซอร์

**ฝั่ง server:** `applyMaps(db)` (บูต + หลังเผยแพร่/ย้อนกลับ/เปลี่ยนสวิตช์) โหลดแถวที่เผยแพร่เข้า `MapRegistry` แล้ว `refreshZone` ทุกแมพ
**ฝั่งเบราว์เซอร์:** `loadPublishedMaps()` (`src/client/mapSync.ts`) ก่อนโหลดภาพ ถาม `GET /api/maps` แล้วโหลด `GET /api/maps/:id?rev=N` (แคชใน localStorage ต่อโซน) ไม่ได้/offline = ใช้ JSON ที่ bundle มา เกมเริ่มได้เสมอ · เปลี่ยนแมพ server บอก rev ที่ห้องใช้ เบราว์เซอร์โหลด rev นั้นก่อนวาด (`ensureMap`) ให้ `Terrain` ตรงกับ server

**collision:** `Terrain.isBlocked`/`resolve` เช็ควงกลม กล่อง (หมุนตาม `rot`) และ polygon `blockers` · `pathfind.ts` ฝั่ง client อ่าน `terrain.blockers` ชุดเดียวกัน

### เวลาที่เผยแพร่มีผล (ไม่ต้องรีสตาร์ต server)

- **ห้อง/แชนแนลที่เปิดใหม่ = ใช้ทันที**

## 8. วิธีใช้ตัวแก้ (แท็บ "แมพ" ใน `/admin`)

ต้องมีสิทธิ์ `mapEdit` · ด้านล่างตัวแก้มีการ์ด "ที่มาของแมพ" (สวิตช์ใช้แมพจาก DB) สำหรับคนที่มีสิทธิ์ `balance`

**เริ่มงาน:** เลือกแมพที่แถบบน (บอกว่ามีร่าง/เผยแพร่ rev ไหน) → โหลดร่างที่บันทึกไว้ ถ้าไม่มีโหลดที่เผยแพร่ล่าสุด ถ้าไม่มีโหลดไฟล์ใน repo · **บันทึกร่างอัตโนมัติ** 1 วินาทีหลังแก้ (เตือนถ้าปิดหน้าตอนยังไม่บันทึก) · ผู้เล่นไม่เห็นร่าง

**จอ:** ซ้าย = เครื่องมือ, ตัวช่วยวาง, เลเยอร์ (ซ่อน 👁 / ล็อก 🔒 ต่อเลเยอร์), รายการข้อผิดพลาด · กลาง = canvas มุม isometric ตามเกม วางภาพกระดาษจริง · ขวา = กล่องคุณสมบัติของชิ้นที่เลือก + คลังภาพ (ค้นหา, แยกหมวด, ลากมาวางหรือคลิกเลือกแล้วคลิกวาง)

**เครื่องมือ**

| เครื่องมือ | ทำอะไร |
|---|---|
| 🖱️ เลือก/ย้าย | คลิกเลือก · Shift+คลิก เลือกเพิ่ม · ลากชิ้น = ย้าย · ลากพื้นว่าง = กรอบเลือกหลายชิ้น · ลากจุดฟ้าเหนือชิ้น = หมุน |
| ➕ วางของ | คลิกภาพในคลังแล้วคลิกบนแมพ (วางต่อได้) หรือลากภาพจากคลังมาปล่อย · Esc เลิก |
| 📍 NPC/ประตู | ย้ายหมุด NPC (ฟ้า, เพิ่ม/ลบไม่ได้), ประตู (ม่วง ปุ่ม "＋ เพิ่มประตู" เลือกปลายทาง+เลเวลขั้นต่ำ Delete ลบได้), จุดพัก (เหลือง), ที่เรียกบอส (แดง) |
| 👹 จุดเกิดมอน | คลิกพื้นว่างวางจุดใหม่ เลือกชนิดมอน/จำนวน/เวลาเกิดใหม่ที่ช่องขวา ลากกลางวง = ย้าย ลากจุดแดง = รัศมี |
| ⛔ ขอบเขต (polygon) | "＋ วาดใหม่" แล้วคลิกจุดต่อกัน ปิดด้วยคลิกจุดแรก/Enter/ดับเบิลคลิก · ลากจุด/ก้อน คลิกขอบเพิ่มจุด Delete ลบ หมุนด้วยแถบเลื่อน |
| 🛤️ ทางเดิน | เส้นหลายจุด + ความกว้าง (เป็นภาพพื้นเท่านั้น ไม่กั้นการเดิน) |
| 🌊 ทะเลสาบ/ลาวา | วงรี ลากกลาง = ย้าย ลากจุดฟ้า = รัศมีแกน x/z เพิ่มด้วยปุ่มด้านขวา |
| 🖌️ แปรงโปรย / ยางลบ | ดูหัวข้อ "แปรงโปรยและยางลบ" ด้านล่าง (ห้องบอสใช้ได้) |

**ปุ่มลัด:** Delete/Backspace ลบ · Ctrl+D ทำสำเนา · Ctrl+A เลือกทั้งหมด · Esc เลิกเลือก · ลูกศร ขยับทีละช่อง snap ตามทิศบนจอ · Ctrl+Z ย้อน · Ctrl+Y หรือ Ctrl+Shift+Z ทำซ้ำ · Alt (ค้างตอนลาก/วาง) ปิด snap ชั่วคราว · ล้อเมาส์ ซูม · ลากด้วยปุ่มขวา/กลาง หรือค้าง Space แล้วลาก เลื่อนมุมมอง

**Snap:** สวิตช์ "Snap เข้ากริด" + ขนาดช่อง 0.5 / 1 / 2 หน่วยโลก + "ชิดขอบชิ้นข้างเคียง" + โชว์กริด (ที่ "ตัวช่วยวาง" ด้านซ้าย)

**Undo/Redo:** ทุกการกระทำ (วาง ย้าย ลบ หมุน แก้ค่า) เป็นหนึ่งคำสั่ง ลึก 200 ขั้น (`HISTORY_DEPTH`) · ชี้ปุ่ม ↶/↷ เห็นชื่อการกระทำ

**หมุน 360°:** ช่ององศา + แถบเลื่อน (ที่กล่องคุณสมบัติ) หรือลากจุดฟ้า (Shift = ทีละ 15°) หมุนทั้งภาพและ collision (กล่อง/วงกลม) · มีกลับซ้าย-ขวา (flip), จางเมื่อบัง (fade), ปรับ collision (ทะลุได้/วงกลม/กล่อง), ปรับ x z สูง (h) · ถ้าชิ้นมีชุดภาพหน้า/หลัง (`*_front`/`*_back`) มีปุ่มสลับด้าน

**พื้นแบบในเกม (เจ้าของตกลง 2026-11-21):** สวิตช์ "พื้นแบบในเกม" ใน "ตัวช่วยวาง" (ค่าตั้งต้น = เปิด, ปิด = สีเรียบแบบเดิม ระหว่างภาพพื้นยังโหลดไม่เสร็จก็โชว์สีเรียบ) ปูด้วยภาพพื้นจริง `sprites/paper/ground/` ตามกติกาเดียวกับเกม (`src/shared/groundLook.ts` ที่ `world.ts` ใช้ด้วย): ภาพพื้นหลักต่อธีม (เมืองกลางแยก 4 ส่วน เส้นแบ่งคดตาม `QUADRANT_JITTER`), ทางเดินกว้างตามธีม `TRAIL_WIDTH` (**เกมไม่อ่าน `w` ของทาง** ตัวแก้จึงวาดตามเกม), ลานดินรอบจุดเริ่ม/ที่เรียกบอส/ริมทะเลสาบ, เมืองกลางปูอิฐถึงกำแพง + ลานน้ำพุหินปู (รัศมี `HUB_PLAZA_RADIUS`), ห้องบอสปูพื้น `room_<ธีม>`, ทะเลสาบเป็นน้ำแข็ง/ลาวา, นอกกรอบเดินได้มืดลง · เป็นภาพประมาณ: ไม่มี noise/การผสมขอบ/แสงของ shader ในเกม · วาดเป็น pattern ทีละชิ้นในพิกัดโลก (canvas transform = มุม isometric) + ภาพย่อหลายขนาด (mip) จึงไม่ช้าตอนซูมออก
- เลเยอร์ **"ของประดับเล็ก (ตัวอย่าง ไม่ตรงเป๊ะ)"** (ปิดไว้ตั้งต้น เปิดที่รายการเลเยอร์) หญ้า ดอกไม้ ก้อนหินจาก atlas `decor_<ธีม>` วางแบบเดียวกับเกม (ริมทาง ทุ่ง ริมทะเลสาบ หลบจุดเริ่ม ประตู collision) แต่สุ่มคนละ seed กับเกม ตำแหน่งจึงไม่ตรง แก้ไม่ได้ ไม่เซฟ ซูมออกมาก (scale < 3) ไม่วาด

**ตรวจแมพ:** ปุ่ม 🔍 ตรวจแมพ รัน `validateMap` ตามกฎเดียวกับ server แล้วลิสต์ข้อผิดพลาด/คำเตือนด้านซ้าย คลิกรายการ = กระโดดไปเลือกชิ้นนั้น · ปุ่ม ⭕ วง collision โชว์/ซ่อนวงกล่องกั้นของทุกชิ้น (ตรวจบ้านทับธง) · ⛶ ทั้งแมพ

**พรีวิว (🎮 ทดลองเดิน):** บันทึกร่างล่าสุดแล้วเปิดเกมแท็บใหม่ที่ `/?previewMap=<รหัสแมพ>` · เกมโหลดร่างด้วยการล็อกอินของคุณ (`GET /api/admin/maps/:id/draft`) ส่ง `previewMap` ตอน join · server ตรวจสิทธิ์ `mapEdit` ซ้ำ (ไม่ใช่ Guest) แล้วสร้าง **ห้องส่วนตัวของคุณคนเดียว** จากร่างนั้น ไม่เซฟตัวละคร ไม่ได้ของ/EXP จริง ผู้เล่นอื่นไม่เห็น มีแถบแดงบนจอ ปิดแท็บเมื่อเสร็จ · ร่างที่ไม่ผ่านตรวจเดินไม่ได้ · คนที่ไม่มีสิทธิ์ใส่ `?previewMap` จะเข้าเกมปกติ

**เผยแพร่ (🚀):** บันทึกร่างก่อน → ตรวจ (มี error = เผยแพร่ไม่ได้) → กล่องยืนยันบอกสรุป เพิ่ม/ลบ/แก้กี่ชิ้น และเวลามีผล → rev ใหม่ · แถบบนแสดง "ต่างจากที่เผยแพร่" ตลอด · ปุ่ม ↩ โหลดที่เผยแพร่ล่าสุด ทิ้งร่างแล้วโหลดฉบับที่ใช้อยู่

### แปรงโปรยและยางลบ (🖌️, เจ้าของตกลง 2026-11-21)

- **เลือกภาพ:** ตอนเครื่องมือนี้เปิดอยู่ คลิกภาพในคลังด้านขวา = เพิ่ม/เอาออกจากแปรง (เลือกได้หลายภาพ แปรงสุ่มจากภาพที่เลือก) รายการที่เลือกอยู่ในกล่องคุณสมบัติ (คลิกเพื่อเอาออก / ล้าง)
- **โปรย:** คลิกหรือลากบนแมพ ทุกครั้งที่เมาส์เลื่อนไปครึ่งรัศมี วางชุดใหม่ในวง · ค่าในกล่องคุณสมบัติ: รัศมี 1–25 (ตั้งต้น 4, ปุ่ม `[` `]` ย่อ/ขยาย), ความหนาแน่น น้อย/กลาง/มาก = 1.5/4/9 ชิ้นต่อ 100 ตารางหน่วยต่อครั้ง (ตั้งต้น กลาง), ขนาดสุ่ม ×0.85–×1.15 ของความสูงในคลัง (วงกั้นขยายตามขนาด), สุ่มกลับซ้าย-ขวา (เปิด), สุ่มหมุน (ปิด), หลบทางเดินและทะเลสาบ (เปิด) · ไม่ใช้ snap
- **ไม่วางทับ** (`spotIsFree`/`KEEP_CLEAR` ใน `scatter.ts`): นอกกรอบเดินได้, ใน/ชิดขอบ polygon ขอบเขต, วงกั้นที่ไม่ผูกกับชิ้น, NPC 1.5, ประตู 2.5, จุดพัก 2, จุดเกิดมอน (จุดกลาง) 2, ที่เรียกบอส 3, จุดเริ่ม 3 (แมพฟาร์ม), ห้องบอส: สนามบอส (`arena + 1`) และจุดเกิดผู้เล่น 2 (หน่วยโลก บวกรัศมีของชิ้นเอง) · ชิ้นที่กั้นทางไม่ซ้อนวงกั้นกัน ชิ้นที่เดินทะลุเว้นห่างกันเล็กน้อย
- **ยางลบ:** ลบของวางที่จุดยืนอยู่ในวง (เลือก "ลบเฉพาะภาพที่เลือกไว้" ได้) วงกั้นที่ผูกกับบ้านเมืองกลางหายไปด้วยเหมือนกด Delete · ไม่ลบ NPC ประตู จุดเกิด ขอบเขต
- **ย้อนกลับ:** กด-ลาก-ปล่อยหนึ่งครั้ง = หนึ่งขั้น (`โปรย N ชิ้น` / `ยางลบ N ชิ้น`) · ชั้นของวางที่ล็อก/ซ่อนอยู่ แปรงไม่ทำงาน (วงเป็นเส้นประ)
- **ค่าแปรงเก็บในเบราว์เซอร์ของแต่ละคน** (`localStorage` `me.scatter`) ไม่มีค่าระดับเซิร์ฟใน `/admin` (เจ้าของตกลง 2026-11-21: เป็นเครื่องมือของตัวแก้ ไม่ใช่ค่าเกม)

### เทียบ revision (เจ้าของตกลง 2026-11-21)

ใต้ตาราง "ประวัติการเผยแพร่" เลือก **A (เดิม)** กับ **B (ใหม่)** จาก: ร่างที่เปิดอยู่, rev ที่เผยแพร่ (20 ตัวล่าสุด), ไฟล์ที่มากับเกม (rev ใน repo) · ตั้งต้น A = rev ที่ใช้อยู่ (ยังไม่เคยเผยแพร่ = ไฟล์ในเกม), B = ร่าง · กด 🔍 เทียบ:
- บนแมพ (ทับภาพร่างที่เปิดอยู่ จอมืดลงเล็กน้อย): **เขียว = เพิ่ม**, **แดง = ลบ** (โชว์ภาพจางของชิ้นที่หายไป), **เหลือง = ย้าย** (ประที่เดิม เส้นลูกศรไปที่ใหม่) / **แก้** (ค่าอื่นเปลี่ยน เช่น หมุน ขนาด ภาพ)
- รายการสรุป (ลบ → เพิ่ม → ย้าย → แก้, ชี้ดูชื่อค่าที่ต่าง) คลิก = ซูมไปที่ชิ้นนั้น และเลือกชิ้นถ้ายังอยู่ในร่าง
- **ดูอย่างเดียว ไม่แตะร่าง** · ร่างที่ใช้เทียบคือสภาพตอนกดเทียบ (แก้ต่อแล้วกดเทียบใหม่) · เปลี่ยนแมพ/เผยแพร่/ย้อนกลับ = ปิดการเทียบเอง
- ตรรกะ: `diffMapItems()` ใน `src/shared/mapDiff.ts` (ข้าง `diffMaps` ที่กล่องยืนยันเผยแพร่และ audit ใช้ ซึ่งไม่เปลี่ยน) ชิ้นที่มี id จับคู่ด้วย id; รายการที่ไม่มี id (ประตู จุดเกิด จุดพัก ทะเลสาบ วงกั้น) จับคู่ตัวที่เหมือนกันเป๊ะก่อน แล้วจับคู่ที่เหลือด้วยชนิดเดียวกัน (ประตูไปที่เดียวกัน มอนเดียวกัน) + ใกล้สุด แล้วค่อยใกล้สุดข้ามชนิด จำนวนเพิ่ม/ลบ/แก้จึงตรงกับ `diffMaps` · จุดเริ่ม/เขตปลอดภัย/กรอบเดิน รวมเป็นรายการ "ค่าของแมพ" · `tests/map-compare.test.ts`

**ประวัติการเผยแพร่ (ใต้ตัวแก้):** ตาราง rev / ใคร / เมื่อไหร่ / หมายเหตุ (rev บนสุด = ที่ใช้อยู่) · ปุ่ม **↩ ย้อนกลับไป rev นี้** (สิทธิ์ `mapRollback`) เผยแพร่ rev นั้นซ้ำเป็น rev ใหม่ทันที ของเดิมยังอยู่ในประวัติ ร่างในตัวแก้ไม่ถูกแตะ · ปุ่ม **📦 ส่งออกเข้า repo** (สิทธิ์ `mapExport`) ดาวน์โหลด `<รหัสแมพ>.json` ที่เผยแพร่ล่าสุด ในรูปแบบเดียวกับไฟล์ใน repo

### ส่งออกเข้า repo (ควรทำเป็นระยะ)

1. กด 📦 ส่งออก ได้ `<zoneId>.json`
2. วางที่ `src/shared/data/maps/<zoneId>.json` ทับไฟล์เดิม
3. แตก branch, `npm run typecheck`, commit, เปิด PR (กฎ Git ปกติ)

ผล: git เก็บประวัติ เครื่อง dev/CI ได้แมพล่าสุด และถ้าปิดสวิตช์ "ใช้แมพจาก DB" เกมก็ยังได้ฉบับล่าสุด (ไม่บังคับ แต่ควรทำ เพราะ DB ล่ม/ปิดสวิตช์จะถอยกลับไปไฟล์ใน repo) · ค่า `rev` ในไฟล์ที่ส่งออกคือ rev ที่เผยแพร่

## 9. ขั้นตอนสุ่มแมพใหม่ / อบใหม่

ตอนนี้ **ไม่มีปุ่ม "สุ่มเติม" ในตัวแก้** (แผนเดิมมี ยังไม่ทำ) generator ยังอยู่ในโค้ดสำหรับ `tools/bake_maps.ts` เท่านั้น

**อยากได้แมพสุ่มใหม่ทั้งใบ** (เจ้าของสั่ง AI/คนทำ ทำเป็น PR):
1. ถามเจ้าของก่อนว่ายอมทิ้งของที่เคยแก้ในแมพนั้นหรือไม่ (การอบเขียนทับทุกไฟล์ ถ้าต้องการไว้ให้ส่งออกที่เผยแพร่ล่าสุดมาไว้ก่อน หรือเก็บไฟล์ที่ไม่ต้องการให้ทับไว้ข้างนอกแล้ววางกลับ)
2. แก้ `seed` ของโซนใน `src/shared/data/zones.ts` (หรือโค้ด generator) ตามที่ต้องการ
3. `node --import tsx tools/bake_maps.ts` → ได้ JSON ใหม่ทุกไฟล์ (อยากเปลี่ยนแค่ไฟล์เดียว ให้ `git checkout` ไฟล์ที่เหลือกลับ)
4. `tests/map-bake.test.ts` ต้องผ่าน (ถ้าแก้ generator ตั้งใจให้ต่างจากเดิม ให้ปรับเทสต์ตามที่ตกลง) แล้ว `npm run typecheck`
5. PR → merge → deploy · **อย่าลืม** ถ้าแมพนั้นเคยเผยแพร่ใน DB แล้ว ค่า DB จะ **ชนะไฟล์ใหม่** (ลำดับในหัวข้อ 7) ต้องให้ผู้มีสิทธิ์เผยแพร่ไฟล์ใหม่ทับใน DB (โหลดไฟล์ที่มากับเกมมาเป็นร่างแล้วเผยแพร่) หรือปิดสวิตช์ชั่วคราว

**ภาพกระดาษใหม่** ดูหัวข้อ 5 (รัน `build_prop_catalog.ts` + เพิ่ม `SHEET_SPECS`)

## 10. ข้อจำกัดที่รู้

- **ภาพกระดาษเป็นภาพแบนหันเข้ากล้อง** การหมุนจึงเป็นแค่เอียงภาพบนจอ ไม่ใช่เห็นด้านข้างของบ้านจริง มุมเล็กดูปกติ บ้านใหญ่ที่หมุนมากดูเหมือนสติกเกอร์เอียง · collision และเงาหมุนตามจริง เหมาะกับกำแพง รั้ว สะพาน ป้าย
- **ท่าเรือ:** รูปแพ (ที่เดินได้) อยู่ในโค้ด แก้ในตัวแก้ไม่ได้ (ดูหัวข้อบนสุด) · การตรวจ "เดินถึงไหม" ของตัวแก้ไม่รู้จักน้ำ: ลากประตู/NPC/จุดเกิดไปไว้กลางน้ำ ตัวแก้จะไม่เตือน แต่ในเกมเดินไปไม่ถึง ให้วางบนแพเสมอ · ภาพตัว NPC พ่อค้าของเถื่อนใช้ชื่อ `hb_smuggler_npc` (เดิมชนกับภาพตึก `hb_smuggler` ทำให้ตึกวาดเป็นภาพตัวคน แก้ใน PR 9 เจ้าของ OK) · แมพชั้น 2 ที่เหลือ (อ่าวลักลอบ สุสานเรือผี วังวน) ยังไม่มีในเกม เมื่อทำแมพใหม่ให้เพิ่ม id ใน `FLOOR2_IDS` (`tools/bake_maps.ts`) + import ใน `mapRegistry.ts` แล้วอบใหม่
- ทางเดิน (`paths`) เป็นภาพพื้น ไม่กั้นการเดิน · กรอบเดินได้เป็นสี่เหลี่ยมจัตุรัสด้วย `walkable.half` ตัวเดียว (ยังไม่มี polygon) และตัวแก้ยังไม่มีช่องแก้ค่านี้ ใช้ polygon "ขอบเขต" แทน
- NPC เพิ่ม/ลบจากตัวแก้ไม่ได้ (ย้ายได้) · จุดพักและที่เรียกบอสย้ายได้เท่านั้น
- ค่า `boost` ของมอนผูกกับลำดับจุดเกิด (หัวข้อ 4)
- แถวที่เผยแพร่ซึ่งไม่ผ่านการตรวจตามกฎปัจจุบัน (เช่น กฎเข้มขึ้นภายหลัง) จะถูกข้ามและใช้ไฟล์ใน repo แทน
- แคชเบราว์เซอร์เก็บ layout ที่เผยแพร่ล่าสุดต่อโซน 1 รายการใน localStorage

## 12. ห้องบอสชั้น 1 ในตัวแก้ (เจ้าของสั่ง 2026-11-21)

ห้องบอส 4 ห้อง (`emerald_forest_room`, `misty_marsh_room`, `frost_reach_room`, `ashen_isle_room`) อยู่ในรายการแมพของตัวแก้ ใต้แมพแม่ ใช้ endpoint/DB/สิทธิ์ `mapEdit` ชุดเดิม โดยใช้ id ของห้อง (`<field>_room`) เป็น `zone_id`

**ไฟล์:** `src/shared/data/maps/<field>_room.json` อบด้วย `tools/bake_maps.ts` (`BOSS_ROOM_IDS`) จาก `GENERATED_ROOMS` ใน `zones.ts` (ผลของ `bossRoom()` ล้วน) ตาม schema เดิม ฟิลด์เดิมความหมายเดิม เพิ่มฟิลด์เสริม `room: {of, arena, boss: {monster, x, z, radius}}` ที่บอกว่าเป็นห้องบอสและเก็บค่าที่ล็อก (ไฟล์ที่ไม่มี `room` อ่านได้เหมือนเดิมทุกอย่าง) · `paths`/`water`/`portals`/`spawns`/`npcs`/`rest` เป็น `[]` · ห้องภูเขาไฟมีวง collision พิเศษหนึ่งวง (ก้อนหินกลางห้อง `bossSolid`) อยู่ใน `colliders` และล็อกไว้ · `tests/map-bake.test.ts` เทียบทุกค่ากับ generator เดิม (`seed` ของห้อง = seed ฟาร์ม+500 อยู่ในโค้ด ไม่อยู่ในไฟล์ ใช้ตอนอบครั้งเดียว)

**อ่านจาก registry:** `Terrain` ของห้องอ่าน `MapRegistry.get('<field>_room')` เหมือนแมพอื่น ลำดับเดิม (DB published → JSON ใน repo, สวิตช์ "ใช้แมพจาก DB") · `zones.ts`: `roomWithMap()` เอาเฉพาะ `zone.start` (จุดเกิดผู้เล่น) จากไฟล์ ที่เหลือ (ขนาด ธีม seed บอส สนาม สถิติ) มาจาก `bossRoom()` · `refreshZone(id)` ทำงานกับ id ห้องด้วย (server `applyMaps`, client `mapSync`/`mapPreview`) · ห้องที่มีคนอยู่ไม่เปลี่ยนกลางคัน ห้องที่เปิดใหม่ใช้ของใหม่

**ล็อก** (`validateMap()` บังคับทั้งตอนบันทึกร่าง เผยแพร่ ย้อนกลับ และโหลด DB — ร่างที่ผิดเก็บได้แต่เผยแพร่ไม่ได้, แถวที่เผยแพร่แล้วผิดถูกข้าม): ต้องเท่ากับไฟล์ที่มากับเกม (`ctx.baseline`): `id`, `floor`, `zone.half`, `zone.theme`, `walkable.half`, บล็อก `room` (ตำแหน่งบอส รัศมีสนาม), `colliders` · ต้องไม่มี `portals`/`spawns`/`npcs`/`rest`/`paths`/`water`/`lair`/`safe`/`quadrants` · **จุดเกิดผู้เล่น** คือ `zone.start − (2, 2)` (`Sim.spawnPoint`; `zone.start` เองอยู่นอกวงสนามตามสูตรเดิม ตัวแก้ลากหมุดที่จุดเกิดจริงแล้วเขียน `start` กลับให้) ต้องอยู่ในวงสนาม (`arena + 1` หัก 0.5) และไม่อยู่ใน collision/ใน polygon · ต้องมีช่องว่างที่เดินจากจุดเกิดไปถึงระยะ 4 หน่วยจากบอสได้ (BFS บนตาราง นับวงสนามเป็นกำแพง) ไม่งั้น `unreachable` · ข้อความผิดพลาดรหัส `locked` = ไปแตะของที่ล็อก

**ในตัวแก้:** เลือก "ห้องบอส · …" ในรายการ (ย่อหน้าใต้ฟาร์มแม่) · เครื่องมือเหลือ เลือก/ย้าย, วางของ, ขอบเขต (polygon), จุดเกิดผู้เล่น (หมุดเขียว) · ซ่อนเครื่องมือประตู/NPC/จุดเกิดมอน/ทางเดิน/ทะเลสาบ · เลเยอร์ "แนวช่วยดู" วาดวงสนามบอส (เหลืองประ) ขอบที่เดินออกไม่ได้ (แดง) และบอส (ล็อก ลากไม่ได้)

**ทดลองเดิน (`?previewMap=<field>_room`):** เข้าห้องส่วนตัวของร่างได้เหมือนแมพอื่น แต่ **ไม่มีบอส** (เจ้าของเลือก 2026-11-21: พรีวิวไม่ใช่รอบห้องบอสจริง ไม่มีปุ่มออก/นับแพ้) เดินดูของประดับ collision และจุดเกิดได้ · รอบห้องบอสจริงดูได้ด้วยกุญแจที่แท่นเรียกบอสของฟาร์มแม่

## 13. สร้างแมพใหม่ (＋ แมพใหม่, เจ้าของตกลง 2026-11-21)

**ปุ่ม "＋ แมพใหม่"** (แถบบนของตัวแก้, สิทธิ์ `mapCreate`) สร้างได้ 3 แบบ:
1. **คัดลอกแมพเดิม** ได้ทุกแมพ รวมห้องบอสและแมพที่สร้างเอง · ต้นฉบับ = ฉบับที่เผยแพร่อยู่ (ยังไม่เคยเผยแพร่ = ไฟล์ในเกม, แมพสร้างเองที่ยังไม่เผยแพร่ = ร่าง)
2. **พื้นเปล่า** เลือกธีม + ครึ่งความกว้าง **20–150 หน่วย ตั้งต้น 50** (`EMPTY_HALF`) กรอบเดินได้ = ครึ่งกว้าง − 8 จุดเริ่มกลางแมพ
3. **นำเข้าไฟล์ JSON** ของตัวแก้ (เช่นไฟล์จาก 📦 ส่งออก) server ตรวจรูปแบบก่อน

ทุกแบบ (`copyMap` ใน `src/shared/customZones.ts`): **ไม่มีบอสและ NPC** — ห้องบอสที่คัดลอกกลายเป็นแมพธรรมดา สนามบอสเหลือแค่พื้นและของประดับ จุดเกิดผู้เล่นเดิมของห้องกลายเป็นจุดเริ่ม · ที่เรียกบอสของแมพฟาร์มและ NPC เมืองกลางไม่ติดมา · ประตูเดิมติดมา (ลบ/แก้ได้)

**ค่าแมพ** (กรอกตอนสร้าง แก้ทีหลังได้ที่การ์ด "⚙️ ตั้งค่าแมพ" ใต้ตัวแก้, เก็บเป็น `CustomZoneDef` ในตาราง `custom_zones`): ชื่อไทย (ต้องมี ≤ 40), ชื่ออังกฤษ (ใช้ตั้งรหัส `c_<ชื่อ>` ซ้ำได้เป็น `_2` ไม่มี = `c_map` รหัสเปลี่ยนไม่ได้), ชั้น 1–9, เลเวลแนะนำ (โชว์เหมือนแมพอื่น · เลเวลขั้นต่ำที่เข้าได้ตั้งที่ประตูแต่ละบาน), เขตปลอดภัย (ทั้งแมพ หรือในกำแพงถ้าคัดลอกเมืองกลาง · ทั้งแมพปลอดภัย = มอนถูกดันออก การ์ดเตือนถ้ามีจุดเกิดมอน), แชนแนล (CH 1–10 แบบแมพฟาร์ม), Auto Play ได้/ไม่ได้ · ธีมและขนาดมาจากผังแมพ

**เข้าเกมเมื่อไหร่:** แมพใหม่เป็น **ร่าง** ผู้เล่นไม่เห็น จนกด 🚀 เผยแพร่ (ผ่านการตรวจเหมือนแมพอื่น) · ผู้เล่นเข้าได้ผ่าน **ประตู** ที่วางในแมพอื่น (📍 ＋ เพิ่มประตู แล้วเลือกปลายทาง ★ ชื่อแมพ) หรือ GM วาร์ป · ทดลองเดิน ประวัติ ย้อนกลับ เทียบ revision แปรง ใช้ได้เหมือนแมพอื่น · 📦 ส่งออกได้เป็นไฟล์สำรอง (แมพสร้างเองไม่มีไฟล์ใน repo สร้างกลับด้วย "นำเข้าไฟล์ JSON")

**ซ่อน (🙈)** (สิทธิ์ `mapCreate`): ออกจากเกมทันที ผู้เล่นที่อยู่ในแมพถูกย้ายไปเมืองกลางพร้อมข้อความ ประตูที่ชี้มาไม่ทำงาน ร่างและประวัติยังอยู่ ทดลองเดินยังได้ · เปิดกลับ (👁) ได้

**ลบจริง (🗑)** (สิทธิ์ `mapDelete`, เจ้าของตกลงให้ลบจริงได้): ถามยืนยัน + พิมพ์รหัสแมพ · ค่าแมพ ร่าง และทุก revision หายจาก DB (กู้ได้จากไฟล์สำรอง DB เท่านั้น) · ผู้เล่นในแมพไปเมืองกลาง · **ลบไม่ได้ถ้ายังมีประตูจากแมพอื่น (ร่าง ฉบับที่เผยแพร่ หรือไฟล์ในเกม) ชี้มา** — ไม่งั้นแมพนั้นจะไม่ผ่านการตรวจแล้วเกมถอยไปใช้ไฟล์ใน repo · แมพที่มากับเกมลบไม่ได้

**สิทธิ์:** `mapCreate` "สร้างแมพใหม่" และ `mapDelete` "ลบแมพที่สร้างเอง" ตั้งต้น owner + GM (เจ้าของ 2026-11-21 "ได้ทั้งสอง") ปรับต่อ role ได้ในแท็บสิทธิ์ ต้องมี `mapEdit` ด้วย · **Audit:** `map-create` (วิธีสร้าง), `map-settings`, `map-hide`/`map-show`, `map-delete` (+ จำนวนผู้เล่นที่ถูกย้าย)

**ในเกม (โค้ด):** server `applyMaps` อ่าน `custom_zones` + แถวเผยแพร่ล่าสุด แมพที่ไม่ซ่อนและผ่านการตรวจเข้า `MapRegistry.setCustom` แล้ว `refreshZone` สร้าง `ZoneDef` (`zoneFromCustom`, `custom: true`) ใส่ `ZONES` · `Channels` รับโซนที่เพิ่มทีหลัง (`find`) แมพไม่มีแชนแนลปิดห้องเมื่อว่าง · `GameWorld.closeZone` ย้ายคนออกตอนซ่อน/ลบ · เบราว์เซอร์: `GET /api/zones` (ค่าแมพ + rev ที่เผยแพร่) ตอนบูต และถามใหม่เมื่อ server พาไปแมพที่ยังไม่รู้จัก (`ensureMap`) · การตรวจ (`checkMap`) นับรหัสแมพสร้างเองทุกตัว (รวมที่ซ่อน) เป็นปลายทางประตูที่ถูกต้อง · **สวิตช์ "ใช้แมพจาก DB" ไม่มีผลกับแมพสร้างเอง** (ไม่มีไฟล์ให้ถอยไป) · **เซฟเก่าปลอดภัย:** ไม่เปลี่ยนรูปแบบเซฟ เข้าเกมเริ่มที่เมืองกลางเหมือนเดิม ตัวละครที่หลุดในแมพที่ถูกซ่อน/ลบ กลับเข้าเกมที่เมืองกลาง

**ยังไม่ทำ:** บอส/ที่เรียกบอส/NPC ในแมพสร้างเอง · มินิเกมแบบอื่น (ทำทีละแบบ แบบแรก = รอดมอนเป็นระลอก หัวข้อ 14)

**ตั้งในตัวแก้:** การ์ด "⚙️ ตั้งค่าแมพ" › มินิเกม "รอดมอนเป็นระลอก" + ติ๊กชนิดมอนที่ใช้ (มอนธรรมดาทุกชนิด ไม่รวมบอส ≤ 10 ชนิด, ไม่ติ๊ก = สไลม์เขียว) · เครื่องมือ 🌀 **จุดเกิดระลอก** (เฉพาะแมพสร้างเอง ≤ 30 จุด รัศมี 0.5–30, `MapData.waveSpots` ฟิลด์เสริม แมพเก่าไม่มี) มอนแต่ละระลอกวนวางทีละจุด ไม่มีจุดเลย = รอบจุดเริ่ม · แมพมินิเกมไม่มีแชนแนลและ Auto Play · เผยแพร่และวางประตูชี้มาเหมือนแมพสร้างเองอื่น

**เล่น:** เดินเข้าประตู (หรือ GM วาร์ป) → **ห้องของกลุ่มตัวเอง** (Sim ละกลุ่ม ห้อง 1, 2, …) · มีปาร์ตี้: สมาชิกที่ยืนแมพเดียวกันเข้าด้วยกัน คนที่ตามมาทีหลังเข้าห้องของปาร์ตี้ (ถ้ายังไม่ชนะ) · นับถอยหลัง (ตัวเลขใหญ่กลางจอ) → ระลอก 1 → ฆ่าหมด → ได้ทอง → พัก → ระลอกถัดไป · บรรทัดกลางจอ "ระลอก n/N · มอนเหลือ x ตัว · ❤ ชุบได้" · ปุ่ม **"ออกจากมินิเกม"** ออกได้ตลอด · มอนทุกตัวในระลอกไล่ผู้เล่น (aggro 60) แรงขึ้นทุกระลอก
- **นับถอยหลังก่อนระลอกแรกเริ่มเมื่อทุกคนโหลดแมพเสร็จ** (เจ้าของ 2026-11-24) หรือครบ "เวลารอผู้เล่นโหลดสูงสุด" (`roomLoadWait` แท็บปรับสมดุล ค่าเดียวกับห้องบอส โค้ด 10 วิ) ระหว่างรอขึ้น "รอผู้เล่นโหลด… 2/3" (`WaveSnap.wait`) · สมาชิกตี้ที่ตามเข้ามาระหว่างรอ ถูกรอด้วย · กติกาเดียวกับห้องบอส ดู [boss-rooms.md](boss-rooms.md)
- **รางวัล:** มอนให้ EXP ปกติ **ไม่ดรอปของ** · ผ่านระลอก n ได้ "ทองต่อระลอก × n" ทุกคนในห้อง (ตายอยู่ก็ได้) · ผ่านครบได้โบนัสทอง + EXP · แพ้กลางทางได้ทองของระลอกที่ผ่านแล้ว
- **ตาย:** ชุบด้วยขนนกฟีนิกซ์ได้ 3 ครั้งเหมือนห้องบอส ×1 · กด "ฟื้นคืนชีพหน้าประตู" = ออกจากมินิเกม (เสีย EXP ตามปกติ) · ตายหมดทีม: มีเวลาชุบตาม "เวลาชุบตอนตายหมดทีม" (แท็บปรับสมดุล) ไม่มีใครชุบ = แพ้
- **ออก:** ชนะ/แพ้/กดออก/ฟื้น → ไปยืนหน้าประตูที่เดินเข้ามา (ห่างประตู ~4 หน่วยไปทางจุดเริ่มของแมพนั้น ไม่เด้งกลับเข้า) · วาร์ปเข้า (ไม่มีประตู) = กลับจุดที่ยืนตอนถูกวาร์ป · ซ่อน/ลบแมพ = ทุกคนในห้องไปเมืองกลาง
- **จำกัดรอบต่อวัน** (ตั้งต้น 0 = ไม่จำกัด) นับต่อตัวละครตามวันไทย **เก็บในหน่วยความจำ รีสตาร์ต server แล้วนับใหม่** · Guest เล่นได้

**ค่าใน /admin** (แท็บ "แมพ" การ์ด "มินิเกม: รอดมอนเป็นระลอก", สิทธิ์ `balance`, เก็บใน `BalanceTuning.waves` เฉพาะที่ต่างจากโค้ด ลง audit ของแท็บปรับสมดุล, ห้องที่กำลังเล่นใช้ค่าเดิมจนจบ):

## 15. ขยายแมพฟาร์มชั้น 1 ×1.5 (เจ้าของตกลง 2026-11-24)

**ขอบเขต:** แมพฟาร์มชั้น 1 ทั้ง 4 (`emerald_forest`, `misty_marsh`, `frost_reach`, `ashen_isle`) ใหญ่ขึ้นด้านละ ×1.5 (`half` 64 → 96, กรอบเดินได้ 56 → 88, พื้นที่ราว 2.25 เท่า) · **ไม่เปลี่ยน:** เมืองทุกเมือง ห้องบอสทุกห้อง แมพชั้น 2 และแมพที่สร้างเอง

**ทำในตัวสร้างแมพ ไม่ได้แก้ JSON ด้วยมือ:** `grownFarm()` + `FARM_SCALE` ใน `zones.ts` ขยายค่าที่วาดไว้ (ขนาด จุดเริ่ม/ค่าย ทางเดิน ที่เรียกบอส ทะเลสาบ/บ่อลาวาทั้งตำแหน่งและรัศมี) ก่อน `scatterZone` แล้วอบใหม่ด้วย `tools/bake_maps.ts` (ไฟล์ที่เปลี่ยนมีแค่ 4 แมพนี้ ที่เหลือเหมือนเดิมทุกไบต์ `map-bake.test.ts` ยังเทียบกับตัวสร้าง)
- **ค่ายกับประตูกลับเมือง:** ค่ายขนาดเท่าเดิม ประตูกลับเมืองจึงอยู่ข้างค่ายระยะเท่าเดิม (ย้ายตามค่าย ไม่ได้ถูกดันออกจากกลางแมพ)
- **จำนวนมอน:** แต่ละชนิด ×2.25 ตามพื้นที่ (`FARM_DENSITY`) แล้ว **×3 ให้เต็มแมพ** (`FARM_FILL`, เจ้าของ 2026-11-25 "จุดเกิดให้เต็มไม่มีที่ว่าง" เลือก ×3 จากตัวเลือก ×2 / ×3 / เต็มทุกที่ ≈350 จุด): ป่ามรกต 47 → 318 ตัว 176 จุด · หนองน้ำ 44 → 297 ตัว 159 จุด · หิมะ 41 → 276 ตัว 169 จุด · ภูเขาไฟ 42 → 284 ตัว 189 จุด · ยังเรียงชนิดจากค่ายไปบอสตามแถบเดิม สุ่มด้วย seed เดิม · เวลาเกิดใหม่เท่าเดิม · ภาระ server ต่อห้องราว 3 เท่าของ ×2.25
- **จุดเกิดที่เปิดใช้ % (`/admin` แท็บปรับสมดุล การ์ดมอน ตาราง "จุดเกิดที่เปิดใช้ (แมพฟาร์มชั้น 1)", `Balance.farmSpots`, สิทธิ์ `balance`, ลง audit):** ต่อแมพ 0–100 ค่าในโค้ด 100 · จุดที่ปิดเลือกด้วยลำดับ golden ratio ตาม index (`packCount`) จึงกระจายทั้งแมพและทุกชนิด (33% ≈ เท่ากับก่อนเติม) · มีผลทันที: ลด = มอนของจุดที่ปิดตายแล้วไม่เกิดใหม่, เพิ่ม = ทยอยเกิดตามเวลาเกิดใหม่ · จุดที่ปิดไม่กันที่ตอนจุดอื่นย้าย (`moveSpawner`) · ใช้คู่กับ "มอนต่อจุด ×" ได้
- **เดี่ยว/กลุ่มปนกัน (เจ้าของ 2026-11-25 "ไม่อยากให้ฟิก สุ่มเกิดเป็นกลุ่มบ้างเดี่ยวบ้าง"):** ตอนอบแมพ แต่ละจุดสุ่มขนาดเอง ครึ่งหนึ่งตัวเดียว ครึ่งหนึ่งกลุ่ม 2 หรือ 3 ตัว (`FARM_GROUP` + `Scatter.mixed` ใน `zones.ts`, รัศมีกลุ่ม 3 เว้นห่าง 9 เหมือนทีม) จำนวนมอนรวมเท่าเดิม จุดจึงน้อยลง (56/62/53/59 จุด) · ทีมผสมเดิม (ภูตหิมะ+นักมวย, จอมเวท+อัศวิน) คงเดิม · เป็นค่าในโค้ด ไม่มีใน /admin (ปรับรายจุดได้ที่ตัวแก้แมพ ช่องจำนวน)
- **เกิดใหม่สุ่มที่ (เจ้าของเลือก "สุ่มจุดใหม่ในย่านของมันทุกครั้ง"):** เมื่อมอนของจุดหนึ่งตายหมด (ตัวเดี่ยว หรือทั้งกลุ่ม) จุดนั้นย้ายไปที่ใหม่ก่อนเกิดรอบถัดไป (`Sim.moveSpawner`): สุ่มจุดของมอนชนิดเดียวกันในแมพหนึ่งจุด แล้วสุ่มตำแหน่งในรัศมี 8 หน่วยจากจุดนั้น (`ROAM_REACH`) ห่างจุดอื่นที่ยืนอยู่ตอนนั้น ≥ 6 (`ROAM_APART`) ไม่ทับทาง/ค่าย/ที่เรียกบอส/ทะเลสาบ/collision หาไม่ได้ = กลับจุดเดิมในแมพ · กลุ่มที่ยังเหลือบางตัว ตัวที่เกิดใหม่เกิดกับกลุ่มเดิม (กลุ่มยังอยู่ด้วยกัน) · ย่านของแต่ละชนิดจึงยังอยู่ในแถบเดิม (อ่อนใกล้ค่าย แรงใกล้บอส) · เฉพาะ 4 แมพฟาร์มชั้น 1 (`FARM_IDS`) · แต่ละแชนแนลย้ายของตัวเอง ไม่เซฟ (รีสตาร์ท = กลับจุดในแมพ) · **สวิตช์ `mobRoam`** "มอนแมพฟาร์มชั้น 1 เกิดใหม่สุ่มที่" แท็บปรับสมดุล การ์ดการไล่เป้าหมาย (ค่าในโค้ด เปิด, ปิด = เกิดที่จุดเดิมเสมอ, ลง audit)
- **แผนที่ใหญ่:** แมพฟาร์มมีป้ายชื่อมอนชนิดละ 1 ป้าย (เดิมรวมเฉพาะจุดที่ห่างไม่เกิน 24 หน่วย พอจุดเพิ่มป้ายซ้อนจนอ่านไม่ออก เจ้าของ 2026-11-25) วงสีของจุดเกิดยังโชว์ตามจุดในแมพ (ไม่ตามจุดที่ย้ายไป)
- **ต้นไม้ ของประดับ ของประดับเล็กบนพื้น:** สุ่มใหม่ตามพื้นที่ (เดิมก็คิดความหนาแน่นตามพื้นที่อยู่แล้ว `placeProps`/`world.ts`) เจ้าของเลือกแบบนี้แทนการย้ายทีละชิ้น ×1.5 · ตำแหน่งต้นไม้จึงไม่ตรงกับแมพเดิม
- **ไม่เปลี่ยน:** seed, วงสนามที่เรียกบอส (`arenaRadius`) ห้องบอสสร้างจากค่าพวกนี้ · กล้อง มินิแมพ แผนที่ใหญ่ พื้น ขอบเกาะ หา path คิดจาก `half` เองทั้งหมด · เซฟไม่เก็บตำแหน่ง (เก็บแค่แมพ) ไม่ต้องย้ายเซฟ
- **ค่าใน /admin:** สวิตช์ `mobRoam` และ % จุดเกิดที่เปิดใช้ `farmSpots` (ด้านบน) ปรับจุดเกิด/ของประดับรายแมพด้วยตัวแก้แมพ + "มอนต่อจุดเกิดต่อแมพ ×1–×5" ในแท็บปรับสมดุล · เพิ่มปุ่ม **"📄 โหลดไฟล์ที่มากับเกม"** ในแถบบนของตัวแก้

**กฎใหม่: แมพที่มากับเกมต้องขนาดเท่าไฟล์ในเกม** (เจ้าของเลือก "ข้ามอัตโนมัติ + ปุ่ม"): `validateMap` เทียบ `zone.half` กับไฟล์ที่มากับเกม (`ctx.baseline`) ไม่เท่า = error `locked` (แมพที่สร้างเองไม่มีไฟล์ ขนาดอิสระ) ผล:
- ฉบับที่เผยแพร่ใน DB ที่วาดตอนขนาดเก่า **ถูกข้ามเอง** เกมใช้ไฟล์ใหม่ (log `[maps] <id> rev N fails the check, using the bundled layout`)
- `GET /api/maps` (`publishedRevs`) บอกเบราว์เซอร์เฉพาะฉบับที่ server ใช้จริง (เดิมบอกทุกแถวที่เผยแพร่ แม้ server ข้าม → เบราว์เซอร์วาดคนละแมพกับ server)
- ร่างเก่า/ย้อนกลับไป rev ขนาดเก่า เผยแพร่ไม่ได้ (ตัวแก้ขึ้นข้อผิดพลาดบอกให้กด 📄)
- **📄 โหลดไฟล์ที่มากับเกม:** ทิ้งร่าง โหลดไฟล์ในเกมเป็นร่าง (เลข rev ตามฉบับที่เผยแพร่ล่าสุด ไม่ขึ้นเตือนว่าร่างเก่า) แล้วแก้ต่อ/เผยแพร่ได้ · ของที่เคยแก้ในฉบับเก่าไม่ติดมา ต้องวางใหม่บนแมพใหญ่
- **หลัง deploy:** ไม่ต้องทำอะไรก็เล่นได้ (แถวเก่าถูกข้าม) · ถ้าเคยแก้แมพฟาร์มชั้น 1 ใน /admin แล้วอยากได้ของที่แก้คืน ให้กด 📄 วางใหม่ แล้วเผยแพร่ · เทสต์ `tests/map-farm-scale.test.ts`
