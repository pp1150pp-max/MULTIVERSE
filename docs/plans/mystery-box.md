## วิธีทำ

### ข้อมูล (`src/shared/`, ไม่ใช้ three/DOM)

- **กล่อง** = ของใช้ชนิดใหม่ `mystery_box` ในกองหิน (`Consumable` ใน `types.ts`) ซ้อนได้ 10 ขายพ่อค้า 250 G ลงตลาดแท็บ "ของใช้" เทรด/ฝากคลังได้ ใส่แนบจดหมาย admin ได้ ชื่อ/คำอธิบาย/สี/หน่วย "กล่อง" ใน `data/stones.ts`
- **ไอเทมลูกแก้ว** = ของในกระเป๋าแบบใหม่ `CosItemStack { cos: <id ลูกแก้ว>, count }` ซ้อนได้ 10 ชิ้นต่อช่อง (ลูกเดียวกัน) · ไอคอนใช้หน้าตาลูกแก้วลูกนั้น · ไปได้ทุกที่ที่หินไปได้ (กระเป๋า คลัง เทรด ตลาด แท็บใหม่ "ของแต่งตัว") ยกเว้นขายพ่อค้า · คลิกใช้ → server ใส่เข้า `account_cosmetics` ถ้ามีอยู่แล้วขึ้น "มีของแต่งตัวชิ้นนี้แล้ว" ของไม่หาย · Guest ใช้ได้เหมือนของแต่งตัวที่ admin แจกปัจจุบัน (จะเช็กตอนทำ)
- **`src/shared/mysteryBox.ts`** (ใหม่): ค่าเริ่มต้น, `cleanBoxConfig()` ตรวจค่าจาก /admin, `boxPool()` สร้างรายการตอนเปิด (อ่าน `COSMETICS` ปัจจุบันและชิ้นที่ซ่อน ไม่ copy เก็บ), `rollBox(cfg, rng, level, cls)` สุ่มแถวตาม % แล้วถ้าเป็นแถวลูกแก้วค่อยสุ่มลูกในแถว · ฟังก์ชันล้วนรับ rng จึงเทสต์ด้วย seed ได้
  - จำนวนต่อแถวตามตาราง (ยา HP/MP ใหญ่ 5 · ที่เหลือ 1) ตั้งได้ใน /admin 1–10 · โอกาสทุกแถวปรับได้ใน /admin

### การเปิด (server เป็นคนสุ่ม)

- action ใหม่ `openBox { slot, all }` ครบ 5 ที่ตาม `CLAUDE.md` · server ตรวจ slot ว่าเป็นกล่องจริง, กล่องเปิดใช้อยู่, กระเป๋ามีที่ ก่อนหักกล่อง · client ไม่ส่งผลสุ่มใดๆ
- action ใหม่ `useCosItem { slot }` สำหรับคลิกใช้ไอเทมของแต่งตัว (เข้าบัญชี) ครบ 5 ที่
- ผล: ข้อความลอยบนหัวสีตามกลุ่ม/เกรด + ข้อความในแชท ("เปิดกล่องปริศนาได้ …") · ได้ของแต่งตัว (หรือกลุ่มที่ตั้งให้ประกาศ) → แบนเนอร์ประกาศกลางจอถึงทุกคนในเซิร์ฟ (ใช้ทางเดียวกับประกาศ admin) มีชื่อผู้เล่นและชื่อของ ไม่กินคิวโทรโข่งของผู้เล่น
- ดรอป: ใน `Sim` ตอนมอน/บอสตาย ใช้โอกาสจากค่า /admin × ใบคูณดรอป ถ้ากล่องปิด = ไม่ดรอป

### หน้า `/admin`

- แท็บใหม่ **"กล่องปริศนา"** ไฟล์ใหม่ `src/admin/mysteryBox.ts` (ไม่แตะ `src/admin/balance.ts` ที่ระบบสกิลกำลังแก้) สวิตช์สิทธิ์ใหม่ `mysteryBox` (ดู: owner+GM) และ `mysteryBoxEdit` (บันทึก: owner)
- ปรับได้: เปิด/ปิดกล่อง · โอกาสดรอปมอน/บอส (%) · รายแถว: เปิด/ปิด % (หรือ "แบ่งส่วนที่เหลือ") จำนวน ติ๊กประกาศทั้งเซิร์ฟ (ค่าเริ่ม = ลูกแก้ว) · ลูกแก้วขายในแคชช็อปหรือไม่
- แสดงโอกาส**เป็น % ต่อกล่อง**ทุกแถว และ % รวมต่อกลุ่ม คำนวณสดตอนแก้ (เช่น "ปีกเทวดา 0.0019%")
- เก็บในตาราง `settings` key `mystery_box` **เฉพาะค่าที่ต่างจากค่าเริ่มต้น** (แบบล็อกอินรายวัน) · ส่ง `base` มาด้วยกันบันทึกทับ (409) · บันทึกลง audit

### เซฟเก่า

- ไม่เปลี่ยน `CharacterData` เดิม ของในกระเป๋าแบบใหม่เป็นแค่ชนิดเพิ่ม · DB ไม่มี key `mystery_box` = ค่าเริ่มต้น (กล่องปิด)
- ตลาด/คลัง/จดหมายเก่าอ่านได้เหมือนเดิม
