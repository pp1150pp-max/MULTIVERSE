ร่าง 2026-11-15 · เจ้าของเลือกว่า "อิงทั้งดาเมจและผลอื่น" · ทุกตัวเลขเป็นค่าเริ่มต้นที่ปรับได้ใน /admin

ตัวอย่างใช้นักดาบ Lv.40 ที่ไม่ใส่ของ: ATK 227 · DEF 113 · HP สูงสุด 1,820 ตัวเลขเหล่านี้คิดตาม `classes.ts` แล้ว ×2 จาก `statMult`

## ท่าโจมตี (4 ท่า)

โดนแต่ละครั้งได้ดาเมจเพิ่ม = **DEF × 100% + HP สูงสุด × 3%**
- ดาเมจส่วนนี้บวกก่อนคิดคริติคอลและก่อนหักพลังป้องกันของมอน เหมือนดาเมจปกติ
- ส่วนเพิ่มนี้โตตาม "ดาเมจ %/แรงก์" ของแต่ละท่า

| ท่า | ตอนนี้ (Lv.40) | หลังปรับ |
|---|---|---|
| ปฐพีแยก (2.0 ×ATK) | 454 | 454 + 113 + 55 = **622** (+37%) |
| กระแทกเกราะ (1.6) | 363 | **531** (+46%) |
| คลื่นสั่นสะเทือน (2.4) | 545 | **713** (+31%) |
| ปฐพีถล่ม (3.0 ต่อระลอก) | 681 | **849** (+25%) |

ยิ่งใส่ของ DEF/HP เยอะ ส่วนเพิ่มยิ่งมาก คนเล่นสายแท็งก์จึงยังตีได้

## ท่าบัฟ: ได้โล่ดูดซับดาเมจ (หักจากโล่ก่อน HP) ตลอดเวลาบัฟ

| ท่า | ผลเดิม (คงไว้) | เพิ่มใหม่ | ตัวอย่าง Lv.40 |
|---|---|---|---|
| ยั่วยุ | รับดาเมจ −20% | โล่ = HP สูงสุด 5% + DEF ×100% | 204 |
| ตั้งรับ | รับดาเมจ −40% | โล่ = HP สูงสุด 10% + DEF ×100% | 295 |
| ปักหลัก | รับดาเมจ −50% ไม่โดนสตัน | โล่ = HP สูงสุด 10% + DEF ×150% | 352 |
| ราชันย์ไม่ล้ม | −60% + ฟื้น 25% HP | โล่ = HP สูงสุด 20% + DEF ×200% | 590 |
| เกราะสะท้อน | สะท้อน 30% | สะท้อนแต่ละครั้งได้ดาเมจเพิ่ม DEF ×50% | +57 ต่อครั้ง |
| ปลุกใจนักรบ | DEF +30% และดาเมจ +15% ให้ทุกคนในวง | ทุกคนในวงได้ DEF เพิ่มอีก 20% ของ DEF คนร่าย | +23 DEF |

- ค่าโล่และส่วนเพิ่มโตตามแรงก์ +5% ของค่าต่อแรงก์ (ตาม "เวลาสถานะ/ผลพาสซีฟ %/แรงก์")
- ร่ายซ้ำ: โล่ที่ใหญ่กว่าเป็นตัวที่ใช้ และเวลาต่อใหม่
- โล่ใช้ระบบกลางที่มีอยู่แล้ว (`Player.shield`) ตัวเลขโล่ที่ขึ้นบนหัวเป็นของเดิม
- คำอธิบายสกิลในเกมจะบอกว่าท่าไหนอิง DEF/HP
