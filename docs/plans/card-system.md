# แผนระบบการ์ดมอนสเตอร์

> สถานะ: **ร่างแผน (ยังไม่แก้โค้ดเกม)** · เขียน 2026-11-11 · การตัดสินใจหลักมาจากเจ้าของ (ดูหัวข้อ 1)
> ตัวเลขที่มีป้าย **(เสนอ)** ยังเป็นค่าที่ Claude เสนอ ต้องให้เจ้าของยืนยันก่อนทำ PR นั้น

แนวคิด: มอนสเตอร์ทุกตัวในชั้น 1 มีการ์ดของตัวเอง 1 ใบ ซึ่งดรอปยากมาก ผู้เล่นต้องเจาะรูบนอุปกรณ์ที่ช่างตีเหล็กก่อน แล้วจึงเสียบการ์ดลงรู การ์ดให้ **% สเตตัส** และ **ผลพิเศษ** ที่หินสุ่มค่าหรือหินสุ่มสเตตัสให้ไม่ได้

## 1. สิ่งที่เจ้าของตัดสินใจแล้ว

| เรื่อง | ที่ตกลง |
|---|---|
| ช่องเสียบ | ต้อง**เจาะรู**ที่ช่างตีเหล็กก่อน ใช้ทอง + **หินเจาะรู** ได้ 0 ช่อง 40% · 1 ช่อง 50% · 2 ช่อง 10% |
| เจาะซ้ำ | เจาะได้**ครั้งเดียวต่อชิ้น** (อนาคตอาจมีไอเทมแก้ได้) |
| ถอดการ์ด | ถอดได้ แต่**การ์ดแตก** (หายไป) |
| การ์ดซ้ำในชิ้นเดียว | ใส่การ์ดใบเดียวกัน 2 ช่องได้ ผลบวกกัน (ผลพิเศษบางอย่างมีเพดานรวม) |
| ใบไหนใส่ช่องไหน | แบ่งเป็น 3 กลุ่ม: **อาวุธ** (อาวุธ อาวุธรอง) · **เกราะ** (หมวก เกราะ ถุงมือ เข็มขัด รองเท้า) · **เครื่องประดับ** (สร้อย แหวน 2 วง) |
| ผลของการ์ด | 2–3 ผลต่อใบ: % สเตตัส + ผลพิเศษใหม่ |
| ระดับการ์ด | มอนทั่วไป = **หายาก** · มินิบอสหมี = **มหากาพย์** · บอส 3 ตัว = **ตำนาน** (ใช้สีเดียวกับความหายากของไอเทม) |
| ดรอปมอนทั่วไป | **0.01%** (1 ใน 10,000) เป็นการ์ดของมอนตัวนั้น |
| ดรอปการ์ดบอส | **0.1%** ต่อกุญแจ: ใส่กุญแจ N อันสุ่ม N ครั้ง กุญแจเควสสุ่ม 1 ครั้ง |
| เศรษฐกิจ | **เหมือนกุญแจบอส**: รวมกองได้ช่องละ 10 · เทรด · คลัง · จดหมาย · ตลาดฝากขาย · ขายพ่อค้า |
| รวมการ์ด | ใช้การ์ด**ระดับเดียวกัน 3 ใบใดก็ได้** สุ่มได้การ์ดใบใหม่ระดับเดียวกัน 1 ใบ |
| ตีบวก | **ไม่เพิ่มผลการ์ด** และหินสุ่มค่า/หินสุ่มสเตตัสไม่แตะการ์ด |
| ภาพ | เจ้าของเจนเองจาก GPT แผนนี้ระบุแค่ว่าต้องมีภาพอะไร (สไตล์ 16-bit SNES) |
| ตัวอย่าง UI | วิดีโอตัวอย่างหน้าต่างดูการ์ดของเจ้าของ (ดูหัวข้อ 7.1) ใช้เป็นแนวทาง แต่ทำในสไตล์ภาพของเกมเรา |
| ค่าตามแมพ | การ์ดหายากจากแมพหลังแรงกว่าแมพต้น และการรวมการ์ดคือทางอัปเกรดที่ตั้งใจไว้ |
| ปรับตัวเลข | **ปรับตัวเลขทั้งหมดได้เองในหน้า `/admin` แท็บ "การ์ด"** (หัวข้อ 7.6) ตัวเลขในแผนนี้เป็นแค่ค่าเริ่มต้น |

## 2. ของเดิมที่ระบบนี้ต้องเข้ากันได้ (จากโค้ดใน `origin/main`)

- **ช่องสวม 10 ช่อง** (`EQUIP_SLOTS` ใน `src/shared/types.ts`): อาวุธ อาวุธรอง หมวก สร้อย เกราะ ถุงมือ เข็มขัด รองเท้า แหวน 1 แหวน 2 · อาวุธรองแยกตามคลาส (ปลอกดาบ ลูกแก้ว ซองกระสุน)
- **สเตตัส 10 ชนิด** (`STAT_KEYS`) คือ HP MP ATK DEF คริ ดาเมจคริ ความเร็วตี ความเร็วเดิน ฟื้น HP ฟื้น MP เป็นตัวเลขบวกตรงทุกชนิด หินสุ่มสเตตัสสุ่มได้ทั้ง 10 ชนิด
  → **การ์ดไม่ให้สเตตัสเหล่านี้แบบตัวเลขบวกตรง** แต่ให้แบบ % ของผลรวม (ATK% DEF% HP% MP%) และผลพิเศษที่ยังไม่มีในเกม
- **ตีบวก** (`enhance.ts`) เพิ่ม % ให้ทุกบรรทัดใน `item.lines` และ**หินสุ่มค่า/หินสุ่มสเตตัส** (`rerollValues`/`rerollStat` ใน `items.ts`) ทำงานกับ `item.lines`
  → การ์ดและรู**ต้องเก็บนอก `item.lines`** ตีบวกและหินทั้งสองชนิดจึงไม่แตะ
- **หินและกุญแจ** ใช้ระบบกอง `StoneStack` ร่วมกัน (`stones.ts`): ช่องละ 10 ขายพ่อค้า เทรด คลัง จดหมาย และตลาดหมวด Artifact
  → การ์ดและหินเจาะรูใช้ระบบกองเดียวกันนี้ (การ์ดได้หมวดตลาดของตัวเอง)
- **ดรอป** (`Sim.dropLoot`): มอนที่ `itemChance > 0` สุ่มหินสุ่มค่า 0.2% ต่อชนิดและกุญแจ 0.3% · บอสสุ่มหินช่าง 10% ต่อชนิด N รอบตามกุญแจ · **ลูกน้องที่บอสเรียก (`summoned`) ไม่ดรอปอะไร** จึงฟาร์มการ์ดหมาป่าในห้องหมีไม่ได้ · มอนที่ยืนในมุมเมืองกลางดรอปของแมพบ้านตัวเอง
- **ลูกน้องเยติ** (`yeti_minion`) ไม่มีการ์ด
- **ปุ่มขายของทั้งหมดตามความหายาก** ที่พ่อค้าข้ามของที่ตีบวกแล้ว → ต้อง**ข้ามของที่เจาะรูแล้วหรือมีการ์ด**ด้วย
- **นักดาบ** มีดาเมจต่อบอส ×2 และฟื้นจากยา HP มากกว่าคลาสอื่น 75% อยู่แล้ว → การ์ดผลต่อบอสและผลยาต้องมีค่าน้อย
- **การ์ดเลเวล/ชั้น 2**: `MAX_LEVEL` = 50 และชั้น 2 ยังไม่มีแผน การ์ดตั้งชื่อด้วย id มอน (`card_<monsterId>`) จึงเพิ่มการ์ดของชั้น 2 ได้โดยไม่ต้องเปลี่ยนโครงสร้าง

## 3. ที่มาของการ์ด

### 3.1 มอนทั่วไป (ระดับหายาก)
- มอนที่ดรอปไอเทมได้ (`itemChance > 0`) ทุกตัวมีโอกาส **0.01%** ต่อการฆ่า 1 ครั้งที่จะดรอปการ์ดของตัวเอง
- ใช้กฎเดียวกับของดรอปอื่น: คนที่ทำดาเมจมากสุด (และปาร์ตี้) เก็บได้ก่อน 10 วินาที
- มอนในมุมเมืองกลางก็ดรอปการ์ดของตัวเอง

### 3.2 การ์ดบอส (มหากาพย์และตำนาน)
- ดรอป**เฉพาะในห้องบอส** ตอนบอสตาย สุ่ม N ครั้ง (N = จำนวนกุญแจที่ใส่ กุญแจเควส = 1 ครั้ง) ครั้งละ **0.1%**
- เป็นการ์ดของบอสตัวนั้น และลูกน้องที่บอสเรียกมาไม่ดรอปการ์ด

### 3.2.1 ต้องฟาร์มนานแค่ไหน (คิดจากค่าเฉลี่ย)
- การ์ดหายาก 0.01%: ต้องฆ่า**มอนชนิดนั้น**ประมาณ 10,000 ตัวต่อการ์ด 1 ใบ
- การ์ดบอส 0.1% ต่อกุญแจ: ใช้กุญแจประมาณ 1,000 อันต่อการ์ด 1 ใบ และกุญแจดรอป 0.3% จึงเท่ากับฆ่ามอนในแมพนั้นราว **330,000 ตัว**
- รวมการ์ดตำนานต้องใช้ 3 ใบ ค่าทองรวมการ์ดจึงแทบไม่มีผลกับระดับนี้

### 3.3 ประกาศทั้งเซิร์ฟเวอร์ (เสนอ)
- ใครได้การ์ด ระบบประกาศทั้งเซิร์ฟเวอร์ ใช้แบบเดียวกับประกาศตีบวก +10 ขึ้นไป

### 3.4 หินเจาะรู (ของใหม่ ใช้เจาะรู)
- เป็นหินช่างชนิดที่ 5 อยู่ในกองหินเดิม (ช่องละ 10)
- **(เสนอ)** ดรอปเหมือนหินสุ่มค่า: มอนทั่วไป 0.2% · บอส 10% ต่อกุญแจ
- **(เสนอ)** ขายพ่อค้าได้ 1,000 G เท่าหินอื่น และเทรด คลัง จดหมาย ลงตลาดได้

## 4. รูและการเสียบการ์ด (ทำที่ช่างตีเหล็ก)

### 4.1 เจาะรู
- อุปกรณ์ทุกชิ้นเริ่มแบบ**ยังไม่เจาะ** ซึ่งรวมของเก่าในเซฟด้วย
- เจาะ 1 ครั้งใช้ทองและหินเจาะรู 1 ก้อน ผลที่ได้คือ **0 ช่อง 40% · 1 ช่อง 50% · 2 ช่อง 10%**
- **เจาะได้ครั้งเดียวต่อชิ้น** แม้ได้ 0 ช่องก็เจาะใหม่ไม่ได้ (tooltip เขียนว่า "เจาะแล้ว: ไม่มีช่อง")
- **(เสนอ)** ค่าทอง = ค่าตีบวกพื้นฐาน (15 + iLv × 6) × 5 × ตัวคูณความหายากของหินสุ่มค่า (ธรรมดา 1 · ดี 1.5 · หายาก 2 · มหากาพย์ 3 · ตำนาน 5)
  เช่น ของตำนาน Lv40 ใช้ (15 + 240) × 5 × 5 = 6,375 G
- ช่องเจาะไม่เปลี่ยนตอนตีบวก ตอนสุ่มค่า และตอนสุ่มสเตตัส

### 4.2 เสียบการ์ด
- ลากอุปกรณ์ที่มีช่องว่างลงช่องของช่าง แล้วลากการ์ดจากกระเป๋าลงช่องการ์ด
- การ์ดต้องอยู่ในกลุ่มที่ตรงกับอุปกรณ์ (เช่น การ์ดกลุ่มอาวุธใส่หมวกไม่ได้) ไม่ตรงกลุ่มก็ใส่ไม่ได้ และมีข้อความบอก
- ใส่แล้วการ์ด 1 ใบออกจากกอง **(เสนอ)** เสียบฟรี ไม่เสียทอง
- อุปกรณ์ที่สวมอยู่ก็เสียบได้ เหมือนตีบวกของที่สวมอยู่

### 4.3 ถอดการ์ด
- ถอดได้ทีละช่อง แต่**การ์ดแตก** ช่องกลับเป็นว่าง ต้องกดยืนยันก่อน ("การ์ด X จะแตกหายไป")
- **(เสนอ)** ถอดฟรี
- ถ้าเสียบการ์ดใบใหม่ลงช่องที่มีการ์ดอยู่ ต้องถอดใบเดิม (ใบเดิมแตก) ก่อนเสมอ ไม่มีการเปลี่ยนการ์ดในขั้นเดียว

### 4.4 อุปกรณ์ที่มีการ์ด
- ขาย เทรด ฝากคลัง ส่งจดหมาย และลงตลาดได้เหมือนเดิม **การ์ดติดไปกับอุปกรณ์**
- พ่อค้า "ขายทั้งหมดตามความหายาก" **ข้าม**ของที่เจาะแล้วหรือมีการ์ด เหมือนที่ข้ามของที่ตีบวกแล้ว
- **(เสนอ)** ราคาขายพ่อค้าของอุปกรณ์ไม่รวมราคาการ์ด (เตือนก่อนขายของที่มีการ์ด)
- ประวัติเทรด (`trade_log`) และหน้าตลาดแสดงการ์ดบนอุปกรณ์ด้วย

## 5. ผลของการ์ด

### 5.1 ชนิดผล (12 ชนิด)

| รหัส | ชื่อในเกม | ทำอะไร | เพดานรวมทั้งตัว (เสนอ) |
|---|---|---|---|
| `atkPct` | พลังโจมตี % | คูณ ATK รวมสุดท้าย | — |
| `defPct` | พลังป้องกัน % | คูณ DEF รวมสุดท้าย | — |
| `hpPct` | HP สูงสุด % | คูณ HP รวมสุดท้าย | — |
| `mpPct` | MP สูงสุด % | คูณ MP รวมสุดท้าย | — |
| `pierce` | เจาะเกราะ % | ไม่นับ DEF ของมอนตามเปอร์เซ็นต์ก่อนเข้าสูตร `mitigate` | 50% |
| `lifesteal` | ดูดเลือด % | ฟื้น HP ตาม % ของดาเมจที่ทำ (รวมกับดูดเลือดพายุดาบ) | 10% |
| `dmgReduce` | ลดดาเมจที่ได้รับ % | ลดดาเมจหลังสูตร `mitigate` | 30% |
| `bossDmg` | ดาเมจต่อบอส % | ใช้กับบอสเท่านั้น ลูกน้องไม่นับ (คูณต่อจาก ×2 ของนักดาบ) | 40% |
| `cdr` | ลดคูลดาวน์สกิล % | ใช้กับสกิล Q/E/R ไม่รวมพุ่งหลบ | 20% |
| `potion` | ยาฟื้นเพิ่ม % | ยา HP/MP ฟื้นมากขึ้น (คูณต่อจากโบนัสยา HP ของนักดาบ) | 40% |
| `expPct` | EXP % | EXP ที่ได้จากการฆ่า | 30% |
| `goldPct` | ทอง % | ทองที่ดรอป | 30% |

- % สเตตัส 4 ชนิดแรกคูณผลรวม (คลาส + เลเวล + อุปกรณ์ + ตีบวก) **ก่อน** `statMult` ของคลาส
- ผลชนิดเดียวกันจากทุกการ์ดที่สวมอยู่**บวกกัน** แล้วตัดที่เพดาน
- ตีบวกไม่เพิ่มผลการ์ด

### 5.2 ค่าตามแมพ
การ์ดหายากทุกใบอยู่ระดับเดียวกัน แต่ใบจากแมพหลังแรงกว่า ดูได้จากตารางด้านล่าง เพื่อให้การ์ดแมพ 1 ยังมีค่าตอนเริ่มเล่น และการ์ดแมพ 4 ใช้ได้ถึงเลเวลตัน

### 5.3 การ์ดทั้ง 26 ใบของชั้น 1 (ค่าทั้งหมดเป็น **(เสนอ)**)

### 5.4 สมดุลกับ 3 คลาส
- **ทุกคลาสใช้ได้**: ATK% เจาะเกราะ ดาเมจต่อบอส HP% DEF% ลดดาเมจ EXP และทอง เพราะทั้ง 3 คลาสตีด้วย ATK และสูตร `mitigate` เดียวกัน
- **นักดาบ** (ตีใกล้ รับดาเมจเยอะ): ดูดเลือด ลดดาเมจ ยาฟื้นเพิ่ม · ผลต่อบอสและผลยาของนักดาบมีโบนัสคลาสอยู่แล้ว จึงตั้งค่าการ์ดให้น้อย
- **เมจ** (ใช้ MP มาก คูลดาวน์สกิลเป็นหลัก): MP% และลดคูลดาวน์ ซึ่งอยู่ในกลุ่มเครื่องประดับทั้งหมด ไม่แย่งช่องกับการ์ดโจมตี
- **Gunslinger** (ตีเร็ว ตีหลายนัด): ATK% และเจาะเกราะได้ผลทุกนัด ดูดเลือดทำงานทุกนัดเช่นกัน
  - **ช่องโหว่ที่รู้อยู่**: ยังไม่มีผลที่เอียงมาทาง Gunslinger โดยตรงแบบที่นักดาบและเมจมี (การ์ดในวิดีโอมีคริ แต่คริเป็นสเตตัสของหินจึงไม่ใส่) ดูข้อเสนอในหัวข้อ 11 ข้อ 10
- เพดานรวมทั้งตัวทำให้ไม่มีคลาสไหนเอาผลเดียวมาซ้อนจนเสียสมดุล เช่น ลดดาเมจไม่เกิน 30% และลดคูลดาวน์ไม่เกิน 20%
- ใส่การ์ดซ้ำได้ แต่ช่องมีจำกัด: ของ 1 ชิ้นมีได้มากสุด 2 ช่อง (โอกาส 10%) ช่องสวม 10 ช่อง จึงมีช่องการ์ดมากสุด 20 ช่องทั้งตัว

### 6.1 รวมการ์ด (ที่ช่างตีเหล็ก)
- ใส่การ์ด**ระดับเดียวกัน** 3 ใบใดก็ได้ ซ้ำกันได้ จะได้การ์ดใบใหม่ระดับเดียวกัน 1 ใบ สุ่มจากการ์ดทุกใบในระดับนั้นโอกาสเท่ากัน และอาจได้ใบเดิม
- **ระดับมหากาพย์มีการ์ดใบเดียว (หมี)** รวมแล้วได้หมีเสมอ จึง**ปิดการรวมระดับนี้**จนกว่าชั้น 2 จะมีการ์ดมหากาพย์เพิ่ม

- หน้าต่างมีตารางโอกาสแบบเดียวกับตารางโอกาสสุ่มสเตตัส แสดงว่าได้การ์ดแต่ละใบกี่ %

## 7. UI ที่ต้องมี

ทุกส่วนใช้ CSS ก่อนแล้วรอภาพจริงจากเจ้าของ ทุกชิ้นมี id ของตัวเองแบบหน้าต่างช่างตีเหล็กและหน้าต่างเทรด

### 7.1 หน้าต่างดูการ์ด (ตามวิดีโอตัวอย่างของเจ้าของ)
- เปิดแบบเต็มจอ เกมด้านหลังมืดลง และมีแสงเป็นลำพุ่งออกจากหลังการ์ด (สีตามระดับการ์ด)
- การ์ดใบใหญ่กลางจอ **เอียงตามเมาส์แบบ 3D** ขอบเรืองแสง
- บนการ์ดมีป้ายระดับ (หายาก/มหากาพย์/ตำนาน) รหัสการ์ด (เช่น F1-03) ภาพมอนเต็มใบ ชื่อการ์ด แถบผล 2–3 อย่าง และสัญลักษณ์กลุ่ม (⚔/🛡/💍)
- ใต้การ์ดมีชื่อการ์ดและผลในกรอบ ตามด้วย "ใส่ได้: อาวุธ อาวุธรอง" และ "คลิกที่ไหนก็ได้เพื่อปิด"
- ปิดด้วย ✕ / Esc / คลิก
- เปิดได้จาก: คลิกขวาการ์ดในกระเป๋า/คลัง → "ดูการ์ด" · คลิกการ์ดในตลาดหรือหน้าต่างเทรด · **(เสนอ)** เด้งขึ้นเองครั้งแรกที่เก็บการ์ดใบนั้นได้
- ใช้กรอบและภาพพิกเซล 16-bit SNES ของเกมเรา ไม่ใช้ภาพหรือกรอบจากเกมในวิดีโอ

### 7.2 กระเป๋า คลัง และ tooltip
- ไอคอนการ์ดในกระเป๋ามีขอบสีตามระดับ และมีตัวเลขจำนวนในกอง
- tooltip ของการ์ดแสดงชื่อ ระดับ กลุ่มที่ใส่ได้ ผล และวิธีได้มา
- tooltip ของอุปกรณ์มีบรรทัดรูใหม่ต่อท้ายสเตตัส: "ยังไม่เจาะรู" / "เจาะแล้ว: ไม่มีช่อง" / "◇ ช่องว่าง" / "◆ การ์ดหมาป่า: ATK +2% · ดูดเลือด +0.5%"
- ไอคอนอุปกรณ์ในกระเป๋ามีจุดเล็กบอกจำนวนรู และบอกว่ามีการ์ดหรือไม่

### 7.3 ช่างตีเหล็ก: 3 เมนูใหม่ (เพิ่มจาก ตีบวก / สุ่มค่าตัวเลข / สุ่มสเตตัส)
- **เจาะรู**: ช่องอุปกรณ์ · ค่าทอง + หินเจาะรู · ตารางโอกาส 0/1/2 ช่อง · ปุ่ม "เจาะรู" · ของที่เจาะแล้วขึ้นข้อความว่าเจาะซ้ำไม่ได้
- **เสียบการ์ด**: ช่องอุปกรณ์ แสดงรู 1–2 รู ลากการ์ดลงแต่ละรู · การ์ดที่กลุ่มไม่ตรงเป็นสีเทา · ปุ่ม "เสียบการ์ด" · ปุ่ม "ถอดการ์ด" ที่ขึ้นกล่องยืนยันว่าการ์ดจะแตก
- **รวมการ์ด**: การ์ด 3 ช่อง (ต้องระดับเดียวกัน) · ค่าทอง · ตารางโอกาส · ปุ่ม "รวมการ์ด" แล้วเปิดหน้าต่างดูการ์ด (7.1) เพื่อโชว์ใบที่ได้

### 7.4 หน้าต่างตัวละคร
- ส่วน "ผลการ์ด" รวมผลจากการ์ดที่สวมอยู่ทั้งหมด ผลที่ชนเพดานแสดงเป็น "30% (เต็ม)"

### 7.5 ตลาดฝากขาย
- หมวด "การ์ด" กรองตามระดับและกลุ่ม · แถวของอุปกรณ์แสดงรูและการ์ดที่เสียบอยู่ · ตัวกรองเพิ่มเติม "มีรู" / "มีการ์ด"

### 7.6 หน้า `/admin` แท็บ "การ์ด" (ปรับตัวเลขเอง)
ทำแบบเดียวกับแท็บ "ของแต่งตัว" ที่บันทึกค่าเป็นของทั้งเซิร์ฟได้
- **ค่าที่ปรับได้**
  - เรทดรอป: การ์ดมอน (0.01%), การ์ดบอสต่อกุญแจ (0.1%) และหินเจาะรูจากมอน/บอส
  - โอกาสเจาะรู 0/1/2 ช่อง (ต้องรวมกันได้ 100%) และสูตรค่าทองเจาะรู (ตัวคูณ)
  - ค่าเสียบ ค่าถอด และค่ารวมการ์ดแยกตามระดับ
  - ราคาขายพ่อค้าของการ์ดแยกตามระดับ และของหินเจาะรู
  - เพดานรวมของผลแต่ละชนิด
  - **ผลของการ์ดแต่ละใบ**: ปรับค่าเดิม เพิ่ม หรือลบชนิดผลได้ (เลือกจาก 12 ชนิด) และเปลี่ยนกลุ่มช่องที่ใส่ได้
  - ปิด/เปิดการรวมการ์ดแยกตามระดับ
- **หน้าตา**: ตารางการ์ดทั้งหมด (ภาพเล็ก ชื่อ ระดับ กลุ่ม ผล) คลิกแถวแล้วแก้ทางขวา มีตัวอย่างการ์ดแบบหน้าต่างดูการ์ด (7.1) ให้เห็นผลทันที · ค่าที่ต่างจากในโค้ดเป็นสีเหลือง
- **ปุ่ม** (แบบแท็บของแต่งตัว): คืนค่าใบนี้/ทุกใบเป็นค่าในโค้ด · โหลดค่าของเซิร์ฟ · บันทึกเป็นค่าของทั้งเซิร์ฟ (ถามยืนยันก่อน) · คัดลอกค่าเป็นโค้ด (เอาไปใส่ `cards.ts` ภายหลังได้)
- **เก็บค่า**: ตาราง `settings` key `card_tuning` เก็บ**เฉพาะค่าที่ต่างจากในโค้ด** ถ้าไม่มีแถวก็ใช้ค่าในโค้ดทั้งหมด (DB เก่าใช้ได้เลย) · server ตรวจทุกค่าก่อนบันทึก (ช่วงตัวเลข ชนิดผลต้องมีอยู่จริง โอกาสเจาะรวม 100%)
- **มีผลทันที ไม่ต้องรีสตาร์ท** และ server ส่งค่าใหม่ให้เบราว์เซอร์ทุกคน (tooltip และหน้าต่างช่างแสดงค่าตรงกัน)
  - อุปกรณ์เก็บแค่ว่า "เสียบการ์ดใบไหน" ไม่เก็บตัวเลขผล → ปรับผลการ์ดแล้ว**การ์ดที่เสียบอยู่แล้วเปลี่ยนตามทันที**
- **สิทธิ์** **(เสนอ)** ตามแบบของแต่งตัว: ดูและทดลองได้ owner และ GM (สวิตช์ `cardView`) · บันทึกค่าทั้งเซิร์ฟได้เฉพาะ owner (สวิตช์ `cardTune`) · ตั้งต่อ role ได้ในแท็บ "สิทธิ์"
- ทุกครั้งที่บันทึกจะเก็บประวัติว่าใครเปลี่ยนค่าอะไรเมื่อไหร่ แสดงในแท็บเดียวกัน

### 7.7 บนพื้นและประกาศ
- การ์ดที่ดรอปบนพื้นมีแสงสีตามระดับ ให้เห็นแตกต่างจากหิน
- ข้อความประกาศทั้งเซิร์ฟเวอร์ (ถ้าเจ้าของเอา ดู 3.3)

  - `cards?: (CardId | null)[]` ยาวเท่า `sockets`
- `Player.recompute` คิดผลการ์ดจากของที่สวมอยู่ แล้วเก็บเป็น `cardFx` (ตัดที่เพดาน) · Sim ใช้ `cardFx` ในสูตรดาเมจ (pierce, bossDmg, dmgReduce), ดูดเลือด, คูลดาวน์, ยา, EXP และทอง
- action ใหม่ (แก้ครบ 5 ที่ตาม CLAUDE.md): `drill`, `socketCard`, `unsocketCard`, `fuseCards` · server ตรวจทุกค่า (ช่องกระเป๋า, กลุ่มตรงกัน, รูว่าง, ระดับเดียวกัน, ทอง/หินพอ, ไม่ได้อยู่ระหว่างเทรด)
