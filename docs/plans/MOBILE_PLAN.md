# แผนเล่นบนมือถือและ iPad

> สถานะ: **ร่างแผน (ยังไม่แก้โค้ดเกม)** · เขียน 2026-11-11 · การตัดสินใจหลักมาจากเจ้าของ (ดูหัวข้อ 1)
> ค่าที่มีป้าย **(เสนอ)** ยังเป็นค่าที่ Claude เสนอ ต้องให้เจ้าของยืนยันก่อนทำ PR นั้น

เป้าหมาย: เปิดเกมใน Safari/Chrome บนมือถือหรือ iPad แล้วเล่นได้ครบเหมือน PC (เดิน ตี สกิล ยา คุย NPC กระเป๋า ตลาด แชท Auto) โดยไม่ต้องต่อคีย์บอร์ดหรือเมาส์ และบน PC ทุกอย่างต้องเหมือนเดิม

## 1. สิ่งที่เจ้าของตัดสินใจแล้ว

| เรื่อง | ที่ตกลง |
|---|---|
| การเดิน | **จอยเสมือน + แตะเพื่อเดิน**: จอยลอยฝั่งซ้าย (แตะตรงไหนจอยขึ้นตรงนั้น) และแตะพื้น/NPC/ของดรอป/น้ำพุเพื่อเดินไปเอง |
| แนวจอ | **รองรับทั้งแนวนอนและแนวตั้ง** และทำ**พร้อมกันในเฟสแรก** |
| การเล็ง | **ล็อกเป้าอัตโนมัติ + ลากปุ่มเพื่อเล็งเอง**: แตะปุ่ม = ใช้ใส่เป้าที่ล็อก/มอนใกล้สุด · กดค้างแล้วลาก = เล็งทิศหรือจุดเอง มีเส้นเล็งให้เห็น |
| Auto | **เหมือน PC + ปุ่มใหญ่บนจอ**: ขยับจอยแล้ว Auto ปิดเอง กดสกิลเองได้โดย Auto ยังเปิด · ตั้งค่า Auto จากปุ่ม ⚙ |
| ปุ่มที่ติดจอตลอด | ตี · Q · E · R · แดช · ยา HP · ยา MP · AUTO (ตายตัว) + **ม้วนกลับเมือง (G) · พาหนะ (Z) · แชท** |
| ปุ่มในเมนู ☰ | **กระเป๋า** · ช่วยเหลือ (H) · แผนที่ (M, กดมินิแมพได้อยู่แล้ว) · เมนูระบบ (Esc) และหน้าต่างอื่นที่เปิดจากแถบไอคอนเดิม |
| ปุ่ม T (คุย/ใช้) | กลายเป็นปุ่ม **"คุย/ใช้"** ที่โผล่เฉพาะตอนอยู่ใกล้ NPC น้ำพุ หรือแท่นเรียกบอส |
| ภาพปุ่ม | **เจ้าของเจนจาก GPT ก่อนเริ่ม** สไตล์ 16-bit SNES (รายการภาพดูหัวข้อ 9) · PR ที่ต้องใช้ภาพรอภาพก่อน |

> หมายเหตุ: เจ้าของเลือกให้ **กระเป๋าอยู่ในเมนู ☰** ไม่ใช่ปุ่มติดจอ ถ้าเล่นจริงแล้วเปิดยาก ย้ายมาติดจอได้ภายหลังโดยไม่ต้องแก้โครงสร้าง

## 2. ของเดิมที่ต้องเข้ากันได้ (จากโค้ดใน `origin/main`)

### 2.1 ระบบรับปุ่ม
- `src/client/input.ts` (68 บรรทัด) เก็บสถานะเป็น `keys` (ปุ่มที่กดค้าง) `pressedSet` (ปุ่มที่เพิ่งกดเฟรมนี้) `lmb`/`rmb`/`lmbPressed`/`rmbPressed` `mouseX/Y` และ `wheel` ฟังแค่ `keydown/keyup/mousedown/mouseup/mousemove/wheel` **ไม่มี touch หรือ pointer events**
- `Game.manualIntent()` (`src/client/Game.ts` ~บรรทัด 450) แปลงสถานะเป็น `Intent` ที่ส่งให้ server:
  - `move` จาก WASD/ลูกศร (หมุนเข้าแกน isometric ด้วย `RIGHT`/`UP`)
  - `moveTo` จากคลิกขวาค้าง หรือ `goal` ที่คลิกไว้
  - `aim` = มอนที่เมาส์ชี้ (`hovered`) หรือจุดบนพื้นใต้เมาส์ (`mouseWorld`)
  - `basic` = คลิกซ้าย**ค้าง** · `skills` = Q/E/R **ค้าง** · `dash` = Space (กดครั้งเดียว) · `potion` = 1/2
- `Game.update()` คลิกซ้ายครั้งเดียวทำได้ 3 อย่างตามสิ่งที่อยู่ใต้เมาส์: เดินไปเก็บของ/คุย NPC/พักน้ำพุ/แท่นบอส (`hoverUse` → `goal`), เปิดเมนูผู้เล่น (`hoveredPlayer` → `party.playerMenu`) หรือโจมตี
- ปุ่มลัดอื่น: F (Auto) G (ม้วนกลับเมือง) Z (พาหนะ) I/B (กระเป๋า) H (ช่วยเหลือ) M (แผนที่) Esc (เมนูระบบ) Enter (แชท) T (คุย/ใช้) ล้อเมาส์ (ซูม `viewSize` 10–28)
- **กล้องหมุนไม่ได้** มีแค่ซูม → บนจอสัมผัสใช้ **นิ้วบีบ (pinch)** แทนล้อเมาส์

### 2.2 สกิลแต่ละคลาส (`src/shared/data/classes.ts`)
| คลาส | ตี | Q | E | R | แดช |
|---|---|---|---|---|---|
| นักดาบ | ฟัน (วงหน้า) | พายุดาบ (รอบตัว) | ปฐพีแยก (รอบตัว) | พุ่งชน (**ทิศ**) | แดช (ทิศ) |
| นักเวท | ลูกเวท (**ทิศ**) | ลูกไฟ (**ทิศ/จุด**) | วงน้ำแข็ง (รอบตัว) | อุกกาบาต (**จุดบนพื้น**) | วาร์ป (ทิศ) |
| มือปืน | ยิงเร็ว (**ทิศ**) | ยิงรัว (**ทิศ**) | กระสุนเจาะเกราะ (**ทิศ**) | ยิงหัว (**ทิศ** ยืนนิ่ง 0.8 วิ) | กลิ้งหลบ (ทิศ) |

→ สกิลรอบตัวไม่ต้องเล็ง · สกิลทิศ/จุดใช้ระบบเล็งในหัวข้อ 3.3

### 2.3 หน้าเว็บและ UI
- `index.html`: `<meta name="viewport" content="width=device-width, initial-scale=1.0">` ไม่กันซูม ไม่มี `viewport-fit=cover` ไม่มี manifest/ไอคอนหน้าจอหลัก
- `src/style.css` มี `@media (max-width: 700px) and (orientation: portrait)` และ `@media (max-height: 560px)` บางส่วน · `body` มี `user-select: none` แล้ว · `.drag-handle` มี `touch-action: none`
- `dragwindow.ts` ใช้ pointer events อยู่แล้ว (ลากหน้าต่างด้วยนิ้วได้)
- `questTracker.ts` พับเองบนจอแนวตั้ง
- **UI ที่ใช้เมาส์อย่างเดียว** (ต้องมีทางแทนบนจอสัมผัส):
  - คลิกขวา (`contextmenu`): กระเป๋า (`hud.ts:338` ใช้/เสนอเทรด), ร้านซื้อทีละกอง (`hud.ts:490`), ถอนจากคลัง (`hud.ts:520`), ปักหมุดบนแผนที่ใหญ่ (`hud.ts:206`), เมนูแถวปาร์ตี้ (`party.ts:267`)
  - ชี้เมาส์ค้างดูรายละเอียด (`mousemove`/`mouseleave` ราว 21 จุดใน `hud.ts`, 3 จุดใน `market.ts`, 2 จุดใน `trade.ts`): tooltip ไอเทม, ช่องตีเหล็ก
  - ลากไอเทม (`setupDrag` ใน `hud.ts` เช็ค `e.button`): กระเป๋า ↔ คลัง/ร้าน/ช่างตีเหล็ก/เทรด
  - Shift+คลิก ซื้อทั้งกอง
  - `noBrowserMenu.ts` กัน `contextmenu` ทั้งหน้า (ดีบนมือถือ: กดค้างไม่ขึ้นเมนูของเบราว์เซอร์)
- **เสียง**: `audio/engine.ts` ปลุก `AudioContext` ด้วย `pointerdown`/`keydown` อยู่แล้ว → ต้อง**ทดสอบ**ว่า iOS ปลดล็อกเสียงด้วย `pointerdown` จริง ถ้าไม่ได้ให้เพิ่ม `touchend`
- **กราฟิก**: `Game.ts:133` `setPixelRatio(min(devicePixelRatio, 2))` · `antialias: false` · `cosPreview.ts` และ `orbPreview.ts` สร้าง `WebGLRenderer` แยกอีก 2 ตัว
- **dev server**: `vite.config.ts` ไม่ได้ตั้ง `server.host` → เปิดจากเครื่องอื่นใน LAN ไม่ได้ถ้าไม่ใส่ `--host`

### 2.4 งานค้างในคันบังที่เกี่ยว (รวมเข้าแผนนี้)
- หน้าต่างกระเป๋าล้นจอมือถือแนวตั้ง
- ลูกแก้ว MP บังปุ่มเมนูบนจอเล็ก
- หน้าต่างตลาด (640px) ซ้อนกับกระเป๋าบนจอที่แคบกว่า ~1220px
- ทดสอบประตูมิติบนเครื่องสเปกต่ำ

## 3. ระบบควบคุมแบบสัมผัส

### 3.1 หลักการ: ชั้นสัมผัสเขียนลง `Input` เดิม
เพิ่ม `src/client/touch/` ที่**เขียนสถานะลง `Input` ตัวเดิม** แทนการแก้ `Game.manualIntent` มาก:
- ปุ่มบนจอกด → ใส่ code เสมือนลง `keys`/`pressedSet` เช่น ปุ่ม Q กดค้าง = `keys.add('KeyQ')` ปล่อย = ลบ (สกิลและการตีเป็นแบบ**กดค้าง**อยู่แล้ว จึงได้พฤติกรรมเดียวกับ PC)
- จอย → เพิ่มฟิลด์ `Input.stick: {x, y} | null` แล้ว `manualIntent` ใช้แทน WASD เมื่อมีค่า (เดินตามทิศจอยจริง 360° ไม่ใช่ 8 ทิศ · เฟส 1 ใช้**ความเร็วเต็มเสมอ** โดย normalize ทิศเหมือน WASD · `Player.ts:882` ใช้ `move.x/z` ตรง ๆ จึงทำ "ดันจอยเบา = เดินช้า" ได้ภายหลัง แต่ต้องตรวจการเดาตำแหน่งฝั่ง client และการตรวจระยะใน `server/world.ts` ก่อน — **(เสนอ) ไม่ทำ**)
- เล็ง → เพิ่ม `Input.aimOverride: Vec2 | null` ที่ `manualIntent` ใช้ก่อน `hovered`/`mouseWorld`
- ฟัง `pointerdown/move/up/cancel` และเรียก `setPointerCapture` ทุกนิ้วแยกด้วย `pointerId` (กดจอยกับปุ่มสกิลพร้อมกันได้)
- ปิดตอน `blur`/`visibilitychange`/`pointercancel`: ล้างปุ่มค้างทั้งหมด (กันตัวละครเดินค้างตอนสลับแอป)

### 3.2 ตารางปุ่ม PC → จอสัมผัส

| การกระทำ | PC | จอสัมผัส |
|---|---|---|
| เดิน | WASD / ลูกศร / คลิกขวาค้าง | **จอยลอย** ครึ่งซ้ายของจอ (แตะตรงไหนจอยขึ้นตรงนั้น ปล่อยแล้วหาย) |
| เดินไปจุด | คลิกขวา | **แตะพื้นว่าง**ครึ่งขวา/กลางจอ → เดินไป มีวงเครื่องหมาย (`fx.marker`) |
| เก็บของ / คุย NPC / พักน้ำพุ / แท่นบอส | คลิกซ้ายที่ของ | **แตะที่ของ/NPC** → เดินไปแล้วใช้เอง (ใช้ `findUsable` เดิม รัศมีแตะใหญ่ขึ้น **(เสนอ) ×1.5**) |
| คุย/ใช้ตอนยืนใกล้ | T | ปุ่ม **"คุย/ใช้"** ที่โผล่เหนือปุ่มสกิลเมื่อมีป้าย "กด T เพื่อ…" (ข้อความป้ายเปลี่ยนเป็น "แตะ คุย/ใช้") |
| ตี | คลิกซ้ายค้าง | ปุ่ม**ตี**ใหญ่สุด กดค้าง = ตีต่อเนื่อง |
| Q / E / R | กดค้าง | ปุ่มวงรอบปุ่มตี แตะ/ค้าง/ลากเล็ง (3.3) แสดงคูลดาวน์และ MP ไม่พอเหมือนแถบสกิลเดิม |
| แดช | Space | ปุ่มแดช แตะ = ไปทางที่จอยชี้ (ไม่แตะจอย = ทางที่หันอยู่) · ลาก = เลือกทิศ |
| ยา HP / MP | 1 / 2 | ปุ่มยา 2 ปุ่มข้างลูกแก้ว HP/MP **(เสนอ)** แสดงจำนวนที่เหลือ · กดค้าง = เลือกขนาดยา |
| Auto | F | ปุ่ม **AUTO** ใหญ่ ติดจอ · ⚙ อยู่ข้างกัน |
| ม้วนกลับเมือง | G | ปุ่มเล็กติดจอ |
| พาหนะ | Z | ปุ่มเล็กติดจอ |
| แชท | Enter | ปุ่มแชทข้างกล่องแชท → เปิดช่องพิมพ์ + คีย์บอร์ดจอ (หัวข้อ 5.6) |
| กระเป๋า / ช่วยเหลือ / เมนูระบบ | I / H / Esc | อยู่ใน**เมนู ☰** |
| แผนที่ | M | แตะมินิแมพ (มีอยู่แล้ว) |
| ซูมกล้อง | ล้อเมาส์ | **นิ้วบีบ 2 นิ้ว**บนพื้นที่เกม + ปุ่ม +/− ที่มินิแมพ (มีอยู่แล้ว) |
| เลือกผู้เล่นอื่น (ปาร์ตี้/เทรด) | คลิกซ้ายที่ผู้เล่น | **แตะที่ผู้เล่น** → เมนูผู้เล่นเดิม |
| เลือกเป้า | ชี้เมาส์ | **แตะที่มอน** = ล็อกเป้า (วงสีแดงใต้เท้า) แตะซ้ำหรือแตะพื้นว่าง = ยกเลิก |

แยกงานของ "คลิกซ้าย" ที่เคยรวมกัน: บนจอสัมผัส **แตะพื้นที่เกมไม่โจมตีเลย** (ตีด้วยปุ่มเท่านั้น) แตะมอน = ล็อกเป้า แตะของ/NPC = ใช้ แตะผู้เล่น = เมนู แตะพื้น = เดิน

### 3.3 การเล็ง
- **เป้าที่ล็อก**: มอนที่แตะเลือกไว้ ถ้าไม่ได้เลือก ใช้**มอนที่มีชีวิตใกล้ตัวที่สุดในระยะ (เสนอ) 10 หน่วย** ถ้าไม่มีมอนเลย ยิงไปทางที่ตัวละครหัน
- **แตะปุ่มสกิล** → `aim` = ตำแหน่งเป้าที่ล็อก
- **กดค้างแล้วลากออกจากปุ่ม** (เกิน (เสนอ) 12px) → เข้าโหมดเล็ง: แสดงเส้นทิศ (สกิลทิศ) หรือวงบนพื้น (อุกกาบาต ลูกไฟ) ระยะตามระยะสกิล · ปล่อยนิ้ว = ใช้สกิล · ลากกลับเข้าปุ่ม = ยกเลิก
- สกิลรอบตัว (พายุดาบ ปฐพีแยก วงน้ำแข็ง) ไม่มีโหมดลาก แตะ = ใช้ทันที
- **ยิงหัว** (ยืนนิ่ง 0.8 วิ): ล็อกทิศตอนกด และระหว่างเล็งจอยไม่ขยับตัว (ตรงกับ server)
- วาดเส้นเล็งด้วย Three.js ใน `effects.ts` (ไม่ต้องใช้ภาพ)

### 3.4 ตำแหน่งปุ่ม **(เสนอ)**
- **แนวนอน**: จอยครึ่งซ้ายล่าง · ปุ่มตีมุมขวาล่าง Q/E/R/แดชเป็นครึ่งวงรอบปุ่มตี · ยา 2 ปุ่มเหนือวงสกิล · AUTO + ⚙ เหนือยา · G/Z/คุย-ใช้ เรียงแนวตั้งข้างวงสกิล · ☰ มุมขวาบนข้างมินิแมพ · แชทซ้ายบนเหนือจอย
- **แนวตั้ง**: จอยและวงสกิลอยู่ 40% ล่างของจอเหมือนกัน (มือซ้าย/ขวา) · มินิแมพเล็กลงมุมขวาบน · กล่องแชทพับเหลือ 2 บรรทัด · แถบ EXP บางลงเหนือปุ่ม
- ลูกแก้ว HP/MP: แนวนอนอยู่มุมล่างเหมือนเดิมแต่ย่อ · แนวตั้งย้ายไปเป็นแถบบนข้างรูปตัวละคร (แก้ปัญหา "ลูกแก้ว MP บังปุ่มเมนู" ในคันบัง)
- **ซ่อนแถบสกิลเดิม** (`#skillbar` ที่บอก LMB/Q/E/R/SPACE) ในโหมดสัมผัส เพราะปุ่มสัมผัสแสดงคูลดาวน์เองแล้ว
- ตัวเลือกในการตั้งค่า **(เสนอ, เฟส 3)**: ขนาดปุ่ม (เล็ก/กลาง/ใหญ่) ความโปร่งใส สลับซ้าย-ขวา

## 4. การตรวจอุปกรณ์

- **ไม่ใช้ User-Agent** (iPadOS Safari บอกตัวเองเป็น Mac จึงแยกไม่ได้)
- โมดูล `src/client/touch/device.ts` เก็บค่า `mode: 'mouse' | 'touch'` แล้วใส่ class `touch-ui` ที่ `<body>`:
  - **ค่าเริ่ม**: `matchMedia('(any-pointer: coarse)')` หรือ `navigator.maxTouchPoints > 0` และไม่มี `(pointer: fine)` เป็นตัวหลัก → `touch`
  - **สลับตามการใช้จริง**: `pointerdown` ที่ `pointerType === 'touch'`/`'pen'` → `touch` · `pointerType === 'mouse'` หรือ `keydown` ปุ่มเดิน/สกิล → `mouse` (ซ่อนปุ่มบนจอ)
  - กันกระพริบ: สลับเป็น `mouse` เฉพาะเมื่อมีเมาส์ขยับต่อเนื่อง (เสนอ) ≥ 3 ครั้ง หรือกดปุ่มเกม
- **iPad + Magic Keyboard/เมาส์** ใช้ได้ทันทีด้วยกติกาข้างบน: ใช้คีย์บอร์ดเล่น → ปุ่มบนจอหายและใช้ระบบ PC · แตะจอ → ปุ่มกลับมา · โน้ตบุ๊กจอสัมผัสใช้กติกาเดียวกัน
- **แยกมือถือกับ iPad ด้วยขนาดจอ ไม่ใช่ชนิดเครื่อง**: CSS ใช้ `min(vw, vh)` เช่น ด้านสั้น < 500px = จอเล็ก (มือถือ) ≥ 700px = แท็บเล็ต ตัวแปร `--ui-scale` และขนาดปุ่มคำนวณจากนี้
- มีตัวเลือกบังคับในเมนูระบบ **(เสนอ)**: "ปุ่มบนจอ: อัตโนมัติ / เปิดเสมอ / ปิดเสมอ"

## 5. ทางเทคนิค (หน้าเว็บ)

### 5.1 viewport และกันซูม
```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover">
```
- iOS Safari ไม่สนใจ `user-scalable=no` บางกรณี จึงต้องเพิ่ม:
  - CSS `touch-action: none` บน canvas เกมและชั้นปุ่ม · `touch-action: manipulation` บนปุ่มใน UI (ตัดดีเลย์ 300ms และดับเบิลแทปซูม)
  - `preventDefault()` ใน `gesturestart`/`gesturechange` (pinch ของ Safari) และ `touchmove` ที่มีมากกว่า 1 นิ้วบน canvas

### 5.2 กันการเลื่อนหน้าและดึงรีเฟรช
- `html, body { position: fixed; inset: 0; overflow: hidden; overscroll-behavior: none; }`
- รายการที่เลื่อนได้ (กระเป๋า ตลาด แชท) ใส่ `overscroll-behavior: contain` และ `touch-action: pan-y`
- ใช้ `100dvh` แทน `100vh` (แถบที่อยู่ของเบราว์เซอร์มือถือยืดหด) — `max-height: calc(100vh - …)` ในตลาด กระเป๋า ฯลฯ ต้องเปลี่ยนทั้งหมด

### 5.3 safe-area (รอยบาก / Dynamic Island / แถบโฮม)
- ใช้ `env(safe-area-inset-*)` เป็น padding ของ `#hud` และชั้นปุ่มสัมผัส (เช่น `#hud-topleft { left: max(12px, env(safe-area-inset-left)) }`)
- แนวนอน iPhone รอยบากอยู่ซ้าย/ขวา → จอยและปุ่มสกิลต้องขยับเข้าใน

### 5.4 เต็มจอ
- Android Chrome / iPad Safari: ปุ่ม "เต็มจอ" ในเมนู ☰ เรียก `document.documentElement.requestFullscreen()` (ต้องมาจากการแตะ)
- **iPhone Safari ไม่รองรับ fullscreen ของ element** → ทางเดียวคือ**เพิ่มลงหน้าจอหลัก** (5.5) แล้วเปิดแบบ standalone
- แสดงคำแนะนำครั้งเดียวบน iPhone: "แตะ แชร์ → เพิ่มไปยังหน้าจอโฮม เพื่อเล่นเต็มจอ" (จำว่าปิดแล้วใน `localStorage`)

### 5.5 PWA / เพิ่มลงหน้าจอหลัก
- `public/manifest.webmanifest`: `name` "MULTIVERSE", `display: "fullscreen"` (fallback `standalone`), `orientation: "any"`, `background_color`/`theme_color` สีพื้นหลังเกม, ไอคอน 192/512 + maskable
- `index.html`: `<link rel="manifest">`, `<link rel="apple-touch-icon" href="…180.png">`, `<meta name="apple-mobile-web-app-capable" content="yes">`, `<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">`, `<meta name="theme-color">`
- **ไม่ทำ service worker / ออฟไลน์** ในแผนนี้ (เกมต้องต่อ server ตลอด และ cache อาจทำให้ client เก่าไม่ตรงกับ server) **(เสนอ)**
- หมายเหตุ: PWA ติดตั้งได้เฉพาะผ่าน **HTTPS** → ใช้ลิงก์ Cloudflare (`npm run tunnel`/`online`) ได้ ส่วน LAN แบบ http ติดตั้งไม่ได้

### 5.6 คีย์บอร์ดบนจอตอนพิมพ์
- ช่องที่พิมพ์ได้: แชท (`#chat-input`), ชื่อเพื่อน, ค้นหาตลาด, ราคา, จำนวนทอง (คลัง/เทรด), รายงาน, ชื่อตัวละคร, ฟอร์ม login
- ฟอนต์ช่องพิมพ์ต้อง **≥ 16px** (iOS ซูมเข้าเองถ้าเล็กกว่า)
- คีย์บอร์ดเด้งขึ้น: ใช้ `visualViewport` (`resize`) ย้าย `#chat` ขึ้นไปอยู่เหนือคีย์บอร์ด และ**ปิดปุ่มบนจอชั่วคราว**ระหว่างพิมพ์
- ปุ่ม "ส่ง" ข้างช่องแชท (มือถือไม่มี Enter บางคีย์บอร์ด) · ใส่ `enterkeyhint="send"` · แตะนอกช่อง = ปิดแชท (แทน Esc)
- ช่องตัวเลขใช้ `inputmode="numeric"`
- ระหว่างพิมพ์ ปล่อยปุ่มค้างทั้งหมดใน `Input` (กันตัวละครเดินค้าง)

### 5.7 เสียงบน iOS
- ทดสอบว่า `pointerdown` ใน `audio/engine.ts` ปลดล็อกได้บน iOS Safari จริง ถ้าไม่ได้ เพิ่ม `touchend` ใน `wake`
- ปุ่มปิดเสียงด้านข้างของ iPhone (โหมดเงียบ) ปิดเสียง Web Audio → ไม่ต้องแก้ แต่เขียนไว้ใน "ช่วยเหลือ"
- กลับจากพื้นหลัง (`visibilitychange`) ต้อง `resume()` อีกครั้ง (มีอยู่แล้วบางส่วน ต้องทดสอบ)

### 5.8 อื่น ๆ
- กันการเลือกข้อความ/แว่นขยายตอนกดค้าง: `-webkit-user-select: none; -webkit-touch-callout: none;` ทั้งหน้า ยกเว้น input
- `-webkit-tap-highlight-color: transparent`
- ตอนแอปไปอยู่พื้นหลัง WebSocket อาจถูกตัด → ตรวจว่าระบบต่อใหม่ (`net/online.ts`) ทำงานเมื่อกลับมา และ Auto ยังฟาร์มบน server ต่อ (เป็นอยู่แล้วตาม CLAUDE.md)

## 7. ประสิทธิภาพ

- **pixel ratio**: ตอนนี้ `min(dpr, 2)` · มือถือ dpr 3 → 2 ยังหนัก · เพิ่มตั้งค่า **"คุณภาพกราฟิก" ต่ำ/กลาง/สูง (เสนอ)** = pixel ratio 1 / 1.5 / 2 · ค่าเริ่มบนจอสัมผัส = กลาง
- **ปรับอัตโนมัติ (เสนอ)**: วัด FPS เฉลี่ย 5 วิ ถ้า < 40 ลด pixel ratio ทีละขั้น (ไม่ขึ้นเองเพื่อกันแกว่ง) แจ้งในบันทึกครั้งเดียว
- **จำกัด FPS (เสนอ)**: ตัวเลือก 30/60 ช่วยแบตและความร้อน
- **WebGL context**: `cosPreview.ts` และ `orbPreview.ts` สร้าง renderer แยก → iOS จำกัดจำนวน context และหน่วยความจำ ต้อง `dispose()` + `forceContextLoss()` ตอนปิด หรือย้ายไปวาดด้วย renderer หลัก (`setScissor`)
- **พื้นผิว**: เช็คขนาด texture ใหญ่สุดที่ใช้ (sprite sheet, ลายพื้น) เทียบกับ `MAX_TEXTURE_SIZE` ของ iPhone รุ่นเก่า (4096) · shader ผสมลายพื้นใน `world.ts` อาจหนักบนเครื่องอ่อน → มีโหมดลายเดียวในคุณภาพต่ำ
- **เงา/เอฟเฟกต์**: ปิดเงาเงาไดนามิก (ถ้ามี) และลดอนุภาคใน `effects.ts`/`hazards.ts` ในคุณภาพต่ำ
- **DOM**: ป้ายลอย (`floating.ts`) ตัวเลขดาเมจ ฟองแชท อัปเดตทุกเฟรม → ใช้ `transform` แทน `left/top` และจำกัดจำนวนตัวเลขดาเมจบนจอเล็ก
- **หน่วยความจำ**: iOS Safari ปิดแท็บเมื่อใช้เกิน ~1–1.5GB → ตรวจหน่วยความจำตอนข้ามโซน (ประตูมิติ) ว่าคืน texture/geometry ของโซนเก่า (เชื่อมกับการ์ด "ทดสอบประตูมิติบนเครื่องสเปกต่ำ" ในคันบัง)
- **ข้อความวัดผล**: เพิ่มแผงดีบัก FPS/draw calls/pixel ratio (เปิดจากเมนูระบบ) สำหรับทดสอบบนเครื่องจริง

### 8.2 เครื่องจริง
- **LAN (เร็วสุด)**: รัน `npm run dev -- --host` (หรือเพิ่ม `server.host: true` ใน `vite.config.ts` **(เสนอ)**) แล้วเปิด `http://<IP เครื่อง dev>:5173` จากมือถือ Wi-Fi เดียวกัน · ต้องอนุญาต Windows Firewall port 5173
  - ข้อจำกัด: http ไม่ใช่ secure context → **PWA/เพิ่มหน้าจอหลักแบบเต็มจอ และ fullscreen บางเครื่องใช้ไม่ได้**
- **HTTPS ผ่าน Cloudflare**: `npm run tunnel` (ลิงก์ไม่เปลี่ยน) → ทดสอบ PWA, เพิ่มลงหน้าจอหลัก, เสียง iOS, เต็มจอ · **ระวัง**: อย่า build ทับ `dist/` ตอน server ของเจ้าของเปิดให้เพื่อนเล่น (ดู CLAUDE.md) ให้ใช้ dev server หรือ `--outDir` แยก
- **ดีบักบนเครื่อง**: iPhone/iPad ผ่าน Safari Web Inspector บน Mac (ถ้ามี) · Android ผ่าน `chrome://inspect` · ถ้าไม่มี Mac ใช้แผงดีบักในเกม (หัวข้อ 7) + ส่ง error เข้าบันทึก
- **เครื่องที่ควรมี**: iPhone รุ่นมีรอยบาก (iOS 16+), Android ระดับกลาง/ล่าง (สำหรับประสิทธิภาพ), iPad (+ คีย์บอร์ดถ้ามี)

### 8.3 เช็คลิสต์ "เล่นได้จริง" (ต้องผ่านก่อนปิดเฟส 1)
1. เข้าสู่ระบบ/สร้างตัวละครด้วยคีย์บอร์ดจอได้
2. เดินด้วยจอย + แตะเพื่อเดิน · ตี + Q/E/R/แดช + ยาทั้ง 3 คลาส · เล็งด้วยการลากได้
3. แตะ NPC → คุย → ซื้อยา / ขายของ · แตะของดรอปเก็บได้ · พักน้ำพุได้ · ใส่กุญแจที่แท่นบอสได้
4. เปิดกระเป๋า สวม/ถอดของ ใช้ยา ได้โดยไม่ล้นจอทั้งสองแนว
5. แชทพิมพ์ส่งได้ คีย์บอร์ดไม่บัง
6. Auto เปิด/ปิด/ตั้งค่าได้
7. หมุนจอระหว่างเล่นไม่พัง · สลับแอปแล้วกลับมาไม่มีปุ่มค้าง
8. หน้าไม่เลื่อน ไม่ซูมเอง ไม่ดึงรีเฟรช
9. PC เล่นได้เหมือนเดิมทุกอย่าง
