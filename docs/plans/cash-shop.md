## วิธีทำ

### ข้อมูล (`src/shared/cashShop.ts` ไฟล์ใหม่ ไม่ใช้ three/DOM)

- รายการสินค้า id: `cos:<id ของแต่งตัว>` และ `stone:<ชนิด>` (exp_scroll, drop_scroll, megaphone, enhance, protect, reroll_values, reroll_stat)
- ค่าต่อชิ้น `CashItemCfg { on?, price?, sale?, limit?, start?, end?, badge?: 'new'|'hot', featured? }`
  - ของแต่งตัว: ราคามาจาก `cos_shop` เดิม (`cosPrice`) ไม่เก็บซ้ำ ที่เหลือ (ราคาลด เวลา ป้าย แนะนำ) เก็บในแคชช็อป · จำกัดต่อบัญชี = 1 เสมอ (มีแล้ว = "มีแล้ว")
  - ราคาเป็นจำนวนเต็ม 1–1,000,000 · ราคาลดต้องน้อยกว่าราคาเต็ม · จำกัด 1–9,999 หรือว่าง = ไม่จำกัด · เวลาเริ่ม < เวลาจบ
- ตั้งค่าทั้งร้าน `{ open: false, items: {...}, packages: [{ id, crystals, bonus, baht }] }` เก็บในตาราง `settings` key `cash_shop` **เฉพาะที่ต่างจากค่าเริ่ม** (ไม่มีแถว = ร้านปิดขาย ราคาชุด ก แพ็กเกจว่าง → DB เก่าใช้ได้เลย)
- `checkCashShop(v, strict)` ตรวจแบบเข้ม (บันทึกจาก /admin) / ผ่อน (อ่าน DB) เหมือน `checkCosShop`
- `cashCatalog(cfg, cosShop, now)` สร้างรายการที่ส่งให้ผู้เล่น: ชื่อ หมวด ราคา ราคาลด จำกัด เวลาเหลือ ป้าย · ชิ้นที่ปิด/หมดเวลา/ของแต่งตัวที่ซ่อนหรือไม่มีราคา ไม่ส่ง

### เงิน: คริสตัลมิติ

- คอลัมน์ใหม่ `accounts.crystals INTEGER NOT NULL DEFAULT 0` (`ALTER TABLE` แบบคอลัมน์อื่น บัญชีเก่าได้ 0)
- รอบนี้**ไม่มีทางได้คริสตัล** (ไม่มีปุ่มให้ใน /admin ตามที่เจ้าของเลือก) เทสต์ใส่ค่าใน DB ชั่วคราวเอง
- ผู้เล่นเห็นยอดของบัญชีตัวเองตอนเข้าเกมและหลังซื้อ (`welcome.crystals`, `{ t: 'crystals', n }`)

### การซื้อ (server เป็นคนหักและให้ของ)

- action ใหม่ `cashBuy { id, qty, price }` ครบ 5 ที่ตาม `CLAUDE.md` (`price` = ราคาต่อชิ้นที่ผู้เล่นเห็น ถ้าไม่ตรงกับตอนนี้ = ปฏิเสธ "ราคาเปลี่ยนแล้ว" กันซื้อตอนเจ้าของเพิ่งแก้ราคา)
- server ตรวจ: ร้านเปิดขาย · ไม่ใช่ Guest (Guest ไม่มีจดหมาย/ของแต่งตัว) · สินค้ามีอยู่และอยู่ในช่วงเวลา (เวลา server) · qty จำนวนเต็ม 1–10 (ของแต่งตัว = 1) · ยังไม่เกินจำนวนจำกัด · จำกัด 1 ครั้ง/300 ms ต่อคน
- ทำใน **transaction เดียว**:
  1. `UPDATE accounts SET crystals = crystals - ? WHERE id = ? AND crystals >= ?` ถ้าไม่มีแถวเปลี่ยน = คริสตัลไม่พอ (กันสองตัวละครของบัญชีเดียวกันกดพร้อมกัน)
  2. นับที่ซื้อไปแล้วจากตารางใหม่ `cash_purchases (id, account_id, char_id, item, qty, price, at)` ถ้ารวมแล้วเกินจำกัด = ย้อนทั้งหมด
  3. ของแต่งตัว: `INSERT OR IGNORE` เข้า `account_cosmetics` ถ้าไม่มีแถวเพิ่ม (มีอยู่แล้ว) = ย้อน ไม่เสียคริสตัล
  4. ของอื่น: สร้างจดหมายเข้ากล่องบัญชี ผู้ส่ง "แคชช็อป" ของแนบ = กองหิน/ของใช้ qty ชิ้น (หินไม่ผูก, ใบคูณ/โทรโข่งผูกตอนกดรับตามกติกาเดิม) หมดอายุ 30 วันเหมือนจดหมายปกติ
  5. บันทึกแถว `cash_purchases`
- ผล: ข้อความในแชท "ซื้อ … สำเร็จ ของอยู่ในจดหมาย" + ยอดคริสตัลใหม่ · ของแต่งตัวใช้ได้ทันทีในหน้าต่าง "แต่งตัว"

### หน้าต่างแคชช็อป (`src/client/cashShop.ts` ไฟล์ใหม่)

- หัว: "แคชช็อป" · แท็บ แนะนำ / ของแต่งตัว / ของใช้ / หิน · ยอดคริสตัล + ปุ่ม + · ปุ่มปิด
- ร้านปิดขาย: แถบ "ร้านยังไม่เปิดขาย ดูสินค้าได้อย่างเดียว"
- เมนูซ้าย: ของแต่งตัวแยก ปีก สัตว์ขี่ สัตว์เลี้ยง ออร่า กรอบชื่อ/แชท ลูกแก้วตีบวก · ของใช้แยก ใบคูณ / โทรโข่ง · หิน ไม่มีเมนูย่อย
- การ์ด: ภาพ (ใช้ไอคอน/ภาพการ์ดของแต่งตัวที่มีอยู่) ชื่อ "ซื้อได้ x/y" หรือ "มีแล้ว" เวลาเหลือ ป้ายมุม แถบราคา (ราคาลด = ราคาเดิมขีดฆ่า)
- ชี้: กล่องรายละเอียด (คำอธิบาย ผูก/เทรดได้ จำกัด เวลา) · กด: หน้าต่างซื้อ (ภาพใหญ่ คำอธิบาย ตัวเลือกจำนวน 1–10 สำหรับของใช้/หิน ปุ่ม "ลองสวม" ของแต่งตัว ใช้ตัวลองสวมเดิมของหน้าต่างแต่งตัว ราคารวม ปุ่มยืนยัน) ปุ่มยืนยันกดไม่ได้เมื่อร้านปิด/คริสตัลไม่พอ/Guest พร้อมบอกเหตุผล
- ปุ่ม +: หน้าต่างแพ็กเกจ (คริสตัล + โบนัส ราคาบาท) ป้าย "เร็วๆ นี้" ไม่มีแพ็กเกจ = ข้อความ "เติมคริสตัลมิติได้เร็วๆ นี้"
- สกินกรอบ 16-bit เดียวกับหน้าต่างอื่น รองรับมือถือ (แตะ = ชี้, แตะซ้ำ/ปุ่ม = ซื้อ ตามแบบหน้าต่างอื่นหลัง #290)
- รับรายการตอนเข้าเกม (`welcome.cashShop`) และทุกคนได้ใหม่ทันทีเมื่อเจ้าของบันทึก (`{ t: 'cashShop' }`) · ของหมดเวลาหายตอนเปิดหน้าต่าง/เมื่อนับถอยหลังถึง 0

### ทางเข้า

- ไอคอน `top-cashshop` ในแถวมุมขวาบน (ข้างรายวัน) + ช่องในตารางเมนู `sysmenu.ts` ระหว่างรอภาพใช้ป้ายเปล่ากับสัญลักษณ์
- NPC ใหม่ `crystal_merchant` "พ่อค้าคริสตัล" ใน `NPC_IDS` คุยแล้วเปิดแคชช็อป ป้ายบนหัว "แคชช็อป" · **ตำแหน่งในเมือง: เสนอข้างช่างแต่งตัว** (เจ้าของยืนยันตอนอนุมัติแผน)

### หน้า `/admin` (แท็บใหม่ "แคชช็อป" ไฟล์ใหม่ `src/admin/cashShop.ts`)

- สิทธิ์ใหม่ `cashShop` (ดู: owner + GM) และ `cashShopEdit` (บันทึก: owner) ตั้งต่อ role ได้ในแท็บ "สิทธิ์"
- สวิตช์ **เปิดขาย** (ถามยืนยัน) · ตารางทุกสินค้า: เปิด/ปิด ราคา (ของแต่งตัวแก้ที่นี่ได้ด้วย บันทึกลง `cos_shop` เดิม) ราคาลด จำกัดต่อบัญชี เวลาเริ่ม/จบ ป้าย ติดแนะนำ · ตารางแพ็กเกจ เพิ่ม/ลบ
- ประวัติการซื้อ 200 รายการล่าสุด (บัญชี ตัวละคร ของ จำนวน ราคา เวลา) · หน้าบัญชีโชว์ยอดคริสตัล (ดูอย่างเดียว)
- ส่ง `base` กันบันทึกทับ (409) · บันทึกลง `admin_audit` action `cash-shop` แบบเดิม → ใหม่
