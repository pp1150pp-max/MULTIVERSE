# เล่น MULTIVERSE กับเพื่อน

## คุณ (เจ้าของ server)

**ทุกครั้งที่จะเล่น:** เปิดโฟลเดอร์เกมใน Terminal แล้วพิมพ์

```
npm run online
```

รอสักครู่จะขึ้นแบบนี้ (ครั้งแรกจะช้ากว่าปกตินิดหน่อย เพราะระบบดาวน์โหลดโปรแกรมสร้างลิงก์ของ Cloudflare ให้เอง)

```
================================================================
  🌐 ลิงก์สำหรับเพื่อน (กดแล้วเข้าเล่นได้เลย ไม่ต้องลงอะไร):

     https://xxxx-xxxx-xxxx.trycloudflare.com

  📋 คัดลอกลิงก์ไว้แล้ว — กด Ctrl+V วางส่งเพื่อนได้เลย
================================================================
```

กด **Ctrl+V** วางลิงก์ส่งเพื่อนใน LINE หรือ Discord ได้เลย

- ระหว่างเล่นห้ามปิดหน้าต่าง Terminal นั้น
- อย่าให้คอมเข้าโหมด Sleep (ตั้งที่ **Settings → System → Power → Sleep = Never**)
- **ลิงก์จะเปลี่ยนทุกครั้งที่เปิด server ใหม่** ต้องส่งลิงก์ใหม่ให้เพื่อนทุกรอบ ลิงก์เก่าใช้ไม่ได้แล้ว
  - อยากให้ลิงก์เดิมตอนอัปเดตเกม: เปิดอีกหน้าต่างพิมพ์ `npm run tunnel` ค้างไว้ก่อน แล้วค่อย `npm run online` — ปิด/เปิด server ใหม่กี่ครั้งลิงก์ก็เหมือนเดิม จนกว่าจะปิดหน้าต่าง tunnel หรือปิดคอม

## เพื่อน

1. กดลิงก์ที่ได้มา (แนะนำเปิดด้วย Chrome หรือ Edge บนคอม)
2. กด **Multiplayer** → **สมัครสมาชิกใหม่** → สร้างตัวละคร → **เข้าสู่โลก**

ไม่ต้องติดตั้งอะไร ครั้งหน้าแค่กดลิงก์ใหม่ แล้วกด **เข้าสู่ระบบ** ด้วยชื่อผู้ใช้และรหัสผ่านเดิม ตัวละครยังอยู่ครบ

## ถ้าอยู่บ้านเดียวกัน (Wi-Fi เดียวกัน)

ใช้ที่อยู่ `Wi-Fi บ้าน: http://192.168.x.x:2567` ที่ server แสดงแทนลิงก์ก็ได้ จะเร็วกว่า
ครั้งแรกต้องรัน `npm run firewall` แล้วกด Yes ด้วย

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ไม่มีลิงก์ขึ้น แต่ขึ้นว่า "หาโปรแกรม cloudflared ไม่เจอ" | เช็คอินเทอร์เน็ตแล้วรัน `npm run online` ใหม่ หรือติดตั้งเองด้วย `winget install Cloudflare.cloudflared` |
| เพื่อนกดลิงก์ใหม่แล้วขึ้นว่าหาเว็บไม่เจอ | ลิงก์ที่เพิ่งสร้างอาจต้องรอสักครู่ (ไม่เกิน 1 นาที) ให้เพื่อนลองกดใหม่ |
| เพื่อนกดลิงก์แล้วขึ้น error ของ Cloudflare | server ปิดอยู่ หรือเป็นลิงก์เก่า ให้รัน `npm run online` แล้วส่งลิงก์ใหม่ |
| กำลังเล่นแล้วขึ้น "หลุดการเชื่อมต่อ" | คอมเจ้าของเข้าโหมด Sleep หรือปิดหน้าต่าง server ให้เปิดใหม่แล้วส่งลิงก์ใหม่ |
| ขึ้นว่า "บัญชีนี้เข้าเกมจากที่อื่น" | มีคนเข้าบัญชีเดียวกันจากอีกเครื่อง บัญชีหนึ่งเล่นได้ทีละเครื่อง |
| ลืมรหัสผ่าน | ยังไม่มีระบบรีเซ็ตรหัสผ่าน ให้สมัครชื่อผู้ใช้ใหม่ไปก่อน |

## เรื่องความปลอดภัย

- **ใครได้ลิงก์ไปก็สมัครเล่นได้** ให้ส่งลิงก์เฉพาะคนที่อยากให้เล่น ถ้าลิงก์หลุดออกไป แค่ปิด server แล้วเปิดใหม่ ลิงก์เก่าจะใช้ไม่ได้ทันที
- คนที่ได้ลิงก์เข้าได้แค่ตัวเกม เข้าไฟล์อื่นในคอมคุณไม่ได้ และไม่เห็น IP บ้านคุณ
- รหัสผ่านถูกเข้ารหัสก่อนเก็บ และถ้าใครเดารหัสผิดหลายครั้ง ระบบจะพักการลองของคนนั้นชั่วคราว
- **สำรองข้อมูล:** ปิด server ก่อน แล้ว copy ไฟล์ `server/data/multiverse.db` เก็บไว้ ไฟล์นี้คือบัญชีและตัวละครออนไลน์ทั้งหมด
