# เล่น MULTIVERSE กับเพื่อนนอกบ้าน (ผ่าน Tailscale)

**Tailscale** เป็นโปรแกรมฟรี ทำให้คอมของเพื่อนต่อเข้าคอมเราได้เหมือนใช้ Wi-Fi บ้านเดียวกัน แม้จะอยู่คนละที่
- ไม่ต้องตั้งค่าเราเตอร์ และไม่ต้องเปิด port ออกอินเทอร์เน็ต
- คนที่ไม่ได้รับเชิญจะมองไม่เห็นเครื่องเราเลย

> ถ้าเพื่อนต่อ Wi-Fi บ้านเดียวกับคุณ ไม่ต้องใช้ Tailscale
> ทำแค่ **ข้อ 1.2** แล้วให้เพื่อนเปิดที่อยู่ `วง LAN` ที่ server แสดง

---

## ส่วนที่ 1 — เจ้าของ server (ทำครั้งเดียว)

### 1.1 ติดตั้ง Tailscale

1. ดาวน์โหลดที่ https://tailscale.com/download แล้วเลือก **Windows**
2. ติดตั้ง แล้วกด **Log in** ใช้บัญชี Google, Microsoft หรือ GitHub ก็ได้
3. ไอคอน Tailscale ที่มุมขวาล่างของจอต้องขึ้นว่า **Connected**

### 1.2 เปิดทางใน Windows Firewall

ตอนนี้ Windows บล็อกไม่ให้เครื่องอื่นเข้า server ได้ ให้เปิดโฟลเดอร์เกมใน Terminal แล้วพิมพ์

```
npm run firewall
```

Windows จะถามสิทธิ์ผู้ดูแลระบบ ให้กด **Yes** แล้วรอจนขึ้นว่า `Done`

- คำสั่งนี้เปิดเฉพาะ port 2567 และเฉพาะเครื่องใน Tailscale กับวง Wi-Fi บ้าน คนอื่นในอินเทอร์เน็ตยังเข้าไม่ได้
- ถ้าวันหลังอยากปิด ให้พิมพ์ใน PowerShell (เปิดแบบผู้ดูแลระบบ)

  ```
  Remove-NetFirewallRule -DisplayName 'MULTIVERSE server (port 2567)'
  ```

### 1.3 แชร์เครื่องให้เพื่อน

1. เข้า https://login.tailscale.com/admin/machines
2. หาชื่อเครื่องของคุณ กด **⋯** ท้ายแถว แล้วเลือก **Share…**
3. ใส่อีเมลเพื่อน หรือกด **Copy share link** แล้วส่งลิงก์ให้เพื่อน

เพื่อนจะเห็นแค่เครื่องนี้เครื่องเดียว ไม่เห็นเครื่องอื่นในบ้านคุณ

### 1.4 ทุกครั้งที่จะเล่น

1. เปิดโฟลเดอร์เกมใน Terminal แล้วพิมพ์ `npm run online`
2. รอจนขึ้นบรรทัดประมาณนี้

   ```
   Tailscale  http://100.101.102.103:2567   ← ส่งที่อยู่นี้ให้เพื่อนนอกบ้าน
   ```

3. ส่งที่อยู่นั้นให้เพื่อน ที่อยู่นี้ไม่เปลี่ยน ส่งครั้งเดียวใช้ได้ตลอด
4. ระหว่างเล่น ห้ามปิดหน้าต่าง Terminal นั้น และอย่าให้คอมเข้าโหมด Sleep
   (ตั้งที่ **Settings → System → Power → Sleep = Never**)

## ส่วนที่ 2 — เพื่อน (ทำครั้งเดียว)

ไม่ต้องลง Node.js และไม่ต้องโหลดโค้ดเกม ใช้แค่เบราว์เซอร์ (แนะนำ Chrome หรือ Edge)

1. ติดตั้ง Tailscale จาก https://tailscale.com/download แล้ว Log in ด้วยบัญชีของตัวเอง
2. เปิดลิงก์แชร์ที่เจ้าของ server ส่งมา แล้วกด **Accept**
3. เช็คว่าไอคอน Tailscale ขึ้นว่า **Connected**
4. เปิดเบราว์เซอร์ไปที่ที่อยู่ที่ได้มา เช่น `http://100.101.102.103:2567`
5. กด **Multiplayer** → **สมัครสมาชิกใหม่** → สร้างตัวละคร → **เข้าสู่โลก**

ครั้งต่อไปแค่เปิด Tailscale ให้ Connected แล้วเข้าที่อยู่เดิม

ทำด้วยกันครั้งแรก จะได้รู้ว่าทุกอย่างพร้อม

## แก้ปัญหา

**เพื่อนเปิดที่อยู่แล้วหน้าไม่ขึ้น หรือหมุนค้าง**
1. เช็คว่าหน้าต่าง `npm run online` ของเจ้าของยังเปิดอยู่
2. เช็คว่า Tailscale ของ **ทั้งสองเครื่อง** ขึ้น Connected และเพื่อนเห็นเครื่องเจ้าของในรายการเครื่องของ Tailscale
3. เช็คว่าเจ้าของรัน `npm run firewall` แล้ว (ข้อ 1.2)
4. เช็คว่าพิมพ์ `http://` ไม่ใช่ `https://` และมี `:2567` ต่อท้าย

**หน้าเกมขึ้น แต่สมัครแล้วขึ้น "เชื่อมต่อ server ไม่ได้"**
server ปิดไปแล้ว ให้เจ้าของรัน `npm run online` ใหม่ แล้วเพื่อนกด F5

**กำลังเล่นแล้วขึ้น "หลุดการเชื่อมต่อ"**
- คอมเจ้าของเข้าโหมด Sleep หรือปิดหน้าต่าง server ไป ให้เปิด server ใหม่ แล้วกด "กลับไปหน้าเมนู"
- ถ้าขึ้นว่า "บัญชีนี้เข้าเกมจากที่อื่น" แปลว่ามีคนเข้าบัญชีเดียวกันจากอีกเครื่อง บัญชีหนึ่งเล่นได้ทีละเครื่อง

**แลคมาก**
- Tailscale พยายามต่อเครื่องตรงหากันก่อน ถ้าต่อตรงไม่ได้จะส่งผ่านเครื่องกลาง (relay) ซึ่งช้ากว่า
- เช็คได้โดยเจ้าของพิมพ์ `tailscale status` แล้วดูแถวของเครื่องเพื่อน ถ้าเห็นคำว่า `relay` แปลว่ากำลังส่งผ่านเครื่องกลาง
- ลองให้เพื่อนสลับเน็ต เช่น จาก Wi-Fi ไปใช้ Hotspot มือถือ หรือรีสตาร์ทเราเตอร์

**ลืมรหัสผ่าน**
ตอนนี้ยังไม่มีระบบรีเซ็ตรหัสผ่าน ให้สมัครชื่อผู้ใช้ใหม่ไปก่อน

## ความปลอดภัย

- **ไม่ต้องและไม่ควร** เปิด port ที่เราเตอร์ (port forwarding) ใช้ Tailscale อย่างเดียวก็พอ
- กฎ Firewall จาก `npm run firewall` เปิดให้เฉพาะเครื่องใน Tailscale (`100.64.0.0/10`) และวง Wi-Fi บ้าน
- รหัสผ่านถูกเข้ารหัสก่อนเก็บ เจ้าของ server ก็อ่านรหัสผ่านของเพื่อนไม่ได้
- **เลิกแชร์ให้เพื่อน:** เข้า https://login.tailscale.com/admin/machines กด ⋯ ที่เครื่องคุณ เลือก **Share…** แล้วกด **Revoke** ที่ชื่อเพื่อน
- **สำรองข้อมูล:** ปิด server ก่อน แล้ว copy ไฟล์ `server/data/multiverse.db` เก็บไว้ ไฟล์นี้คือบัญชีและตัวละครออนไลน์ทั้งหมด
