ข้อตกลงการใช้งาน

MULTIVERSE · ผู้ให้บริการ: ทีม MULTIVERSE · มีผลตั้งแต่ 15 พฤศจิกายน 2569

การสมัคร เข้าสู่ระบบ หรือเล่นเกม MULTIVERSE (play.multiverse-game.com) ถือว่าคุณยอมรับข้อตกลงนี้และนโยบายความเป็นส่วนตัว

1. เกมอยู่ในช่วงทดสอบ

  • เกมยังอยู่ในช่วงพัฒนาและทดสอบ อาจมีบั๊ก server ปิดปรับปรุง หรือระบบเปลี่ยนได้ตลอด
  • ข้อมูลในเกม (ตัวละคร ไอเทม ทอง) อาจถูกล้างหรือปรับ เช่น ก่อนเปิดให้เล่นทั่วไป หรือเมื่อแก้บั๊กที่ทำให้ได้ของผิดปกติ

2. บัญชีของคุณ

  • บัญชีละ 1 คน ห้ามซื้อ ขาย หรือให้ยืมบัญชี
  • รักษารหัสผ่านและบัญชี Google ที่ผูกไว้ให้ปลอดภัย การกระทำในบัญชีของคุณถือเป็นความรับผิดชอบของคุณ
  • ชื่อผู้ใช้และชื่อตัวละครต้องไม่หยาบคาย ไม่ปลอมเป็นผู้ดูแลหรือคนอื่น
  • บัญชี Guest เป็นบัญชีชั่วคราว ถูกลบเมื่อไม่ได้ออนไลน์เกิน 24 ชั่วโมง

3. สิ่งที่ห้ามทำ

  • ใช้โปรแกรมโกง บอท สคริปต์ หรือแก้ไขตัวเกม/ข้อมูลที่ส่งไปยัง server
  • ใช้บั๊กหาประโยชน์ — ถ้าเจอบั๊ก ให้แจ้งผ่านปุ่มแจ้งปัญหาในเกม
  • โจมตี ทำให้ server ล่ม หรือเข้าถึงส่วนที่ไม่ได้รับอนุญาต
  • ด่า คุกคาม สแปม หลอกลวง หรือโพสต์เนื้อหาผิดกฎหมายในแชท
  • ซื้อขายไอเทม ทอง หรือบัญชีในเกมด้วยเงินจริงนอกช่องทางของเกม

4. การลงโทษ

ทีมผู้ดูแลอาจตักเตือน ห้ามแชท ยึดของที่ได้มาโดยผิดกติกา ระงับบัญชีชั่วคราว หรือแบนถาวร ตามความร้ายแรง โดยไม่ต้องแจ้งล่วงหน้า

5. ไอเทมและของในเกม

ไอเทม ทอง และของทุกอย่างในเกมเป็นส่วนหนึ่งของบริการ ไม่ใช่ทรัพย์สินที่แลกเป็นเงินได้ และไม่มีมูลค่าเป็นเงินจริง

6. ข้อจำกัดความรับผิด

เกมให้บริการตามสภาพที่เป็นอยู่ ทีม MULTIVERSE ไม่รับประกันว่าเกมจะใช้งานได้ตลอดเวลาหรือไม่มีข้อผิดพลาด และไม่รับผิดชอบต่อความเสียหายจากการที่ใช้งานเกมไม่ได้ ข้อมูลในเกมสูญหาย หรือการกระทำของผู้เล่นคนอื่น

7. การเปลี่ยนข้อตกลง

เราอาจแก้ข้อตกลงนี้ได้ โดยแก้หน้านี้และวันที่ด้านบน การเล่นต่อหลังจากนั้นถือว่ายอมรับข้อตกลงใหม่
