# MULTIVERSE — The Shattering (Prototype v0.1)

Isometric 2.5D Action MMORPG บนเว็บ · Three.js + TypeScript + Vite

> อยากช่วยเขียนโค้ด? อ่าน [CONTRIBUTING.md](CONTRIBUTING.md) — ทุกงานต้องแตก branch แล้วเปิด Pull Request

## วิธีรัน

```bash
npm install
npm run dev        # เปิด http://localhost:5173
npm run build      # สร้างไฟล์สำหรับขึ้นเว็บไว้ใน dist/
```

## สิ่งที่มีใน Prototype นี้

- **Zone 1: Emerald Forest** (Lv.1–10) มีแคมป์จุดเกิด, The Seeker (NPC บทนำ), ทางเดิน และป่าที่จะโปร่งใสเมื่อตัวละครเดินไปอยู่ด้านหลัง
- **มอนสเตอร์ 5 ชนิด + Mini Boss** ตามชีตคอนเซ็ปต์ แต่ละชนิดมี AI ต่างกัน
  - สไลม์: ไม่สนใจผู้เล่น จนกว่าจะถูกตี
  - กระต่าย: ถูกตีแล้วบางครั้งจะวิ่งหนี
  - จิ้งจอก: เข้ามาโจมตีเองเมื่อผู้เล่นเข้าใกล้
  - หมูป่า: พุ่งชน และมีเส้นเตือนสีแดงก่อนพุ่ง
  - หมาป่า: ตัวหนึ่งถูกตี ทั้งฝูงจะเข้ามาช่วย
  - หมี (Mini Boss): ทุบพื้นโดยมีวงเตือน และคลั่งเมื่อ HP เหลือต่ำกว่า 50%
- **3 คลาส** ได้แก่ Sword, Mage และ Gunslinger แต่ละคลาสมีโจมตีปกติ, สกิล Q/E/R และ Dash
- **ระบบไอเทม** มี 5 ระดับความหายาก ค่าสถานะเสริมสุ่ม สวมใส่และเปรียบเทียบค่าได้ และมียา HP/MP
  - ขายของได้ที่ **พ่อค้า** ในแคมป์เท่านั้น (พ่อค้าขายยา HP/MP ด้วย)
  - คลิกขวาในกระเป๋าตอนไม่ได้อยู่ที่ร้าน = วางของลงพื้น เก็บคืนได้ภายใน 60 วินาที
- **ช่างตีเหล็ก** ตีบวกอาวุธได้ถึง +10 ทุกระดับเพิ่มพลังโจมตีและโอกาสคริติคอล
  - +1 ถึง +5 สำเร็จ 100% · +6 90% · +7 75% · +8 60% · +9 45% · +10 30%
  - ตั้งแต่ +7 ขึ้นไป ถ้าล้มจะเสียทองและระดับลดลง 1 ขั้น (ปรับได้ใน `src/shared/data/enhance.ts`)
- **เลเวลอัพ / EXP / Gold** · EXP ที่ต้องใช้เพิ่มขึ้นเร็วตามเลเวล · ตีมอนสเตอร์ที่เลเวลต่ำกว่าเกิน 3 เลเวล (ชื่อสีเทา) ได้ EXP ลดลง 20% ต่อเลเวล (เหลือต่ำสุด 10%) · เมื่อตายจะเสีย EXP 10% แล้วเกิดใหม่ที่แคมป์
- **Auto Play (F)** ฟาร์มได้เฉพาะใน Open World โดยจะข้ามบอส และผู้เล่นควบคุมเองแทรกได้ตลอดเวลา
- เซฟลงเบราว์เซอร์อัตโนมัติ (localStorage)

## โครงสร้างโค้ด

```
src/shared/      ← ข้อมูลและสูตรคำนวณล้วน ๆ (ไม่มีโค้ดกราฟิก) ส่วนนี้จะย้ายไปใช้บนเซิร์ฟเวอร์ Colyseus ได้
  data/classes.ts    คลาสและสกิล
  data/monsters.ts   ค่าสถานะมอนสเตอร์
  data/zones.ts      แผนที่ จุดเกิด และเส้นทาง
  data/items.ts      การสุ่มไอเทม
  data/enhance.ts    กฎการตีบวกอาวุธ
  data/shop.ts       ราคาของที่พ่อค้า
src/client/      ← ฝั่งแสดงผล: Three.js, HUD และ input
  Game.ts            game loop, การต่อสู้, การดรอปของ
  entities/          Player, Monster, Projectile, Loot
  skills.ts          การทำงานของสกิลทุกตัว
  autoplay.ts        บอท Auto Play
  placeholder.ts     ภาพตัวแทนที่วาดด้วยโค้ด
public/assets/   ← ใส่ไฟล์ภาพจริงที่นี่ (ดู public/assets/README.md)
```
