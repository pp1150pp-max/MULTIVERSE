# MULTIVERSE — The Shattering (Prototype v0.1)

Isometric 2.5D Action MMORPG บนเว็บ · Three.js + TypeScript + Vite

> อยากช่วยเขียนโค้ด? อ่าน [CONTRIBUTING.md](CONTRIBUTING.md) — ทุกงานต้องแตก branch แล้วเปิด Pull Request

## วิธีรัน

```bash
npm install
npm run dev        # เปิด http://localhost:5173
npm run build      # สร้างไฟล์สำหรับขึ้นเว็บไว้ใน dist/
```

## เปิด Server สำหรับเล่นออนไลน์ (Multiplayer)

```bash
npm run online     # build เกม เปิด server และสร้างลิงก์ https://….trycloudflare.com ให้เพื่อนกดเข้าเล่น
npm run server     # เปิดเฉพาะ server ไม่มีลิงก์ (ใช้คู่กับ npm run dev ตอนพัฒนา — Vite ส่ง /api ต่อให้เอง)
```

- **เล่นกับเพื่อน:** ดูคู่มือ [docs/PLAY-WITH-FRIENDS.md](docs/PLAY-WITH-FRIENDS.md)
  `npm run online` จะแสดงลิงก์และคัดลอกไว้ให้ (ครั้งแรกจะดาวน์โหลดโปรแกรม cloudflared ของ Cloudflare มาไว้ที่ `tools/bin/` เอง)
  เพื่อนกดลิงก์แล้วเล่นได้เลย ไม่ต้องติดตั้งอะไร (ลิงก์เปลี่ยนทุกครั้งที่เปิด server ใหม่)
- เพื่อนที่ต่อ Wi-Fi บ้านเดียวกัน เข้าที่ `http://192.168.x.x:2567` ได้ด้วย ครั้งแรกต้องรัน `npm run firewall`
- บัญชีและตัวละครออนไลน์เก็บในไฟล์ `server/data/multiverse.db` (ไฟล์นี้ไม่ขึ้น GitHub)
  สำรองข้อมูลได้โดยปิด server แล้ว copy ไฟล์นั้นเก็บไว้
- รหัสผ่านถูกเข้ารหัส (scrypt) ก่อนเก็บ และถ้าใส่ผิดเกิน 10 ครั้งใน 10 นาที จะถูกพักการลองชั่วคราว
- ตัวละคร Singleplayer กับ Multiplayer แยกกันเด็ดขาด

### ในโลกออนไลน์

- ทุกคนอยู่ในป่ามรกตเดียวกัน เห็นตัวละครเพื่อนพร้อมชื่อ เลเวล และหลอด HP
- กด **Enter** เพื่อแชท (Esc = ยกเลิก)
- server เป็นคนคำนวณการต่อสู้ ของดรอป EXP ร้านค้า และการตีบวกทั้งหมด
  ตัวละครของเราเดินได้ทันทีในเครื่อง แล้ว server ตรวจว่าระยะที่เดินเป็นไปได้จริง (กันวาร์ป)
- **EXP** แบ่งตามสัดส่วนดาเมจที่แต่ละคนทำใส่มอนตัวนั้น
- **ของดรอป** คนที่ทำดาเมจมากที่สุดได้สิทธิ์เก็บก่อน 10 วินาที (ชื่อของจะมี 🔒 ถ้ายังไม่ใช่สิทธิ์เรา) หลังจากนั้นใครเก็บก็ได้
- เซฟอัตโนมัติทุก 30 วินาที ทุกครั้งที่ซื้อขาย/เลเวลอัพ และตอนออกจากเกม
- บัญชีเดียวเข้าได้ทีละที่ ถ้าเข้าจากอีกเครื่อง เครื่องเดิมจะหลุด

## สิ่งที่มีใน Prototype นี้

- **Zone 1: Emerald Forest** (Lv.1–10) มีแคมป์จุดเกิด, The Seeker (NPC บทนำ), ทางเดิน และป่าที่จะโปร่งใสเมื่อตัวละครเดินไปอยู่ด้านหลัง
- **มอนสเตอร์ 5 ชนิด + Mini Boss** ตามชีตคอนเซ็ปต์ แต่ละชนิดมี AI ต่างกัน
  - สไลม์: ไม่สนใจผู้เล่น จนกว่าจะถูกตี
  - กระต่าย: ถูกตีแล้วบางครั้งจะวิ่งหนี
  - จิ้งจอก: เข้ามาโจมตีเองเมื่อผู้เล่นเข้าใกล้
  - หมูป่า: พุ่งชน และมีเส้นเตือนสีแดงก่อนพุ่ง
  - หมาป่า: ตัวหนึ่งถูกตี ทั้งฝูงจะเข้ามาช่วย
  - หมี (Mini Boss): ทุบพื้นโดยมีวงเตือน และคลั่งเมื่อ HP เหลือต่ำกว่า 50%
- **3 คลาส** ได้แก่ Sword, Mage และ Gunslinger แต่ละคลาสมีโจมตีปกติ, สกิล Q/E/R และ Dash
- **ระบบไอเทม** มี 5 ระดับความหายาก ค่าสถานะเสริมสุ่ม สวมใส่และเปรียบเทียบค่าได้
  - กระเป๋ามีปุ่มเรียงของ เลือกได้ว่าจะเรียงตามความหายาก เลเวล ประเภทช่อง หรือราคาขาย และเรียงจากมากไปน้อยหรือน้อยไปมาก
  - ขายของได้ที่ **พ่อค้า** ในแคมป์เท่านั้น (พ่อค้าขายยา HP/MP ด้วย) มีปุ่มขายของทั้งหมดตามระดับความหายาก
- **ยา HP/MP** มี 3 ขนาด (เล็ก / กลาง / ใหญ่) ยิ่งใหญ่ยิ่งเติมเยอะและแพงขึ้น
  - ยาเก็บในกระเป๋าร่วมกับของสวมใส่ ช่องละไม่เกิน 10 ขวด ต้องเลือกว่าจะพกยาเท่าไหร่ และขายคืนได้ครึ่งราคา
  - คลิกยาในกระเป๋าเพื่อเลือกขนาดที่ปุ่ม 1 / 2 จะใช้
  - คลิกขวาในกระเป๋าตอนไม่ได้อยู่ที่ร้าน = วางของลงพื้น เก็บคืนได้ภายใน 60 วินาที
- **ช่างตีเหล็ก** ตีบวกอาวุธได้ถึง +10 ทุกระดับเพิ่มพลังโจมตีและโอกาสคริติคอล
  - +1 ถึง +5 สำเร็จ 100% · +6 90% · +7 75% · +8 60% · +9 45% · +10 30%
  - ตั้งแต่ +7 ขึ้นไป ถ้าล้มจะเสียทองและระดับลดลง 1 ขั้น (ปรับได้ใน `src/shared/data/enhance.ts`)
- **เลเวลอัพ / EXP / Gold** · EXP ที่ต้องใช้เพิ่มขึ้นเร็วตามเลเวล · ตีมอนสเตอร์ที่เลเวลต่ำกว่าเกิน 3 เลเวล (ชื่อสีเทา) ได้ EXP ลดลง 20% ต่อเลเวล (เหลือต่ำสุด 10%) · เมื่อตายจะเสีย EXP 10% แล้วเกิดใหม่ที่แคมป์
- **Auto Play (F)** ฟาร์มได้เฉพาะใน Open World โดยจะข้ามบอส กดโจมตีหรือสกิลเองแทรกได้ แต่ถ้าเดินเอง Auto จะปิด · โหมดออนไลน์ server เล่น Auto ให้ จึงฟาร์มต่อได้แม้สลับแท็บ
- เซฟลงเบราว์เซอร์อัตโนมัติ (localStorage)

## โครงสร้างโค้ด

```
src/shared/      ← กติกาเกมล้วน ๆ ไม่มีโค้ดกราฟิก ใช้ร่วมกันระหว่าง singleplayer กับ server
  sim/Sim.ts         ตัวจำลองโลก: มอนสเตอร์, การต่อสู้, ของดรอป, EXP, ร้านค้า, ตีบวก
  sim/Player.ts      ตัวละครผู้เล่น (สเตตัส, กระเป๋า, สกิล, Dash)
  sim/Monster.ts     AI มอนสเตอร์ (เลือกเป้าจากผู้เล่นทุกคน, เก็บดาเมจแยกรายคน)
  sim/skills.ts      การทำงานของสกิลทุกตัว
  sim/terrain.ts     ตำแหน่งต้นไม้/หิน/แคมป์ และการชน
  sim/types.ts       Intent (คำสั่งจากผู้เล่น) และ SimEvent (สิ่งที่ต้องแสดงบนจอ)
  sim/autoplay.ts    บอท Auto Play (เบราว์เซอร์ใช้ใน Singleplayer, server ใช้ในโหมดออนไลน์)
  data/              ข้อมูลเกม: คลาส, มอนสเตอร์, แผนที่, ไอเทม, ตีบวก, ยา, NPC
server/          ← game server (Node.js): API บัญชี/ตัวละคร + ฐานข้อมูล SQLite + เสิร์ฟไฟล์เกม
  main.ts            จุดเริ่ม server และ API ทั้งหมด
  db.ts              ตาราง accounts / sessions / characters
  auth.ts            เข้ารหัสรหัสผ่าน, token, กันการเดารหัส
  world.ts           โลกออนไลน์: รัน Sim, รับ input, ตรวจตำแหน่ง, ส่ง snapshot, แชท, เซฟ
  tunnel.ts          สร้างลิงก์ Cloudflare ให้เพื่อน (npm run online)
src/shared/api.ts  ← รูปแบบข้อมูล API และกติกาตรวจชื่อ/รหัสผ่าน (ใช้ร่วมกันทั้งเบราว์เซอร์และ server)
src/shared/net/protocol.ts ← ข้อความ WebSocket ระหว่างเบราว์เซอร์กับ server
src/client/      ← ฝั่งแสดงผล: Three.js, HUD และ input
  Game.ts            วาดโลก กล้อง เมาส์/คีย์บอร์ด (ใช้ได้ทั้ง 2 โหมดผ่าน Backend)
  backend.ts         Backend = แหล่งข้อมูลโลก: LocalBackend รัน Sim ในเครื่อง (singleplayer)
  net/online.ts      OnlineBackend: ต่อ server, จำลองโลกตาม snapshot, เดินตัวเองทันที
  menu.ts            หน้าเมนู: เลือกโหมด, login/สมัคร, เลือก/สร้าง/ลบตัวละคร
  net/api.ts         เรียก API ของ server
  views.ts           สไปรต์ของผู้เล่น/มอน/กระสุน/ของดรอป ที่อ่านค่าจาก Sim ทุกเฟรม
  world.ts           วาดพื้นและพร็อพตามตำแหน่งจาก terrain
  placeholder.ts     ภาพตัวแทนที่วาดด้วยโค้ด
public/assets/   ← ใส่ไฟล์ภาพจริงที่นี่ (ดู public/assets/README.md)
```

**กติกาสำคัญ:** โค้ดใน `src/shared/` ห้าม import `three` หรือใช้ `document` / `window`
เพราะ server จะรันโค้ดชุดนี้ด้วย ถ้า Sim อยากให้แสดงอะไรบนจอ ให้ส่งเป็น `SimEvent` แทน
