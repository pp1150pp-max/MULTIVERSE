# เอฟเฟกต์สกิลทั้งหมด: ภาพ + ชั้นเสริม (สำหรับเพื่อนที่จะแก้ภาพ)

อัปเดต 2026-11-15 · รายชื่อภาพที่แต่ละสกิลใช้ได้จากการร่ายสกิลจริงทุกท่าใน Sim (`npx tsx tools/skill-fx-list.ts`)

เอฟเฟกต์แต่ละท่าประกอบด้วย 2 ส่วน:

1. **ภาพ** คือแผ่นเฟรมใน `public/assets/sprites/fx/` ซึ่งเป็นส่วนที่เพื่อนวาดใหม่
2. **ชั้นเสริม** คือส่วนที่เกมวาดทับให้เอง ได้แก่ แสงเรือง แสงบนพื้น อนุภาค ภาพขยายเด้ง และความรู้สึกตอนโดน ค่าพวกนี้ผูกกับ "ชื่อภาพ" ไม่ได้ผูกกับไฟล์ ถ้าเปลี่ยนไฟล์ภาพแต่ยังใช้ชื่อ แผ่น และแถวเดิม ชั้นเสริมก็ยังทำงานเหมือนเดิม

ตอนนี้ชั้นเสริมเปิดจริงแล้ว 7 ภาพ (✅) ซึ่งเป็นภาพที่ 5 สกิลตัวอย่างใช้ ส่วนภาพอื่นที่มีค่าในตาราง ผมใส่ค่า **แนะนำ** ไว้ให้ ยังไม่ได้ใส่ในเกม แก้ตัวเลขในไฟล์นี้ได้เลย แล้วส่งกลับมา จะเอาไปใส่โค้ดให้ (หรือแก้ตรงใน `src/client/fxLayer.ts` ที่ `FX_RECIPES` ก็ได้)

## 1. รูปแบบแผ่นภาพ

- PNG พื้นหลังโปร่งใส แถวละ 1 ภาพเคลื่อนไหว **6 เฟรม** เรียงจากซ้ายไปขวา
- ช่องละ **256×256 px** (เช่น แผ่น 4 แถว = 1536×1024) ยกเว้นแผ่น `mage` เก่าที่ช่องละ 229×229
- ภาพแบบ **พื้น** วางราบบนพื้น หมุนตามทิศที่ร่าย ให้วาดเหมือนมองลงจากด้านบนและหันไปทางขวา
- ภาพแบบ **ตั้ง** หันเข้ากล้อง และหมุนตามทิศที่ร่าย
- ภาพแบบ **ตั้งตรง** หันเข้ากล้องและไม่หมุน
- ภาพแบบ **ยืน** ตั้งบนพื้น ให้วาดชิดขอบล่างของช่อง
- ภาพของ **ลูกที่บิน** เกมจะวนเฉพาะเฟรม 2–5 ระหว่างบิน (เฟรม 1 กับ 6 คือตอนเริ่มกับตอนจาง) ให้วาดหัวลูกชี้ไปทางขวา
- ภาพยังวาดแบบตัดขอบ (alphaTest 0.5) จึงไม่ต้องวาดแสงฟุ้งเอง ชั้นเสริมทำให้ ขอบดำของภาพยังเห็นเหมือนเดิม
- ภาพที่เป็นพื้นที่ค้าง (พื้นเพลิง หมอกพิษ ป้อมปืน ฯลฯ) เกมจะเล่นซ้ำทุก tick เวลาที่เขียนในตารางจึงเป็นเวลาต่อรอบ ไม่ใช่เวลาทั้งท่า

## 2. ค่าชั้นเสริม (แต่ละคอลัมน์หมายถึงอะไร)

| คอลัมน์ | ความหมาย |
|---|---|
| สี | สีของแสงเรือง แสงพื้น และอนุภาค |
| เรือง | ความแรงของแสงรอบภาพ (0 = ไม่มี, 1 = ปกติ, สูงสุดราว 1.5) |
| พื้น | รัศมีของแสงบนพื้น เทียบกับขนาดภาพ (0 = ไม่มี) |
| อนุภาค | ชนิด×จำนวน: `spark` ประกายเป็นเส้น · `shard` เศษหนักที่ตกลงพื้น · `ember` ถ่านไฟลอยขึ้น · `star` ดาวกะพริบ · `dust` ฝุ่นต่ำ (มือถือได้ครึ่งเดียว) |
| เด้ง | ✔ = ตอนปล่อยภาพขยายใหญ่แล้วหดกลับ |
| หนัก | 0–1 คือความหนักตอนโดน ทำให้จอสั่น ภาพค้าง และมอนกะพริบขาว (เกิดเฉพาะจอของคนที่ร่าย) 0 = ไม่มี เหมาะกับบัฟหรือพื้นที่ค้าง |

ค่ารวมทั้งเซิร์ฟ (เปิด/ปิด ×แสง ×พื้น ×อนุภาค ×จอสั่น ms ค้าง ×ตัวเลขคริ) ปรับได้ที่ /admin → ปรับสมดุล → "เอฟเฟกต์สกิล (ชั้นเสริม)"

## 5. ถ้าจะเพิ่มภาพใหม่ (ไม่ใช่วาดทับของเดิม)

ภาพใหม่ต้องได้ชื่อใหม่และแถวใหม่ในโค้ด (`src/client/effects.ts` ตาราง `EFFECTS`) และต้องแก้ตรงที่สกิลสั่งเล่นภาพนั้น บอกได้ว่าสกิลไหนอยากได้ภาพแยก จะเพิ่มให้ ส่วนการวาดทับภาพเดิมในตำแหน่งเดิมไม่ต้องแก้โค้ดเลย
